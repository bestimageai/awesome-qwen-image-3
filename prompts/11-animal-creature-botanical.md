# Animals, creatures, and botanical studies

Ten Qwen Image 3.0 prompt recipes. Replace bracketed inputs before generation. All quoted text is exact; no translation is implied unless explicitly requested. Outputs require human review.

<a id="nat-01"></a>

## NAT-01 — Pet portrait from reference

```text
Use an authorized pet photograph to create a 3:4 portrait on a plain warm-gray background. Preserve coat markings, eye color, ear shape, body size and natural expression. Use soft window light and a relaxed seated pose matching the animal's anatomy. Keep whiskers, paws and fur edges detailed without over-smoothing. No clothing, human-like hands, text or added collar unless present in the reference. Variables: pet reference and approved background color.
```

<a id="nat-02"></a>

## NAT-02 — Fantasy marsh creature

```text
Create a 16:9 concept sheet for an original small marsh creature with otter-like proportions, moss-colored fur and broad webbed feet. Show front, side and three-quarter views on a pale background, using the same anatomy and markings throughout. Use believable natural-history illustration and no text. Do not copy a known fictional character or add inconsistent horns, limbs or wings. Variables: original creature description and habitat palette; this is imaginary, not a real species.
```

<a id="nat-03"></a>

## NAT-03 — Pollinator observation plate

```text
Using [VERIFIED SPECIES REFERENCES], create a 4:3 educational plate showing one pollinator beside its approved host flower. Include an enlarged inset of the relevant feeding structure, connected to the correct location by one thin line. Render only supplied species names and labels. Use precise natural-history illustration, white background and consistent scale notation only if provided. No invented anatomy, ecological claims or decorative scientific symbols. Variables: references, labels and source note; require expert review.
```

<a id="nat-04"></a>

## NAT-04 — Woodland wildlife scene

```text
Create a 16:9 fictional woodland scene with one red fox pausing beside a fallen birch trunk at dawn. Use realistic fur, restrained mist and low warm light through trees. Keep paws in contact with uneven ground and ears naturally alert. No anthropomorphic expression, prey injury, human objects or text. Avoid duplicating tree patterns or exaggerating body proportions. Variables: species, season and approved habitat details; do not identify the scene as a real wildlife photograph.
```

<a id="nat-05"></a>

## NAT-05 — Animal motion study

```text
Using [VERIFIED ANATOMICAL REFERENCES], create a 16:9 four-panel study of a domestic cat walking from left to right. Keep coat markings, scale, camera height and background identical. Show four distinct approved gait phases with plausible weight transfer and grounded paws. Label panels only "1" through "4". Do not invent limb positions or present the sheet as animation-ready frames without further testing. Variables: references and gait sequence.
```

<a id="nat-06"></a>

## NAT-06 — Leaf identification sheet

```text
Create a 3:4 botanical teaching sheet using [VERIFIED LEAF REFERENCES]. Arrange six leaves in a two-by-three grid, each with its supplied common name below. Preserve blade shape, margins, venation and stem attachment; use the same neutral lighting and a plain ivory background. Do not invent species names, medicinal uses or relative scale. Add only the approved title and labels. Variables: six references and name mapping; botanical identification requires review.
```

<a id="nat-07"></a>

## NAT-07 — Plant lifecycle diagram

```text
Create a 16:9 lifecycle illustration for [VERIFIED PLANT SPECIES] using [APPROVED STAGES]. Place exactly five stages in a left-to-right sequence with simple arrows, from seed to the supplied mature form. Use natural watercolor detail and clear labels beneath each stage. Preserve species-specific leaves, roots and fruit; do not invent durations or growing advice. Variables: reference pack, stages and exact labels. Keep the diagram educational and require subject-matter review.
```

<a id="nat-08"></a>

## NAT-08 — Aquarium habitat concept

```text
Create a 4:3 fictional freshwater habitat concept with rounded stones, aquatic plants and three small fish of one supplied species. Use a clear side view, natural underwater light and believable scale. Keep fish anatomy consistent and avoid overcrowding or incompatible species. No equipment claims, stocking advice, labels or decorative treasure chests. Variables: verified species references and habitat brief; this illustration is not an animal-care recommendation.
```

<a id="nat-09"></a>

## NAT-09 — Seed packet illustration

```text
Create a 3:4 front-panel concept for a fictional seed packet using [VERIFIED PLANT REFERENCE]. Show one flowering stem with a small seed inset, leaving the upper quarter for [APPROVED PLANT NAME]. Use original botanical gouache on cream paper. Render only the supplied name and "Illustrated study". No germination rate, origin, certification, planting instruction or weight unless provided. Preserve flower and leaf morphology. Variables: reference, name and palette.
```

<a id="nat-10"></a>

## NAT-10 — Urban bird observation card

```text
Create a square observation card for [VERIFIED BIRD SPECIES]. Show a perched side view and one smaller wing-detail inset against a pale background. Use natural-history illustration with accurate beak, feet and plumage. Render only the approved common name and three supplied observation labels, connected to the correct features. Do not invent rarity, migration dates or conservation status. Variables: reference pack, labels and source note; human verification is required.
```
