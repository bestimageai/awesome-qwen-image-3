# EC、製品、食品

Qwen Image 3.0 用のプロンプト集、全10件。生成前に角括弧内の入力を置き換えてください。引用符内の文字は正確に再現し、明示的な指定がない限り追加の翻訳は行いません。出力には人による確認が必要です。

<a id="com-01"></a>

## COM-01 — モジュール式デスクランプのメイン写真

```text
架空のモジュール式デスクランプの正方形カタログ写真を作成する。マットなバターイエローのランプを1台、円柱形の重り入り台座、1本のヒンジ式アーム、浅い円錐形シェードで構成する。アイボリーの卓上に置き、台座の横にコバルト色の修理用ノブを置く。左上からの柔らかな光と穏やかな接触影を使う。文字は台座の「LATCH」と左上の余白の「灯りを使い続けよう」のみ。関節を自然にし、電源コードは1本とする。認証バッジ、価格、追加部品は不要。変数：仕上げと承認済みのブランド文言。
```

<a id="com-02"></a>

## COM-02 — ランチボックスの製品ビュー

```text
使用許可のある製品写真1枚を形状の参照にして、同じ長方形ランチボックスを4つの等しいビューで見せる16:9の展示画像を作成する。閉じた正面、閉じた背面、開いた状態の真上、留め具の接写を並べる。薄い無地背景と同じ柔らかな照明を使う。ラベルは「正面」「背面」「内側」「留め具」のみ。すべてのビューで仕切り数、パッキンの色、留め具の位置を保ち、寸法や素材の主張を捏造しない。パネル間には明確な隙間を残す。変数：製品参照画像と翻訳済みラベル。
```

<a id="com-03"></a>

## COM-03 — 3種類の茶缶

```text
同じ円柱形を共有する架空の茶缶3個の3:2パッケージコンセプトを作成する。一直線に並べ、それぞれクリーム、ラベンダー、セージ色のラベル帯を付ける。共通ブランド「Field Notes」と、各名称「朝」「昼」「夕方」だけを使い、ほかの文字は加えない。中間色の棚で撮影し、ハイライトと縮尺を統一する。3缶すべての蓋、文字の位置揃え、ラベル幅を同じにする。原材料、原産地、健康効果は主張しない。変数：承認済みのブランド、名称、色。
```

<a id="com-04"></a>

## COM-04 — バックパックの機能紹介ボード

```text
使用許可のあるバックパックの参照画像と、提供された3つの機能説明から、3:4の製品情報画像を作成する。左側に全体を置き、右側に3つの詳細円を縦に揃え、それぞれ対応するファスナー、肩ストラップ、サイドポケットだけにつなぐ。各円の横に対応する [APPROVED FEATURE LABELS] を正確に描く。薄いグレーの背景と管理されたスタジオ照明を使う。実際の構造と色を維持し、明示的な提供がない限り防水、容量、人間工学の主張はしない。変数：参照画像、ラベル、アクセントカラー。
```

<a id="com-05"></a>

## COM-05 — パン作りの工程

```text
架空のベーカリーのサワードウ作りを示す16:9の4パネル画像を作成する。生地を混ぜる、生地を折る、成形したパンに切れ目を入れる、焼き上がりを見せる順にする。同じ木製作業台での近接ドキュメンタリー写真を使い、左から右へ読み進め、粉の付いた手を一致させる。ラベルは「混ぜる」「折る」「切れ目を入れる」「焼く」。パネルは正確に4つとし、生の生地と焼けた皮を区別する。温度や時間は加えない。これは工程のイメージであり、食品安全の指示ではない。変数：生地の種類と承認済みラベル。
```

<a id="com-06"></a>

## COM-06 — ランチの盛り合わせ

```text
リアルなランチボウル4個を2×2に並べた、16:9の真上からのカタログ画像を作成する。内容はローストしたカボチャと米、キノコと麺、レンズ豆とニンジン、トマトとクスクス。同じ浅い白い器、異なる食感、柔らかな日光、落ち着いた緑のテーブルを使う。間隔を等しくし、食器類を重ねない。文字、カロリー、食事制限への適合保証、食材ラベルは加えない。分量を自然にし、食べ物のテクスチャを反復しない。変数：提供された4つのレシピ、器の仕上げ、卓上の色。
```

<a id="com-07"></a>

## COM-07 — 二言語の麺メニュー

```text
架空の店「小巷面馆」に、サブタイトル「LANE NOODLES」を付けた3:4メニューを作成する。アイボリーの紙、チャコールの文字、横長の3行を使い、各行の左に小さなリアルな麺の写真、右に文言を配置する。「番茄面 · Tomato noodles · 28」「菌菇面 · Mushroom noodles · 32」「芝麻面 · Sesame noodles · 30」を正確に描く。赤いトマトスープ、キノコの具、ごまのたれをそれぞれ該当行と一致させる。通貨記号、アレルゲン、追加料理、主張は不要。架空のメニュー文言であり、両言語をそのまま保持する。
```

<a id="com-08"></a>

## COM-08 — 室内ファブリックの比較

```text
使用許可のある室内写真1枚から16:9の2パネル比較を作成する。左は元画像を再現し、右はソファのスローとクッション2個だけを [APPROVED COLORS] に変更する。窓、壁、家具の位置、カメラ角度、光は変えない。写真の外の細い枠に「元の写真」「ファブリック案」と付ける。布の折り目と接触影を維持し、部屋の補修、私物の除去、追加装飾の創作はしない。変数：元画像と色。
```

<a id="com-09"></a>

## COM-09 — 詰め替えパッケージの使い方

```text
3つのパネルを縦に積んだ3:4のパッケージ使用コンセプトを作成する。空のボトルと詰め替え袋、袋の注ぎ口からボトルへ注ぐ様子、蓋を閉じたボトルと折り畳んだ空袋を順に描く。すべて同じブランドなしの琥珀色ボトルとアイボリーの袋を使い、明快な技術イラストとセージ色の矢印で表現する。文字は「開ける」「詰め替える」「閉める」のみ。正確に3手順とし、液だれや逆方向への注入は描かない。食品や化学薬品との適合性を示唆しない。変数：確認済み容器設計と承認済み手順ラベル。
```

## COM-10 — セット内容のフラットレイ

```text
[APPROVED CONTENTS LIST] と使用許可のある製品参照画像を使い、入門文具セットの各同梱品を正確に1個ずつ見せる正方形フラットレイを作成する。ノートを中央に、小物を周囲に広い間隔で並べ、温かい紙の質感と柔らかな真上からの光を使う。タイトル「セットの中身」と、各物体に揃えた提供済みの品名だけを追加する。品数、相対的な大きさ、色を保つ。リストにない景品、価格、保証シール、付属品は追加しない。
```
