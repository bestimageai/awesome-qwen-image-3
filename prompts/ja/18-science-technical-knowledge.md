# 科学、技術図、解説

Qwen Image 3.0 用のプロンプト集、全10件。生成前に角括弧内の入力を置き換えてください。引用符内の文字は正確に再現し、明示的な指定がない限り追加の翻訳は行いません。出力には人による確認が必要です。

## SCI-01 — 植物の茎の断面図

```text
[APPROVED DIAGRAM REFERENCES] を使い、[VERIFIED PLANT STEM STRUCTURE] の3:4教材断面図を作成する。主横断面1つと組織の拡大図1つを示し、正しい構造へラベルをつなぐ。抑えた科学イラスト、統一した色、明確な余白を使う。提供名称と単位だけを描く。解剖、縮尺、機能、装飾分子を捏造しない。変数：参照資料、ラベル、出典注記。分野専門家が結果を検証する。
```

## SCI-02 — 機械故障の図解

```text
[VERIFIED MECHANICAL DRAWING AND FAULT DESCRIPTION] から16:9解説図を作成する。左に正常組立、右に記録された故障を示し、影響部分だけを強調する。部品順、接続、形状を保つ。提供ラベルと見出し「正常」「故障箇所」を描く。提供がなければ修理手順、トルク、電気助言、安全主張を加えない。変数：図面と確認済み故障説明。工学的レビューが必要。
```

## SCI-03 — 人が確認するAIワークフロー

```text
「入力」「モデル」「確認」「承認済み出力」「修正」の正確に5ノードを持つ16:9システム図を作成する。入力からモデル、モデルから確認、確認から承認済み出力、確認から修正へ接続し、修正からモデルへ戻す。左から右の配置、紺の箱、青緑の承認経路、琥珀の修正経路を使う。矢印を明確にし、追加サービスやデータ保管先は入れない。説明用ワークフローであり検証済みシステム構成ではない。
```
