# タイポグラフィ、編集デザイン、パターン

Qwen Image 3.0 用のプロンプト集、全10件。生成前に角括弧内の入力を置き換えてください。引用符内の文字は正確に再現し、明示的な指定がない限り追加の翻訳は行いません。出力には人による確認が必要です。

<a id="typ-01"></a>

## TYP-01 — 2階層の文字ポスター

```text
正確なタイトル「物語のある道具」と副題「日常のデザインを見つめる」を使い、3:4文字ポスターを作成する。タイトルは大きな濃青のセリフ体で均衡の取れた3行にし、副題はその下の小さくても読めるサンセリフ帯に置く。タイトル右下領域の背後に簡単なテラコッタ円1つを加え、文字を隠さない。暖かな紙質と広い余白を使う。追加語、歪んだベースライン、既存ブランドのコピーは不要。変数：承認済みタイトル、副題、配色。
```

## TYP-02 — 多文字体系の書体見本

```text
等幅3列に「你好」「Hello」「こんにちは」を正確に配置した16:9書体見本を作成する。形の正しい中国語、ラテン文字、日本語を同じ視覚的重みで、濃いインクとアイボリー背景に描く。各見本下に細い青線を引き、言語名や追加文字は入れない。音写や自動翻訳をせず、提供された文字体系を保つ。余裕ある間隔を取り、飾りの偽文字を避ける。変数：承認済み多言語文字列と書体。
```

## TYP-03 — オリジナル工房ワードマーク

```text
架空の陶芸スタジオ「Soft Corner」の正方形ラスターワードマーク案を作成する。特注風の丸い小文字、抑えたチャコール配色、唯一の記号として小さなずれた正方形1つを使う。名前を読みやすく正確に1回綴る。アイボリー地に平面案1つのみを示し、壁面モックアップや複数案にはしない。既存ブランドをまねず、商標調査済みと主張しない。変数：架空の名前と配色。最終ベクターマークはデザイナーが再構築して確認する。
```

## TYP-04 — モノグラム探索シート

```text
提供された「A」と「R」の文字から、異なる3つのオリジナルモノグラム案を3:2シートにする。無地背景の等しいパネルごとに1案を置き、黒線の太さを統一し、周囲を十分空ける。装飾王冠やファッションブランドの模様をコピーせず、両文字を認識可能に保つ。単語や番号は加えない。ラスターの探索であり、登録商標や編集可能ベクターではない。変数：イニシャルと幾何学スタイル。
```

## TYP-06 — 地域新聞の一面

```text
「中庭新聞」という3:4架空新聞の表紙を作成する。明確な3列グリッド、共同庭園の大写真1つ、小さな画像枠2つを使う。見出しと本文には [APPROVED SHORT COPY] だけを入れる。段間を広く、階層を統一し、すべての語を読めるようにする。ニュース、日付、引用、署名記事、公式印章を捏造しない。変数：承認済み文言、画像、提供された場合の発行日。レイアウト案であり実際の出来事の報道ではない。
```

## TYP-07 — リピートパターン案

```text
アイボリー背景にオリジナルの図案化した洋梨と葉を描く正方形パターンタイルを作成する。黄土色、セージ、濃青だけを使い、向きを変え、空白を均衡させる。一辺をまたぐ模様は反対辺へ整合して続け、見た目の間隔を均一にする。文字、ロゴ、グラデーション、識別可能なブランド柄は不要。変数：モチーフ、配色、密度。生成された繰り返し候補なので、製造前にタイル表示で継ぎ目を検証する。
```

