# ブランド、ポスター、キャンペーン

Qwen Image 3.0 用のプロンプト集、全10件。生成前に角括弧内の入力を置き換えてください。引用符内の文字は正確に再現し、明示的な指定がない限り追加の翻訳は行いません。出力には人による確認が必要です。

## MKT-01 — 修理できるランプの発売ポスター

```text
架空のスタジオ LATCH と、同社の修理できるデスクランプのために、3:4 の発売ポスターを作成する。青い作業台に折り畳んだ黄土色のランプを1台置き、取り外せるシェードを横に並べる。ランプは画面下部の3分の2を占める。鮮明な製品写真、柔らかな側光、抑制されたエディトリアルグリッドを使う。文字は「LATCH」「長く使うために」「部品を替えて、ランプはそのまま。」のみを、この順に階層を下げて配置する。関節は機械的に成立させ、部品を一致させる。価格、環境認証、性能の主張は追加しない。変数：スタジオ名、仕上げ、承認済みの標語。
```

## MKT-02 — 川辺の読書フェスティバル

```text
架空の水上図書館フェスティバルの3:4イラストポスターを作成する。右下に青い図書船を係留し、曲線状の赤い歩道橋で、左上の見出しから縞模様の日よけの下にいる3人の読者へ視線を導く。平面的なシルクスクリーンの形、アイボリーの紙、十分な余白を使う。「河畔读书节」「RIVER READING DAYS」「川辺の読書会」「SAT–SUN · 10:00–17:00」を、それぞれ別のブロックに1回ずつ正確に描く。中国語、英語、日本語は提供されたまま維持する。ほかの看板、スポンサー、透かしは加えない。変数：承認済みのイベント文言と配色。
```

## MKT-03 — 音のアーカイブ番組カバー

```text
架空のポッドキャスト「小さな音」の正方形カバーを作成する。浅いトレーに大きく写した真鍮の鍵を1本置き、その後ろに繊細な同心円状の振動リングを3本描く。温かみのあるマクロ写真と深い茄子色の背景を使い、上部4分の1にタイトル、その下に「耳を傾けたい物語」を配置する。どちらの行も幅100ピクセルで読めるようにする。マイク、ヘッドホン、プラットフォームのバッジ、エピソード番号は不要。鍵は1本だけとし、反射はリアルに、余白はすっきり保つ。変数：タイトル、物体、背景色。
```

## MKT-04 — 工具比較のサムネイル

```text
手工具の選び方を説明する16:9動画サムネイルを作成する。右側にブランドのないドライバーを3本縦に並べ、マイナス、プラス、六角の先端を明確に区別する。左側には「どの先端が合う？」だけを2行で配置する。各先端の下に対応するねじ頭の小さな図を置き、追加ラベルは付けない。明るい卓上写真、チャコールの文字、黄色の背景アクセントを使う。先端とねじ頭のくぼみを機械的に一致させる。偽のリアクション、評価、誇張した主張は加えない。変数：工具セットと正確な見出し。
```

## MKT-05 — 梱包ガイドのカルーセル表紙

```text
壊れやすい陶器の梱包を説明する全6枚のガイドに、3:4の表紙を作成する。折り畳んだ段ボールの仕切りの間に、宙に浮いて見える碗を1個置き、下部に紙製緩衝材のロールを配置する。薄いグレーを背景に整然とした真上からの写真を使う。上部に「心を込めて梱包」、その下に「陶器の発送ガイド」、右下に「1/6」を描く。碗は無傷に保ち、素材をリアルにする。配送会社のロゴ、破損防止の保証、追加の文字は加えない。変数：物体、タイトル、スライド枚数。
```

## MKT-06 — 地域工房のスタッフ募集

```text
架空の自転車修理協同組合に、縦3:4の募集ポスターを作成する。整頓された工具板の横に、誰も着ていない整備士のエプロンを掛ける。上半分は文字用に空ける。ドキュメンタリー写真、穏やかな窓光、深緑の文字を使う。提供された内容に置き換えて「工房の仲間を募集」「[ROLE]」「[CITY] · [SCHEDULE]」「応募締切：[DATE]」を描く。工具は識別可能にし、給与、資格、連絡先を捏造しない。QRコードは生成しない。生成前にすべての変数を置き換えること。
```

## MKT-07 — マイカップ持参の案内

```text
繰り返し使えるカップの持参を促す9:16のカフェ案内を作成する。使い込まれたクリーム色のトラベルカップを1個、チョークブルーの陶器の水差しの横に置き、温かな朝の光でカウンターの高さから撮影する。カップの上に「いつもの一杯を、あなたのカップで」、下に「次は忘れずに」を配置する。中央はゆったり空け、離れて見ても文字のコントラストを高く保つ。割引、環境統計、健康の主張、余分な物体や文字は加えない。蓋の形と接地した影をリアルに保つ。変数：カップの色と承認済みの2行の文言。
```

## MKT-08 — ランタン散歩のキービジュアル

```text
架空の夜のランタン散歩「光の小径」に、16:9の静止キービジュアルを作成する。小さな琥珀色の紙ランタンの列が、暗い植物園を曲がりながら開いた門へと続く。中央左はタイトル用に静かな空間を残し、すぐ下に「ともに過ごす夕べ」を置く。繊細な奥行きと紙の繊維が見える重ね紙のイラストを使い、ネオン効果は使わない。特定できるランドマーク、スポンサーのロゴ、追加コピーは避ける。これは1枚の静止コンセプト画であり、アニメーション出力ではない。変数：タイトル、道の形、アクセントカラー。
```

## MKT-09 — 修理ワークショップのポスター

```text
架空の地域修理ワークショップの3:4ポスターを作成する。テラコッタ色のテーブルに黄色いトースター、小さなドライバー、青い糸巻きを置き、向かい合う側から伸びた大人の手2本がトースターを修理している様子を描く。明快な切り紙の形、クリーム色の背景、紺色の文字、広い余白を使う。上部に「土曜日は修理の日」、その下に「小さな品をひとつ持ってきて」、下部に「14:00–17:00」を描く。各行は1回のみ、ほかの文字は不要。手の解剖学的構造を自然にし、トースターの電源プラグは抜いておく。変数：承認済みの翻訳文言と配色。
```

## MKT-10 — 写真プリント店の開店案内

```text
架空の近所の写真プリントスタジオに、2:3の窓貼り案内を作成する。下半分にはブランドのないインスタント写真を3枚、1本の水平なひもにクリップで留める。その上に「日常をプリントしよう」、続けて「[DATE] オープン」「[STREET]」を描く。質感のあるクリーム色の紙、コバルトの文字、自然な影を使う。生成前に日付と住所を提供し、開店特典を捏造しない。3枚は異なる画像のみとし、私的な顔写真や読める個人書類を含めない。変数：日付、場所、写真の題材。
```
