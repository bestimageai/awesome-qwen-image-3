# ファッション、美容、テキスタイル

Qwen Image 3.0 用のプロンプト集、全10件。生成前に角括弧内の入力を置き換えてください。引用符内の文字は正確に再現し、明示的な指定がない限り追加の翻訳は行いません。出力には人による確認が必要です。

## FAS-01 — 4ルックのカプセルワードローブ

```text
使用許可のある成人モデル参照1枚と [APPROVED GARMENT LIST] から、等しい4パネルの16:9ルックブックを作成する。淡い背景、同じカメラ距離で、提供された4つの服の組み合わせを示す。人物の同一性と各服の構造、色、フィットを維持する。ラベルは「01」「02」「03」「04」のみ。体の比率を変えず、柔らかなファッション誌風の照明を使う。アクセサリー、ロゴ、サステナビリティの主張は追加しない。変数：参照、衣服、組み合わせ対応表。
```

## FAS-02 — ユーティリティベスト設計シート

```text
オリジナルのスレートブルーのユーティリティベストに4:3服飾コンセプトシートを作成する。正面、背面、ポケット詳細1つを描き、縫い目、ファスナー方向、布の質感を合わせる。明確な技術イラストを使い、文字は「正面」「背面」「ポケット」のみ。ポケット数とシルエットを統一し、提供されていない寸法は加えない。有名ブランド固有の意匠をコピーせず、製造準備完了と示唆しない。変数：承認済みスケッチ、布、ラベル。
```

## FAS-03 — 陶器ジュエリーのキャンペーン

```text
畳んだアイボリーのリネンに、オリジナルのコバルト色陶器イヤリング2個を置いた正方形ジュエリー写真を作成する。釉薬のハイライトを白飛びさせず見せる柔らかな側光を使い、尺度と質感の参考に小さな乾いた枝1本を加える。2個の構造を揃えつつ、自然な手仕上げを残す。文字、宝石、貴金属の主張、ブランド印は不要。取り付け金具と自然な影を保つ。変数：許可済み製品参照、釉薬、布の色。
```

## FAS-04 — メイク比較編集

```text
使用許可のある成人肖像1枚から、4:3の2×2メイク比較を作成する。顔、肌色、髪、照明、表情を同じにする。提供された4種のメイク配色だけを適用し、変更を唇、まぶた、頬に限定する。[APPROVED LOOK NAMES] を各パネル名に使う。自然な肌の質感と顔の個性を保つ。顔の造形変更、年齢変更、製品効能の主張、追加アクセサリーは禁止。変数：肖像、配色、ラベル対応表。
```


## FAS-06 — 旅行小物フラットレイ

```text
オリジナルのキャンバストート1個、畳んだ柄スカーフ、無地のサングラス、小さなノートを使い、3:4の真上からのファッションフラットレイを作成する。砂色の面に斜めに配置し、重要な形を重なりで隠さない。柔らかな自然な影と控えめな紺色アクセントを使う。高級ブランドロゴ、旅券、切符、読める個人情報は不要。眼鏡を左右対称にし、布の折り目を自然にする。変数：承認済み小物、布柄、配色。
```

## FAS-07 — ヘアスタイルの視覚化

```text
使用許可のある成人肖像1枚から、提供された髪型6案の3:2シートを作成する。顔、生え際、年齢、肌色、カメラ角度、照明を保つ。[APPROVED STYLE LIST] に従い、髪の長さ、まとめ方、質感だけを変え、指定がなければ元の髪色を保つ。パネルを「1」から「6」と番号付けする。顔の修整、メイク変更、額からの不自然な発毛は不可。変数：元肖像と6つの髪型説明。
```

## FAS-08 — 織り組織比較

```text

```

