# インターフェース、限定編集、ローカライズ

Qwen Image 3.0 用のプロンプト集、全10件。生成前に角括弧内の入力を置き換えてください。引用符内の文字は正確に再現し、明示的な指定がない限り追加の翻訳は行いません。出力には人による確認が必要です。

<a id="dig-01"></a>

## DIG-01 — 工具貸出アプリのモバイル画面

```text
架空のアプリ「Borrow Bench」のカタログ、品目詳細、予約確認という3つのモバイル画面を示す16:9ボードを作成する。アイボリー背景、紺色の文字、青緑の操作ボタン、統一した角丸カードを使う。選択品は黄色いドリル。「Borrow Bench」「工具を探す」「コードレスドリル」「予約する」「受取時間」「土曜日 10:00」「予約を保存しました」「予約を見る」だけを適切な画面に描く。価格、個人情報、追加のナビゲーション名は不要。静止画のUI案であり、操作可能なコントロールであるとは示唆しない。
```

## DIG-02 — CSVインポート確認画面

```text
架空の在庫アプリ「Stockroom」に16:9のデスクトップUIモックアップを作成する。「品目」「数量」「状態」の列を持つインポート確認表を置き、提供されたサンプル3行のうち1行を「要確認」と目立たせる。表の上に「インポート内容を確認」、下に「戻る」「有効な行をインポート」ボタンを置く。白い整然としたレイアウト、琥珀色のエラー強調、「在庫」のみを含む読みやすいサイドバーを使う。提供データを維持し、個人情報は表示しない。変数：サンプル行と承認済み文言。
```

## DIG-03 — 地方鉄道のホームページ

```text
架空の旅行計画サービス「Local Lines」に16:9のデスクトップホームページ案を作成する。右側に海沿いを走る列車の大きな写真、左側に実用的な検索パネルを配置する。「ゆっくり行く旅を」「出発地」「目的地」「旅行日」「旅程を探す」を正確に描き、入力欄は空にする。クリーム色の背景、深緑の操作部、十分な間隔を使う。実際の時刻表、運賃、運行会社ロゴ、空き状況の主張は加えない。列車の構造を自然に保ち、UI文字を写真と分ける。変数：地域の画像と承認済み見出し。
```

## DIG-04 — 協力ゲームのHUD

```text
架空の山岳配達ゲーム用に16:9の静止HUD案を作成する。雪道の中央60パーセントを遮らずに残す。上に小型コンパス、左上に仲間2人のステータスバー、右下にアイテム枠3つを置く。文字は「北」「チーム」「荷物」「ロープ」「地図」のみ。高コントラストの形と控えめな琥珀色の強調を使い、映画的な浮遊ホログラムにはしない。実際の軍隊記章、読めない極小文字、過剰なオーバーレイは避ける。変数：ゲーム設定と承認済みラベル。
```

## DIG-05 — ポスターの文字差し替え

```text
画像1を編集対象にし、[APPROVED SOURCE-TO-TARGET TEXT MAP] のみを差し替え文言に使う。指定されたポスターの文字だけを置き換え、写真、イラスト、配色、余白、ロゴ、対象外の文字は変えない。文字の太さと階層を保ち、訳先言語に必要な場合だけ改行を調整する。句読点、アクセント記号、読み方向を正しく保つ。元の文字は削除し、重複させない。指定外の文字を翻訳せず、説明も加えない。変数：元画像と完全な文字対応表。
```

## DIG-06 — 写真の損傷修復

```text
使用許可のあるスキャン写真1枚を編集対象にする。見えるほこり、傷、折れによる損傷だけを修復し、小さな欠損部分は隣接テクスチャから補う。人物同一性、年齢、表情、トリミング、服装、元の粒状感、階調範囲を保つ。モノクロ原稿の着色、美肌化、閉じた目を開くこと、背景物体の創作は禁止。不確かな大きな欠損領域は、細部を捏造せずそのまま残す。比較ラベルや透かしのない修復画像1枚を出力する。変数：元写真と明示した修復範囲。
```

## DIG-07 — 3参照画像からの製品合成

```text
画像1をベースの卓上場面、画像2を陶器カップの正確な参照、画像3を釉薬の色だけの参照として使う。画像2のカップ1個を画像1の空いたコースターに置き、提供された釉薬の色相だけを適用する。ベースのカメラ、トリミング、周囲の物体、カップの形状を維持する。光の方向、接触影、遠近感、反射を合わせる。画像3の物体や文字をコピーしない。文字は追加しない。変数：使用許可のある3画像とカップの配置場所。
```

## DIG-08 — スケッチから閲覧室へ

```text
承認済みの室内スケッチを配置の参照にする。淡いオーク材の棚、苔色のベンチ、拡散した天井光を持つ4:3のリアルな閲覧室案を作成する。スケッチのすべての壁、窓、出入口、家具の占有範囲を保ち、素材パレットは既存面の仕上げだけに使う。遠近法を整合させ、通路幅の見た目を変えない。人物、追加家具、植物、看板は加えない。これはイメージ案であり、実測の施工図ではない。変数：スケッチと承認済み材料。
```

## DIG-09 — アクセシブルな空の状態

```text
保存済み記事リストが空の状態を示す3:4モバイルUIモックアップを作成する。クリーム色の背景、紺色の文字、閉じた本3冊の小さなイラストを使う。「まだ保存されていません」「役立つ記事をひとまとめに」「記事を探す」を正確に描く。見出しの下に説明、その下に大きなボタンを置き、余白を十分に取る。高コントラストにし、小さすぎる文字、スケルトン表示、偽の記事カード、通知バッジは使わない。静的なデザイン提案であり、アクセシビリティには実装後のテストが必要。
```

## DIG-10 — 言語の読み方向比較

```text
[APPROVED ENGLISH AND ARABIC COPY] から、左右に並べた16:9のUI組版ボードを作成する。左パネルは左から右、右パネルは自然な右から左の配置を使う。読み順を調整しながら、同じコンポーネント階層、間隔、2つのボタンの役割を維持する。製品写真は反転させず元のまま保つ。提供文字列だけを描き、アラビア文字を正しく接続し、ラテン文字のブランド名を完全に保つ。音写、元文の重複、文言の捏造はしない。変数：対訳文字列とコンポーネントラベル。アラビア語に堪能な人の確認を必須とする。
```
