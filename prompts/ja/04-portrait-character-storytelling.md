# キャラクター、肖像、絵コンテ

Qwen Image 3.0 用のプロンプト集、全10件。生成前に角括弧内の入力を置き換えてください。引用符内の文字は正確に再現し、明示的な指定がない限り追加の翻訳は行いません。出力には人による確認が必要です。

## ART-01 — ミラと本の返却

```text
短い黒の巻き髪、丸眼鏡、錆色のカーディガン、青い自転車かごを持つ、オリジナルの成人移動図書館員ミラの16:9の4コマ物語を作成する。左から右へ、ベンチで本を見つけ、無地の表紙を確かめ、かごに入れ、小さな図書館の入口へ届ける。温かいガッシュイラストと柔らかな朝の光を使う。顔、服装、自転車、黄色い本を全コマで一致させる。等しい4コマのみとし、説明文、吹き出し、読める書名は不要。静止絵コンテであり、動画ではない。
```

## ART-02 — 自然なポートレート編集

```text
使用許可のある成人の肖像写真を人物同一性の参照にする。目線の高さの3:4仕事用ポートレートを作成し、背景だけを柔らかく照らした淡青色のスタジオに、服だけを無地のチャコール色ジャケットに変える。年齢、顔の比率、髪型、肌の質感、表情を維持する。新しい背景の光を顔に合わせ、肩の解剖学的構造を自然に保つ。文字、宝飾品、美肌修整、体型変更は加えない。変数：背景色と承認済み衣装。無許可の人物の容姿を使わない。
```

## ART-03 — 架空の駅員

```text
海辺の小さな鉄道事務所にいる、オリジナルの成人駅員の正方形肖像を作成する。銀色の短髪、着古した紺色ジャケット、注意深い表情とし、背後にぼけた壁時計を置く。自然なフィルム風写真、曇天の窓光、目に見える肌の質感を使う。顔を中央に置き、頭の周囲に空間を残す。実名の人物に似せず、公式制服の記章、読める切符、身分証明書は描かない。変数：年齢層、配色、架空の職業。
```

## ART-04 — 配達員の四季設定シート

```text
長い三つ編み、緑の肩掛けかばん、赤い自転車を持つ、同じオリジナル成人配達員の16:9の4パネル設定シートを作成する。春の小雨、夏の日陰、秋風、冬の霜を等しいパネルで見せる。季節の上着と天候だけを変え、顔の特徴、体の比率、自転車形状を固定する。明快なエディトリアルイラスト、同じカメラ高、中立的なポーズを使う。各パネルの下には「春」「夏」「秋」「冬」だけを描く。ブランドロゴや架空の安全認証は不要。変数：キャラクター設計と季節の配色。
```

## ART-05 — カワウソの絵本見開き

```text
小さなカワウソがカメを助け、葦の間から紙の舟を取り戻す2:1の絵本見開きを作成する。カワウソは左、カメは右、舟は下部中央近くに置くが、本の綴じ目から離す。水彩のにじみ、温かな午後の光、読み取りやすい表情を使う。左上の空は後の組版用に空ける。生成文字、危険な水辺の場面、追加キャラクターは描かない。動物の縮尺と舟の形を一致させる。変数：場所、配色、承認済みキャラクター参照。
```

## ART-06 — セリフのない傘の漫画

```text
縦2:3、2列3段の等しい6コマ漫画を作成する。オリジナルの成人が小さな傘を開く、濡れた犬に気づく、一緒に入る、両者が水たまりのしぶきを受ける、店の広いひさしを見つける、最後にその下で濡れずに座る順に描く。明快なペンと淡彩のイラストを使い、服装を統一し、茶色の犬を1匹に保つ。左から右、上から下の順に読み、動作を因果関係でつなぐ。セリフ、看板、追加コマ、けがは不要。変数：人物の外見と傘の色。
```

## ART-07 — お茶の広告絵コンテ

```text
架空の20秒のお茶の広告用に、16:9の6パネル静止絵コンテを作成する。閉じた茶缶、手で開ける、茶葉がカップへ入る、お湯を注ぐ、窓辺の湯気、缶の横のカップを順に示す。同じクリーム色の缶1個、青いカップ1個、一貫した朝の光を使う。文字は最後のパネルの「静かなひととき」のみ。各パネルを異なるショットにし、小道具を固定する。健康効果、抽出温度、ブランドの主張は不要。変数：小道具設計と承認済みの最後の文言。コンセプトであり、生成映像ではない。
```

## ART-08 — 歴史的街路の復元

```text
[DATED EVIDENCE PACK] を使い、[YEAR] 年の [PLACE] における日常活動の16:9イラストを作成する。記録された街路の配置、建材、服装を維持し、不確かな背景は細部を抑える。提供された対応関係に基づいて「記録に基づく」「解釈による」要素を区別する細い凡例を入れる。碑文、有名人の顔、記念建造物、現代の物を捏造しない。本物の写真として提示せず、抑制された記録的イラストを使う。変数：場所、年、根拠資料、不確実性の対応図。歴史の専門的確認を受ける。
```

## ART-09 — 表情リファレンスシート

```text
[APPROVED CHARACTER REFERENCE] を使い、同じオリジナル成人キャラクターの頭から肩までの6ビューを3:2シートにまとめる。2×3グリッドに、平静、好奇心、安堵、困惑、決意、楽しさの表情を並べる。頭蓋の形、髪、年齢、衣装、カメラ距離を保ち、眉、口、わずかな頭の傾きだけを変える。柔らかなスタジオ風イラストと均一な淡い背景を使う。各表情を正確に1回ずつラベル付けする。解剖学的な誇張、人物の同一性の変化、追加アクセサリーは不要。変数：参照画像、配色、翻訳済みラベル。
```

## ART-10 — 物体の連続性を保つ絵コンテ

```text
赤い陶器の碗を棚からテーブルへ移し、オレンジを3個入れ、窓へ運ぶ16:9の4パネル絵コンテを作成する。すべてのパネルで同じ碗を使い、縁の見える位置にある欠け1つを維持する。オレンジは登場後ずっと正確に3個とし、室内形状と温かい側光を一致させる。明快でリアルなイラストを使い、中景から近景へ進め、文字は入れない。欠けを移動せず、果物を複製せず、碗の形を変えない。変数：物体の参照と承認済み室内配置。
```
