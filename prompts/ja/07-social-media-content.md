# SNS投稿、カバー、クリエイターコンテンツ

Qwen Image 3.0 用のプロンプト集、全10件。生成前に角括弧内の入力を置き換えてください。引用符内の文字は正確に再現し、明示的な指定がない限り追加の翻訳は行いません。出力には人による確認が必要です。

<a id="soc-01"></a>

## SOC-01 — ベランダ栽培ガイドの表紙

```text
初心者向けベランダ栽培ガイドの3:4SNSカバーを作成する。狭い棚に小さなテラコッタ鉢3個を置き、それぞれ異なる葉のハーブを植え、下に小型じょうろを置く。明るい自然写真と暖かいクリーム背景を使う。「小さなベランダ、新しい一歩」「3鉢から始めよう」「1/5」を描き、タイトルは上部3分の1を占める。収穫量、健康、成長保証は主張しない。鉢を接地させ、手すりの形を整える。変数：承認済みハーブとタイトル。
```

## SOC-02 — 三連の手作りイベント案内

```text
正方形SNS投稿3枚に分割するための、3:1マスター画像を1枚作成する。長い作業台の左に陶芸道具、中央に陶器の水差し、右に畳んだリネンを置く。各正方形を単独でもバランスよくし、「作る」「分かち合う」「集う」を別々のパネルに置く。温かな照明と静かなクリームの余白を統一する。重要な物体や文字を切り抜き境界にまたがせない。これはビジュアル原稿であり、書き出した3ファイルではない。変数：工芸品と承認済みの3語。
```

## SOC-03 — 研究結果カード

```text
[VERIFIED FINDING, DATA AND SOURCE] を使い、16:9の専門的なSNSカードを作成する。上に正確な発見を1つ、中央に簡潔な裏付けグラフ、下に出典を置く。白地にチャコールの文字と青緑1色のアクセントを使う。単位、日付、標本の限界、不確実性を保つ。相関を因果に変えず、大げさな割合を足さない。携帯画面で読める文字にする。変数：承認済み発見、データセット、引用。グラフの正しさは人が確認する。
```

## SOC-04 — 料理比較サムネイル

```text
洋梨の盛り付け用の切り方3種、薄切り、角切り、扇形を比較する16:9動画サムネイルを作成する。コバルト色の卓上に同じ白い皿3枚を一列に置き、洋梨の色と真上の照明を揃える。上には「洋梨ひとつ、3つの切り方」だけを描く。切り方を明確に区別し、量を自然にする。栄養の主張、偽の評価、手の近くの刃物、追加文字は不要。変数：果物と承認済み見出し。
```

## SOC-05 — デスク整理のショート動画表紙

```text
半分片付いた机の9:16カバーを作成する。左に揃えた紙、右に閉じたノートとカップを置く。自然な真上からの写真、柔らかな影、抑えた砂色と青の配色を使う。中央の安全領域に「デスクを整えよう」、下に「ひとつの面から始めよう」を描く。プラットフォームの表示が重なるため、重要な文字は下部4分の1と右端を避ける。所要時間の主張、アプリのロゴ、追加コピーは不要。変数：机の物品と2行タイトル。
```

## SOC-06 — ゲスト2人のライブ配信告知

```text
使用許可のある成人肖像2枚から3:4ライブ配信告知を作成する。各ゲストの面積、切り抜き倍率、中立的な照明を揃え、名前を対応する肖像の直下に置く。[EVENT TITLE]、[GUEST NAMES]、[DATE]、[TIME ZONE] だけを描く。紺とクリームの簡潔なグリッドを使い、偽のライブ表示やプラットフォームロゴは加えない。同一性を保持し、資格や参加者数を捏造しない。変数：2参照画像と承認済みイベント文言。
```

## SOC-07 — 確認済み引用カード

```text
[EXACT VERIFIED QUOTE] と [AUTHOR ATTRIBUTION] を使い正方形引用カードを作成する。暖かいオフホワイト紙に大きく読みやすいセリフ体で引用を組み、下に同じ左端で著者名を揃える。下隅に小さな抽象的な青い線画を1つ加える。句読点と言い回しを正確に保ち、短縮、創作、別人への誤帰属はしない。肖像、署名、推薦バッジは不要。変数：確認済み引用、出典者、配色。
```

## SOC-08 — 9段階の手作りグリッド

```text
[NINE APPROVED CRAFT STEPS] を説明する正方形3×3グリッドを作成する。同じ卓上、手、材料を全体で使い、原料から完成品への進行を明確にする。ラベルは左から右、上から下の順に「1」から「9」だけとする。道具と物体の比率を一定にし、手順を捏造せず、危険な工具操作を描かない。装飾文字や重複パネルは不要。変数：検証済み手順と材料。指導内容の正確さは確認が必要。
```

```

```
