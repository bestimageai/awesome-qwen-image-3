# 歴史、文化、根拠に基づく解釈

Qwen Image 3.0 用のプロンプト集、全10件。生成前に角括弧内の入力を置き換えてください。引用符内の文字は正確に再現し、明示的な指定がない限り追加の翻訳は行いません。出力には人による確認が必要です。

<a id="cul-01"></a>

## CUL-01 — 歴史的街路の日常

```text
[DATED PHOTOGRAPHS AND MAP] を使い、[YEAR] 年の [STREET] の日常を16:9で復元する。記録された建物輪郭、交通手段、路面を保つ。提供資料で裏付けられた日常行動だけを示し、不確かな領域は視覚的に抑える。記録的イラストを使い、アーカイブ写真とは称さない。碑文、有名人、現代の物を捏造しない。変数：場所、日付、根拠、不確実性注記。歴史的確認が必要。
```

<a id="cul-02"></a>

## CUL-02 — 遺物復元研究ボード

```text
[AUTHORIZED ARTIFACT IMAGES] から16:9の3パネル博物館研究ボードを作成する。現存資料、抑えた復元、不確実な部分を示す図を並べる。記録された形状と表面損傷を保つ。「現存」「復元」「不確実」のラベルと異なる視覚処理で、推測を証拠と誤認させない。制作者、来歴、儀式的意味を捏造しない。変数：参照資料と承認済み解釈。専門家の確認が必要。
```

<a id="cul-03"></a>

## CUL-03 — 歴史的市場のイラスト

```text
[EVIDENCE PACK] を使い、[VERIFIED REGION AND PERIOD] の市場の3:2教材イラストを作成する。提供された露店の種類、衣服、商品、建築だけを含める。前景の取引を読み取りやすく、背景を静かにし、自然光と抑えた細部を使う。読める価格、架空文字体系、ステレオタイプ、別時代の物は不要。変数：地域、年代、記録要素。真正な歴史画像ではなく解釈イラストと表示する。
```

<a id="cul-04"></a>

## CUL-04 — 歴史衣装の研究

```text
[MUSEUM-VERIFIED GARMENT REFERENCES] から、中立的な人型に正面、側面、背面を見せる16:9衣装研究を作成する。縫い目、留め具、布の重なり、提供された色の根拠を保つ。承認済み衣装名、地域、時代だけを付ける。身分、民族、儀式的意味、未記録の装飾を捏造しない。変数：参照と正確なラベル。不確かな色は提供注記で区別し、専門家の確認を受ける。
```

<a id="cul-05"></a>

## CUL-05 — 伝統工芸の工程

```text
[PRACTITIONER-APPROVED STEPS] で [DOCUMENTED CRAFT PROCESS] を説明する16:9の4パネルを作成する。正しい道具、手の位置、材料状態を順に示す。明確な自然主義イラストと提供ラベルだけを使う。非公開知識を明かさず、神聖な細部を捏造せず、生きた伝統を一般的模様で置き換えない。変数：承認済み参照、手順、帰属表示。公開前に実践者の確認と必要な許可を得る。
```

<a id="cul-06"></a>

## CUL-06 — 二言語の文化遺産解説板

```text
[APPROVED TWO-LANGUAGE COPY] と許可済み現地画像1枚から3:4文化遺産解説板を作成する。両言語を独立して明確に揃えたブロックに同等の組版上の地位で配置する。名前、日付、発音区別符、読み方向を保ち、画像は文章の上に置く。歴史、観光の主張、機関ロゴ、翻訳を創作しない。変数：確定二言語文、画像、出典クレジット。地域コミュニティと事実の確認が必要なレイアウト案とする。
```

<a id="cul-07"></a>

## CUL-07 — 歴史地図の重ね合わせ

```text
許可済み歴史地図と [VERIFIED MODERN ALIGNMENT] から16:9比較イラストを作成する。歴史地図を土台に保ち、提供された現代参照線だけを明確な青のオーバーレイで加える。2つの年代と不確実な位置合わせを区別する凡例を入れる。境界、所有の主張、経路、地理空間精度を捏造しない。変数：地図、位置合わせ、正確なラベル。歴史と地理の確認を必須とする。
```

<a id="cul-08"></a>

## CUL-08 — 復元における連続性

```text
[VERIFIED PERIOD] における同じ記録済み中庭を、夜明け、正午、午後、夕暮れの16:9の4パネルで復元する。[EVIDENCE PACK] で建築、素材、家具、カメラ位置を固定する。光と提供された日常活動だけを変える。現代の物、架空碑文、裏付けのない儀式を避ける。時間帯だけをラベルにする。変数：参照と承認済み活動一覧。解釈上の連続場面であり、描いた出来事の発生証拠ではない。
```

## CUL-09 — アーカイブ取り扱いポスター

```text
[ARCHIVIST-APPROVED HANDLING RULES] から3:4研修ポスター案を作成する。明確な3パネルに提供された取り扱い動作、対応工具、正確な短いラベルを示す。中立的技術イラスト、高コントラスト、広い余白を使う。手袋の要否、洗浄法、保存処理を捏造しない。変数：確認済み手順と資料種別。使用前にアーキビストと確認する。機関の印、署名、根拠のない保存効果は不要。
```

## CUL-10 — オーラルヒストリー引用パネル

```text
[CONSENTED VERIFIED QUOTATION]、[APPROVED ATTRIBUTION]、許可済み背景画像から4:3展示パネルを作成する。引用を大きく、その下に帰属表示、横に画像を置く。語句、方言、句読点を正確に保ち、証言を書き換えたり話者肖像を捏造したりしない。静かな編集組版とクリーム背景を使う。変数：同意済み文、帰属、画像。提供された文脈と許諾クレジットだけを含める。
```
