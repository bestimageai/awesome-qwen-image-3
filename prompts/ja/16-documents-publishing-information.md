# 文書、出版、情報デザイン

Qwen Image 3.0 用のプロンプト集、全10件。生成前に角括弧内の入力を置き換えてください。引用符内の文字は正確に再現し、明示的な指定がない限り追加の翻訳は行いません。出力には人による確認が必要です。

<a id="doc-01"></a>

## DOC-01 — 2ページのプロジェクト概要

```text
縦長のプロジェクト概要2ページを横並びにする16:9展示を作成する。[APPROVED COPY] を使い、1ページ目は目的と背景、2ページ目は範囲と次の段階を含める。余白と見出し階層を揃え、ページ番号は提供された場合だけ使う。チャコールの文字、青線、白紙を使う。ダミー文、架空日付、署名、承認印は不要。変数：全文とページ対応表。ラスターのレイアウト案であり、最終文書には編集可能な組版が必要。
```

## DOC-02 — 製品お手入れリーフレット

```text
[MANUFACTURER-APPROVED CARE INSTRUCTIONS] から3:4のお手入れ図解リーフレットを作成する。提供された4作業を2×2に配置し、各々に対応する簡単な物体イラストと正確なラベルを付ける。警告文は独立した下帯に置く。洗浄薬品、温度、廃棄助言、保証条件を捏造しない。高コントラスト文字と抑えた青配色を使う。変数：確認済み手順と製品参照。公開前に全手順を確認する。
```

## DOC-03 — 博物館の資料ラベル

```text
[VERIFIED OBJECT METADATA] から4:3博物館ラベル案を作成する。左に小さな許可済み資料画像、右に正確な題名、制作者、日付、素材、説明を置く。静かなクリーム背景と読みやすい濃色文字を使う。提供のない欄は推測せず省く。来歴、評価額、収蔵番号、機関ロゴを捏造しない。変数：画像と承認済みメタデータ。レイアウト研究であり真贋や所有の証拠ではない。
```

## DOC-04 — 年次報告書の見開き

```text

```

## DOC-05 — 会議スケジュールカード

```text

```

## DOC-06 — 確認済みリマインダーカード

```text

```

## DOC-07 — 図書館利用登録ガイド

```text
[APPROVED MEMBERSHIP RULES] から架空の地域図書館の3:4案内を作成する。「登録」「借りる」「返す」の3節に、簡単なイラスト1つと提供短文をそれぞれ置く。クリーム紙、紺の文字、広い間隔を使う。料金、本人確認条件、開館時間、貸出上限を捏造しない。変数：確認済み規則と承認済みタイトル。個人情報と読み取り可能なコードをデザインに入れない。
```

## DOC-08 — 文書比較レイアウト

```text
提供された短い公開文書2版を比較する16:9横並びレイアウトを作成する。ページ倍率を同じにし、[APPROVED CHANGED PASSAGES] だけを淡い黄色で強調する。ラベルは「旧版」「改訂版」。全文をそのまま保ち、法的意義を推定せず、解説を加えず、不変の文言を変えない。変数：2原文と明示的な変更対応表。視覚比較案であり法的レビューや変更履歴ファイルではない。
```

