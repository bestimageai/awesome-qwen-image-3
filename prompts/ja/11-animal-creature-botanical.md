# 動物、想像上の生物、植物研究

Qwen Image 3.0 用のプロンプト集、全10件。生成前に角括弧内の入力を置き換えてください。引用符内の文字は正確に再現し、明示的な指定がない限り追加の翻訳は行いません。出力には人による確認が必要です。

<a id="nat-01"></a>

## NAT-01 — 参照写真からのペット肖像

```text
使用許可のあるペット写真を使い、無地の暖かなグレー背景に3:4肖像を作成する。毛の模様、目の色、耳の形、体格、自然な表情を保つ。柔らかな窓光と、動物の解剖に合うくつろいだ座り姿を使う。ひげ、足、毛の輪郭を細かく保ち、過度に滑らかにしない。衣服、人のような手、文字は加えず、参照にない首輪も付けない。変数：ペット参照と承認済み背景色。
```

<a id="nat-02"></a>

## NAT-02 — 幻想の湿地生物

```text
カワウソに似た比率、苔色の毛、幅広い水かき足を持つ、小さなオリジナル湿地生物の16:9コンセプトシートを作成する。淡い背景に正面、側面、斜めのビューを示し、身体構造と模様を全体で一致させる。自然史的な説得力のあるイラストを使い、文字は入れない。既知の架空キャラクターをコピーせず、不一致な角、脚、翼を追加しない。変数：独自の生物説明と生息地配色。想像上の生物であり、実在種ではない。
```

## NAT-03 — 送粉動物の観察図版

```text
[VERIFIED SPECIES REFERENCES] から、送粉動物1個体と承認済みの訪花対象を並べる4:3教材図版を作成する。採食に関わる構造の拡大図を加え、細線1本で正しい位置につなぐ。提供された種名とラベルだけを描く。精密な自然史イラスト、白背景を使い、縮尺表示は提供時のみ統一して入れる。架空の解剖、生態学的主張、飾りの科学記号は不要。変数：参照、ラベル、出典注記。専門家の確認を受ける。
```

## NAT-04 — 森の野生動物風景

```text
夜明けに倒れたシラカバの幹の横で立ち止まるアカギツネ1匹の、16:9架空の森の情景を作成する。リアルな毛、抑えた霧、木々を通る低い暖光を使う。足を起伏ある地面に接地させ、耳を自然に警戒させる。擬人的表情、傷ついた獲物、人造物、文字は不要。木の模様の反復や体の比率の誇張を避ける。変数：種、季節、承認済み生息地詳細。実際の野生動物写真とは表示しない。
```

<a id="nat-05"></a>

## NAT-05 — 動物の歩行研究

```text
[VERIFIED ANATOMICAL REFERENCES] を使い、家猫が左から右へ歩く16:9の4パネル研究を作成する。毛模様、縮尺、カメラ高、背景を同じにする。承認済みの異なる歩行4段階を、自然な荷重移動と接地した足で示す。ラベルは「1」から「4」のみ。脚位置を捏造せず、追加検証なしにアニメーション用フレームと称さない。変数：参照と歩行順序。
```

<a id="nat-06"></a>

## NAT-06 — 葉の識別シート

```text
[VERIFIED LEAF REFERENCES] から3:4植物教材を作成する。6枚の葉を2×3に並べ、各下に提供された一般名を置く。葉身形、葉縁、葉脈、葉柄の接続を保ち、同じ中立照明と無地のアイボリー背景を使う。種名、薬効、相対縮尺を捏造しない。承認済みタイトルとラベルのみを追加する。変数：6参照と名称対応表。植物同定には確認が必要。
```

<a id="nat-07"></a>

## NAT-07 — 植物の生活環図

```text
[VERIFIED PLANT SPECIES] について [APPROVED STAGES] を使い、16:9生活環イラストを作成する。種から提供された成熟形まで、ちょうど5段階を左から右へ単純な矢印でつなぐ。自然な水彩細部と各段階下の明確なラベルを使う。種固有の葉、根、実を保ち、期間や栽培助言を捏造しない。変数：参照資料、段階、正確なラベル。教育図として扱い、分野専門家の確認を必須とする。
```

<a id="nat-08"></a>

## NAT-08 — 水槽の生息環境案

```text
丸い石、水草、提供された1種の小魚3匹を含む4:3の架空の淡水環境案を作成する。明確な側面、自然な水中光、妥当な縮尺を使う。魚の解剖を統一し、過密や相性の悪い種を避ける。機器性能の主張、飼育数の助言、ラベル、装飾宝箱は不要。変数：確認済み種参照と環境説明。このイラストは動物飼育の推奨ではない。
```

<a id="nat-09"></a>

## NAT-09 — 種袋のイラスト

```text
[VERIFIED PLANT REFERENCE] から、架空の種袋の3:4正面案を作成する。花を付けた茎1本と小さな種の挿図を示し、上部4分の1を [APPROVED PLANT NAME] 用に空ける。クリーム紙のオリジナル植物ガッシュを使う。文字は提供名称と「イラスト習作」のみ。提供がなければ発芽率、原産地、認証、栽培手順、重量を加えない。花と葉の形態を維持する。変数：参照、名称、配色。
```

## NAT-10 — 都市の鳥の観察カード

```text
[VERIFIED BIRD SPECIES] の正方形観察カードを作成する。淡い背景に止まった姿の側面と、小さめの翼の詳細挿図を1つ示す。正確なくちばし、足、羽の自然史イラストを使う。承認済み一般名と提供された3観察ラベルだけを描き、該当部位へつなぐ。希少性、渡りの日付、保全状況を捏造しない。変数：参照資料、ラベル、出典注記。人による検証が必要。
```
