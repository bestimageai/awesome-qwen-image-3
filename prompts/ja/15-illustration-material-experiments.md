# イラストと素材表現の実験

Qwen Image 3.0 用のプロンプト集、全10件。生成前に角括弧内の入力を置き換えてください。引用符内の文字は正確に再現し、明示的な指定がない限り追加の翻訳は行いません。出力には人による確認が必要です。

## ILL-01 — 重ね紙の流域

```text
色紙を重ねて丘、小川、池を示す3:4教材ペーパーアート案を作成する。紙の端を明確に見せ、抑えた青と緑、上からの柔らかな影を使う。小川を連続して斜面下の池へ流し、上部4分の1は提供タイトル用に空ける。[APPROVED TITLE AND LABELS] だけを描く。測定値や生態学的主張を捏造しない。変数：確認済み地形関係と正確な文言。授業前に科学的正確さを確認する。
```

## ILL-02 — 2色刷りの街区マップ

```text
パン屋、図書館、庭、修理店が広場1つを囲む、4:3架空街区のイラスト地図を作成する。アイボリー紙にコバルトと暖かなオレンジのインクだけを使い、軽い版ずれの質感を付ける。建物を明確な歩道でつなぎ、提供された4つの場所ラベルだけを描く。実住所、ロゴ、距離の主張、経路のアクセシビリティに関する勝手な前提は不要。変数：架空配置とラベル。重ね刷りを統一し、第3の印刷色を加えない。
```

## ILL-03 — ガッシュ植物図版

```text
[VERIFIED PLANT REFERENCE] から、暖かなアイボリー紙に茎1本、葉2枚、花1輪の3:4ガッシュ習作を作成する。種固有の構造を保ち、解剖を隠さない筆触を見せる。下部に提供された植物名だけを置く。提供がなければ縮尺は表記しない。薬効、装飾的な偽ラテン語、花弁数変更は不可。変数：参照、承認済み名称、配色。
```

## ILL-04 — 地域サービスのイラスト

```text
図書キオスク、工具小屋、庭、座席エリアを結ぶ架空の共用中庭を16:9等角イラストにする。明確に分かれた4区域、暖かな建築色を使い、連続したバリアフリーに見える道は [APPROVED LAYOUT] の指定どおりにのみ描く。提供された区域名を各1回描く。法令適合、参加人数、社会的効果を主張しない。階段、扉、屋根の遠近を整える。変数：配置とラベル。コンセプトイラストである。
```

## ILL-05 — 刺繍アイコン研究

```text
[APPROVED MOTIF LIST] から16点の刺繍アイコン案を正方形4×4シートにする。共通のクリーム布、紺と黄土色の糸、見える縫い方向を使い、各セル中央に1モチーフを置く。小さくてもわかる単純な輪郭を保つ。文字、重複モチーフ、ロゴのコピー、不可能な浮遊ステッチは不要。変数：16モチーフと糸色。ラスターの工芸案であり、機械刺繍データではない。
```

## ILL-06 — 小さな困りごとの絵本見開き

```text
オリジナルの子ウサギが、カタツムリのため庭の浅い水たまりに飛び石道を作る2:1絵本見開きを作成する。優しい色鉛筆の質感、柔らかな春光、明確な左から右への物語の動きを使う。綴じ目に顔や重要動作を置かない。左上を後の組版用に空ける。文字、追加人物、危険な水場は不要。変数：承認済みキャラクターと配色。
```

## ILL-07 — 陶器レリーフのポスター

```text
手作り陶器レリーフを撮影したような3:4ポスターを作成する。曲がった枝に止まる図案化した鳥3羽を、コバルト釉、アイボリー粘土、小さな自然の表面差で描く。平坦な上帯に「土と飛翔」、下帯に「スタジオの展覧会」を配置する。各句は1回、浮いた紙への印刷でなく明確な浮き彫りで示す。日付、スポンサー印、架空会場は不要。変数：承認済み文言と釉色。
```

## ILL-08 — 抽象的な編集メタファー

```text
注意を整理することを題材に正方形編集イラストを作成する。開いた引き出し1つの中に色紙の形を整然と分け、赤いリボン1本だけを外へ垂らす。触感あるコラージュ、暖かなアイボリー背景、柔らかな影を使う。言葉、人の顔、会社ロゴ、医療画像なしで秩序と中断を表す。引き出し形状を自然にし、過度な混雑を避ける。変数：承認済みテーマと配色。創作上の比喩であり、事実の主張ではない。
```

## ILL-09 — リノカットのパン

```text

```
