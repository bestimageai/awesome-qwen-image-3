# 写真と映画的リアリズム

Qwen Image 3.0 用のプロンプト集、全10件。生成前に角括弧内の入力を置き換えてください。引用符内の文字は正確に再現し、明示的な指定がない限り追加の翻訳は行いません。出力には人による確認が必要です。

<a id="pho-01"></a>

## PHO-01 — 朝の市場の記録写真

```text
成人の花屋が開店前にブランドなしの花入りバケツを整える3:4架空の記録写真を作成する。目線の高さの中景、曇った朝の光、抑えた自然色を使う。自然な手、濡れた舗装、売り場の小さな不完全さを見せる。背景の人々は不明瞭にし、読める店看板は省く。有名人の容姿、広告用の作り笑い、劇的HDR、架空のイベント主張は不要。変数：架空人物、花、場所の特色。
```

## PHO-02 — スマートフォンで撮った朝食

```text
食べかけの朝食、台所のテーブル上のトースト、小皿のジャム、陶器カップを3:4の気軽なスマートフォン写真にする。柔らかな窓光、適度な被写界深度、少し不完全な構図を使う。量をリアルにし、パンくずを多様に、カップの反射を自然にする。文字、高級ブランド、過剰な背景ぼけ、洗練されたスタジオ小道具は不要。変数：食事、卓上、光方向。商業カタログでなく日常を感じさせる。
```

## PHO-03 — 再利用できる製品照明

```text
許可済み製品参照から淡いグレー地の正方形スタジオ写真を作成する。カメラ左に大きな柔光、右に控えめな白い補助光を置き、製品の形、色、ラベル、摩耗を保つ。接地した接触影1つと自然なハイライトの減衰を維持する。追加小物、文字、浮遊物体、過剰にシャープな輪郭は不要。変数：参照と承認済み背景。関連製品画像でもこの照明説明を保つが、同一出力は保証されない。
```

## PHO-04 — 夜のバス待合所の静止画

```text
小雨後の夜、空のバス待合所の16:9架空の映画的静止画を作成する。暖かな天井灯と遠くの冷たい街路を対比させ、控えめな反射と深いが読み取れる影を使う。ベンチに折り畳んだ新聞1部を置き、文字は読めないようにする。遠近、ガラス反射、光の減衰を自然に保つ。人物、路線番号、広告、実在場所の主張は不要。変数：待合所設計、天候、色バランス。
```

## PHO-05 — 4コマのコンタクトストリップ

```text
同じオリジナル成人陶芸家が窓を向く4つの等しい写真枠を、16:9コンタクトストリップにする。うつむく、振り向き始める、光を向く、穏やかに笑うという別々の瞬間を示す。人物、服、室内、露出を固定する。微妙なフィルム粒子とリアルな動きの差を使い、姿勢を反復しない。枠番号、フィルム銘柄、文字は不要。変数：架空人物と工房。構成された静止シートであり映像の切り出しではない。
```

## PHO-06 — ガラス反射の研究

```text
濃青のテーブル上に、水を半分入れた透明タンブラー1個の正方形静物写真を作成する。広い側光と淡い縦の反射板を使い、水面のメニスカスは控えめに見せ、ガラス越しの屈折を自然にする。口を楕円、底を接地、水面を水平に保つ。文字、氷、果物、追加グラス、不可能な内部反射は不要。変数：グラス形状、水位、背景色調。
```

## PHO-07 — 食べ物の湯気の接写

```text
窓辺の無地陶器碗に入った野菜スープの4:3近接写真を作成する。暖かな自然光を使い、表面から細く不規則な湯気を一筋立たせる。野菜を識別可能に、液体反射を整合させ、碗の縁を清潔にする。文字、スープに浮く食器、過剰な煙、カロリー表示、健康主張は不要。変数：承認済みレシピ、碗、光方向。湯気を装飾的な固いリボンにしない。
```

## PHO-08 — 静かな工房のワイド写真

```text
閉店時の架空修理工房の16:9広角内観写真を作成する。中央の木製作業台、点灯したデスクランプ1台、後壁に整頓された工具を見せる。適度な広角とまっすぐな垂直線、暖色の実用灯、冷たい環境補助光を使う。通路を空け、物体を物理的に支える。人物、読めるブランド、映画の霧、不可能な室内形状は不要。変数：工房の種類と承認済み素材配色。
```

## PHO-09 — 浅い被写界深度の素材詳細

```text
ブランドなしバッグの、縫った帆布と摩耗した革の継ぎ目を3:2マクロ写真にする。中央3針に鋭く焦点を合わせ、端へ徐々に細部を柔らかくする。広い自然光、リアルな繊維、抑えた色を使う。縫い目間隔、穴、素材厚を自然に保つ。文字、ブランド紋章、極端なシャープ処理、反復したテクスチャスタンプは不要。変数：許可済み製品詳細と素材色。
```

## PHO-10 — 長時間露光風の流水

```text
小さな石の歩道橋が小川を渡る16:9架空風景写真を作成する。長時間露光風に流水を柔らかくし、橋、岩、草木は鮮明に保つ。橋を中心から外し、岩を回る水の向きを自然にする。曇天光と自然な緑を使う。文字、人物、識別可能な名所、過剰な霧、発光する水は不要。変数：橋の設計と季節。実際のカメラ露光や場所とは称さない。
```
