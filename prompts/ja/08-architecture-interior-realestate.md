# 建築、内装、不動産コンセプト

Qwen Image 3.0 用のプロンプト集、全10件。生成前に角括弧内の入力を置き換えてください。引用符内の文字は正確に再現し、明示的な指定がない限り追加の翻訳は行いません。出力には人による確認が必要です。

<a id="arc-01"></a>

## ARC-01 — 小さな読書スペース

```text
階段下の小さな読書スペースの4:3建築内観を作成する。造り付けのオークベンチ1つ、浅い本棚、丸い壁灯、折り畳んだ青いクッションを描く。自然な人体スケール、まっすぐな垂直線、画面外の窓からの柔らかな日光を使う。使える頭上空間と出入りを保つ。人物、文字、不可能な片持ち構造、大きすぎる家具は不要。変数：室寸法、承認済み素材と配色。設計イラストであり施工資料ではない。
```

<a id="arc-02"></a>

## ARC-02 — ベーカリーカウンター改装

```text
使用許可のあるベーカリー内観写真1枚を編集対象にする。カウンター正面だけを淡い縦木格子に、その後ろの壁だけを落ち着いた青に変える。寸法、陳列ガラス、扉、天井器具、カメラ角度、既存の文字をすべて保つ。反射と接触影を元の光に合わせる。商品追加、設備除去、部屋の拡張はしない。変数：元写真と承認済み表面仕上げ。ビフォーアフター表示のないコンセプト画像1枚を出力する。
```

<a id="arc-03"></a>

## ARC-03 — 家具配置図のレンダリング

```text
[APPROVED FLOOR PLAN] から真上視点の4:3家具配置イラストを作成する。すべての壁、開口、階段、提供寸法を維持する。[APPROVED FURNITURE LIST] だけを指定場所に、統一した縮尺と柔らかな中性色の陰影で置く。動線を見せ、提供された部屋名だけを描く。寸法を捏造せず、壁を動かさず、法令適合を示唆しない。変数：平面図、家具位置、ラベル。空間の正確さは別途検証する。
```

<a id="arc-04"></a>

## ARC-04 — ブルーアワーの外観編集

```text
使用許可のある物件写真を編集対象にする。時間帯だけをブルーアワーの初めに変え、既存の窓から柔らかな暖色光を見せる。明示がない限り、建物、植栽、隣の建造物、カメラ位置、天候を保つ。空の明るさと窓の反射を物理的に自然にする。照明を増やさず、欠陥を隠さず、眺望を変えない。文字や不動産の主張は不要。変数：元画像と承認済み照明処理。公開時は視覚化画像と表示する。
```

<a id="arc-05"></a>

## ARC-05 — 客室情報カード

```text
[VERIFIED ROOM PLAN AND AMENITIES] を使い3:4宿泊情報カードを作成する。上に簡略な客室イラスト、その下に提供された設備の短い一覧を置く。ベッド数、浴室位置、窓位置を保つ。暖かな中性色、大きな文字、承認済みラベルだけを使う。海の眺め、バリアフリー設備、星評価、寸法、予約空き状況を捏造しない。見出しの下に「イラスト客室ガイド」を入れる。変数：確認済み平面図、設備一覧、承認済みタイトル。
```

<a id="arc-06"></a>

## ARC-06 — 素材パレットボード

```text
「静かな工房」という16:9内装素材ボードを作成する。淡いオーク、ヘアライン仕上げのアルミ、青いウール、暖色の漆喰、斑点のある陶器の5サンプルを並べる。リアルな質感と厚さを示し、柔らかな方向性のある影と清潔なクリーム背景を使う。各素材の下に名称を正確に1回ずつ付ける。サンプルサイズの視覚的均衡を保ち、同じ物理縮尺とは示唆しない。供給会社ブランド、環境認証、性能主張は不要。変数：素材、ラベル、プロジェクト名。
```

<a id="arc-07"></a>

## ARC-07 — 展示会の来場者動線

```text
[APPROVED EXHIBITION PLAN] から16:9の軸測イラストを作成する。すべての間仕切り、入口、提供された展示設備を維持する。承認済みの来場者ルート1本を青線と方向矢印で示す。避難経路は提供されている場合だけ視覚的に区別する。[APPROVED ZONE NAMES] で区域名を付ける。中立的な建築陰影を使い、飾りの群衆は置かない。避難出口、アクセシビリティ、収容人数を捏造しない。変数：計画図、経路、ラベル。使用前に会場の確認を受ける。
```

<a id="arc-08"></a>

## ARC-08 — 中庭の四季

```text
同じ小さな中庭の春夏秋冬を示す16:9の4パネル景観案を作成する。カメラ、石の道、ベンチ、樹木位置、建物壁を固定する。[VERIFIED CLIMATE] に合う植生の外見、日光、季節の地面状態だけを変える。各季節名を1回付ける。リアルな建築ビジュアライゼーションを使い、パネル間で物体を動かさない。通年開花や成木になる成長速度を捏造しない。変数：承認済み植栽一覧と気候。
```

<a id="arc-09"></a>

## ARC-09 — 店舗の視線研究

```text
承認済み平面図1枚から16:9の2パネル店舗配置案を作成する。両パネルは入口からの同じ目線の高さで見る。左は現在の棚配置、右は [APPROVED NEW POSITIONS] のみを使う。建築、棚寸法、商品カテゴリ、照明を変えない。画像外に「現状」「提案」と付ける。売上改善、アクセシビリティの主張、追加床面積を捏造しない。変数：平面図と承認済み家具移動。
```

<a id="arc-10"></a>

## ARC-10 — 窓辺の座席の昼光研究

```text
同じ窓辺の座席を朝、正午、夕方に見る3:2の3パネル昼光研究を作成する。同じ部屋、クッション、カメラ位置、窓の方角を使う。[SUPPLIED ORIENTATION AND LOCATION] に従い、光の向きと強度だけを変える。対応パネルの下に「朝」「正午」「午後」を描く。反射と影の向きを依頼内容に合わせる。省エネ効果や昼光の測定値を捏造しない。変数：場所、方角、素材。説明画像でありシミュレーションではない。
```
