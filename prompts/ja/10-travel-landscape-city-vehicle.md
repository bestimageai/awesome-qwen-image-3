# 旅行、風景、都市、乗り物

Qwen Image 3.0 用のプロンプト集、全10件。生成前に角括弧内の入力を置き換えてください。引用符内の文字は正確に再現し、明示的な指定がない限り追加の翻訳は行いません。出力には人による確認が必要です。

## TRV-01 — 丘の路面電車旅行ポスター

```text
架空の丘の町の3:4旅行ポスター案を作成する。小さな黄色い路面電車1両が、パステル色の家々の間の曲がった道を登り、遠くに海が見える。オリジナルのシルクスクリーンイラスト、暖かなテラコッタの影、明確なタイトル領域を使う。文字は「遠回りしてみよう」「丘の町で過ごす週末」のみ。実際の観光キャンペーン、特定できる名所、交通機関ロゴをコピーしない。変数：配色と承認済みタイトル。実在目的地の写真として提示しない。
```

## TRV-02 — 散歩ルートのイラスト

```text
[VERIFIED MAP AND ROUTE] から3:4の街歩きガイドを作成する。道の接続、始点終点、提供された立ち寄り先を保つ。ルート1本を連続した青線で強調し、提供リストと完全に対応する番号マーカーを付ける。簡潔な建築アイコンと読めるラベルを使う。距離、営業時間、アクセシビリティ、安全な横断地点を捏造しない。フッターに「現地の状況をご確認ください」を加える。変数：地図、経路、立ち寄り先、承認済み文言。
```

## TRV-03 — 海岸風景写真

```text
層状の暗い岩、低い海霧、草の岬の細い道1本を持つ、16:9の架空の海岸風景を作成する。日の出の自然な広角写真の遠近感を使い、ハイライトを抑え、波の大きさを自然にする。水平線を水平に、道を物理的につながった状態に保つ。人物、文字、特定できる名所、不可能な太陽の反射は不要。変数：天候、海岸地質、配色。実際の目的地写真ではなく生成画像と表示する。
```

## TRV-04 — 夜の駅の情景

```text
雨上がりの架空の郊外駅ホームを16:9で作成する。空のベンチ1つ、小さな待合屋根、背景に停車中のブランドなし列車を描く。屋根下の暖光と冷たい空の光をリアルに混ぜ、控えめな反射と薄いかすみを使う。線路を平行にし、屋根の支柱を自然にする。読める時刻表、行先表示、人物、運行会社ロゴ、劇的な危険行為は不要。変数：建築様式、天候、照明。
```

## TRV-05 — 乗り物の特徴を保つ編集

```text
使用許可のある自転車写真から正方形カタログ画像を作成する。背景だけを薄いグレーのスタジオに変え、照明を柔らかな側光に調整する。フレーム形状、車輪寸法、スポーク、駆動系、付属品、塗装、既存デカールを正確に保つ。両タイヤを接地させ、一貫した接触影を落とす。損傷部品を直線に直したり、部品を追加したり、ブランドを変えたりしない。変数：参照と承認済み背景色。
```

## TRV-06 — 山小屋のイラスト

```text
湖畔に小さな木造小屋1軒、その背後に重なる森のシルエットを置いた3:4の架空の山小屋ポスターを作成する。質感あるガッシュ、落ち着いた松葉色、暖かな窓光を使う。上部4分の1に「もっと静かな地平へ」、下の余白に「山小屋の習作」を配置する。反射を小屋に合わせ、地形を自然にする。実在物件名、予約の主張、星評価、架空の設備は不要。変数：風景、配色、承認済み文言。
```

## TRV-07 — 都市交通の比較

```text
1つの架空街区内で自転車、路面電車、徒歩のルートを比較する16:9編集イラストを作成する。3手段を明確に分け、視覚的な比重を同じにする。明快な等角投影、落ち着いた色、「自転車」「乗車」「徒歩」のラベルを使う。所要時間、排出量、安全性が優れるという主張は加えない。線路、歩道、横断箇所をつなげる。変数：承認済み街路配置とラベル。
```

## TRV-08 — 自動車の4方向ボード

```text
許可済み車両参照から、正面、背面、左側面、斜め前方の4ビューを持つ16:9コンセプトボードを作成する。車体比率、ホイールベース、ライト、ミラー、塗装を全ビューで保つ。同じ中立的なスタジオと統一縮尺を使う。各ビューに1回ラベルを付ける。ナンバーは省くか、明確に架空の空白プレートを使う。架空のバッジ、航続距離、性能主張は不要。変数：参照と正確なビュー名。
```

## TRV-09 — 旅日記の見開き

```text
架空の川辺の週末を題材に、3:2イラスト旅行日記の見開きを作成する。左に橋のスケッチ、右に舟、カフェのカップ、葉の付いた枝の小さな習作3点を置く。鉛筆線、水彩のにじみ、アイボリー紙を使う。「川辺の週末」「ゆっくりした日の記録」だけを描き、残るメモ欄は本当に空白にする。偽切符、旅券スタンプ、住所、偽手書き文字は不要。変数：場所のコンセプトと配色。
```

## TRV-10 — 天候の連続性を保つ三連図

```text
同じ架空の湖畔の桟橋を晴天、小雨、霧で示す16:9の3パネルを作成する。カメラ、桟橋の板、手すり、係留船、岸線を固定する。視程、空、濡れ具合、光への反応だけを変える。ラベルは「晴れ」「雨」「霧」。反射を物理的に整合させ、パネル間で物体を追加削除しない。予報、日付、実在地点の主張は不要。変数：承認済み場面参照と天候ラベル。
```
