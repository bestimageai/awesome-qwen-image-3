# インフォグラフィック、教育、ビジネス

Qwen Image 3.0 用のプロンプト集、全10件。生成前に角括弧内の入力を置き換えてください。引用符内の文字は正確に再現し、明示的な指定がない限り追加の翻訳は行いません。出力には人による確認が必要です。

## EDU-01 — 雨水の行方

```text
「雨はどこへ行く？」という16:9の授業用インフォグラフィックを作成する。左から右へ、屋根1つ、それにつながる雨どい1つ、蓋付き雨水タンク1つ、植物のある雨庭1つを明確な4段階で見せる。屋根から雨どい、タンクへ青い水流矢印を引き、さらにタンクから庭へ独立した越流水の矢印を引く。正しい物体の横に「屋根」「雨どい」「貯水」「雨庭」だけを付ける。クリーム色の背景と簡単な断面イラストを使う。飲料水としての使用を描かず、容量を捏造しない。矢印を明確にし、タンクは閉じた状態にする。
```

## EDU-02 — 都市の日陰比較

```text
同じ太陽角度の下にある架空の街路2区画を比較する16:9教材図を作成する。左は樹木なし、右は成木2本が歩道に日陰をつくる。同じ建物、道路幅、歩行者を使い、簡潔な建築イラストと明確な影の範囲で描く。パネル名は「直射日光」「木陰」。気温、割合、健康上の結果は加えない。日射方向を統一し、日陰がすべての熱をなくすとは示唆しない。変数：街路の形状と承認済みラベル。
```

## EDU-03 — 種の成長観察シート

```text
豆の種を観察する子ども向けの縦3:4ワークシートを作成する。同じ大きさの枠4つに、種、根の出現、最初の芽、2枚の葉を描く。各枠の下に罫線付き観察欄を空ける。鮮明なグレースケールの線画と大きな文字を使う。描く文字は「種の成長を見てみよう」「1」「2」「3」「4」「観察したこと」のみ。経過日数を指定せず、生物学的順序を明確にする。解答欄を埋めたり、装飾用の偽文字を追加したりしない。変数：承認済みの植物種とシートのタイトル。
```

## EDU-04 — 分数テープの比較

```text
同じ横長の帯を3本並べた、グレースケールでも見やすい3:4教材シートを作成する。それぞれ2等分、4等分、8等分し、1区画、2区画、4区画を塗る。行ラベルは「1/2」「2/4」「4/8」、タイトルは「分け方が違っても、同じ量」。帯の始点と終点を正確に揃え、下部4分の1は話し合いのメモ用に空ける。明確な黒い輪郭と1種類のグレーの塗りを使う。円、不均等な区画、解答バブル、追加の数式は不要。
```

## EDU-05 — 月次サービスダッシュボード

```text
[VERIFIED MONTHLY TABLE] だけを使い、16:9ダッシュボード案を作成する。提供された主要指標を左、折れ線グラフを右に配置し、その下にラベル付きの補助数値3つを示す。白背景、チャコールの文字、青い1系列を使う。表の正確な日付、単位、出典注記を描く。欠損値は空白のままにし、補間や比較の捏造をしない。軸は提供された目盛りに合わせ、単位を表示する。変数：表、指標名、出典、期間。
```

## EDU-06 — 3段階ロードマップ

```text
[APPROVED INITIATIVES] を使い16:9の製品ロードマップを作成する。「現在」「次の段階」「検討中」の同じ幅の3列を置き、各列に施策カードを最大3枚配置する。明快なエディトリアルグリッド、クリーム色のカード、落ち着いた青のアクセントを使い、明示された依存関係だけを接続する。フッターに「計画の見通しであり、リリースの確約ではありません」を入れる。日程、完了状態、担当者、約束を捏造しない。各施策は指定された列に置く。変数：施策一覧と依存関係一覧。
```

## EDU-07 — 博物館の順路マップ

```text
承認済み平面図と [ROOM LABELS] を使い、縦長の来館者マップ案を作成する。入口、階段、エレベーター、壁、バリアフリー経路を正確に保ち、装飾的な細部だけを簡略化する。提供された1つの順路を連続した青線で強調し、始点と終点を示す。提供された記号で明確な凡例を作り、承認済みの部屋名だけを描く。出口、アクセシビリティ設備、縮尺を捏造しない。「イラスト案内 — 現地でご確認ください」を入れる。変数：平面図、経路、ラベル。公開前に施設側の確認を必須とする。
```

## EDU-08 — 図書館サービスブループリント

```text
図書館資料を借りる手順の16:9サービスブループリントを作成する。列は「探す」「予約する」「受け取る」「返す」の4列、行は「利用者」「図書館」「システム」の3行とする。セルには [APPROVED ACTIONS] だけを入れ、提供された引き継ぎにのみ矢印を引く。控えめな青線、白いセル、大きな文字を使う。利用者の行動と内部業務を明確に分ける。処理時間を捏造せず、個人情報や行動を代替する装飾アイコンを使わない。変数：行動マトリクスと確認済みの引き継ぎ。
```

## EDU-09 — ワークショップの空き枠グラフ

```text
月曜8席、火曜12席、水曜6席という架空データから4:3の情報カードを作成する。タイトルは「ワークショップの空き枠」。共通のゼロ始点の尺度で横棒を3本描き、末端に正確な値を付ける。白地に紺色のラベルと黄土色の棒を使う。フッターに「説明用データ」を入れる。席数を出席人数や割合に変換せず、棒の順番も変えない。12席の棒は6席の棒の2倍の長さにする。
```

## EDU-10 — 決定木の教材カード

```text
[TEACHER-APPROVED QUESTIONS AND OUTCOMES] を使い、架空の植物の世話の授業用に3:4決定木カードを作成する。上に根となる質問1つ、その下に分岐質問2つ、最下部に提供された結果を配置する。「はい」「いいえ」と記した枝、統一した角丸ボックス、十分な余白を使う。すべての条件と終了点を維持し、水やり量、診断、品種別助言を捏造しない。承認済みの文言とタイトルだけを描く。変数：正確な木構造、植物の文脈、タイトル。教師による確認を必須とする。
```
