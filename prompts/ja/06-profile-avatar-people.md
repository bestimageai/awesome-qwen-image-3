# アバター、チーム、日常のポートレート

Qwen Image 3.0 用のプロンプト集、全10件。生成前に角括弧内の入力を置き換えてください。引用符内の文字は正確に再現し、明示的な指定がない限り追加の翻訳は行いません。出力には人による確認が必要です。

<a id="ava-01"></a>

## AVA-01 — 工房創業者の肖像

```text
使用許可のある成人の肖像から、小さな家具工房の創業者を紹介する3:4画像を作成する。年齢、顔の比率、自然な肌の質感を保つ。未完成の木製スツールの横に座らせ、手は自然に置き、背後の工具を柔らかくぼかす。目線の高さのドキュメンタリー写真と広い窓光を使う。豪華なオフィスの小道具、架空の受賞歴、追加人物、文字は不要。明示された着替えがない限り、参照画像の服装を維持する。変数：肖像、承認済み衣装、工房の設定。
```

## AVA-02 — 円形クリエイターアバター

```text
使用許可のある成人の肖像1枚から正方形アバターを作成する。円形に切り抜いても髪や顎が切れないよう、顔と肩の上部を中央70パーセントに収める。暖かいグレー背景、柔らかな正面光、自然な表情を使う。人物同一性、年齢、髪型、見える顔の個性を保ち、背景の散らかりだけを除去する。文字、バッジ、新しいアクセサリー、過剰な肌の平滑化、体型変更は不要。変数：肖像参照と背景色相。小さなプロフィールアイコンの大きさで結果を確認する。
```

## AVA-03 — 3人のチーム紹介帯

```text
使用許可のある成人の肖像3枚を使い、等幅で背景を中間色に揃えた3つの独立した顔写真からなる16:9の帯を作成する。各人の顔と髪型を個別に保持し、特徴を混ぜない。自然な差を残しつつ、目の高さ、見かけのカメラ距離、照明方向を揃える。提供された名前を対応する肖像の下に1回ずつ置く。役職の創作、追加人物、美化はしない。変数：3参照画像と名前の対応表。この作業には3枚すべての参照画像を受け付ける編集ワークフローが必要。
```

## AVA-04 — 職人インタビューの肖像

```text
オリジナルの成人製本職人が木の机で布張りの本を修理する3:2編集用ポートレートを作成する。作業中の手、小さな刷毛、見返し紙1枚を見せ、道具を論理的に配置する。窓からの側光、抑えた色、中景を使い、右側に余白を残す。実名人物をまねず、読める本の文字、資格、歴史的主張を加えない。指を自然にし、接着剤を顔から遠ざける。変数：工芸、架空の人物、承認済み配色。
```

## AVA-05 — 家族で料理するひととき

```text
使用許可のある家族の参照から、同じ人々が台所のテーブルで野菜を並べる16:9の家庭風景を作成する。人物同一性、年齢差、関係、服装を保ち、無理に目を合わせず自然な表情にする。刃物や熱い器具を子どもの手が届かない場所に置く。柔らかな午後の光と生活感のある自然な背景を使う。家族の追加、文字、大げさな体型変更、実住所の開示はしない。変数：許可済み参照と承認済み場面。依頼文にない関係性を推測しない。
```

## AVA-06 — アダプティブスポーツの肖像

```text
屋外コートの横で休む、オリジナルの成人車いすテニス選手の3:4編集用ポートレートを作成する。競技用車いすの車輪、フレーム、握る部分をリアルに描き、ラケットを膝に横たえる。夕方の光、目線の高さ、自主性のある穏やかな表情を使う。かわいそうな人物として描かず、励ましの標語、メダル、スポンサー、医療の主張を加えない。身体と器具の構造を自然に保つ。変数：架空の選手の外見、衣装、コートの配色。
```

## AVA-07 — 雨の街角ポートレート

```text
使用許可のある成人参照を使い、透明な傘の下にいる3:4ストリートポートレートを作成する。顔の同一性、衣装、体の比率を維持する。無地のレンガ壁の近くに人物を置き、濡れた歩道と柔らかな反射を描く。ネオンではなく曇天の自然光を使う。傘の骨、柄、手の握り方を整合させる。追加人物、見える住所、店のロゴ、文字、年齢変更は不要。変数：肖像、承認済み上着、背景素材。
```

## AVA-08 — 著者のプレス写真

```text
使用許可のある成人参照から、プレスキット用の正方形肖像を作成する。無地の本の山の横に座らせ、肩を少し斜めにし、顔をカメラへ向ける。柔らかな側光、整然としたアイボリーの壁、リアルな肌の質感を使う。髪型、顔立ち、表情を維持する。別の切り抜きに対応できるよう頭の周囲に空間を残す。架空の書名、賞、署名、文字、美肌フィルターは不要。変数：肖像、承認済み服装、壁の色。
```

## AVA-09 — ボランティアの集合イラスト

```text
[APPROVED GROUP DESCRIPTION] を使い、長机を囲んで寄贈本を仕分ける成人ボランティアちょうど5人の16:9イラストを作成する。それぞれ別の作業を割り当て、提供された外見の詳細を誇張せず保つ。温かな編集用ガッシュと明確な手と物体の関わりを使う。通路を空け、本の山を安定させる。名前、団体ロゴ、寄付額、支援を受ける人に関する主張は加えない。変数：承認済みの集団詳細と場所。架空人物を特定可能な個人に似せない。
```

## AVA-10 — ポートレートの照明研究

```text
使用許可のある成人肖像1枚から、3:2の2パネル照明研究を作成する。左はカメラ左からの広い窓光、右は同じ光をカーテンで柔らかくしたものを使う。同一性、カメラ位置、表情、服装、切り抜き、背景を固定する。各パネル下に「直接の窓光」「拡散した窓光」だけを描く。変更は影の柔らかさとハイライトの移り変わりに限定する。顔の形、肌色、年齢を変えない。変数：参照と翻訳済みラベル。
```
