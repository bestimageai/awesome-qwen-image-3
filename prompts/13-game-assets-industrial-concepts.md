# Game assets, equipment, and industrial concepts

Ten Qwen Image 3.0 prompt recipes. Replace bracketed inputs before generation. All quoted text is exact; no translation is implied unless explicitly requested. Outputs require human review.

<a id="pro-01"></a>

## PRO-01 — Forest surveyor equipment

```text
Create a 16:9 original game-character equipment sheet for an adult forest surveyor. Show one full-body neutral pose and separate views of a canvas satchel, folding ruler and weatherproof notebook. Use stylized realistic illustration, muted greens and consistent scale relationships. Keep clothing, straps and tool attachments mechanically plausible. No weapons, recognizable franchise symbols or text. Variables: original character brief and approved equipment list; this is concept art, not a production-ready asset.
```

## PRO-02 — Modular greenhouse kit

```text
Create a 16:9 game-environment concept board with six modular greenhouse pieces: straight wall, corner, doorway, roof panel, window panel and floor tile. Use an orthographic-like view, shared grid proportions, pale metal frames and translucent glass. Arrange pieces in two rows and label them only with supplied names. Keep connection points compatible and avoid impossible roof joints. Variables: approved module dimensions and labels; geometry must be rebuilt and tested in a 3D tool.
```

## PRO-03 — Inventory icon sheet

```text
Create a square four-by-four sheet of sixteen distinct inventory-icon concepts from [APPROVED ITEM LIST]. Use one shared isometric angle, consistent light from the upper left and a flat neutral background. Center one item per equal cell with generous padding; keep silhouettes readable at small size. No text, duplicate items, clipping or invented branded equipment. Variables: exact sixteen-item list and palette. This is a concept sheet, not a verified transparent sprite atlas.
```

## PRO-04 — Four material previews

```text
Create a 16:9 board of four equal square material studies: worn painted wood, brushed steel, rough stone and woven canvas. Use [AUTHORIZED REFERENCES] to preserve material identity and a consistent scale impression. Show flat surface views with neutral light, no dramatic shadows or objects. Label each material once outside its preview. Variables: references and exact labels. Do not claim these are seamless textures, physically based maps or engine-ready assets without separate processing.
```

## PRO-05 — Portable radio concept

```text
Create a 3:2 industrial-design sheet for an original portable radio with a rounded rectangular body, one tuning dial and a folding handle. Show front, rear and three-quarter views with consistent proportions and control placement. Use warm gray polymer, a blue speaker grille and soft studio light. Add only "Front", "Rear", and "Perspective". No brand marks, electrical ratings, dimensions or safety certifications unless supplied. Variables: approved sketch and palette; this is not an engineering specification.
```

## PRO-06 — Assembly training board

```text
Create a 16:9 four-step assembly illustration from [VERIFIED MANUAL AND PART LIST]. Show only the supplied parts, one clear action per panel and consistent orientation of the main object. Use clean technical drawing, numbered steps and arrows matching the approved sequence. Render only supplied warnings and labels. Do not invent torque values, tools, safety procedures or missing steps. Variables: manual, parts and exact copy; expert validation is required before instructional use.
```

## PRO-07 — Exploded enclosure view

```text
Using [APPROVED CAD VIEWS], create a 4:3 exploded illustration of a small electronic enclosure. Separate cover, gasket, internal board and base along one shared axis, preserving attachment points and supplied component order. Use neutral technical shading and labels from [APPROVED PART NAMES]. Do not invent wiring, dimensions or electrical connections. Variables: authorized views and labels. This is an explanatory image, not validated CAD or a repair procedure.
```

## PRO-08 — Character prop consistency

```text
Create a 16:9 sheet showing one original explorer's lantern in three states: carried by the handle, resting on a stone and hanging from a hook. Preserve the lantern's hexagonal body, amber glass, brass latch and handle geometry in every panel. Use stylized realistic game art and consistent light. No text, added mechanisms or recognizable franchise motifs. Variables: approved prop reference and setting; check mesh feasibility separately.
```

## PRO-09 — Game dialogue portrait set

```text
Create a 3:2 two-by-three sheet of six bust portraits of one original adult lighthouse keeper. Preserve gray curls, blue coat, face shape and a small eyebrow scar. Show calm, curious, skeptical, concerned, relieved and cheerful expressions. Use clean painted game-art style with flat neutral backgrounds and no text. Keep camera distance and head size identical. Variables: character reference and palette. This is a concept set, not a rigged or automatically animated character.
```

## PRO-10 — Foldable stand study

```text
Create a 16:9 industrial concept board of an original folding tablet stand in closed, half-open and working positions. Use the same aluminum frame, hinge axis and rubber feet throughout; show clear side views on an ivory background. Render only "Closed", "Opening", and "Ready" below the panels. Keep mechanical motion plausible and do not invent load capacity or compatibility claims. Variables: approved sketch and material finish; engineering review is required.
```
