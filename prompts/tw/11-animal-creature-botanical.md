# 動物、幻想生物與植物研究

十則 Qwen Image 3.0 提示詞範例。生成前請替換方括號中的輸入內容。所有引號內文字均須原樣呈現；除非明確要求，否則不作額外翻譯。輸出結果需要人工審核。

<a id="nat-01"></a>

## NAT-01 — 參考圖寵物肖像

```text
使用獲授權的寵物照片，在純暖灰背景上製作 3:4 肖像。保留毛色花紋、眼睛顏色、耳形、體型和自然表情。採用柔和窗光，以及符合動物解剖結構的放鬆坐姿。鬍鬚、爪子和毛髮邊緣細節清楚，不過度平滑。不添加衣服、人類手形或文字；參考圖沒有項圈時不新增。可調變數：寵物參考圖和經核准的背景色。
```

<a id="nat-02"></a>

## NAT-02 — 幻想沼澤生物

```text
為原創小型沼澤生物製作 16:9 概念設定圖，比例類似水獺，苔色皮毛，寬大的蹼足。淺背景上展示正面、側面和四分之三視角，全程保持同一解剖結構與斑紋。採用可信的博物插畫，不添加文字。不複製已知虛構角色，不添加不一致的角、肢體或翅膀。可調變數：原創生物說明和棲地配色；這是想像生物，不是真實物種。
```

<a id="nat-03"></a>

## NAT-03 — 授粉動物觀察圖版

```text
使用 [VERIFIED SPECIES REFERENCES] 製作 4:3 教育圖版，展示一個授粉動物及經核准的寄主花。加入相關取食構造的放大插圖，用一條細線連接到正確位置。僅呈現提供的物種名稱與標籤。採用精確博物插畫、白底；只有提供比例標註時才統一加入。不編造解剖結構、生態宣稱或裝飾性科學符號。可調變數：參考圖、標籤和來源註記；須由專家審核。
```

<a id="nat-04"></a>

## NAT-04 — 林地野生動物場景

```text
製作 16:9 虛構林地場景，一隻赤狐在黎明時停在倒下的樺樹幹旁。採用真實皮毛、節制薄霧和穿過樹木的低角度暖光。爪子接觸不平地面，耳朵自然警覺。不添加擬人表情、獵物受傷、人造物件或文字。避免重複樹木紋樣或誇張身體比例。可調變數：物種、季節和經核准的棲地細節；不稱其為真實野生動物照片。
```

<a id="nat-05"></a>

## NAT-05 — 動物運動研究

```text
使用 [VERIFIED ANATOMICAL REFERENCES] 製作 16:9 四格研究圖，展示家貓由左向右行走。毛色花紋、比例、鏡頭高度和背景相同。展示四個不同且經核准的步態階段，重心轉移合理，爪子接地。畫格僅標「1」至「4」。不編造肢體位置，未經進一步測試不宣稱其為可直接用於動畫的影格。可調變數：參考圖和步態順序。
```

<a id="nat-06"></a>

## NAT-06 — 葉片辨識教學單

```text
使用 [VERIFIED LEAF REFERENCES] 製作 3:4 植物教學單。六片葉子排列為二乘三網格，下方分別標註提供的俗名。保留葉片形狀、葉緣、葉脈和葉柄連接處；採用相同中性照明和純象牙白背景。不編造物種名、藥用用途或相對比例。僅添加經核准的標題和標籤。可調變數：六張參考圖和名稱對照表；植物辨識需要審核。
```

<a id="nat-07"></a>

## NAT-07 — 植物生命週期圖

```text
為 [VERIFIED PLANT SPECIES] 使用 [APPROVED STAGES] 製作 16:9 生命週期插畫。從種子到提供的成熟形態，恰好五個階段由左至右排列，用簡潔箭頭連接。採用自然水彩細節，各階段下方標籤清晰。保留該物種特有的葉片、根和果實；不編造持續時間或種植建議。可調變數：參考資料包、階段和準確標籤。圖示用於教育，須由相關領域專家審核。
```

<a id="nat-08"></a>

## NAT-08 — 水族棲地概念

```text
製作 4:3 虛構淡水棲地概念圖，包含圓石、水草和提供的同一物種的三條小魚。採用清楚側視圖、自然水下光和可信比例。魚類解剖結構一致，避免過度擁擠或不相容物種。不添加設備宣稱、放養建議、標籤或裝飾寶箱。可調變數：已核實物種參考和棲地說明；此插畫不是動物飼養建議。
```

<a id="nat-09"></a>

## NAT-09 — 種子包裝插畫

```text
使用 [VERIFIED PLANT REFERENCE] 為虛構種子袋製作 3:4 正面概念圖。展示一枝開花莖和小型種子插圖，上方四分之一留給 [APPROVED PLANT NAME]。採用奶油色紙上的原創植物不透明水彩。僅呈現提供的名稱和「插畫習作」。未提供時不添加發芽率、產地、認證、種植說明或重量。保留花和葉的形態。可調變數：參考圖、名稱和配色。
```

<a id="nat-10"></a>

## NAT-10 — 都市鳥類觀察卡

```text
為 [VERIFIED BIRD SPECIES] 製作正方形觀察卡。淺背景上展示棲停側視圖和一個較小的翅膀細節插圖。採用博物插畫，喙、足和羽毛準確。僅呈現經核准的俗名與提供的三個觀察標籤，並連接至正確特徵。不編造稀有程度、遷徙日期或保育狀態。可調變數：參考資料包、標籤和來源註記；必須人工核驗。
```
