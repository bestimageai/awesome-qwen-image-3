# 科學、技術圖與知識解說

十則 Qwen Image 3.0 提示詞範例。生成前請替換方括號中的輸入內容。所有引號內文字均須原樣呈現；除非明確要求，否則不作額外翻譯。輸出結果需要人工審核。

<a id="sci-01"></a>

## SCI-01 — 植物莖剖視圖

```text
使用 [APPROVED DIAGRAM REFERENCES]，為 [VERIFIED PLANT STEM STRUCTURE] 製作 3:4 教育剖視圖。展示一個主橫截面和一個放大組織插圖，標籤連接至正確結構。採用節制科學插畫、一致顏色和清楚留白。僅呈現提供的名稱與單位。不編造解剖結構、比例、功能或裝飾分子。可調變數：參考資料包、標籤和來源註記；結果須由領域專家核實。
```

<a id="sci-02"></a>

## SCI-02 — 機械故障圖

```text
根據 [VERIFIED MECHANICAL DRAWING AND FAULT DESCRIPTION] 製作 16:9 解釋圖。左側正常組裝，右側有紀錄的故障，僅突顯受影響部件。保留元件順序、連接與幾何結構。呈現提供的標籤以及標題「正常」和「故障示意」。未提供時不添加維修步驟、扭矩、電氣建議或安全宣稱。可調變數：圖紙和審核後的故障說明；須進行工程審核。
```

<a id="sci-03"></a>

## SCI-03 — 人工審核 AI 流程

```text
製作 16:9 系統圖，恰好五個節點：「輸入」、「模型」、「審核」、「通過的輸出」和「修訂」。依序連接輸入至模型、模型至審核、審核至通過的輸出、審核至修訂，再將修訂連回模型。採用由左至右配置、海軍藍框、藍綠色通過路徑和琥珀色修訂路徑。箭頭明確，不增加服務或資料儲存。這是示例流程，不是經驗證的系統架構。
```

<a id="sci-04"></a>

## SCI-04 — 氣候資料比較

```text
僅使用 [VERIFIED CLIMATE DATA AND UNCERTAINTY] 製作 16:9 圖表。展示提供的時間序列，座標軸、單位、基準線和來源註記均有標籤。按指定帶狀區域表現不確定性，缺失值保留空缺。採用中性背景和一條節制藍色序列。不編造預測、因果解釋、紀錄或精度。可調變數：資料集、區間定義和經核准標題；資料與圖表解讀需要專家審核。
```

<a id="sci-05"></a>

## SCI-05 — 實驗室順序板

```text
僅使用 [APPROVED NON-HAZARDOUS LAB PROCEDURE] 製作 3:4 流程插畫。嚴格按順序展示提供的步驟，設備、標籤和單位匹配。採用清楚技術插畫，將警告與動作標籤分開。不編造用量、溫度、時間、安全措施或額外實驗。可調變數：經審核流程和準確文案。輸出是視覺輔助，不能替代獲核准的操作規程或監督。
```

<a id="sci-06"></a>

## SCI-06 — 電器保養概覽

```text
根據 [MANUFACTURER-APPROVED USER MAINTENANCE GUIDE] 製作 16:9 概覽。僅展示外部可接觸且使用者可維護的部件，以及提供的操作順序。採用帶標籤的簡潔插畫，朝向一致。準確保留警告和電源狀態指示；不編造拆卸、接線、化學品或維修建議。可調變數：經核實指南和電器參考。用於教學前須經專家審核，不增加認證或保證。
```

<a id="sci-07"></a>

## SCI-07 — 研究證據摘要

```text
使用 [REVIEWED STUDY SUMMARY] 製作 3:4 研究摘要版面。分為「問題」、「方法」、「發現」和「限制」，使用準確的提供文案和一個經核准圖表。樣本數、不確定性和來源保持可見。採用可讀深色文字與節制藍色點綴。不編造顯著性、因果關係、建議或引用。可調變數：經核實摘要和圖表資料。這是溝通概念，不是科學同儕審查。
```

<a id="sci-08"></a>

## SCI-08 — 多尺度結構圖

```text
製作 16:9 教育圖，連接 [APPROVED LARGE-SCALE OBJECT]、[COMPONENT] 和 [DETAIL]。三個畫面清楚分離，採用提供的尺度標籤和相連的放大框。保留實際包含關係和一致顏色對應。僅呈現審核後的標籤、單位和來源文字。不編造放大倍率、物理尺寸或因果箭頭。可調變數：參考圖和準確尺度資訊；須由專家核驗。
```

<a id="sci-09"></a>

## SCI-09 — 單位換算教學板

```text
製作 4:3 教學板，準確呈現「1 m = 100 cm」和「1 cm = 10 mm」。一條長參考條等分成十個大段，另將一個放大的段等分為十個小段。僅按 [TEACHER-APPROVED SCALE MAP] 標註示意圖，避免視覺尺度暗示錯誤換算。採用黑線和單一藍色點綴。不加其他算式或近似標籤；須由教師審核。
```

<a id="sci-10"></a>

## SCI-10 — 網路狀態圖例

```text
使用 [APPROVED NETWORK TOPOLOGY AND STATUS DATA] 製作 16:9 技術資訊卡。保留提供的每個節點和連接；正常、警告、無法使用狀態同時用顏色和不同形狀表示。包含提供的準確圖例和時間戳記。採用乾淨線條和寬裕間距。不編造 IP 位址、憑證、故障、復原指令或監控涵蓋範圍。可調變數：經審核拓樸和狀態快照。這是靜態插畫，不是即時儀表板。
```
