# 旅行、景觀、城市與交通工具

十則 Qwen Image 3.0 提示詞範例。生成前請替換方括號中的輸入內容。所有引號內文字均須原樣呈現；除非明確要求，否則不作額外翻譯。輸出結果需要人工審核。

<a id="trv-01"></a>

## TRV-01 — 山城電車旅行海報

```text
為虛構山坡小鎮製作 3:4 旅行海報概念圖。一輛小黃電車沿彎曲街道在淺彩色房屋間爬坡，遠處可見大海。採用原創絹印插畫、暖陶土色陰影和清楚的標題區域。僅呈現「繞遠一點也無妨」和「山城週末」。不複製真實旅遊宣傳、可辨識地標或交通標誌。可調變數：配色和經核准標題；不將場景呈現為真實目的地照片。
```

<a id="trv-02"></a>

## TRV-02 — 步行路線插畫

```text
使用 [VERIFIED MAP AND ROUTE] 製作 3:4 街區步行指南。保留道路連接、起終點和提供的停留點。用連續藍線突顯一條路線，編號標記須與提供的清單完全對應。使用簡潔建築圖示和可讀標籤。不編造距離、營業時間、無障礙條件或安全過街點。頁尾寫「請確認當地情況」。可調變數：地圖、路線、停留點和經核准文案。
```

## TRV-03 — 海岸風景照片

```text
製作 16:9 虛構海岸風景，包含層疊深色岩石、低海霧和草地岬角上的一條窄路。採用日出時自然廣角攝影視角，節制亮部和可信的海浪尺度。地平線水平，道路在物理上相連。不添加人物、文字、可辨識地標或不可能的太陽反射。可調變數：天氣、海岸地質和配色；結果須標明為生成影像，而非真實目的地照片。
```

<a id="trv-04"></a>

## TRV-04 — 夜間車站場景

```text
製作 16:9 雨後虛構郊區鐵路月臺場景。展示一張空長椅、小候車棚和背景中靜止的無品牌列車。採用真實的棚內暖光與天空冷光混合、適度反射和輕微薄霧。軌道保持平行，候車棚支撐結構合理。不添加可讀時刻表、目的地標牌、人物、營運商標誌或戲劇性危險活動。可調變數：建築風格、天氣和照明。
```

<a id="trv-05"></a>

## TRV-05 — 保持車輛特徵的編輯

```text
使用獲授權的自行車照片製作正方形型錄圖。僅將背景換為淺灰攝影棚，並將照明調整為柔和側光。準確保留車架結構、車輪尺寸、輻條、傳動系統、配件、漆面和全部已有貼花。兩條輪胎須接地，接觸陰影一致。不矯正損壞部件、不增加元件，也不改變品牌。可調變數：參考圖和經核准的背景色調。
```

## TRV-06 — 山間小屋插畫

```text
製作 3:4 虛構山間小屋海報，湖邊一間小木屋，背後是層疊森林剪影。使用有質感的不透明水彩、低飽和松綠色和暖窗光。上方四分之一留給「更寧靜的遠方」，下邊距寫「小屋習作」。反射與小屋對齊，地形可信。不添加真實房產名稱、訂房宣稱、星級或虛構設施。可調變數：景觀、配色和經核准文案。
```

<a id="trv-07"></a>

## TRV-07 — 城市移動方式比較

```text
製作 16:9 編輯插畫，在一個虛構街區內比較自行車、電車和步行路線。三種方式須清楚分離，視覺權重相等。採用乾淨的等距視角、低飽和顏色，標籤為「騎車」、「搭車」和「步行」。不添加移動時間、排放數字或安全性更優的宣稱。軌道、人行道和過街處須相連。可調變數：經核准街道配置和標籤。
```

<a id="trv-08"></a>

## TRV-08 — 汽車四視圖展示板

```text
使用獲授權的車輛參考圖製作 16:9 四視圖概念板：正面、後面、左側和四分之三視角。各視圖保持車身比例、軸距、車燈、後視鏡和漆面一致。採用相同中性攝影棚環境與統一比例。每個視圖標註一次；省略車牌，或使用明確虛構的空白車牌。不編造徽章、續航數字或效能宣稱。可調變數：參考圖和準確視圖標籤。
```

## TRV-09 — 旅行手帳跨頁

```text
為虛構河畔週末製作 3:2 插畫旅行手帳跨頁。左側放橋梁速寫，右側放船、咖啡杯和帶葉樹枝的三幅小習作。採用鉛筆線條、水彩暈染和象牙白紙。僅呈現「河畔週末」和「慢日子的筆記」；其餘筆記區必須真正留白。不添加假票券、護照印章、地址或偽手寫字。可調變數：地點概念和配色。
```

## TRV-10 — 天氣連續性三聯圖

```text
製作 16:9 三格圖，展示同一虛構湖畔碼頭在晴天、小雨和霧中的狀態。鎖定相機、碼頭木板、欄杆、停泊船隻和岸線。僅改變能見度、天空、濕潤程度和光照反應。畫格標註「晴」、「雨」和「霧」。反射須符合物理規律，不在畫格間增加或移除物件。不添加預報、日期或真實地點宣稱。可調變數：經核准的場景參考和天氣標籤。
```
