# 角色、人像與分鏡

十則 Qwen Image 3.0 提示詞範例。生成前請替換方括號中的輸入內容。所有引號內文字均須原樣呈現；除非明確要求，否則不作額外翻譯。輸出結果需要人工審核。

<a id="art-01"></a>

## ART-01 — 米拉歸還圖書

```text
製作一張 16:9 四格故事圖，主角是原創成年行動圖書館員米拉，她有黑色短捲髮、圓眼鏡、鐵鏽色針織外套和藍色自行車車籃。從左至右，她在長椅上找到一本書、查看素色封面、將書放入車籃，最後送到一家小圖書館門口。採用暖調不透明水彩插畫和柔和晨光。她的面容、服裝、自行車和黃色圖書始終相同。嚴格保持四個等大的畫格；不添加字幕、對話泡泡或可讀的書名。這是靜態分鏡，不是影片。
```

<a id="art-02"></a>

## ART-02 — 自然人像編輯

```text
使用一張獲授權的成年人人像作為身分參考。製作一張平視的 3:4 職業人像，僅將背景改為柔光淺藍色攝影棚，服裝改為素面炭灰色外套。保留年齡、臉部比例、髮型、皮膚紋理和表情。新背景的光線須與臉部匹配，肩部解剖結構須自然。不添加文字、珠寶、美肌修飾，也不改變體型。可調變數：背景色和經核准的服裝；不得使用未獲授權的人物肖像。
```

<a id="art-03"></a>

## ART-03 — 虛構車站管理員

```text
創作一張原創成年車站管理員的正方形人像，場景為海邊小鐵路辦公室。角色有銀色短髮，穿著有歲月痕跡的海軍藍夾克，神情專注；身後有一只模糊的掛鐘。採用自然的底片感攝影、陰天窗光和可見的皮膚紋理。臉部置中，頭部周圍留出空間。不模仿指定人物，不出現官方制服徽記、可讀車票或身分證件。可調變數：年齡層、配色和虛構職業。
```

<a id="art-04"></a>

## ART-04 — 四季快遞員設定圖

```text
製作一張 16:9 四格角色設定圖，展示同一位原創成年包裹快遞員，擁有長辮子、綠色斜背包和紅色自行車。等大的四格分別展示春日細雨、夏日樹蔭、秋風和冬霜。僅改變季節外衣和天氣；鎖定臉部特徵、身體比例和自行車幾何結構。採用清晰的編輯式插畫、一致的鏡頭高度和中性姿勢。各格下方僅呈現「春」、「夏」、「秋」和「冬」。不添加品牌標誌或虛構的安全認證。可調變數：角色設計和季節配色。
```

<a id="art-05"></a>

## ART-05 — 水獺繪本跨頁

```text
製作一張 2:1 繪本跨頁，展示一隻小水獺幫助烏龜從蘆葦中取回紙船。水獺在左，烏龜在右，紙船位於下方中央附近但避開裝訂中縫。使用水彩暈染、暖調午後光線和清楚可辨的表情。左上方天空留白，供後續排字。不生成文字，不出現危險涉水場景或額外角色。保持動物尺度和紙船形狀一致。可調變數：場景、配色和經核准的角色參考。
```

<a id="art-06"></a>

## ART-06 — 無對白雨傘漫畫

```text
製作一張直式 2:3 漫畫，六個等大畫格按兩欄三列排列。一位原創成年人打開小雨傘、注意到一隻淋濕的狗、與牠共撐傘、雙方被水窪濺濕、發現寬大的商店雨棚，最後坐在棚下保持乾爽。採用清楚的墨線淡彩插畫，服裝一致，始終只有一隻棕狗。閱讀順序為由左至右、由上至下，動作須有因果銜接。不添加對白、招牌、額外畫格或受傷情節。可調變數：角色外貌和雨傘顏色。
```

<a id="art-07"></a>

## ART-07 — 茶葉廣告分鏡

```text
為虛構的二十秒茶葉廣告製作一張 16:9 六格靜態分鏡。依序展示閉合茶罐、手打開罐子、茶葉落入杯中、倒入熱水、窗邊蒸氣，以及杯子放在茶罐旁。使用同一個奶油色茶罐、同一個藍杯和一致晨光。僅在最後一格呈現「片刻寧靜」。每格為不同鏡頭，全部道具保持穩定。不添加健康益處、沖泡溫度或品牌宣稱。可調變數：道具設計和經核准的結語；這是概念圖，不是生成的影片片段。
```

<a id="art-08"></a>

## ART-08 — 歷史街景重建

```text
使用 [DATED EVIDENCE PACK]，製作一張展示 [YEAR] 年 [PLACE] 日常活動的 16:9 插畫。保留有史料記載的街道走向、建築材料和服裝；對不確定的背景區域降低細節表現。添加窄幅圖例，依據提供的對應關係區分「有文獻依據」和「推測性復原」元素。不虛構銘文、名人面孔、紀念物或現代物件。採用節制的紀實插畫，不將場景偽裝成真實照片。可調變數：地點、年份、證據和不確定性對應圖；須進行歷史專業審核。
```

<a id="art-09"></a>

## ART-09 — 表情參考圖

```text
使用 [APPROVED CHARACTER REFERENCE]，製作一張 3:2 設定圖，包含同一原創成年角色的六個頭肩視圖。以二乘三網格展示平靜、好奇、釋然、困惑、堅定和愉悅表情。保留頭骨形狀、頭髮、年齡、服裝和鏡頭距離；僅改變眉毛、嘴部和輕微的頭部傾角。採用柔和棚拍風格插畫和統一淺色背景。每種表情準確標註一次。不出現誇張變形的解剖結構、身分漂移或額外配件。可調變數：參考圖、配色和翻譯後的標籤。
```

## ART-10 — 物件連續性分鏡

```text
製作一張 16:9 四格分鏡：紅色陶碗從層板移到桌上、裝入三個柳橙，然後被端到窗邊。每格使用同一只碗，碗緣始終有一處可見缺口。柳橙出現後嚴格保持三個，房間幾何結構一致，採用暖調側光。使用清晰的寫實插畫，鏡頭從中景推進至近景，不添加文字。不移動缺口、不複製水果，也不改變碗的形狀。可調變數：物件參考和經核准的房間布局。
```
