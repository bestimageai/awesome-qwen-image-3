# 資訊圖表、教育與商業

十則 Qwen Image 3.0 提示詞範例。生成前請替換方括號中的輸入內容。所有引號內文字均須原樣呈現；除非明確要求，否則不作額外翻譯。輸出結果需要人工審核。

<a id="edu-01"></a>

## EDU-01 — 雨水的旅程

```text
製作一張 16:9 課堂資訊圖表，標題為「雨水去了哪裡」。從左至右清楚展示四個階段：一處屋頂、一條相連的簷溝、一個有蓋蓄水桶和一座種有植物的雨水花園。使用藍色水流箭頭依序連接屋頂、簷溝和蓄水桶，再用單獨的溢流箭頭從蓄水桶指向花園。在正確物件旁僅標註「屋頂」、「簷溝」、「蓄水」和「雨水花園」。採用奶油色背景和簡潔剖視插畫。不展示飲用水用途，不編造容量數據。箭頭須明確無歧義，蓄水桶須有蓋封閉。
```

## EDU-02 — 都市遮蔭比較

```text
製作一張 16:9 教學示意圖，比較相同太陽角度下的兩段虛構街道。左側沒有樹木；右側有兩棵成熟樹木為人行道遮蔭。兩側建築、道路寬度和行人相同，採用簡潔建築插畫，並清楚呈現陰影覆蓋範圍。兩格標籤分別為「陽光直曬」和「樹蔭遮蔽」。不添加溫度、百分比或健康結果。太陽方向保持一致，不暗示樹蔭可以消除全部熱量。可調變數：街道幾何布局和經核准的標籤。
```

## EDU-03 — 種子生長觀察學習單

```text
製作一張直式 3:4 兒童豆子種子觀察學習單。繪製四個等大的方框，分別包含種子、根冒出、第一根芽和兩片葉子。每框下方保留帶橫線的觀察紀錄區。使用清晰的灰階線描和大字。僅呈現「觀察種子生長」、「1」、「2」、「3」、「4」和「我的觀察」。生物生長順序須明確，不指定經過的天數。不填寫作答區域，也不添加裝飾性假文字。可調變數：經核准的植物種類和學習單標題。
```

<a id="edu-04"></a>

## EDU-04 — 分數條比較

```text
製作一張適合灰階列印的 3:4 教學單，展示三條相同的橫向長條。分別等分成兩格、四格和八格；分別為一格、兩格和四格塗色。各列標註「1/2」、「2/4」和「4/8」；標題為「分法不同，數量相同」。長條起點與終點精確對齊，下方四分之一留白供討論筆記使用。採用清晰黑色輪廓和單一灰色填色。不添加圓形、不等分格子、作答泡泡或其他算式。
```

<a id="edu-05"></a>

## EDU-05 — 月度服務儀表板

```text
僅使用 [VERIFIED MONTHLY TABLE] 製作一張 16:9 儀表板概念圖。左側放置提供的核心指標，右側放折線圖；下方展示三個有標籤的輔助數據。使用白色背景、炭灰色文字和一條藍色資料序列。準確呈現表中的日期、單位和來源註記。缺失值保留為空缺；不插值，也不虛構比較。座標軸必須符合提供的刻度並顯示單位。可調變數：資料表、指標名稱、來源和期間。
```

<a id="edu-06"></a>

## EDU-06 — 三階段路線圖

```text
使用 [APPROVED INITIATIVES] 製作一張 16:9 產品路線圖。排列三個等寬欄，標題分別為「目前」、「下一步」和「探索中」，每欄最多三張工作項目卡片。採用乾淨的編輯式網格、奶油色卡片和低飽和藍色點綴；僅連接明確提供的相依關係。頁尾寫「規劃視圖，不代表發布承諾」。不編造日期、完成狀態、負責人或承諾。每項工作必須保留在提供的欄位中。可調變數：工作項目清單和相依關係清單。
```

<a id="edu-07"></a>

## EDU-07 — 博物館參觀路線圖

```text
使用經核准的平面圖和 [ROOM LABELS] 製作一張直式參觀地圖概念圖。準確保留入口、樓梯、電梯、牆體和無障礙路線；僅簡化裝飾細節。用連續藍線突顯一條提供的路線，並標記起點和終點。使用包含所提供符號的清晰圖例，僅呈現經核准的房間名稱。不編造出口、無障礙設施或比例尺。包含「示意導覽——請以現場為準」。可調變數：平面圖、路線和標籤；發布前必須由場館審核。
```

## EDU-08 — 圖書館服務藍圖

```text
製作一張 16:9 圖書館借閱服務藍圖。四欄分別為「查找」、「預約」、「領取」、「歸還」；三列分別為「讀者」、「圖書館」、「系統」。儲存格僅填寫 [APPROVED ACTIONS]，箭頭僅表示所提供的交接關係。採用節制的藍色線條、白色儲存格和大字。讀者行為與內部作業清楚區分。不編造處理時間、不顯示個人資料，也不用裝飾圖示代替行為。可調變數：行為矩陣和經核實的交接關係。
```

## EDU-09 — 工坊剩餘名額圖表

```text
根據以下虛構資料製作一張 4:3 資訊卡：週一 8 個名額、週二 12 個名額、週三 6 個名額。標題為「工坊剩餘名額」，繪製三條共用同一零起點刻度的水平長條，在長條末端標註準確數值。使用白色背景、海軍藍標籤和赭黃色長條。頁尾寫「示例資料」。不將名額換算為出席人數或百分比，也不改變長條順序。十二個名額的長條長度須為六個名額的兩倍。
```

## EDU-10 — 決策樹教學卡

```text
使用 [TEACHER-APPROVED QUESTIONS AND OUTCOMES]，為虛構植物照護課程製作一張 3:4 決策樹卡片。頂部放一個根問題，下方放兩個分支問題，底部放提供的結果。分支標註「是」和「否」，採用統一圓角框和充足留白。保留全部條件與停止點；不編造澆水量、診斷或品種建議。僅呈現經核准的文字和標題。可調變數：準確的樹狀結構、植物背景和標題；須由教師審核。
```
