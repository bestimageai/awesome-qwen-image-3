十則 Qwen Image 3.0 提示詞範例。生成前請替換方括號中的輸入內容。所有引號內文字均須原樣呈現；除非明確要求，否則不作額外翻譯。輸出結果需要人工審核。

## PRO-01 — 森林測量員裝備

```text
為成年森林測量員製作 16:9 原創遊戲角色裝備圖。展示一個全身中性姿勢，以及帆布斜背包、摺尺和防風雨筆記本的獨立視圖。採用風格化寫實插畫、低飽和綠色和一致的比例關係。衣服、背帶和工具固定方式須符合機械常識。不添加武器、可辨識作品系列符號或文字。可調變數：原創角色說明和經核准裝備清單；這是概念美術，不是可直接投入製作的素材。
```

## PRO-02 — 模組化溫室套件

```text
製作 16:9 遊戲環境概念板，包含六個模組化溫室部件：直牆、轉角、門框、屋頂板、窗板和地磚。採用近似正交視角、共用網格比例、淺色金屬框和半透明玻璃。部件分兩排，僅標註提供的名稱。連接點相容，避免不可能的屋頂接縫。可調變數：經核准模組尺寸和標籤；幾何結構須在三維工具中重建並測試。
```

## PRO-03 — 物品欄圖示集

```text
根據 [APPROVED ITEM LIST] 製作正方形四乘四圖集，包含十六個不同的物品欄圖示概念。統一等距角度、左上光源和平坦中性背景。等大單元中各置中放一個物品，內距充足，小尺寸時輪廓仍可讀。不加文字，不重複物品、不裁切，也不編造品牌裝備。可調變數：準確的十六項物品清單和配色。這是概念圖集，不是經驗證的透明精靈圖集。
```

## PRO-04 — 四種材質預覽

```text
製作 16:9 材質板，四個等大正方形研究分別為磨損的塗漆木材、髮絲紋鋼材、粗糙石材和編織帆布。使用 [AUTHORIZED REFERENCES] 保留材料特性與一致的尺度感。採用平面表面視圖和中性光，不加戲劇性陰影或物件。各材料在預覽外標註一次。可調變數：參考圖和準確標籤。未經獨立處理，不宣稱它們是無縫紋理、物理式算繪貼圖或可直接用於引擎的素材。
```
