# 介面、受控編輯與在地化

十則 Qwen Image 3.0 提示詞範例。生成前請替換方括號中的輸入內容。所有引號內文字均須原樣呈現；除非明確要求，否則不作額外翻譯。輸出結果需要人工審核。

<a id="dig-01"></a>

## DIG-01 — 工具借閱行動介面

```text
製作一張 16:9 展示板，呈現虛構應用程式「Borrow Bench」的三個手機頁面：工具目錄、物品詳情和預約確認。採用象牙白背景、海軍藍文字、藍綠色操作按鈕和一致的圓角卡片。選取的物品是一把黃色電鑽。僅在合適頁面呈現「Borrow Bench」、「找一件工具」、「無線電鑽」、「預約」、「領取時間」、「週六 10:00」、「預約已儲存」和「查看預約」。不添加價格、個人資料或額外導覽標籤。這是靜態介面概念圖，不暗示控制項可實際操作。
```

<a id="dig-02"></a>

## DIG-02 — CSV 匯入審核畫面

```text
為虛構庫存應用程式「Stockroom」製作一張 16:9 桌面介面稿。展示匯入審核表，欄名為「物品」、「數量」和「狀態」；包含提供的三列範例資料，其中一列醒目標記「需要審核」。表格上方寫「審核匯入內容」；下方放置「返回」和「匯入有效資料列」按鈕。使用整潔的白色布局，以琥珀色突顯錯誤，可讀的側欄僅包含「庫存」。保留提供的資料，不顯示個人資訊。可調變數：範例資料列和經核准的文案。
```

<a id="dig-03"></a>

## DIG-03 — 區域鐵路首頁

```text
為虛構旅行規劃工具「Local Lines」製作一張 16:9 桌面首頁概念圖。右側放置大幅海岸列車照片，左側放實用搜尋面板。準確呈現「換一條慢行路線」、「出發地」、「目的地」、「出行日期」和「尋找行程」；輸入欄位保持空白。採用奶油色背景、深綠色控制項和寬裕間距。不添加真實時刻表、票價、營運商標誌或有票承諾。列車結構須符合物理常識，介面文字與照片分離。可調變數：地區影像和經核准的標題。
```

<a id="dig-04"></a>

## DIG-04 — 合作遊戲 HUD

```text
為虛構山地送貨遊戲製作一張 16:9 靜態 HUD 概念圖。積雪小徑中央百分之六十的區域保持無遮擋。頂部放小巧羅盤，左上角放兩條隊友狀態列，右下角放三個物品欄位。僅呈現「北」、「隊伍」、「包裹」、「繩索」和「地圖」。採用高對比形狀和節制的琥珀色重點標示，不使用電影式懸浮全像效果。避免真實軍隊徽記、不可讀的細小文字和過多覆蓋層。可調變數：遊戲場景和經核准的標籤。
```

<a id="dig-05"></a>

## DIG-05 — 海報文字替換

```text
將影像 1 用作編輯目標，僅使用 [APPROVED SOURCE-TO-TARGET TEXT MAP] 中的替換文案。替換指定海報文字，不改變攝影、插畫、配色、頁邊距、標誌或非目標文字。保留字重和層級；只有目標語言需要時才調整換行。保持標點、重音符號和閱讀方向正確。移除原文字，不要重複保留。不翻譯未指定文字，也不添加解釋。可調變數：來源影像和完整文字對照表。
```

<a id="dig-06"></a>

## DIG-06 — 照片損傷修復

```text
將一張獲授權的掃描照片作為編輯目標。僅修復可見灰塵、刮痕和摺痕損傷，依據鄰近紋理補全小面積缺失。保留人物身分、年齡、表情、裁切、服裝、原始顆粒和色調範圍。不為黑白原圖上色、不磨皮、不睜開閉著的眼睛，也不虛構背景物件。不確定的大塊缺失區域保持原樣，不憑空補造細節。輸出一張修復圖，不添加比較標籤或浮水印。可調變數：來源照片和明確標記的修復區域。
```

<a id="dig-07"></a>

## DIG-07 — 三參考圖產品合成

```text
將影像 1 作為基礎桌面場景，影像 2 作為陶瓷杯的準確參考，影像 3 僅作為釉色參考。將影像 2 中的一只杯子放到影像 1 的空杯墊上，並僅套用提供的釉色色相。保留基礎畫面的鏡頭、裁切、周邊物件和杯子幾何結構。匹配光線方向、接觸陰影、透視和反射。不複製影像 3 中的物件或文字。不添加文字。可調變數：三張獲授權的圖片和預期杯子位置。
```

<a id="dig-08"></a>

## DIG-08 — 從草圖到閱覽室

```text
使用經核准的房間草圖作為布局參考。製作一張 4:3 寫實閱覽室概念圖，採用淺橡木書架、苔綠色長凳和漫射頂光。保留草圖中的每面牆、窗、門口和家具占地位置；僅用材質方案裝飾現有表面。透視須一致，走道寬度在視覺上保持不變。不添加人物、額外家具、植物或招牌。這是示意概念圖，不是具有測量尺寸的施工圖。可調變數：草圖和經核准的材料。
```

<a id="dig-09"></a>

## DIG-09 — 無障礙空白狀態介面

```text
為尚無內容的收藏閱讀清單製作一張 3:4 手機介面稿。使用奶油色背景、海軍藍文字和一幅由三本闔起的書組成的小插畫。準確呈現「尚未收藏內容」、「把實用文章收藏在一起」和「探索文章」。說明放在標題下方，大按鈕放在更下方；保留舒適的頁邊距。使用高對比度，不添加細小文字、載入骨架、虛假文章卡片或通知徽章。這是靜態設計提案；無障礙表現仍需在實作後測試。
```

<a id="dig-10"></a>

## DIG-10 — 語言閱讀方向比較

```text
使用 [APPROVED ENGLISH AND ARABIC COPY] 製作一張 16:9 並排介面排版展示板。左側採用由左至右的對齊方式；右側採用自然的由右至左對齊方式。調整閱讀順序時，保留相同的元件層級、間距和兩個按鈕的功能角色。產品照片保持原樣，不進行鏡像翻轉。僅呈現提供的字串，阿拉伯文字母須正確連寫，拉丁字母品牌名稱保持完整。不音譯、不重複來源文字，也不編造文案。可調變數：成對字串和元件標籤；須由阿拉伯語流利使用者審核。
```
