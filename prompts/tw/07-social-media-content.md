# 社群貼文、封面與創作者內容

十則 Qwen Image 3.0 提示詞範例。生成前請替換方括號中的輸入內容。所有引號內文字均須原樣呈現；除非明確要求，否則不作額外翻譯。輸出結果需要人工審核。

<a id="soc-01"></a>

## SOC-01 — 陽台種植教學封面

```text
為新手陽台種植指南製作 3:4 社群封面。在窄層板上放三只小陶土盆，每盆種一種不同的綠葉香草，下方放小澆水壺。採用明亮自然攝影和暖奶油色背景。呈現「小陽台，新開始」、「從三盆植物開始」和「1/5」，標題占上方三分之一。不宣稱產量、健康效益或保證生長。花盆須有支撐，欄杆幾何結構一致。可調變數：經核准的香草和標題。
```

<a id="soc-02"></a>

## SOC-02 — 三聯手作活動公告

```text
製作一張 3:1 主圖，預計分割為三個正方形社群貼文。長工作檯左側放陶藝工具，中央放陶瓷水壺，右側放摺疊亞麻布。每個正方形獨立構圖均衡；三個畫面分別寫「動手」、「分享」和「相聚」。採用一致暖光和安靜的奶油色邊距。重要物件或字母不得跨越裁切邊界。這是視覺主圖，不是三個已匯出檔案。可調變數：手作物件和三個經核准的詞。
```

## SOC-03 — 研究發現卡片

```text
使用 [VERIFIED FINDING, DATA AND SOURCE] 製作 16:9 專業社群卡片。頂部放一個準確發現，中央放簡潔輔助圖表，底部標註來源。採用白底、炭灰文字和單一藍綠色點綴。保留單位、日期、樣本限制和不確定性。不將相關性變成因果關係，也不添加誇張百分比。文字在手機上須可讀。可調變數：經核准的發現、資料集和引用；圖表準確性需要人工審核。
```

<a id="soc-04"></a>

## SOC-04 — 烹飪比較縮圖

```text
製作 16:9 影片縮圖，比較梨子的三種擺盤切法：片狀、方塊和扇形。鈷藍桌面上一排三個相同白盤，梨子的顏色與頂光保持一致。上方僅寫「一顆梨，三種切法」。三種切法須明顯不同，份量合理。不添加營養宣稱、虛假評分、靠近手的刀具或其他文字。可調變數：水果和經核准的標題。
```

<a id="soc-05"></a>

## SOC-05 — 桌面整理短影音封面

```text
製作 9:16 封面，展示整理了一半的桌面：左側紙張對齊，右側放闔上的筆記本和杯子。採用自然俯視攝影、柔和陰影和節制的沙色與藍色配色。中央安全區寫「重新整理你的桌面」，下方寫「從一塊檯面開始」。重要文字避開下方四分之一和右邊緣，以預留平台疊加介面空間。不承諾完成時間，不添加應用程式標誌或額外文案。可調變數：桌面物件和兩行標題。
```

## SOC-06 — 雙來賓直播預告

```text
使用兩張獲授權的成年人人像製作 3:4 直播預告。兩位來賓占據等量視覺空間，裁切比例和中性照明一致；姓名直接放在對應人像下方。僅呈現 [EVENT TITLE]、[GUEST NAMES]、[DATE] 和 [TIME ZONE]。採用簡潔海軍藍與奶油色網格，不添加虛假直播指示或平台標誌。保留身分，不編造資歷或參與人數。可調變數：兩張參考圖和經核准的活動文案。
```

## SOC-07 — 核實引言卡片

```text
使用 [EXACT VERIFIED QUOTE] 和 [AUTHOR ATTRIBUTION] 製作正方形引言卡片。在暖調灰白紙面上以大號、易讀襯線字排引言；下方放作者署名，左邊緣對齊。下角添加一幅小型抽象藍色線描。準確保留標點和措辭；不縮短、不虛構，也不將引言歸給其他人。不添加人像、簽名或背書徽章。可調變數：已核實引言、署名和配色。
```

<a id="soc-08"></a>

## SOC-08 — 九步手作網格

```text
製作正方形三乘三網格，圖解 [NINE APPROVED CRAFT STEPS]。全程採用同一桌面、雙手和材料，清楚展示原料到成品的推進。畫面僅編號「1」至「9」，按由左至右、由上至下順序排列。工具與物件比例保持穩定，不編造步驟，也不展示不安全的工具操作。不添加裝飾文字或重複畫格。可調變數：經核實的步驟和材料；教學準確性需要審核。
```

<a id="soc-09"></a>

## SOC-09 — 活動回顧拼圖

```text
為虛構社區繪畫日製作 3:4 編輯式回顧版面。排列四個圖片畫面：桌上的速寫本、正在畫畫的雙手、一面未署名速寫牆，以及結束時的空凳。採用一致日光，頂部小標題寫「一起畫畫的一天」。人物面孔不可辨識，畫作須原創。不添加參與人數、贊助標記或評價引言。底部留一條安靜空白頁尾。可調變數：活動和準確標題。
```

## SOC-10 — 直式封面裁切研究

```text
製作 9:16 創作者封面概念圖，淺色天空背景中央只有一隻紅紙風箏。中間三分之一寫「做一隻紙風箏」，頂部百分之十五和底部百分之二十五不放文字。風箏和標題在中央正方形裁切內也須清晰可辨。採用乾淨的插畫紋理，風箏線輕輕彎曲。不添加平台介面、其他風箏、虛假按鈕或小字說明。可調變數：物件顏色和經核准標題。
```
