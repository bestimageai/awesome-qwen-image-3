# 歷史、文化與基於證據的詮釋

十則 Qwen Image 3.0 提示詞範例。生成前請替換方括號中的輸入內容。所有引號內文字均須原樣呈現；除非明確要求，否則不作額外翻譯。輸出結果需要人工審核。

<a id="cul-01"></a>

## CUL-01 — 歷史街道日常

```text
使用 [DATED PHOTOGRAPHS AND MAP]，製作 [YEAR] 年 [STREET] 日常生活的 16:9 重建圖。保留有紀錄的建築輪廓、交通類型和街道路面。僅展示提供證據支持的日常活動，不確定區域在視覺上弱化。採用紀實插畫，不聲稱是檔案照片。不編造銘文、名人或現代物件。可調變數：地點、日期、證據和不確定性註記；須進行歷史審核。
```

<a id="cul-02"></a>

## CUL-02 — 文物復原研究板

```text
根據 [AUTHORIZED ARTIFACT IMAGES] 製作 16:9 三格博物館研究板。展示現存物件、節制復原圖和標記不確定區域的示意圖。保留有紀錄的幾何結構和表面損傷。畫格標註「現存」、「復原」和「不確定」；用不同視覺處理避免推測被誤認作證據。不編造製作者、來源沿革或儀式含義。可調變數：參考資料包和經核准解讀；須由專家審核。
```

<a id="cul-03"></a>

## CUL-03 — 歷史市場插畫

```text
使用 [EVIDENCE PACK]，為 [VERIFIED REGION AND PERIOD] 的市場製作 3:2 教育插畫。僅包含提供的攤位類型、服裝、商品和建築。前景交易清楚，背景安靜，採用自然日光和節制細節。不添加可讀價格、虛構文字系統、刻板印象或其他時代物件。可調變數：地區、日期和有紀錄的元素。輸出須標明為詮釋插畫，而非真實歷史影像。
```

<a id="cul-04"></a>

## CUL-04 — 歷史服飾研究

```text
使用 [MUSEUM-VERIFIED GARMENT REFERENCES] 製作 16:9 服裝研究圖，在中性人物上展示正面、側面和背面。保留縫線、扣合方式、布料層次和提供的顏色證據。僅標註經核准的服飾名、地區和時期。不編造身分地位、族群、儀式含義或無紀錄的裝飾。可調變數：參考圖和準確標籤。用提供的註記區分不確定顏色，並請專業人員審核。
```

<a id="cul-05"></a>

## CUL-05 — 傳統工藝流程

```text
使用 [PRACTITIONER-APPROVED STEPS]，為 [DOCUMENTED CRAFT PROCESS] 製作 16:9 四格插畫。依序展示正確工具、手部位置和材料狀態。採用清晰自然主義插畫，僅用提供的標籤。不披露受限知識、不編造神聖細節，也不用通用紋樣替代活態傳統。可調變數：經核准參考、步驟和署名。發布前須由實踐者審核並取得適用許可。
```

<a id="cul-06"></a>

## CUL-06 — 雙語文化資產解說板

```text
使用 [APPROVED TWO-LANGUAGE COPY] 和一張獲授權遺址圖，製作 3:4 文化資產解說板。兩種語言排在獨立、清晰對齊的區塊，排版地位相等。保留名稱、日期、變音符號和閱讀方向；圖片位於文字上方。不編造歷史、旅遊宣稱、機構標誌或翻譯。可調變數：定稿雙語文案、圖片和來源署名。結果是需社群與事實審核的版式概念。
```

<a id="cul-07"></a>

## CUL-07 — 歷史地圖疊加

```text
使用獲授權的歷史地圖和 [VERIFIED MODERN ALIGNMENT] 製作 16:9 比較插畫。歷史地圖保留為底圖，僅將提供的現代參照線以明顯藍色疊加。圖例區分兩個日期及不確定的對位。不編造邊界、所有權宣稱、路線或地理空間精度。可調變數：地圖、對位關係和準確標籤；須進行歷史與地理審核。
```

<a id="cul-08"></a>

## CUL-08 — 復原過程的連續性

```text
製作 16:9 四格復原圖，展示 [VERIFIED PERIOD] 中同一有文獻依據的庭院在黎明、正午、午後和黃昏的狀態。使用 [EVIDENCE PACK] 鎖定建築、材料、家具和相機位置。僅改變光線與提供的日常活動。避免現代物件、虛構銘文或無依據的儀式事件。僅標註時段。可調變數：參考圖和經核准活動清單。這是詮釋性序列，不是所示事件發生過的證據。
```

<a id="cul-09"></a>

## CUL-09 — 檔案操作海報

```text
使用 [ARCHIVIST-APPROVED HANDLING RULES] 製作 3:4 訓練海報概念。三個清楚畫格展示提供的操作動作、匹配工具和準確短標籤。採用中性技術插畫、高對比和寬裕邊距。不編造戴手套要求、清潔方法或保存維護處理。可調變數：核實過的流程和物件類型；使用前與檔案專業人員共同審閱。不加機構印章、簽名或無依據的保存效果宣稱。
```

<a id="cul-10"></a>

## CUL-10 — 口述歷史引言展板

```text
使用 [CONSENTED VERIFIED QUOTATION]、[APPROVED ATTRIBUTION] 和獲授權的背景圖片製作 4:3 展板。突顯引言，下方放署名，側面放圖片。準確保留措辭、方言和標點；不改寫證言或虛構講述者肖像。採用安靜編輯排版和奶油色背景。可調變數：獲同意文字、署名和圖片。僅包含提供的背景說明與許可署名。
```
