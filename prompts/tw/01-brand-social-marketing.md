# 品牌、海報與宣傳活動

十則 Qwen Image 3.0 提示詞範例。生成前請替換方括號中的輸入內容。所有引號內文字均須原樣呈現；除非明確要求，否則不作額外翻譯。輸出結果需要人工審核。

## MKT-01 — 可維修檯燈發表海報

```text
為虛構工作室 LATCH 及其可維修檯燈製作一張 3:4 發表海報。在藍色工作檯上展示一盞摺疊的赭黃色檯燈，將可拆卸燈罩放在旁邊；檯燈占據畫面下方三分之二。採用清晰的產品攝影、柔和側光和節制的編輯式網格排版。僅按由大到小的層級呈現「LATCH」、「為長久陪伴而造」和「更換零件，留下檯燈。」。保持關節結構符合機械原理，各部件彼此匹配。不添加價格、永續性認證或效能承諾。可調變數：工作室名稱、表面處理和經核准的標語。
```

## MKT-02 — 河畔讀書節

```text
為虛構的水上圖書館節製作一張 3:4 插畫海報。右下方是一艘停泊的藍色圖書駁船；彎曲的紅色人行橋將視線從左上方標題引向條紋遮陽篷下的三位讀者。採用平面的絹印色塊、象牙白紙張和寬裕頁邊距。準確呈現「河畔读书节」、「RIVER READING DAYS」、「川辺の読書会」和「SAT–SUN · 10:00–17:00」，每項在獨立文字區塊中僅出現一次。保留所提供的中文、英文和日文原文。不添加其他招牌、贊助商或浮水印。可調變數：經核准的節慶文案和配色。
```

## MKT-03 — 聲音檔案播客封面

```text
為虛構播客「小小聲響」製作正方形封面。展示一把放大的黃銅鑰匙，置於淺托盤內，在鑰匙後方繪製三圈纖細的同心振動紋。採用暖調微距攝影和深茄紫色背景；標題橫跨上方四分之一，下方寫「值得聆聽的故事」。兩行文字在畫面縮至 100 像素寬時仍須清晰可讀。不出現麥克風、耳機、平台徽章或集數。僅保留一把鑰匙、真實反射和乾淨留白。可調變數：標題、物件和背景色。
```

## MKT-04 — 工具比較影片縮圖

```text
製作一張講解手工具選擇的 16:9 影片縮圖。右側縱向排列三把無品牌螺絲起子，一字、十字和六角起子頭須明顯不同。左側僅呈現「哪種起子頭合適？」，分為兩行。每種起子頭下方添加一個與之匹配的螺絲頭小示意圖，不加其他標籤。採用明亮的桌面攝影、炭灰色文字和黃色背景點綴。起子頭與螺絲頭凹槽須在機械結構上匹配；不添加虛假反應、評分或誇張承諾。可調變數：工具組合和準確標題。
```

## MKT-05 — 包裝教學輪播封面

```text
為一套六頁的易碎陶瓷包裝指南製作 3:4 封面。展示一個碗，在視覺上懸於摺疊的紙板隔片之間，下方放一捲緩衝包裝紙。以淺灰色背景拍攝整齊的俯視照片。頂部寫「用心包裝」，下方寫「陶瓷寄送指南」，右下角寫「1/6」。保持碗完整，材料真實。不添加物流公司標誌、保證防損的承諾或其他文字。可調變數：物件、標題和頁數。
```

## MKT-06 — 社區工坊招募

```text
為虛構的自行車維修合作社製作一張直式 3:4 招募海報。展示一條無人穿戴的維修圍裙，掛在整齊的工具板旁；上半部留空供文字使用。採用紀實攝影、柔和窗光和深綠色文字。使用提供的替換內容呈現「加入維修工坊」、「[ROLE]」、「[CITY] · [SCHEDULE]」和「申請截止：[DATE]」。保持工具可辨認，不編造薪資、認證或聯絡方式。不生成 QR Code。生成前必須替換全部變數。
```

## MKT-07 — 自備杯提醒

```text
製作一張 9:16 咖啡館告示，鼓勵顧客自備可重複使用的杯子。在暖調晨光下，以櫃檯高度拍攝一個有使用痕跡的奶油色隨行杯，旁邊放一只粉筆藍色陶壺。杯子上方寫「你的杯子，你的日常儀式」，下方寫「下次記得帶上它」。中部保持寬鬆留白，文字在遠觀時仍須對比鮮明。不添加折扣、環保數據或健康宣稱；不添加額外物品或文字。保持杯蓋結構真實，陰影自然落在檯面上。可調變數：杯子顏色和經核准的兩行文案。
```

## MKT-08 — 提燈夜遊主視覺

```text
為名為「光之小徑」的虛構夜間提燈漫步活動製作一張 16:9 靜態主視覺。一串小巧的琥珀色紙燈籠沿曲線穿過幽暗植物園，通向敞開的大門。左側中部保持安靜簡潔以放置標題，正下方寫「共度一個夜晚」。採用層疊紙藝插畫，呈現細膩層次和可見的纖維紋理，不使用霓虹效果。避免可辨識的地標、贊助商標誌和其他文案。這是一張靜態概念畫面，不是動畫輸出。可調變數：標題、路徑形狀和點綴色。
```

## MKT-09 — 維修工坊海報

```text
為虛構社區維修工坊製作一張 3:4 海報。畫一張陶土色桌子，上面放著黃色烤麵包機、小螺絲起子和一捲藍線；兩隻成年人的手從相對兩側修理烤麵包機。使用乾淨的剪紙形狀、奶油色背景、海軍藍文字和寬裕間距。頂部寫「週六一起修」；下方寫「帶上一件小物品」；底部寫「14:00–17:00」。每行僅出現一次，不添加其他文字。手部解剖結構須合理，烤麵包機須處於未插電狀態。可調變數：經核准的在地化文字和配色。
```

## MKT-10 — 相片沖印店開幕櫥窗告示

```text
為虛構社區相片沖印工作室製作一張 2:3 櫥窗告示。在下半部展示三張無品牌拍立得相片，用夾子掛在同一條水平細繩上。上方寫「印下你的日常」，接著寫「[DATE] 開幕」和「[STREET]」。採用有觸感的奶油色紙張、鈷藍文字和自然陰影。生成前提供日期和地址；不編造開幕優惠。三張相片內容須彼此不同，僅含影像，不出現私人面孔或可讀的個人文件。可調變數：日期、地點和相片主題。
```
