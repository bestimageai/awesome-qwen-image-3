# 建築、室內與房產概念

十則 Qwen Image 3.0 提示詞範例。生成前請替換方括號中的輸入內容。所有引號內文字均須原樣呈現；除非明確要求，否則不作額外翻譯。輸出結果需要人工審核。

<a id="arc-01"></a>

## ARC-01 — 小型閱讀壁龕

```text
製作 4:3 建築室內圖，展示樓梯下緊湊的閱讀壁龕。一條嵌入式橡木長凳、一個淺書架和一盞圓壁燈，配摺疊藍坐墊。採用可信的人體尺度、筆直垂線和來自畫外窗戶的柔和日光。保留可用的頭部淨空與暢通出入空間。不添加人物、文字、不可能的懸挑或過大家具。可調變數：房間尺寸、經核准的材料和配色；這是設計插畫，不是施工文件。
```

<a id="arc-02"></a>

## ARC-02 — 麵包店櫃檯改造

```text
將一張獲授權的麵包店室內照片作為編輯目標。僅將櫃檯正面改為淺色直向木條，後牆改為低飽和藍色。保留櫃檯尺寸、展示玻璃、門、天花燈具、相機角度和全部已有文字。反射和接觸陰影須匹配原有光線。不添加產品、不移除設備，也不拓寬房間。可調變數：來源照片和經核准的表面處理。輸出一張概念圖，不帶改造前後標籤。
```

<a id="arc-03"></a>

## ARC-03 — 家具平面配置彩現

```text
使用 [APPROVED FLOOR PLAN] 製作俯視 4:3 家具配置插畫。保留全部牆體、開口、樓梯和提供的尺寸。僅將 [APPROVED FURNITURE LIST] 中的家具放到指定位置，採用統一比例和柔和中性陰影。通行動線須清楚，僅呈現提供的房間名稱。不編造尺寸、不移動牆體，也不暗示符合法規。可調變數：平面圖、家具位置和標籤；空間準確性須單獨核驗。
```

<a id="arc-04"></a>

## ARC-04 — 藍調時刻外景編輯

```text
將獲授權的房產照片作為編輯目標。僅將時間改為藍調時刻初期，現有窗內可見柔和暖光。除非明確指定，否則保留建築、景觀、鄰近建築、相機位置和天氣條件。天空亮度和窗戶反射須符合物理規律。不新增燈具、不遮掩缺陷，也不改變景觀視野。不添加文字或房產宣稱。可調變數：來源影像和經核准的照明處理；發布時標明是視覺化效果圖。
```

<a id="arc-05"></a>

## ARC-05 — 客房資訊卡

```text
使用 [VERIFIED ROOM PLAN AND AMENITIES] 製作 3:4 住宿資訊卡。簡化房間插畫置於上方，下方列出提供的簡短設施清單。保留床位數、浴室位置和窗戶位置。採用暖中性色、大字和經核准的標籤。不編造海景、無障礙設施、星級、尺寸或可訂房狀態。標題下寫「客房圖解指南」。可調變數：已核實的平面圖、設施清單和經核准標題。
```

<a id="arc-06"></a>

## ARC-06 — 材料配色板

```text
製作標題為「靜謐工坊」的 16:9 室內材料板。排列五種不同樣品：淺橡木、髮絲紋鋁材、藍色羊毛、暖色灰泥和斑點陶瓷。呈現真實紋理與厚度，採用柔和定向陰影和乾淨奶油色背景。每種材料在其樣品下方準確標註一次。樣品尺寸在視覺上均衡，但不暗示物理比例相同。不添加供應商品牌、環保認證或效能宣稱。可調變數：材料、標籤和專案標題。
```

<a id="arc-07"></a>

## ARC-07 — 展覽參觀動線

```text
使用 [APPROVED EXHIBITION PLAN] 製作 16:9 軸測插畫。保留全部隔牆、入口和提供的裝置。用藍線和方向箭頭展示一條經核准的參觀路線；僅在提供緊急疏散路線時才將其明確區分。使用 [APPROVED ZONE NAMES] 標註分區。採用中性建築陰影，不添加裝飾性人群。不編造安全出口、無障礙條件或容納人數。可調變數：平面圖、路線和標籤；使用前須由場館審核。
```

<a id="arc-08"></a>

## ARC-08 — 庭院四季

```text
製作 16:9 四格景觀概念圖，展示同一小庭院的春、夏、秋、冬。鎖定相機、石路、長凳、樹木位置和建築牆面。僅改變符合 [VERIFIED CLIMATE] 的植被外觀、日光與季節地面狀態。每個季節標註一次。採用寫實建築視覺化，不在畫格間移動物件。不編造全年開花或成熟生長速度。可調變數：經核准的植物清單和氣候。
```

<a id="arc-09"></a>

## ARC-09 — 零售空間視線研究

```text
根據一份經核准的平面圖製作 16:9 雙格零售配置概念圖。兩格都從入口以相同平視角度觀看。左格使用目前貨架位置；右格僅採用 [APPROVED NEW POSITIONS]。建築、貨架尺寸、商品類別和照明保持不變。影像外分別標註「現況」和「提案」。不虛構銷售提升、無障礙宣稱或額外使用面積。可調變數：平面圖和經核准的家具移動方案。
```

<a id="arc-10"></a>

## ARC-10 — 窗邊座位日光研究

```text
製作 3:2 三格日光研究圖，展示同一窗邊座位的早晨、正午和傍晚。使用同一房間、坐墊、相機位置和窗戶朝向。僅根據 [SUPPLIED ORIENTATION AND LOCATION] 改變光線方向和強度。對應畫格下寫「早晨」、「正午」和「午後」。反射和陰影方向須符合任務說明。不編造節能效果或實測日光數值。可調變數：地點、朝向和材料；這是示意圖，不是模擬計算。
```
