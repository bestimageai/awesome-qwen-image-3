# 文件、出版與資訊設計

十則 Qwen Image 3.0 提示詞範例。生成前請替換方括號中的輸入內容。所有引號內文字均須原樣呈現；除非明確要求，否則不作額外翻譯。輸出結果需要人工審核。

<a id="doc-01"></a>

## DOC-01 — 雙頁專案簡報

```text
製作 16:9 展示圖，將兩張直式專案簡報並排放置。使用 [APPROVED COPY]，第一頁包含目的與背景，第二頁包含範圍與下一步。頁邊距和標題層級一致，只有提供頁碼時才加入。採用炭灰文字、藍線和白紙。不添加佔位文字、虛構日期、簽名或核准印章。可調變數：完整文案和頁面對照表。這是點陣版式概念；最終文件需要可編輯排版。
```

<a id="doc-02"></a>

## DOC-02 — 產品保養單頁

```text
根據 [MANUFACTURER-APPROVED CARE INSTRUCTIONS] 製作 3:4 圖解保養單頁。提供的四個動作排成二乘二網格，每項有匹配的簡潔物件插畫和準確標籤。警告文字放在獨立底部帶。不編造清潔化學品、溫度、處置建議或保固條款。採用高對比文字和節制藍色配色。可調變數：核實過的說明和產品參考；發布前確認每步。
```

<a id="doc-03"></a>

## DOC-03 — 博物館藏品標籤

```text
使用 [VERIFIED OBJECT METADATA] 製作 4:3 博物館標籤概念。左側放獲授權的藏品小圖，右側放準確的標題、製作者、日期、材料和說明。採用安靜奶油色背景和可讀深色文字。未提供的欄位直接省略，不猜測。不編造來源沿革、估值、入藏編號或機構標誌。可調變數：圖片和經核准詮釋資料。這是版式研究，不是真實性或所有權證據。
```

<a id="doc-04"></a>

## DOC-04 — 年報跨頁

```text
使用 [APPROVED REPORT COPY AND DATA] 製作 16:9 雙頁年報版面。左頁一個標題和簡短敘述，右頁一個標籤清楚的圖表及來源註記。採用一致編輯網格和節制海軍藍點綴。保留所有單位、期間和限定說明。不編造財務數字、審計聲明、簽名或背書。可調變數：核實過的文案、資料和來源；這是需事實與製作審核的設計概念。
```

<a id="doc-05"></a>

## DOC-05 — 會議議程卡

```text
根據 [APPROVED SESSION TABLE] 製作 3:4 活動議程。縱向時間軸包含準確開始時間、場次標題和房間，同時舉行的場次在視覺上分組。頂部放活動標題，下方放提供的時區。象牙白底上使用大字深色文字和藍分隔線。不編造講者、休息時段、無障礙安排或場館細節。可調變數：議程和準確文案；核實時間順序及房間對應。
```

<a id="doc-06"></a>

## DOC-06 — 已審核提醒卡

```text
僅使用 [CLINICIAN-APPROVED TEXT] 製作 3:4 大字提醒卡。提供的資訊按清晰分隔的列組織，採用高對比黑字和一個藍標題。準確保留名稱、數量、單位、時間和警告；不添加劑量、診斷或醫療建議。不生成藥片、標誌、簽名或官方印章。可調變數：經核准文字和標題。這是視覺格式概念；任何實際使用前須由合格專業人員核驗。
```

<a id="doc-07"></a>

## DOC-07 — 圖書館會員指南

```text
使用 [APPROVED MEMBERSHIP RULES] 為虛構社區圖書館製作 3:4 資訊單頁。三個區塊標題為「加入」、「借閱」和「歸還」，每塊配一個簡潔插畫與提供的短文。採用奶油色紙、海軍藍字和寬裕間距。不編造費用、身分證明要求、開放時間或借閱限額。可調變數：經核實規則和經核准標題。設計中不包含個人資料或可掃描碼。
```

<a id="doc-08"></a>

## DOC-08 — 文件比較版面

```text
製作 16:9 並排版面，比較提供的兩個簡短公開文件版本。頁面比例一致，僅用淺黃突顯 [APPROVED CHANGED PASSAGES]。畫格標註「舊版」和「修訂版」。所有文字逐字保留，不推斷法律意義、不添加評論，也不改動未變措辭。可調變數：兩份來源文字和明確變更對照表。這是視覺比較概念，不是法律審查或追蹤修訂檔案。
```

<a id="doc-09"></a>

## DOC-09 — 志工交接單

```text
使用 [APPROVED TASK LIST] 製作 3:4 交接單概念。頁面分「已完成」、「進行中」和「下一班次」區塊，每個提供的事項旁有一個核取方塊。未明確提供狀態時方塊留空。採用大字可讀文字、簡潔網格，不加裝飾攝影。不編造姓名、截止日期、聯絡方式或完成宣稱。可調變數：任務清單和提供的狀態；最終實務使用需要可編輯文字。
```

<a id="doc-10"></a>

## DOC-10 — 展覽價目表

```text
使用 [APPROVED ITEM TABLE] 製作 3:4 虛構展覽價目表版式。物品名稱、尺寸和價格對齊成三欄，每項一列。採用節制襯線標題、無襯線數字和白底。準確保留貨幣符號、小數分隔符和單位。不編造折扣、稅務處理、售出狀態或藝術家履歷。可調變數：核實過的表格和標題。這是排版概念，不是報價或交易紀錄。
```
