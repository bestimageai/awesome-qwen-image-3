# 電商、產品與食物

十則 Qwen Image 3.0 提示詞範例。生成前請替換方括號中的輸入內容。所有引號內文字均須原樣呈現；除非明確要求，否則不作額外翻譯。輸出結果需要人工審核。

<a id="com-01"></a>

## COM-01 — 模組化檯燈產品主圖

```text
為虛構的模組化檯燈製作一張正方形型錄照片。一盞霧面奶油黃色檯燈具有圓柱形配重底座、單根鉸接燈臂和淺錐形燈罩；將其放在象牙白桌面上，底座旁放一顆鈷藍色維修旋鈕。使用左上方柔光和輕柔接觸陰影。唯一的文字為底座上的「LATCH」和左上角頁邊的「讓光留下」。保持關節結構合理，僅有一根電源線。不添加認證徽章、價格或其他零件。可調變數：表面處理和經核准的品牌文字。
```

<a id="com-02"></a>

## COM-02 — 餐盒多視圖

```text
使用一張獲授權的產品照片作為幾何結構參考，製作一張 16:9 展示圖，以四個等大的視圖呈現同一個長方形餐盒：閉合正面、閉合背面、打開後的俯視圖和扣具特寫。採用淺色無縫背景和一致的柔光。視圖標籤僅寫「正面」、「背面」、「內部」和「扣具」。每個視圖中保持分隔數量、密封圈顏色和扣具位置一致；不編造尺寸或材質宣稱。各畫面之間保留明顯間隔。可調變數：產品參考圖和翻譯後的標籤。
```

<a id="com-03"></a>

## COM-03 — 三款茶葉罐

```text
為三個共用同一圓柱形外觀的虛構茶葉罐製作一張 3:2 包裝概念圖。將它們排成直線，分別使用奶油色、淡紫色和鼠尾草綠色標籤帶。統一品牌為「Field Notes」，產品名分別為「清晨」、「正午」和「傍晚」；不添加其他文字。在中性色層板上拍攝，保持亮部和比例一致。三個罐子的蓋子、文字對齊方式和標籤寬度完全相同。不宣稱成分、產地或健康益處。可調變數：經核准的品牌、名稱和顏色。
```

<a id="com-04"></a>

## COM-04 — 背包功能展示板

```text
使用獲授權的背包參考圖和提供的三項功能說明，製作一張 3:4 產品資訊圖。左側展示完整背包；右側縱向對齊三個細節圓框，分別只連接對應的拉鍊、肩帶和側袋。在匹配的圓框旁準確呈現 [APPROVED FEATURE LABELS]。使用淺灰背景和受控的棚拍燈光。保留實際結構和顏色；除非明確提供，否則不宣稱防水性、容量或人體工學表現。可調變數：參考圖、標籤和點綴色。
```

## COM-05 — 麵包製作流程

```text
製作一張 16:9 四格圖，展示虛構麵包店的酸種麵包流程：混合麵團、摺疊麵團、為整形後的麵團割線，以及展示烤好的麵包。採用近距離紀實攝影，同一張木工作檯，由左至右閱讀，沾有麵粉的雙手保持一致。各格標籤分別為「混合」、「摺疊」、「割線」和「烘烤」。嚴格保持四格，區分生麵團與烤好的外皮。不添加烹調溫度或時間。這是流程示意概念圖，不是食品安全指導。可調變數：麵團類型和經核准的標籤。
```

## COM-06 — 午餐組合

```text
製作一張 16:9 俯視型錄圖，四碗寫實午餐組成二乘二網格：烤南瓜配米飯、蘑菇配麵條、扁豆配胡蘿蔔，以及番茄配庫斯庫斯。使用相同的淺白碗、各不相同的食物質感、柔和日光和低飽和綠色桌面。間距相等，餐具不重疊。不添加文字、熱量、飲食適用性保證或食材標籤。份量須合理，避免重複的食物紋理。可調變數：提供的四份食譜、碗的表面處理和桌面顏色。
```

## COM-07 — 雙語麵館菜單

```text
為虛構餐館「小巷面馆」製作一張 3:4 菜單，副標題為「LANE NOODLES」。使用象牙白紙張、炭灰色文字和三個水平列；每列左側是一張小型寫實麵碗照片，右側配對應文字。準確呈現「番茄面 · Tomato noodles · 28」、「菌菇面 · Mushroom noodles · 32」和「芝麻面 · Sesame noodles · 30」。紅色番茄湯底、蘑菇配料和芝麻醬須分別與對應列匹配。不添加貨幣符號、過敏原、其他菜色或宣稱。這是虛構菜單文案；須原樣保留兩種語言。
```

## COM-08 — 室內織品比較

```text
使用一張獲授權的房間照片製作 16:9 雙格比較圖。左格重現原圖；右格僅將沙發蓋毯和兩個抱枕改為 [APPROVED COLORS]。窗戶、牆面、家具位置、拍攝角度和光線保持不變。在照片外的窄邊框中分別標註「原圖」和「織品搭配概念」。保留織物皺褶和接觸陰影；不修整房間、不移除私人物品，也不虛構額外裝飾。可調變數：來源影像和顏色。
```

## COM-09 — 補充包使用說明

```text
製作一張 3:4 包裝使用概念圖，包含縱向排列的三個畫面：空瓶旁放著補充袋、袋口向瓶中傾倒，以及蓋好的瓶子旁放著摺疊的空袋。三個畫面均使用同一只無品牌琥珀色瓶和象牙白補充袋，採用乾淨的技術插畫與鼠尾草綠色箭頭。僅呈現「打開」、「補充」和「蓋好」。嚴格保持三個步驟，不出現液體潑灑或相反的傾倒方向。不暗示容器適用於食品或化學品。可調變數：經核實的容器設計和經核准的說明標籤。
```

## COM-10 — 套組內容平鋪圖

```text
使用 [APPROVED CONTENTS LIST] 和獲授權的產品參考圖，製作正方形平鋪圖，展示入門文具套組中包含的物品，每種恰好一件。筆記本置中，小物件在周圍留出寬裕間隔；採用暖調紙張紋理和柔和頂光。僅添加標題「套組內含」，以及與物件對齊的所提供物品名稱。保持物品數量、相對尺寸和顏色不變。不添加清單中沒有的贈品、價格、保固標章或配件。
```
