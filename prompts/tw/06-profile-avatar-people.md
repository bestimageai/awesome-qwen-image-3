# 頭像、團隊與日常人像

十則 Qwen Image 3.0 提示詞範例。生成前請替換方括號中的輸入內容。所有引號內文字均須原樣呈現；除非明確要求，否則不作額外翻譯。輸出結果需要人工審核。

<a id="ava-01"></a>

## AVA-01 — 工坊創辦人人像

```text
使用獲授權的成年人人像，為小型家具工坊製作一張 3:4 創辦人照片。保留人物年齡、臉部比例和自然皮膚紋理。讓人物坐在未完成的木凳旁，雙手自然放置，背景工具輕微模糊。採用平視紀實攝影和大面積窗光。不添加豪華辦公室道具、虛構獎項、額外人物或文字。除非明確提供替換服裝，否則保持參考圖中的衣著。可調變數：人像、經核准的服裝和工坊場景。
```

<a id="ava-02"></a>

## AVA-02 — 圓形創作者頭像

```text
根據一張獲授權的成年人人像製作正方形頭像。臉部和上肩置於中央百分之七十區域，確保圓形裁切不會切掉頭髮或下巴。採用暖灰背景、柔和正面光和自然表情。保留身分、年齡、髮型和可見的臉部差異；僅移除雜亂背景。不添加文字、徽章、新配件，不過度磨皮或重塑體型。可調變數：參考人像和背景色相。以小尺寸個人頭像檢查最終效果。
```

<a id="ava-03"></a>

## AVA-03 — 三人團隊人像橫幅

```text
使用三張獲授權的成年人人像，製作 16:9 三人獨立頭肩照橫幅，三個畫面等寬，採用匹配的中性背景。保留每個人獨有的面容和髮型，不混合特徵。統一眼睛高度、視覺上的鏡頭距離和光線方向，同時保留自然差異。將提供的姓名放在對應人像下方，各出現一次。不編造職稱、不增加人物，也不進行美肌修飾。可調變數：三張參考圖和姓名與影像的對照表。本任務需要可同時接收三張參考圖的編輯流程。
```

<a id="ava-04"></a>

## AVA-04 — 工藝職人訪談人像

```text
製作一張 3:2 編輯人像，展示原創成年裝訂師在木桌上修復布面精裝書。雙手在操作情境中清楚可見，旁邊放一把小刷子和一張襯紙；工具排列須符合使用邏輯。採用側窗光、節制配色和中景，右側留白。不模仿具名人物，不添加可讀書中文字、資歷或歷史宣稱。手指須合理，膠水遠離臉部。可調變數：工藝、虛構人物和經核准的配色。
```

<a id="ava-05"></a>

## AVA-05 — 家庭烹飪時刻

```text
使用獲授權的家庭參考圖，製作 16:9 居家場景，展示同一群人在廚房桌邊整理蔬菜。保留身分、年齡差異、關係和服裝；表情自然，不強求看鏡頭。刀具和高溫設備放在兒童觸及不到的位置。採用柔和午後光和可信的生活化背景。不增加家庭成員、文字，不誇張改變體型，也不洩露真實地址。可調變數：獲授權參考圖和經核准場景；不推斷任務說明未提及的人物關係。
```

<a id="ava-06"></a>

## AVA-06 — 適應性運動人物特寫

```text
製作一張 3:4 編輯人像，展示原創成年輪椅網球選手在室外球場旁休息。真實呈現運動輪椅的車輪、車架和握持部位，球拍橫放在腿上。採用傍晚光線、平視構圖以及平靜自主的表情。不將人物表現得可憐，不添加勵志標語、獎牌、贊助商或醫療宣稱。解剖結構和裝備須合理。可調變數：虛構運動員外貌、服裝和球場配色。
```

<a id="ava-07"></a>

## AVA-07 — 雨天街頭人像

```text
使用獲授權的成年人參考圖，製作透明傘下的 3:4 街拍人像。保留臉部身分、服裝和身體比例。人物靠近素磚牆，地面潮濕並有柔和反射；採用陰天日光，不使用霓虹照明。傘骨、傘柄和握持手勢須協調。不增加人物、可見地址、店家標誌或文字，也不改變年齡。可調變數：人像、經核准的外衣和背景材質。
```

<a id="ava-08"></a>

## AVA-08 — 作者媒體照片

```text
根據獲授權的成年人參考圖製作正方形媒體資料人像。讓人物坐在一疊無字書旁，肩部略微轉向，臉部朝向鏡頭。採用柔和側光、整潔象牙白牆面和真實皮膚紋理。保留髮型、臉部特徵和表情。頭部周圍留出空間，方便其他裁切。不編造書名、獎項、簽名或文字，不添加美肌濾鏡效果。可調變數：人像、經核准的服裝和牆面顏色。
```

<a id="ava-09"></a>

## AVA-09 — 志工群像插畫

```text
使用 [APPROVED GROUP DESCRIPTION]，製作一張 16:9 插畫，恰好五位成年志工圍著長桌整理捐贈圖書。每人執行不同任務，保留提供的外貌細節，不作漫畫式醜化或誇張。採用暖調編輯式不透明水彩，手與物件的互動清楚。保持通道暢通、書堆穩定。不添加姓名、組織標誌、捐贈數字或受助者相關宣稱。可調變數：經核准的群體細節和場景；虛構人物不應像可辨識的真實個人。
```

<a id="ava-10"></a>

## AVA-10 — 人像布光研究

```text
使用一張獲授權的成年人人像製作 3:2 雙格布光研究圖。左格使用來自鏡頭左側的大面積窗光；右格使用同樣的光線，但透過窗簾柔化。鎖定身分、相機位置、表情、服裝、裁切和背景。僅在對應畫面下方寫「直接窗光」和「柔化窗光」。變化僅限陰影柔軟度和亮部過渡。不重塑臉部、不改變膚色，也不模擬其他年齡。可調變數：參考圖和翻譯後的標籤。
```
