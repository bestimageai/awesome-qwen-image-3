# 插畫與材料實驗

十則 Qwen Image 3.0 提示詞範例。生成前請替換方括號中的輸入內容。所有引號內文字均須原樣呈現；除非明確要求，否則不作額外翻譯。輸出結果需要人工審核。

<a id="ill-01"></a>

## ILL-01 — 層疊紙藝流域

```text
製作 3:4 教育紙藝概念，以層疊彩紙展示山丘、溪流和池塘。紙邊清楚可見，採用節制藍綠調和來自上方的柔和陰影。溪流須連續順坡流入池塘；上方四分之一留給提供的標題。僅呈現 [APPROVED TITLE AND LABELS]。不編造測量值或生態宣稱。可調變數：經核實的地形關係和準確文案；用於教學前審核科學準確性。
```

<a id="ill-02"></a>

## ILL-02 — 雙色街區地圖

```text
製作 4:3 虛構街區插畫地圖，麵包店、圖書館、花園和維修店圍繞一個廣場排列。象牙白紙上僅用鈷藍與暖橙油墨，帶輕微印刷對位紋理。清晰步道連接建築，僅呈現提供的四個地點標籤。不添加真實地址、標誌、距離宣稱，也不自行假設路線無障礙條件。可調變數：虛構配置和標籤。疊印保持一致，避免引入第三種印刷色。
```

<a id="ill-03"></a>

## ILL-03 — 不透明水彩植物圖版

```text
使用 [VERIFIED PLANT REFERENCE]，在暖象牙白紙上製作 3:4 不透明水彩習作，包含一根莖、兩片葉和一朵花。保留物種特有結構，筆觸可見但不遮蔽解剖特徵。底部放提供的植物名，不添加其他文字。未提供時不標比例。不編造藥用用途、不加裝飾性偽拉丁語，也不改變花瓣數。可調變數：參考圖、經核准名稱和配色。
```

<a id="ill-04"></a>

## ILL-04 — 社區服務插畫

```text
製作 16:9 等距插畫，虛構共享庭院連接圖書亭、工具棚、花園和座椅區。四區清楚分離，採用暖建築色；僅按 [APPROVED LAYOUT] 畫連續且看似無障礙的路徑。每個提供的區域名出現一次。不宣稱符合法規、參與人數或社會影響。樓梯、門和屋頂透視須一致。可調變數：配置和標籤；這是概念插畫。
```

<a id="ill-05"></a>

## ILL-05 — 刺繡圖示研究

```text
根據 [APPROVED MOTIF LIST] 製作正方形四乘四圖集，包含十六個刺繡圖示概念。採用統一奶油色布料、海軍藍與赭黃線、可見針腳方向，每格置中一個紋樣。輪廓簡潔，小尺寸也能理解。不添加文字、重複紋樣、複製標誌或不可能懸浮的針腳。可調變數：十六個紋樣和線色。這些是點陣手作概念，不是機繡檔案。
```

<a id="ill-06"></a>

## ILL-06 — 解決小難題的繪本跨頁

```text
製作 2:1 繪本跨頁，原創幼兔為蝸牛在花園淺水窪上鋪踏腳石路。採用柔和彩色鉛筆紋理、春日柔光和清楚的左至右敘事推進。裝訂中縫避開面孔與重要動作。左上區域留白供後續排字。不添加文字、額外角色或危險水域。可調變數：經核准角色和配色。
```

<a id="ill-07"></a>

## ILL-07 — 陶瓷浮雕海報

```text
製作 3:4 海報，以手工陶瓷浮雕的攝影形式呈現。三隻風格化鳥棲在彎曲枝條上，採用鈷藍釉、象牙白陶土和細微自然表面差異。頂部平帶留給「陶土與飛翔」，下方帶寫「工作室展覽」。每句僅一次，以清晰浮雕呈現，不是印在漂浮紙上。不加日期、贊助標記或虛構場館。可調變數：經核准文案和釉色。
```

<a id="ill-08"></a>

## ILL-08 — 抽象編輯隱喻

```text
製作關於整理注意力的正方形編輯插畫。一個打開的抽屜內整齊分隔彩色紙形，只有一條紅絲帶拖在外面。採用有觸感的拼貼、暖象牙白背景和柔和陰影。不用文字、人臉、公司標誌或醫療影像，表達秩序與打斷。抽屜幾何結構合理，避免過度雜亂。可調變數：經核准主題和配色；此隱喻是創意解讀，不是事實宣稱。
```

<a id="ill-09"></a>

## ILL-09 — 油氈版畫麵包插畫

```text
製作 3:4 原創油氈版畫風插畫，摺疊布上放一個圓麵包。採用粗黑刻痕、暖奶油色紙和麵包後單一陶土色點綴。割線紋樣和外皮體積清楚，以有方向的排線代替隨機刮痕。不加文字、麵包店標誌、簽名，也不複製藝術家構圖。可調變數：麵包形狀和點綴色。保持有限油墨印刷的視覺邏輯。
```

## ILL-10 — 毛氈微縮景觀

```text
製作 4:3 層疊毛氈微縮景觀：兩座圓丘、一個小藍池塘和三棵簡潔樹。採用可見纖維、縫邊和柔和棚拍光，尺度有趣但一致。嚴格三棵樹，不加其他物件。不添加文字、臉、品牌標記或塑膠質感表面。可調變數：配色和經核准景觀元素。這是材料風格插畫，不是實物產品照片。
```
