# 攝影與電影寫實風格

十則 Qwen Image 3.0 提示詞範例。生成前請替換方括號中的輸入內容。所有引號內文字均須原樣呈現；除非明確要求，否則不作額外翻譯。輸出結果需要人工審核。

<a id="pho-01"></a>

## PHO-01 — 清晨市場紀實

```text
製作 3:4 虛構紀實照片，成年花商在開門前整理無品牌花桶。採用平視中景、陰天晨光和節制自然色。雙手可信、地面潮濕，攤位保留小瑕疵。背景人物模糊，不出現可讀店招。不模仿名人、不擺拍廣告笑容，不使用戲劇性 HDR，也不編造事件宣稱。可調變數：虛構人物、鮮花和地點特色。
```

<a id="pho-02"></a>

## PHO-02 — 手機鏡頭下的早餐

```text
製作 3:4 隨手手機照片，展示吃了一半的早餐：廚房桌上的吐司、一小碟果醬和陶瓷杯。採用柔和窗光、中等景深和略不完美的取景。食物份量真實，麵包屑形態多樣，杯子反射合理。不添加文字、精品品牌、過度背景模糊或精修棚拍道具。可調變數：餐食、桌面和光線方向；影像應有日常感，而非商業型錄感。
```

<a id="pho-03"></a>

## PHO-03 — 可重複使用的產品布光

```text
使用獲授權的產品參考圖，在淺灰背景上製作正方形棚拍照片。鏡頭左側放大面積柔光，右側提供輕微白色補光；保留產品幾何結構、顏色、標籤和表面磨損。保持一處接地的接觸陰影和自然亮部衰減。不添加配件、文字、懸浮物體或過度銳化邊緣。可調變數：參考圖和經核准背景。生成相關產品圖時沿用此布光說明，但不保證輸出完全相同。
```

<a id="pho-04"></a>

## PHO-04 — 夜間公車候車亭畫面

```text
製作 16:9 虛構電影靜幀，小雨後的夜間空公車候車亭。暖色頂燈對比遠處冷色街道，反射適度，陰影深但可辨。長椅上放一份摺疊報紙，無可讀文字。透視、玻璃反射和光線衰減可信。不添加人物、路線編號、廣告或真實地點宣稱。可調變數：候車亭設計、天氣和色彩平衡。
```

<a id="pho-05"></a>

## PHO-05 — 四格接觸印樣條

```text
製作 16:9 接觸印樣條，四個等大攝影畫面展示同一原創成年陶藝師轉向窗戶。四個不同時刻依序為低頭、開始轉身、面向光線和輕輕微笑。鎖定身分、服裝、房間和曝光。採用細微底片顆粒和真實動作差異，不重複姿勢。不添加影格編號、底片品牌或文字。可調變數：虛構人物和工作室場景；這是編排的靜態圖集，不是影片截圖。
```

<a id="pho-06"></a>

## PHO-06 — 玻璃反射研究

```text
製作正方形靜物照片，深藍桌上一個透明平底杯，裝半杯水。採用大面積側光和淺色直向反光板，水面彎月面可見但細微，透過玻璃的折射可信。杯口保持橢圓、杯底接地、水面水平。不添加文字、冰塊、水果、其他杯子或不可能的內部反射。可調變數：杯形、注水量和背景色調。
```

<a id="pho-07"></a>

## PHO-07 — 食物蒸氣特寫

```text
製作 4:3 近距離照片，窗邊一只素陶碗裝著蔬菜湯。採用暖自然光，一縷細而不規則的蒸氣從湯面升起。蔬菜可辨，液體反射一致，碗緣乾淨。不添加文字、漂浮在湯中的餐具、過量煙霧、熱量標籤或健康宣稱。可調變數：經核准食譜、碗和光線方向。不要把蒸氣畫成裝飾性的實體飄帶。
```

<a id="pho-08"></a>

## PHO-08 — 安靜工坊廣角照

```text
製作 16:9 廣角室內照片，展示虛構維修工坊打烊時的場景。中央木工作檯、一盞亮著的檯燈、後牆整齊收納的工具。採用適度廣角透視、筆直垂線、暖實景燈光和冷環境補光。通道暢通，物件有物理支撐。不添加人物、可讀品牌、電影霧氣或不可能的房間幾何結構。可調變數：工坊類型和經核准的材質配色。
```

<a id="pho-09"></a>

## PHO-09 — 淺景深材質細節

```text
製作 3:2 微距照片，展示無品牌包上縫合帆布與磨損皮革之間的接縫。中央三針清晰對焦，細節朝邊緣逐漸柔化。採用大面積自然光、真實纖維和低飽和顏色。針距、針孔和材料厚度合理。不添加文字、品牌徽記、極端銳化或重複紋理印章。可調變數：獲授權的產品細節和材料顏色。
```

<a id="pho-10"></a>

## PHO-10 — 長曝光流水概念

```text
製作 16:9 虛構風景照片，小石人行橋跨過溪流。使用長曝光視覺處理柔化流動水體，同時保持橋、岩石和植物清晰。橋偏離中心，水流繞岩石的方向可信。採用陰天光和自然綠色調。不添加文字、人物、可辨識地標、過量薄霧或發光水體。可調變數：橋梁設計和季節；不宣稱真實相機曝光或地點。
```
