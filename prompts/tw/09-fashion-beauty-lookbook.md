# 時尚、美妝與紡織品概念

十則 Qwen Image 3.0 提示詞範例。生成前請替換方括號中的輸入內容。所有引號內文字均須原樣呈現；除非明確要求，否則不作額外翻譯。輸出結果需要人工審核。

<a id="fas-01"></a>

## FAS-01 — 四套膠囊衣櫥搭配

```text
使用一張獲授權的成年模特兒參考圖和 [APPROVED GARMENT LIST]，製作包含四個等大畫面的 16:9 穿搭型錄。在淺背景上以相同鏡頭距離展示提供的四套服裝組合。保留人物身分以及每件衣服的結構、顏色和合身程度。畫格僅標註「01」、「02」、「03」和「04」。採用柔和時尚編輯光線，不改變身體比例。不添加配件、標誌或永續性宣稱。可調變數：參考圖、服裝和搭配對照表。
```

<a id="fas-02"></a>

## FAS-02 — 工裝背心設計圖

```text
為原創石板藍工裝背心製作 4:3 服裝概念圖。展示正面、背面和一個口袋細節，縫線、拉鍊方向和布料紋理全部一致。採用清晰技術插畫，僅呈現「正面」、「背面」和「口袋」。口袋數量和輪廓保持一致；未提供時不加入尺寸。不複製知名品牌獨特設計，也不暗示已可量產。可調變數：經核准的草圖、布料和標籤。
```

<a id="fas-03"></a>

## FAS-03 — 陶瓷耳飾宣傳圖

```text
製作正方形珠寶照片，兩只原創鈷藍陶瓷耳環放在摺疊的象牙白亞麻布上。採用柔和側光，展現釉面亮部但不過曝；放一根小乾枝提供尺度與質感參照。兩只耳環結構匹配，同時保留自然手工修整感。不添加文字、寶石、貴金屬宣稱或品牌標記。保留連接五金，陰影合理。可調變數：獲授權產品參考、釉色和織物顏色。
```

<a id="fas-04"></a>

## FAS-04 — 妝容比較編輯

```text
使用一張獲授權的成年人人像製作 4:3 二乘二妝容比較圖。面容、膚色、頭髮、照明和表情完全相同。僅套用提供的四套妝容配色，變化限於嘴唇、眼皮和雙頰。使用 [APPROVED LOOK NAMES] 標註畫格。保留自然皮膚紋理和臉部差異。不重塑臉部、不改變年齡、不宣稱產品效果，也不添加配件。可調變數：人像、配色和標籤對照表。
```

<a id="fas-05"></a>

## FAS-05 — 產品使用順序卡

```text
根據 [MANUFACTURER-APPROVED ORDER AND COPY] 製作 3:4 產品使用卡。縱向排列提供的四個容器，數量恰好四個，用簡潔向下箭頭連接，每個容器配一個經核准的步驟標籤。採用乾淨棚拍、淺藍背景和寬裕間距。保留包裝文字和形狀；不編造成分、醫療效果、頻率或相容性。不展示肌膚前後比較圖。可調變數：產品參考和核實過的說明順序；發布前審核全部宣稱。
```

<a id="fas-06"></a>

## FAS-06 — 旅行配飾平鋪

```text
製作 3:4 俯視時尚平鋪圖，包含一個原創帆布托特包、一條摺疊花紋圍巾、素面太陽眼鏡和一本小筆記本。物件沿對角線排在沙色表面，不重疊遮擋重要輪廓。採用柔和自然陰影和節制海軍藍點綴。不添加精品品牌標誌、護照、票券或可讀個人資料。眼鏡須對稱，織物皺褶可信。可調變數：經核准的配飾、織物圖案和配色。
```

<a id="fas-07"></a>

## FAS-07 — 髮型視覺化

```text
使用一張獲授權的成年人人像製作 3:2 設定圖，展示提供的六種髮型。保留臉部、髮際線、年齡、膚色、相機角度和照明。僅根據 [APPROVED STYLE LIST] 改變頭髮長度、排列和質感；未要求時保留原髮色。畫格編號「1」至「6」。不修飾臉部、不改變妝容，也不讓頭髮不合理地從額頭長出。可調變數：來源人像和六種髮型說明。
```

<a id="fas-08"></a>

## FAS-08 — 織物組織比較

```text
製作 16:9 紡織品參考板，以三個等大微距畫面展示亞麻平紋、棉斜紋和針織羊毛。紋理和顏色參考 [AUTHORIZED MATERIAL REFERENCES]。放大倍率和中性照明一致，同時保留各結構獨特的紗線紋路。僅標註提供的材料名稱。不編造纖維成分、耐用性、產地或保養宣稱。可調變數：參考圖和準確標籤；材料辨識須由專家核實。
```

<a id="fas-09"></a>

## FAS-09 — 可見縫補貼片概念

```text
製作正方形服裝細節圖，展示原創牛仔膝部補丁，以醒目的赭黃色針腳修補。清楚展示接縫和針腳路徑，用小皺褶暗示布料彎曲方式。採用近距離編輯攝影、柔和日光和象牙白背景。不添加文字、品牌標籤或衣物強度宣稱。針腳須連續，最終畫面不留縫針。可調變數：獲授權服裝細節、補丁形狀和線色。
```

## FAS-10 — 鞋履配色研究

```text
使用一張獲授權的鞋款參考圖製作 16:9 三格配色研究圖。鞋底、縫線、鞋帶、材料和相機角度完全相同；僅套用 [THREE APPROVED COLOR PALETTES]。採用中性背景和匹配的棚拍光。鞋下方以提供的配色名稱標註各格。不改變鞋底紋路、不添加標誌，也不編造效能規格。可調變數：參考圖、三套配色和標籤。幾何一致性與顏色準確性須分別檢查。
```
