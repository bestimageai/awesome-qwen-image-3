# 字體排版、編輯設計與圖案

十則 Qwen Image 3.0 提示詞範例。生成前請替換方括號中的輸入內容。所有引號內文字均須原樣呈現；除非明確要求，否則不作額外翻譯。輸出結果需要人工審核。

<a id="typ-01"></a>

## TYP-01 — 雙層級文字海報

```text
製作 3:4 文字海報，準確標題為「有故事的物件」，副標題為「日常設計研究」。標題用大號深藍襯線字，分為均衡三行；下方以較小但可讀的無襯線文字帶放副標題。標題區域右下方背後添加一個簡潔陶土色圓形，不遮擋文字。採用暖紙紋理和寬裕邊距。不添加其他文字、扭曲基線或複製的品牌標記。可調變數：經核准的標題、副標題和配色。
```

<a id="typ-02"></a>

## TYP-02 — 多文字系統字樣

```text
製作 16:9 字體樣張，三個等寬欄分別準確包含「你好」、「Hello」和「こんにちは」。使用結構正確的中文、拉丁字母和日文，視覺權重相等，深色油墨與象牙白背景。每組字樣下方放一條細藍線，不加語言標籤或其他文字。保留提供的文字系統，不音譯或自動翻譯。間距充足，避免裝飾性假文字。可調變數：經核准的多語言字串和字體風格。
```

<a id="typ-03"></a>

## TYP-03 — 原創工坊字標

```text
為虛構陶瓷工作室「Soft Corner」製作正方形點陣字標概念。使用具有客製感的圓潤小寫字形、節制炭灰配色，唯一符號是一個小型錯位方塊。名稱易讀，準確拼寫且僅出現一次。象牙白底上只展示一個平面概念，不用牆面示意模型或多方案。不模仿已有品牌，不宣稱已通過商標審查。可調變數：虛構名稱和配色；設計師須重建並檢查最終向量標誌。
```

<a id="typ-04"></a>

## TYP-04 — 字母組合探索圖

```text
製作 3:2 概念圖，使用提供的字母「A」和「R」設計三個不同的原創字母組合。純背景上每個等大畫面放一個方案，黑色線寬一致，每個方案周圍留足空間。兩個字母均須可辨，不添加裝飾皇冠或複製時裝品牌圖案。不加文字或編號。這是點陣圖探索，不是註冊標誌或可編輯向量圖。可調變數：姓名縮寫字母和幾何風格。
```

<a id="typ-05"></a>

## TYP-05 — 雜誌開篇版面

```text
製作標題為「修補物件的層架」的 3:4 雜誌開篇版面。上半部放修復過的家居物件大照片，下方放標題，再下方以兩欄排提供的兩段短文。採用奶油色紙、炭灰襯線字和一條藍線。僅呈現 [APPROVED BODY COPY] 與標題；不加佔位文字、虛構作者或頁碼。文字可讀，物件真實。可調變數：準確文案和獲授權影像；須進行編輯校對。
```

<a id="typ-06"></a>

## TYP-06 — 社區報紙頭版

```text
製作標題為「庭院報」的 3:4 虛構報紙封面。採用清楚三欄網格、一張共享花園大照片和兩個小圖片位。標題和正文區域僅填入 [APPROVED SHORT COPY]。欄間距寬裕、層級一致，所有文字均可讀。不編造新聞、日期、引言、作者署名或官方印章。可調變數：經核准的文案、圖片，以及提供時的刊期日期。這是版式概念，不是真實事件報導。
```

<a id="typ-07"></a>

## TYP-07 — 重複圖案概念

```text
製作正方形圖案單元，象牙白底上是原創風格化梨子和葉片。僅用赭黃、鼠尾草綠和深藍，方向多樣，空白均衡。越過一側邊緣的紋樣須在對側連貫銜接；視覺間距均勻。不添加文字、標誌、漸層或可辨識品牌圖案。可調變數：紋樣、配色和密度。這是生成的候選重複單元；生產前須透過平鋪預覽檢查邊緣匹配。
```

<a id="typ-08"></a>

## TYP-08 — 響應式首屏背景

```text
製作 16:9 網站首屏背景，層疊淺藍紙形從右下沿對角線流動。左半部低對比且幾乎留空，供後續 HTML 文字使用。採用細微物理陰影和柔奶油色底，不添加文字、標誌或介面元件。中央正方形裁切須保留平靜焦點且不切掉重要形狀。可調變數：配色、方向和預期文字安全區。不將介面文案固定製作進圖片。
```

<a id="typ-09"></a>

## TYP-09 — 大字活動指示牌

```text
在白底上製作 3:4 活動方向指示牌。準確呈現「工坊在樓上」、「電梯在左側」和一個大號向上箭頭。採用特大海軍藍無襯線文字、明顯間距，不加裝飾影像。箭頭放在標題上方，第二行在下方，邊距清楚。不自行假設無障礙路線條件，不添加場館標誌；提供的方向須在真實地點核實。可調變數：經核准的方向文字和箭頭朝向。
```

<a id="typ-10"></a>

## TYP-10 — 書脊設計系統

```text
製作 16:9 編輯示意模型，展示五個等高直立書脊。採用統一奶油色與鈷藍設計，每個書脊使用一個提供的書名，系列名一致重複。保留書名與書的順序、可讀的直排方向和寬裕間距。未提供時不加作者、出版社標誌、ISBN、條碼或獎項。可調變數：五個書名和系列名。這是出版視覺概念，不是可直接印刷的檔案。
```
