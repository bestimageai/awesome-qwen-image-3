# Typography, editorial design, and patterns

Ten Qwen Image 3.0 prompt recipes. Replace bracketed inputs before generation. All quoted text is exact; no translation is implied unless explicitly requested. Outputs require human review.

<a id="typ-01"></a>

## TYP-01 — Two-level typography poster

```text
Create a 3:4 typography poster using the exact title "Objects with stories" and subtitle "A study in everyday design". Set the title in large dark-blue serif letters over three balanced lines; place the subtitle in a small but readable sans-serif band below. Add one simple terracotta circle behind the lower-right title area without obscuring letters. Use warm paper texture and generous margins. No extra words, warped baselines or copied brand marks. Variables: approved title, subtitle and palette.
```

<a id="typ-02"></a>

## TYP-02 — Multiscript specimen

```text
Create a 16:9 type specimen with three equal columns containing exactly "你好", "Hello", and "こんにちは". Use corresponding well-formed Chinese, Latin and Japanese characters with equal visual weight, dark ink and ivory background. Put a thin blue rule beneath each sample, with no language labels or extra text. Preserve supplied scripts without transliteration or automatic translation. Keep ample spacing and avoid decorative pseudo-characters. Variables: approved multilingual strings and type style.
```

## TYP-03 — Original workshop wordmark

```text
Create a square raster wordmark concept for fictional ceramics studio "Soft Corner". Use custom-looking rounded lowercase lettering, a restrained charcoal palette and one small offset square as the only symbol. Keep the name legible and spell it exactly once. Present one flat concept on ivory, not a mockup wall or multiple alternatives. Do not imitate an existing brand or claim trademark clearance. Variables: fictional name and palette; a designer must rebuild and check the final vector mark.
```

## TYP-04 — Monogram exploration sheet

```text
Create a 3:2 concept sheet with three distinct original monogram ideas using the supplied letters "A" and "R". Place one idea per equal panel on a plain background, with consistent black line weight and enough space around each. Keep both letters recognizable without decorative crowns or copied fashion-house motifs. Add no words or numbering. This is raster exploration, not a registered logo or editable vector. Variables: initials and geometric style.
```

## TYP-05 — Magazine opener

```text
Create a 3:4 magazine-opening layout titled "The repair shelf". Place a large photograph of repaired household objects in the upper half, the title beneath and two short supplied paragraphs in two columns below. Use cream paper, charcoal serif type and one blue rule. Render only [APPROVED BODY COPY] and the title; no lorem ipsum, invented author or page number. Keep text legible and objects realistic. Variables: exact copy and authorized imagery; editorial proofing is required.
```

## TYP-06 — Community newspaper front page

```text
Create a 3:4 fictional newspaper cover titled "The Courtyard Post". Use a clear three-column grid, one large photograph of a shared garden and two small image slots. Fill headlines and body areas only with [APPROVED SHORT COPY]. Keep gutters wide, hierarchy consistent and all words readable. Do not invent news, dates, quotations, bylines or official seals. Variables: approved copy, images and issue date if supplied. This is a layout concept, not a report of real events.
```

<a id="typ-07"></a>

## TYP-07 — Repeat-pattern concept

```text
Create a square pattern tile of original stylized pears and leaves on an ivory background. Use only ochre, sage and dark blue, with varied orientations and balanced empty space. Motifs crossing one edge must continue coherently at the opposite edge; keep spacing visually even. No text, logos, gradients or recognizable branded pattern. Variables: motif, palette and density. This is a generated repeat candidate; verify edge matching in a tiled preview before manufacturing.
```

<a id="typ-08"></a>

## TYP-08 — Responsive hero background

```text
Create a 16:9 website-hero background of layered pale-blue paper forms flowing diagonally from the lower right. Keep the left half low-contrast and nearly empty for later HTML text. Use subtle physical shadows and a soft cream ground, with no words, logos or UI components. Ensure a central square crop retains a calm focal point without cutting essential shapes. Variables: palette, direction and intended text-safe area. Do not bake interface copy into the image.
```

<a id="typ-09"></a>

## TYP-09 — Large-print event sign

```text
Create a 3:4 event-direction sign on white. Render exactly "Workshop upstairs", "Lift on the left", and one large upward arrow. Use very large navy sans-serif text, strong spacing and no decorative imagery. Place the arrow above the heading and the second line below, with clear margins. Do not add inaccessible-route assumptions or venue logos; the supplied direction must be verified for the real location. Variables: approved directions and arrow orientation.
```

<a id="typ-10"></a>

## TYP-10 — Book spine system

```text
Create a 16:9 editorial mockup showing five upright book spines of equal height. Use a coherent cream-and-cobalt design, with one supplied title on each spine and the supplied series name repeated consistently. Preserve title-to-book order, readable vertical orientation and generous spacing. Add no author, publisher logo, ISBN, barcode or award unless provided. Variables: five titles and series name. Keep this a visual publishing concept, not a print-ready file.
```
