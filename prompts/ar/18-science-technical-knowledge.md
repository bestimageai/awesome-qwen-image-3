# العلوم والمخططات التقنية والشروح

عشرة قوالب أوامر لـ Qwen Image 3.0. استبدل المدخلات بين الأقواس المربعة قبل التوليد. يجب إظهار النصوص بين علامتي الاقتباس كما هي تمامًا؛ ولا تُترجم إلا عند طلب ذلك صراحةً. تحتاج النتائج إلى مراجعة بشرية.

<a id="sci-01"></a>

## SCI-01 — مقطع ساق نبات

```text
أنشئ مقطعًا تعليميًا بنسبة 3:4 لـ [VERIFIED PLANT STEM STRUCTURE] باستخدام [APPROVED DIAGRAM REFERENCES]. مقطع عرضي رئيسي واحد وتفصيل نسيج مكبر واحد، وتسميات متصلة بالبنى الصحيحة. رسم علمي متحفظ وألوان متسقة وفراغ واضح. اعرض الأسماء والوحدات المقدمة فقط. لا تختلق تشريحًا أو مقياسًا أو وظائف أو جزيئات زخرفية. المتغيرات: حزمة المراجع والتسميات والمصدر؛ يجب أن يتحقق خبير موضوعي.
```

<a id="sci-02"></a>

## SCI-02 — مخطط عطل ميكانيكي

```text
أنشئ مخططًا توضيحيًا بنسبة 16:9 من [VERIFIED MECHANICAL DRAWING AND FAULT DESCRIPTION]. التجميع الطبيعي يسارًا والعطل الموثق يمينًا، مع إبراز الجزء المتأثر فقط. حافظ على ترتيب المكونات والاتصالات والهندسة. اعرض التسميات المقدمة وعنواني "طبيعي" و"العطل الموضح". بلا خطوات إصلاح أو عزم أو نصائح كهربائية أو ادعاءات سلامة إلا إن قُدمت. المتغيرات: الرسم ووصف العطل المراجع؛ تلزم مراجعة هندسية.
```

<a id="sci-03"></a>

## SCI-03 — مسار ذكاء اصطناعي بمراجعة بشرية

```text
أنشئ مخطط نظام بنسبة 16:9 بخمس عقد بالضبط: "المدخل" و"النموذج" و"المراجعة" و"المخرج المعتمد" و"التنقيح". صِل المدخل بالنموذج، والنموذج بالمراجعة، والمراجعة بالمخرج المعتمد وبالتنقيح، والتنقيح عائدًا إلى النموذج. تخطيط من اليسار إلى اليمين وصناديق كحلية ومسار اعتماد أزرق مخضر ومسار تنقيح كهرماني. الأسهم غير ملتبسة ولا خدمات أو مخازن إضافية. هذا مسار توضيحي لا عمارة نظام متحقق منها.
```

<a id="sci-04"></a>

## SCI-04 — مقارنة بيانات المناخ

```text
أنشئ مخططًا بنسبة 16:9 باستخدام [VERIFIED CLIMATE DATA AND UNCERTAINTY] فقط. أظهر السلسلة الزمنية المقدمة بمحاور معنونة ووحدات وخط أساس ومصدر. مثّل عدم اليقين بالشريط المحدد واحفظ فجوات القيم المفقودة. خلفية محايدة وسلسلة زرقاء متحفظة واحدة. لا تختلق توقعات أو تفسيرات سببية أو أرقامًا قياسية أو دقة. المتغيرات: البيانات وتعريف الفترة والعنوان المعتمد؛ تفسير البيانات والمخطط يحتاج خبيرًا.
```

<a id="sci-05"></a>

## SCI-05 — لوحة تسلسل مختبر

```text
أنشئ تسلسلًا مصورًا بنسبة 3:4 باستخدام [APPROVED NON-HAZARDOUS LAB PROCEDURE] فقط. أظهر الخطوات المقدمة بالضبط بترتيبها مع المعدات والتسميات والوحدات المطابقة. رسم تقني واضح وتحذيرات منفصلة عن تسميات الأفعال. لا تختلق كميات أو حرارة أو توقيتًا أو تدابير سلامة أو تجارب إضافية. المتغيرات: الإجراء المراجع والنص الدقيق. الناتج مساعد بصري لا بديل بروتوكول معتمد أو إشراف.
```

<a id="sci-06"></a>

## SCI-06 — نظرة عامة لصيانة جهاز

```text
أنشئ نظرة عامة بنسبة 16:9 من [MANUFACTURER-APPROVED USER MAINTENANCE GUIDE]. أظهر فقط الأجزاء المتاحة خارجيًا والقابلة لخدمة المستخدم وتسلسل الأفعال المقدم. رسوم معنونة بسيطة باتجاه ثابت. حافظ على التحذيرات وتعليمات حالة الطاقة حرفيًا؛ لا تختلق تفكيكًا أو أسلاكًا أو كيماويات أو نصائح إصلاح. المتغيرات: الدليل المتحقق منه ومرجع الجهاز. تلزم مراجعة خبير قبل التعليم ولا تضف اعتمادًا أو ضمانًا.
```

<a id="sci-07"></a>

## SCI-07 — ملخص أدلة بحثية

```text
أنشئ تخطيط ملخص بحث بنسبة 3:4 باستخدام [REVIEWED STUDY SUMMARY]. أقسام "السؤال" و"المنهج" و"النتيجة" و"القيود" بالنص المقدم الدقيق ومخطط معتمد واحد. أبقِ حجم العينة وعدم اليقين والمصدر ظاهرة. خط داكن مقروء ولمسات زرقاء متحفظة. لا تختلق دلالة أو سببية أو توصيات أو استشهادات. المتغيرات: الملخص المتحقق منه وبيانات المخطط. هذا تصور تواصل لا مراجعة أقران علمية.
```

<a id="sci-08"></a>

## SCI-08 — مخطط بنية متعدد المقاييس

```text
أنشئ مخططًا تعليميًا بنسبة 16:9 يربط [APPROVED LARGE-SCALE OBJECT] و[COMPONENT] و[DETAIL]. ثلاث لوحات منفصلة بتسميات المقياس المقدمة وصناديق تكبير متصلة. حافظ على علاقات الاحتواء الفعلية وخريطة ألوان متسقة. اعرض التسميات والوحدات والمصدر المراجعة فقط. بلا تكبير أو أبعاد مادية أو أسهم سببية مختلقة. المتغيرات: الصور المرجعية ومعلومات المقياس الدقيقة؛ تلزم مراجعة خبير.
```

<a id="sci-09"></a>

## SCI-09 — لوحة تعليم تحويل الوحدات

```text
أنشئ لوحة تعليم بنسبة 4:3 تعرض تمامًا "1 m = 100 cm" و"1 cm = 10 mm". ارسم شريط مرجع طويلًا مقسمًا لعشرة أجزاء كبيرة متساوية، وجزءًا مكبرًا منفصلًا مقسمًا لعشرة أصغر. سمّ الرسوم وفق [TEACHER-APPROVED SCALE MAP] فقط كي لا توحي المقاييس المرئية بتحويل خاطئ. خطوط سوداء ولمسة زرقاء واحدة. بلا معادلات إضافية أو تسميات تقريبية؛ مراجعة المعلم مطلوبة.
```

<a id="sci-10"></a>

## SCI-10 — مفتاح حالة الشبكة

```text
أنشئ بطاقة معلومات تقنية بنسبة 16:9 باستخدام [APPROVED NETWORK TOPOLOGY AND STATUS DATA]. حافظ على كل عقدة واتصال مقدم؛ أظهر الطبيعي والتحذير وعدم التوفر باللون والأشكال المختلفة معًا. أدرج المفتاح والطابع الزمني المقدمين بدقة. خطوط نظيفة ومسافات واسعة. لا تختلق عناوين IP أو بيانات اعتماد أو أعطالًا أو تعليمات استعادة أو تغطية مراقبة. المتغيرات: الطوبولوجيا المراجعة ولقطة الحالة. هذه صورة ثابتة لا لوحة مباشرة.
```
