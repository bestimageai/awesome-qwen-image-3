# أصول الألعاب والمعدات والتصورات الصناعية

عشرة قوالب أوامر لـ Qwen Image 3.0. استبدل المدخلات بين الأقواس المربعة قبل التوليد. يجب إظهار النصوص بين علامتي الاقتباس كما هي تمامًا؛ ولا تُترجم إلا عند طلب ذلك صراحةً. تحتاج النتائج إلى مراجعة بشرية.

<a id="pro-01"></a>

## PRO-01 — معدات مسّاح الغابات

```text
أنشئ ورقة معدات شخصية لعبة أصلية بنسبة 16:9 لمسّاح غابات بالغ. أظهر وضعية محايدة كاملة الجسم ومناظر منفصلة لحقيبة قماش ومسطرة قابلة للطي ودفتر مقاوم للطقس. استخدم رسمًا واقعيًا مبسطًا ودرجات خضراء هادئة وعلاقات مقياس متسقة. اجعل الملابس والأشرطة وتثبيت الأدوات معقولة ميكانيكيًا. بلا أسلحة أو رموز سلاسل معروفة أو نص. المتغيرات: وصف الشخصية الأصلي وقائمة المعدات المعتمدة؛ هذا فن تصوري، لا أصل جاهز للإنتاج.
```

<a id="pro-02"></a>

## PRO-02 — عدة دفيئة معيارية

```text
أنشئ لوحة تصور بيئة لعبة بنسبة 16:9 بست قطع دفيئة معيارية: جدار مستقيم وزاوية ومدخل ولوح سقف ولوح نافذة وبلاطة أرض. استخدم منظرًا شبه متعامد ونسب شبكة مشتركة وإطارات معدنية فاتحة وزجاجًا نصف شفاف. رتّب القطع بصفين وسمّها بالأسماء المقدمة فقط. اجعل نقاط الاتصال متوافقة وتجنب وصلات سقف مستحيلة. المتغيرات: أبعاد الوحدات المعتمدة والتسميات؛ يجب إعادة بناء الهندسة واختبارها في أداة ثلاثية الأبعاد.
```

<a id="pro-03"></a>

## PRO-03 — ورقة أيقونات مخزون

```text
أنشئ ورقة مربعة أربعة في أربعة لستة عشر تصور أيقونة مخزون مختلفًا من [APPROVED ITEM LIST]. استخدم زاوية متساوية القياس واحدة وضوءًا متسقًا من أعلى اليسار وخلفية محايدة مسطحة. وسّط غرضًا واحدًا في كل خلية متساوية بهوامش وافرة؛ تبقى الظلال الخارجية واضحة بالحجم الصغير. بلا نص أو أغراض مكررة أو قص أو معدات بعلامات مختلقة. المتغيرات: قائمة ستة عشر غرضًا الدقيقة والألوان. هذه ورقة تصور، لا أطلس رسوم شفافة متحقق منه.
```

<a id="pro-04"></a>

## PRO-04 — أربع معاينات مواد

```text
أنشئ لوحة بنسبة 16:9 لأربع دراسات مواد مربعة متساوية: خشب مطلي بالٍ وفولاذ مصقول بالفرشاة وحجر خشن وقماش منسوج. استخدم [AUTHORIZED REFERENCES] للحفاظ على هوية المادة وإحساس مقياس متسق. أظهر أسطحًا مسطحة بضوء محايد بلا ظلال درامية أو أجسام. سمّ كل مادة مرة خارج معاينتها. المتغيرات: المراجع والتسميات الدقيقة. لا تدّعِ أنها خامات سلسة أو خرائط فيزيائية أو أصول جاهزة لمحرك دون معالجة منفصلة.
```

<a id="pro-05"></a>

## PRO-05 — تصور مذياع محمول

```text
أنشئ ورقة تصميم صناعي بنسبة 3:2 لمذياع محمول أصلي بجسم مستطيل مستدير وقرص ضبط واحد ومقبض قابل للطي. أظهر الأمام والخلف وثلاثة أرباع بنسب ومواضع تحكم متسقة. استخدم بوليمرًا رماديًا دافئًا وشبكة سماعة زرقاء وضوء استوديو ناعمًا. أضف فقط "الأمام" و"الخلف" و"المنظور". بلا علامات تجارية أو قيم كهربائية أو أبعاد أو شهادات سلامة إلا إن قُدمت. المتغيرات: الرسم المعتمد والألوان؛ هذه ليست مواصفات هندسية.
```

<a id="pro-06"></a>

## PRO-06 — لوحة تدريب على التجميع

```text
أنشئ رسم تجميع بأربع خطوات بنسبة 16:9 من [VERIFIED MANUAL AND PART LIST]. أظهر الأجزاء المقدمة فقط وفعلًا واضحًا واحدًا لكل لوحة واتجاهًا متسقًا للجسم الرئيسي. استخدم رسمًا تقنيًا نظيفًا وخطوات مرقمة وأسهمًا تطابق التسلسل المعتمد. اعرض التحذيرات والتسميات المقدمة فقط. لا تختلق قيم عزم أو أدوات أو إجراءات سلامة أو خطوات مفقودة. المتغيرات: الدليل والأجزاء والنص الدقيق؛ يلزم تحقق خبير قبل الاستخدام التعليمي.
```

<a id="pro-07"></a>

## PRO-07 — منظر مفكك لحاوية إلكترونية

```text
باستخدام [APPROVED CAD VIEWS]، أنشئ رسمًا تفكيكيًا بنسبة 4:3 لحاوية إلكترونية صغيرة. افصل الغطاء والحشية واللوحة الداخلية والقاعدة على محور مشترك واحد، مع حفظ نقاط التثبيت وترتيب المكونات المقدم. استخدم تظليلًا تقنيًا محايدًا وتسميات من [APPROVED PART NAMES]. لا تختلق أسلاكًا أو أبعادًا أو توصيلات كهربائية. المتغيرات: المناظر المأذونة والتسميات. هذا شرح مصور، لا CAD متحقق منه ولا إجراء إصلاح.
```

<a id="pro-08"></a>

## PRO-08 — اتساق أداة الشخصية

```text
أنشئ ورقة بنسبة 16:9 تظهر فانوس مستكشف أصليًا واحدًا بثلاث حالات: محمولًا بالمقبض ومستقرًا على حجر ومعلقًا بخطاف. حافظ على الجسم السداسي والزجاج الكهرماني والمزلاج النحاسي وهندسة المقبض في كل لوحة. استخدم فن ألعاب واقعيًا مبسطًا وضوءًا متسقًا. بلا نص أو آليات إضافية أو زخارف سلسلة معروفة. المتغيرات: مرجع الأداة المعتمد والمكان؛ افحص قابلية الشبكة للتنفيذ منفصلًا.
```

<a id="pro-09"></a>

## PRO-09 — مجموعة صور حوار لعبة

```text
أنشئ ورقة بنسبة 3:2 بشبكة اثنين في ثلاثة تضم ست صور نصفية لشخصية أصلية بالغة لحارس منارة. حافظ على الخصل الرمادية والمعطف الأزرق وشكل الوجه وندبة الحاجب الصغيرة. أظهر الهدوء والفضول والشك والقلق والارتياح والبهجة. استخدم فن ألعاب مرسومًا نظيفًا بخلفيات محايدة مسطحة بلا نص. ثبّت مسافة الكاميرا وحجم الرأس. المتغيرات: مرجع الشخصية والألوان. هذه مجموعة تصورات، لا شخصية مجهزة للتحريك أو متحركة تلقائيًا.
```

<a id="pro-10"></a>

## PRO-10 — دراسة حامل قابل للطي

```text
أنشئ لوحة تصور صناعي بنسبة 16:9 لحامل جهاز لوحي أصلي قابل للطي في أوضاع مغلق ونصف مفتوح وعامل. استخدم إطار الألمنيوم ومحور المفصلة والأقدام المطاطية نفسها؛ أظهر مناظر جانبية واضحة على العاجي. اعرض فقط "مغلق" و"قيد الفتح" و"جاهز" تحت اللوحات. اجعل الحركة الميكانيكية معقولة ولا تختلق قدرة حمل أو توافقًا. المتغيرات: الرسم المعتمد وتشطيب المادة؛ تلزم مراجعة هندسية.
```
