# التاريخ والثقافة والتفسير القائم على الأدلة

عشرة قوالب أوامر لـ Qwen Image 3.0. استبدل المدخلات بين الأقواس المربعة قبل التوليد. يجب إظهار النصوص بين علامتي الاقتباس كما هي تمامًا؛ ولا تُترجم إلا عند طلب ذلك صراحةً. تحتاج النتائج إلى مراجعة بشرية.

<a id="cul-01"></a>

## CUL-01 — نشاط شارع تاريخي

```text
باستخدام [DATED PHOTOGRAPHS AND MAP]، أنشئ إعادة بناء بنسبة 16:9 للحياة اليومية في [STREET] عام [YEAR]. حافظ على حدود المباني وأنواع النقل وأسطح الشوارع الموثقة. أظهر الأنشطة العادية المدعومة بالأدلة فقط واجعل المناطق غير المؤكدة خافتة. استخدم رسمًا توثيقيًا لا ادعاء صورة أرشيفية. بلا نقوش مختلقة أو مشاهير أو أجسام حديثة. المتغيرات: المكان والتاريخ والأدلة وملاحظات عدم اليقين؛ تلزم مراجعة تاريخية.
```

<a id="cul-02"></a>

## CUL-02 — لوحة إعادة بناء قطعة أثرية

```text
أنشئ لوحة دراسة متحفية بثلاث لوحات بنسبة 16:9 من [AUTHORIZED ARTIFACT IMAGES]. أظهر القطعة الباقية وإعادة بناء متحفظة ومخطط المناطق غير المؤكدة. حافظ على الهندسة والتلف الموثقين. سمّها "الباقي" و"إعادة البناء" و"غير المؤكد"؛ عالجها بصريًا بصورة مختلفة كي لا يلتبس التخمين بالدليل. بلا صانع أو منشأ أو معنى شعائري مختلق. المتغيرات: حزمة المراجع والتفسير المعتمد؛ مراجعة الخبير مطلوبة.
```

<a id="cul-03"></a>

## CUL-03 — رسم سوق تاريخي

```text
أنشئ رسمًا تعليميًا بنسبة 3:2 لسوق في [VERIFIED REGION AND PERIOD] باستخدام [EVIDENCE PACK]. أدرج أنواع الأكشاك والملابس والبضائع والعمارة المقدمة فقط. رتّب معاملة واضحة أمامًا وخلفية أهدأ بضوء نهار طبيعي وتفاصيل متحفظة. بلا أسعار مقروءة أو أنظمة كتابة مختلقة أو صور نمطية أو أجسام من عصر آخر. المتغيرات: المنطقة والتاريخ والعناصر الموثقة. عرّف الناتج كرسم تفسيري لا صورة تاريخية أصلية.
```

<a id="cul-04"></a>

## CUL-04 — دراسة ملابس تاريخية

```text
استخدم [MUSEUM-VERIFIED GARMENT REFERENCES] لإنشاء ورقة ملابس بنسبة 16:9 بمناظر أمامية وجانبية وخلفية على هيئة محايدة. حافظ على الدرزات والمثبتات وطبقات القماش وأدلة اللون المقدمة. سمّ اسم اللباس والمنطقة والفترة المعتمدة فقط. لا تختلق مكانة أو إثنية أو معنى طقسيًا أو زينة غير موثقة. المتغيرات: المراجع والتسميات الدقيقة. ميّز الألوان غير المؤكدة بملاحظة مقدمة واطلب مراجعة متخصص.
```

<a id="cul-05"></a>

## CUL-05 — عملية حرفة تقليدية

```text
أنشئ رسمًا بأربع لوحات بنسبة 16:9 لـ [DOCUMENTED CRAFT PROCESS] باستخدام [PRACTITIONER-APPROVED STEPS]. أظهر الأدوات وأوضاع اليد وحالات المادة الصحيحة بالتسلسل. رسم طبيعي واضح وتسميات مقدمة فقط. لا تكشف معرفة مقيدة أو تختلق تفاصيل مقدسة أو تستبدل تقليدًا حيًا بزخارف عامة. المتغيرات: المراجع المعتمدة والخطوات ونسبة المصدر. تلزم مراجعة الممارس والأذونات السارية قبل النشر.
```

<a id="cul-06"></a>

## CUL-06 — لوحة تراث ثنائية اللغة

```text
أنشئ لوحة تفسير تراث بنسبة 3:4 باستخدام [APPROVED TWO-LANGUAGE COPY] وصورة موقع واحدة مأذونة. امنح اللغتين مكانة طباعية متساوية في كتل منفصلة واضحة المحاذاة. حافظ على الأسماء والتواريخ والعلامات واتجاه القراءة؛ الصورة فوق النص. بلا تاريخ أو ادعاءات سياحة أو شعار مؤسسي أو ترجمة مختلقة. المتغيرات: النص الثنائي النهائي والصورة والمصدر. هذا تصور تخطيط يحتاج مراجعة المجتمع والوقائع.
```

<a id="cul-07"></a>

## CUL-07 — تراكب خريطة تاريخية

```text
استخدم خريطة تاريخية مأذونة و[VERIFIED MODERN ALIGNMENT] لإنشاء رسم مقارنة بنسبة 16:9. احتفظ بالخريطة التاريخية أساسًا وأضف خطوط المرجع الحديثة المقدمة فقط بتراكب أزرق مميز. أدرج مفتاحًا يميز التاريخين وأي محاذاة غير مؤكدة. لا تختلق حدودًا أو ادعاءات ملكية أو طرقًا أو دقة جغرافية مكانية. المتغيرات: الخريطة والمحاذاة والتسميات الدقيقة؛ تلزم مراجعة تاريخية وجغرافية.
```

<a id="cul-08"></a>

## CUL-08 — الاستمرارية في إعادة البناء

```text
أنشئ إعادة بناء بأربع لوحات بنسبة 16:9 للفناء الموثق نفسه فجرًا وظهرًا وعصرًا وغسقًا في [VERIFIED PERIOD]. ثبّت العمارة والمواد والأثاث والكاميرا باستخدام [EVIDENCE PACK]. غيّر الضوء والأنشطة اليومية المقدمة فقط. تجنب الأجسام الحديثة والنقوش المختلقة والاحتفالات غير المدعومة. سمّ أوقات اليوم فقط. المتغيرات: المراجع وقائمة الأنشطة المعتمدة. هذا تسلسل تفسيري لا دليل على وقوع الأحداث المصورة.
```

<a id="cul-09"></a>

## CUL-09 — ملصق التعامل مع الأرشيف

```text
أنشئ تصور ملصق تدريب بنسبة 3:4 باستخدام [ARCHIVIST-APPROVED HANDLING RULES]. ثلاث لوحات واضحة بإجراءات المناولة المقدمة والأدوات المطابقة والتسميات القصيرة الدقيقة. رسم تقني محايد وتباين مرتفع وهوامش واسعة. لا تختلق متطلبات قفازات أو طرق تنظيف أو معالجة حفظ. المتغيرات: الإجراء المتحقق منه ونوع القطعة؛ راجع مع أمين أرشيف قبل الاستخدام. بلا أختام مؤسسات أو توقيعات أو ادعاءات حفظ غير مدعومة.
```

<a id="cul-10"></a>

## CUL-10 — لوحة اقتباس تاريخ شفهي

```text
أنشئ لوحة معرض بنسبة 4:3 باستخدام [CONSENTED VERIFIED QUOTATION] و[APPROVED ATTRIBUTION] وصورة سياقية مأذونة. أبرز الاقتباس مع نسبته تحته والصورة جانبًا. حافظ على الصياغة واللهجة والترقيم بدقة؛ لا تعِد كتابة الشهادة أو تختلق صورة المتحدث. طباعة تحريرية هادئة وخلفية كريمية. المتغيرات: النص المأذون ونسبته والصورة. أدرج السياق وبيان الإذن المقدمين فقط.
```
