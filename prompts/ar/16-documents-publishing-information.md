# المستندات والنشر وتصميم المعلومات

عشرة قوالب أوامر لـ Qwen Image 3.0. استبدل المدخلات بين الأقواس المربعة قبل التوليد. يجب إظهار النصوص بين علامتي الاقتباس كما هي تمامًا؛ ولا تُترجم إلا عند طلب ذلك صراحةً. تحتاج النتائج إلى مراجعة بشرية.

<a id="doc-01"></a>

## DOC-01 — موجز مشروع من صفحتين

```text
أنشئ عرضًا بنسبة 16:9 لصفحتين عموديتين لموجز مشروع جنبًا إلى جنب. استخدم [APPROVED COPY]، الأولى للغرض والسياق والثانية للنطاق والخطوات التالية. حافظ على هوامش وتسلسل عناوين متسقين وترقيم صفحات إن قُدم فقط. خط فحمي وخطوط زرقاء وورق أبيض. بلا نص حشو أو تواريخ مختلقة أو توقيعات أو أختام اعتماد. المتغيرات: النص الكامل وتوزيع الصفحات. هذا تصور نقطي؛ المستندات النهائية تحتاج تنضيدًا قابلًا للتحرير.
```

<a id="doc-02"></a>

## DOC-02 — نشرة عناية بالمنتج

```text
أنشئ نشرة عناية مصورة بنسبة 3:4 من [MANUFACTURER-APPROVED CARE INSTRUCTIONS]. رتّب الإجراءات الأربعة المقدمة في شبكة اثنين في اثنين، لكل منها رسم جسم بسيط مطابق وتسمية دقيقة. أبقِ التحذير في شريط سفلي منفصل. لا تختلق مواد تنظيف أو درجات حرارة أو نصائح تخلص أو شروط ضمان. استخدم خطًا عالي التباين ولوحة زرقاء متحفظة. المتغيرات: التعليمات المتحقق منها ومرجع المنتج؛ أكد كل خطوة قبل النشر.
```

<a id="doc-03"></a>

## DOC-03 — بطاقة تعريف قطعة متحفية

```text
أنشئ تصور بطاقة متحف بنسبة 4:3 باستخدام [VERIFIED OBJECT METADATA]. ضع صورة قطعة صغيرة مأذونة يسارًا والعنوان والصانع والتاريخ والمادة والوصف الدقيقة يمينًا. خلفية كريمية هادئة وخط داكن مقروء. احذف الحقل غير المقدم بدل تخمينه. بلا منشأ أو تقييم أو رقم اقتناء مختلق أو شعار مؤسسة. المتغيرات: الصورة والبيانات المعتمدة. هذه دراسة تخطيط لا دليل أصالة أو ملكية.
```

<a id="doc-04"></a>

## DOC-04 — صفحتان لتقرير سنوي

```text
أنشئ تخطيط تقرير سنوي بصفحتين بنسبة 16:9 باستخدام [APPROVED REPORT COPY AND DATA]. اليسرى عنوان واحد وسرد قصير؛ اليمنى مخطط واحد واضح التسميات وملاحظة مصدر. استخدم شبكة تحريرية متسقة ولمسات كحلية متحفظة. حافظ على الوحدات والفترات والتحفظات. بلا أرقام مالية أو بيانات تدقيق أو توقيعات أو تأييدات مختلقة. المتغيرات: النص والبيانات والمصدر المتحقق منها؛ التصور يحتاج مراجعة وقائعية وإنتاجية.
```

<a id="doc-05"></a>

## DOC-05 — بطاقة جدول مؤتمر

```text
أنشئ جدول حدث بنسبة 3:4 من [APPROVED SESSION TABLE]. استخدم خطًا زمنيًا عموديًا بأوقات البدء وعناوين الجلسات والغرف الدقيقة، مع تجميع المتزامنة بصريًا. عنوان الحدث أعلى والمنطقة الزمنية المقدمة تحته. نص داكن كبير على العاجي وفواصل زرقاء. لا تختلق متحدثين أو استراحات أو ترتيبات إتاحة أو تفاصيل مكان. المتغيرات: الجدول والنص الدقيق؛ تحقق من التسلسل الزمني وربط الغرف.
```

<a id="doc-06"></a>

## DOC-06 — بطاقة تذكير مراجعة

```text
أنشئ بطاقة تذكير كبيرة الخط بنسبة 3:4 باستخدام [CLINICIAN-APPROVED TEXT] فقط. نظّم المعلومات المقدمة بصفوف منفصلة واضحة وخط أسود عالي التباين وعنوان أزرق واحد. حافظ على الأسماء والكميات والوحدات والتوقيت والتحذيرات بدقة؛ لا تضف جرعة أو تشخيصًا أو نصيحة طبية. لا تولّد حبوبًا أو شعارات أو توقيعات أو أختامًا رسمية. المتغيرات: النص والعنوان المعتمدان. هذا تصور تنسيق بصري؛ يجب أن يتحقق مختص مؤهل قبل أي استعمال حقيقي.
```

<a id="doc-07"></a>

## DOC-07 — دليل عضوية المكتبة

```text
أنشئ نشرة معلومات بنسبة 3:4 لمكتبة مجتمع خيالية باستخدام [APPROVED MEMBERSHIP RULES]. ثلاثة أقسام "انضم" و"استعر" و"أعد"، بكل منها رسم بسيط ونص قصير مقدم. ورق كريمي وخط كحلي ومسافات واسعة. لا تختلق رسومًا أو متطلبات هوية أو ساعات عمل أو حدود استعارة. المتغيرات: القواعد المتحقق منها والعنوان المعتمد. أبعد البيانات الشخصية والرموز القابلة للمسح عن التصميم.
```

<a id="doc-08"></a>

## DOC-08 — تخطيط مقارنة مستندات

```text
أنشئ تخطيطًا متجاورًا بنسبة 16:9 لمقارنة نسختين مقدمتين لمستند عام قصير. حافظ على مقياس صفحات متطابق وأبرز [APPROVED CHANGED PASSAGES] فقط بأصفر باهت. سمّ اللوحتين "السابقة" و"المنقحة". حافظ على كل النص حرفيًا ولا تستنتج أهمية قانونية أو تضف تعليقًا أو تعدل الصياغة غير المتغيرة. المتغيرات: النصان الأصليان وخريطة تغيير صريحة. هذا تصور مقارنة بصرية لا مراجعة قانونية أو ملف تعقب تغييرات.
```

<a id="doc-09"></a>

## DOC-09 — ورقة تسليم المتطوعين

```text
أنشئ تصور ورقة تسليم بنسبة 3:4 باستخدام [APPROVED TASK LIST]. قسّم الصفحة إلى "مكتمل" و"قيد التنفيذ" و"الوردية التالية"، بمربع اختيار واحد لكل بند مقدم. اترك المربعات فارغة ما لم تُقدّم الحالة صراحة. نص كبير مقروء وشبكة بسيطة بلا صور زخرفية. لا تختلق أسماء أو مواعيد أو اتصالات أو إنجازًا. المتغيرات: قائمة المهام والحالات المقدمة؛ الاستخدام التشغيلي النهائي يحتاج نصًا قابلًا للتحرير.
```

<a id="doc-10"></a>

## DOC-10 — قائمة أسعار معرض

```text
أنشئ تخطيط قائمة أسعار معرض خيالي بنسبة 3:4 باستخدام [APPROVED ITEM TABLE]. حاذِ أسماء القطع وأحجامها وأسعارها في ثلاثة أعمدة واضحة بصف لكل قطعة. عناوين متحفظة ذات زوائد وأرقام بلا زوائد وخلفية بيضاء. حافظ على رموز العملات والفواصل العشرية والوحدات بدقة. لا تختلق خصومات أو معاملة ضريبية أو حالة بيع أو سير فنانين. المتغيرات: الجدول المتحقق منه والعنوان. هذا تصور تنضيد لا عرض أو سجل معاملة.
```
