# الحيوانات والكائنات والدراسات النباتية

عشرة قوالب أوامر لـ Qwen Image 3.0. استبدل المدخلات بين الأقواس المربعة قبل التوليد. يجب إظهار النصوص بين علامتي الاقتباس كما هي تمامًا؛ ولا تُترجم إلا عند طلب ذلك صراحةً. تحتاج النتائج إلى مراجعة بشرية.

<a id="nat-01"></a>

## NAT-01 — صورة حيوان أليف من مرجع

```text
استخدم صورة حيوان أليف مأذونًا بها لإنشاء صورة بنسبة 3:4 على خلفية رمادية دافئة سادة. حافظ على علامات الفراء ولون العينين وشكل الأذنين وحجم الجسم والتعبير الطبيعي. استخدم ضوء نافذة ناعمًا ووضعية جلوس مريحة تطابق التشريح. أبقِ الشوارب والكفوف وحواف الفراء مفصلة دون تنعيم زائد. بلا ملابس أو أيدٍ بشرية أو نص أو طوق مضاف إلا إن كان في المرجع. المتغيرات: مرجع الحيوان ولون الخلفية المعتمد.
```

<a id="nat-02"></a>

## NAT-02 — كائن مستنقع خيالي

```text
أنشئ ورقة تصور بنسبة 16:9 لكائن مستنقع صغير أصلي بنسب تشبه القضاعة وفراء بلون الطحلب وأقدام عريضة مكففة. أظهر الأمام والجانب وثلاثة أرباع على خلفية باهتة، بالتشريح والعلامات نفسها. استخدم رسم تاريخ طبيعي معقولًا بلا نص. لا تنسخ شخصية خيالية معروفة أو تضف قرونًا أو أطرافًا أو أجنحة غير متسقة. المتغيرات: وصف الكائن الأصلي وألوان الموطن؛ هذا خيال وليس نوعًا حقيقيًا.
```

<a id="nat-03"></a>

## NAT-03 — لوحة مراقبة ملقّح

```text
باستخدام [VERIFIED SPECIES REFERENCES]، أنشئ لوحة تعليمية بنسبة 4:3 تظهر ملقّحًا واحدًا بجانب زهرته المضيفة المعتمدة. أدرج تفصيلًا مكبرًا لبنية التغذية ذات الصلة، متصلًا بالموقع الصحيح بخط رفيع واحد. اعرض أسماء الأنواع والتسميات المقدمة فقط. استخدم رسم تاريخ طبيعي دقيقًا وخلفية بيضاء وبيان مقياس متسقًا إن قُدم فقط. بلا تشريح مختلق أو ادعاءات بيئية أو رموز علمية زخرفية. المتغيرات: المراجع والتسميات وملاحظة المصدر؛ تلزم مراجعة خبير.
```

<a id="nat-04"></a>

## NAT-04 — مشهد حياة برية في الغابة

```text
أنشئ مشهد غابة خياليًا بنسبة 16:9 بثعلب أحمر واحد يتوقف بجوار جذع بتولا ساقط عند الفجر. استخدم فراء واقعيًا وضبابًا محدودًا وضوءًا دافئًا منخفضًا بين الأشجار. أبقِ الكفوف ملامسة للأرض الوعرة والأذنين متيقظتين طبيعيًا. بلا تعبير بشري أو فريسة مصابة أو أجسام بشرية أو نص. تجنب تكرار أنماط الأشجار أو المبالغة بنسب الجسم. المتغيرات: النوع والفصل وتفاصيل الموطن المعتمدة؛ لا تصف المشهد كصورة حياة برية حقيقية.
```

<a id="nat-05"></a>

## NAT-05 — دراسة حركة حيوان

```text
باستخدام [VERIFIED ANATOMICAL REFERENCES]، أنشئ دراسة بنسبة 16:9 من أربع لوحات لقط منزلي يمشي من اليسار إلى اليمين. ثبّت علامات الفراء والمقياس وارتفاع الكاميرا والخلفية. أظهر أربع مراحل مشي مختلفة معتمدة بانتقال وزن معقول وكفوف مستندة. سمّ اللوحات من "1" إلى "4" فقط. لا تختلق أوضاع أطراف ولا تقدّم الورقة كإطارات جاهزة للتحريك دون اختبار إضافي. المتغيرات: المراجع وتسلسل المشي.
```

<a id="nat-06"></a>

## NAT-06 — ورقة تعريف أوراق النبات

```text
أنشئ ورقة تعليم نباتي بنسبة 3:4 باستخدام [VERIFIED LEAF REFERENCES]. رتّب ست أوراق في شبكة اثنين في ثلاثة، تحت كل منها اسمها الشائع المقدم. حافظ على شكل النصل والحواف والتعريق واتصال العنق؛ استخدم إضاءة محايدة واحدة وخلفية عاجية سادة. لا تختلق أسماء أنواع أو استعمالات طبية أو مقياسًا نسبيًا. أضف العنوان والتسميات المعتمدة فقط. المتغيرات: ستة مراجع وربط الأسماء؛ التعريف النباتي يحتاج مراجعة.
```

<a id="nat-07"></a>

## NAT-07 — مخطط دورة حياة نبات

```text
أنشئ رسم دورة حياة بنسبة 16:9 لـ [VERIFIED PLANT SPECIES] باستخدام [APPROVED STAGES]. ضع خمس مراحل بالضبط من اليسار إلى اليمين مع أسهم بسيطة، من البذرة إلى الشكل الناضج المقدم. استخدم تفاصيل ألوان مائية طبيعية وتسميات واضحة تحت كل مرحلة. حافظ على أوراق النوع وجذوره وثماره؛ لا تختلق مددًا أو نصائح نمو. المتغيرات: حزمة المراجع والمراحل والتسميات الدقيقة. اجعل المخطط تعليميًا واشترط مراجعة مختص.
```

<a id="nat-08"></a>

## NAT-08 — تصور موطن حوض أسماك

```text
أنشئ تصور موطن مياه عذبة خياليًا بنسبة 4:3 بحجارة مستديرة ونباتات مائية وثلاث سمكات صغيرة من نوع مقدم واحد. استخدم منظرًا جانبيًا واضحًا وضوءًا طبيعيًا تحت الماء ومقياسًا معقولًا. حافظ على تشريح الأسماك وتجنب الاكتظاظ أو الأنواع غير المتوافقة. بلا ادعاءات معدات أو نصائح كثافة الأسماك أو تسميات أو صناديق كنوز زخرفية. المتغيرات: مراجع النوع المتحقق منها ووصف الموطن؛ هذا الرسم ليس توصية لرعاية الحيوانات.
```

<a id="nat-09"></a>

## NAT-09 — رسم كيس بذور

```text
أنشئ تصور واجهة كيس بذور خيالي بنسبة 3:4 باستخدام [VERIFIED PLANT REFERENCE]. أظهر ساقًا مزهرة واحدة مع تفصيل بذرة صغير واترك الربع العلوي لـ [APPROVED PLANT NAME]. استخدم غواشًا نباتيًا أصليًا على ورق كريمي. اعرض الاسم المقدم و"دراسة مصورة" فقط. بلا نسبة إنبات أو منشأ أو اعتماد أو تعليمات زراعة أو وزن ما لم تُقدّم. حافظ على مورفولوجيا الزهرة والأوراق. المتغيرات: المرجع والاسم والألوان.
```

<a id="nat-10"></a>

## NAT-10 — بطاقة مراقبة طائر حضري

```text
أنشئ بطاقة مراقبة مربعة لـ [VERIFIED BIRD SPECIES]. أظهر منظرًا جانبيًا للطائر جاثمًا وتفصيل جناح أصغر على خلفية باهتة. استخدم رسم تاريخ طبيعي بمنقار وأقدام وريش دقيقة. اعرض فقط الاسم الشائع المعتمد وثلاث تسميات مراقبة مقدمة، متصلة بالميزات الصحيحة. لا تختلق الندرة أو مواعيد الهجرة أو حالة الحفظ. المتغيرات: حزمة المراجع والتسميات وملاحظة المصدر؛ التحقق البشري مطلوب.
```
