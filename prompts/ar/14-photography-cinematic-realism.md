# التصوير والواقعية السينمائية

عشرة قوالب أوامر لـ Qwen Image 3.0. استبدل المدخلات بين الأقواس المربعة قبل التوليد. يجب إظهار النصوص بين علامتي الاقتباس كما هي تمامًا؛ ولا تُترجم إلا عند طلب ذلك صراحةً. تحتاج النتائج إلى مراجعة بشرية.

<a id="pho-01"></a>

## PHO-01 — صباح السوق التحريري

```text
أنشئ صورة توثيقية خيالية بنسبة 3:4 لبائع زهور بالغ يرتب دلاء زهور بلا علامات قبل الافتتاح. استخدم لقطة متوسطة بمستوى العين وضوء صباح غائمًا وألوانًا طبيعية متحفظة. أظهر أيدي معقولة ورصيفًا رطبًا وعيوبًا صغيرة في البسطة. أبقِ أشخاص الخلفية غير واضحين واحذف لافتات المتاجر المقروءة. بلا شبه مشاهير أو ابتسامة إعلانية مصطنعة أو HDR درامي أو ادعاءات حدث مختلقة. المتغيرات: الشخص الخيالي والزهور وطابع الموقع.
```

<a id="pho-02"></a>

## PHO-02 — فطور بكاميرا هاتف

```text
أنشئ صورة عفوية بكاميرا هاتف بنسبة 3:4 لفطور نصف مأكول: خبز محمص وطبق مربى صغير وكوب خزفي على طاولة مطبخ. استخدم ضوء نافذة ناعمًا وعمق مجال متوسطًا وتأطيرًا غير مثالي قليلًا. اجعل الحصص واقعية والفتات متنوعًا وانعكاسات الكوب معقولة. بلا نص أو علامات فاخرة أو ضبابية خلفية مفرطة أو أدوات استوديو مصقولة. المتغيرات: الوجبة وسطح الطاولة واتجاه الضوء؛ ينبغي أن تبدو يومية لا كتالوجًا تجاريًا.
```

<a id="pho-03"></a>

## PHO-03 — إضاءة منتجات قابلة لإعادة الاستخدام

```text
استخدم مرجع منتج مأذونًا به لإنشاء صورة استوديو مربعة على رمادي باهت. ضع مصدرًا ناعمًا واسعًا يسار الكاميرا وملء أبيض خفيفًا يمينًا؛ حافظ على هندسة المنتج ولونه وملصقاته وتآكل سطحه. أبقِ ظل تماس واحدًا مستندًا وانتقال لمعات طبيعيًا. بلا ملحقات إضافية أو نص أو أجسام طافية أو حواف مفرطة الحدة. المتغيرات: المرجع والخلفية المعتمدة. حافظ على وصف الإضاءة هذا للصور المرتبطة؛ النتيجة المتطابقة غير مضمونة.
```

<a id="pho-04"></a>

## PHO-04 — لقطة موقف حافلات ليلي

```text
أنشئ لقطة سينمائية خيالية ثابتة بنسبة 16:9 لمظلة حافلات فارغة ليلًا بعد مطر خفيف. استخدم مصباحًا علويًا دافئًا مقابل شارع بعيد بارد، بانعكاسات معتدلة وظلال عميقة مقروءة. أظهر صحيفة مطوية واحدة على المقعد بلا نص مقروء. اجعل المنظور وانعكاسات الزجاج وتلاشي الضوء معقولة. بلا أشخاص أو أرقام خطوط أو إعلانات أو ادعاءات موقع حقيقي. المتغيرات: تصميم المظلة والطقس وتوازن اللون.
```

<a id="pho-05"></a>

## PHO-05 — شريط تلامس بأربع لقطات

```text
أنشئ شريط تلامس بنسبة 16:9 بأربع لقطات فوتوغرافية متساوية لخزّاف بالغ أصلي يلتفت نحو نافذة. أظهر لحظات مختلفة: ينظر لأسفل ويبدأ الالتفات ويواجه الضوء ويبتسم بلطف. ثبّت الهوية والملابس والغرفة والتعريض. استخدم حبيبات فيلم خفيفة وفروق حركة واقعية، لا وضعيات مكررة. بلا أرقام لقطات أو علامات فيلم أو نص. المتغيرات: الشخصية الخيالية والاستوديو؛ هذه ورقة صور مركبة، لا لقطات مستخرجة من فيديو.
```

<a id="pho-06"></a>

## PHO-06 — دراسة انعكاس الزجاج

```text
أنشئ صورة طبيعة صامتة مربعة لكأس شفاف واحد نصف ممتلئ بالماء على طاولة زرقاء داكنة. استخدم ضوءًا جانبيًا واسعًا وبطاقة انعكاس عمودية باهتة، مع تقعر سطح ماء ظاهر بلطف وانكسار معقول عبر الزجاج. أبقِ الحافة بيضوية والقاعدة مستندة والماء أفقيًا. بلا نص أو ثلج أو فاكهة أو كؤوس إضافية أو انعكاسات داخلية مستحيلة. المتغيرات: شكل الكأس ومستوى التعبئة ودرجة الخلفية.
```

<a id="pho-07"></a>

## PHO-07 — لقطة قريبة لبخار الطعام

```text
أنشئ صورة قريبة بنسبة 4:3 لوعاء خزفي سادة من حساء الخضار بجانب نافذة. استخدم ضوءًا طبيعيًا دافئًا وخيط بخار رفيعًا غير منتظم يصعد من السطح. أبقِ الخضار معروفة وانعكاسات السائل متسقة وحافة الوعاء نظيفة. بلا نص أو أدوات طافية في الحساء أو دخان مفرط أو ملصقات سعرات أو ادعاءات صحية. المتغيرات: الوصفة المعتمدة والوعاء واتجاه الضوء. لا تحوّل البخار إلى شريط زخرفي صلب.
```

<a id="pho-08"></a>

## PHO-08 — لقطة واسعة لورشة هادئة

```text
أنشئ صورة داخلية واسعة بنسبة 16:9 لورشة إصلاح خيالية عند الإغلاق. أظهر منضدة خشبية مركزية ومصباح مكتب واحدًا مضاءً وأدوات مخزنة بترتيب على الجدار الخلفي. استخدم منظورًا واسعًا معتدلًا بعموديات مستقيمة وضوء عمل دافئ وملء محيطي بارد. أبقِ الممرات واضحة والأجسام مسنودة ماديًا. بلا أشخاص أو علامات مقروءة أو ضباب سينمائي أو هندسة غرفة مستحيلة. المتغيرات: نوع الورشة ولوحة المواد المعتمدة.
```

<a id="pho-09"></a>

## PHO-09 — تفصيل مادة بتركيز ضحل

```text
أنشئ صورة ماكرو بنسبة 3:2 للدرز بين قماش مخيط وجلد بالٍ في حقيبة بلا علامة. ركّز بحدة على ثلاث غرز مركزية واترك التفاصيل تلين تدريجيًا نحو الحواف. استخدم ضوءًا طبيعيًا واسعًا وأليافًا واقعية وألوانًا هادئة. اجعل تباعد الغرز والثقوب وسماكة المواد معقولة. بلا نص أو شعارات أو حدة مفرطة أو أختام ملمس متكررة. المتغيرات: تفصيل المنتج المأذون وألوان المواد.
```

<a id="pho-10"></a>

## PHO-10 — تصور ماء بتعريض طويل

```text
أنشئ صورة منظر خيالية بنسبة 16:9 لجسر مشاة حجري صغير فوق جدول. استخدم معالجة تعريض طويل بصريًا تلين الماء المتحرك مع إبقاء الجسر والصخور والأوراق حادة. ضع الجسر خارج الوسط واحتفظ باتجاه ماء معقول حول الصخور. استخدم ضوءًا غائمًا وخضرة طبيعية. بلا نص أو أشخاص أو معلم معروف أو ضباب مفرط أو ماء متوهج. المتغيرات: تصميم الجسر والفصل؛ لا تدّعِ تعريض كاميرا فعليًا أو موقعًا حقيقيًا.
```
