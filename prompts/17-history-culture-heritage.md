# History, culture, and evidence-led interpretation

Ten Qwen Image 3.0 prompt recipes. Replace bracketed inputs before generation. All quoted text is exact; no translation is implied unless explicitly requested. Outputs require human review.

<a id="cul-01"></a>

## CUL-01 — Historic street activity

```text
Using [DATED PHOTOGRAPHS AND MAP], create a 16:9 reconstruction of daily life on [STREET] in [YEAR]. Preserve documented building outlines, transport types and street surfaces. Show only ordinary activities supported by the supplied evidence and keep uncertain areas visually subdued. Use documentary illustration, not a claim of archival photography. No invented inscriptions, famous people or modern objects. Variables: place, date, evidence and uncertainty notes; historical review is required.
```

<a id="cul-02"></a>

## CUL-02 — Artifact reconstruction board

```text
Create a 16:9 three-panel museum-study board from [AUTHORIZED ARTIFACT IMAGES]. Show the surviving object, a restrained reconstruction and a diagram marking uncertain areas. Preserve documented geometry and surface damage. Label panels "Surviving", "Reconstruction", and "Uncertain"; use different visual treatments so conjecture cannot be mistaken for evidence. No invented maker, provenance or ceremonial meaning. Variables: reference pack and approved interpretation; expert review is required.
```

<a id="cul-03"></a>

## CUL-03 — Historic market illustration

```text
Create a 3:2 educational illustration of a market in [VERIFIED REGION AND PERIOD] using [EVIDENCE PACK]. Include only supplied stall types, clothing, goods and architecture. Arrange a readable foreground transaction and a quieter background, with natural daylight and restrained detail. No readable prices, invented scripts, stereotypes or objects from another period. Variables: region, date and documented elements. Identify the output as interpretive illustration rather than an authentic historical image.
```

## CUL-04 — Historical clothing study

```text
Use [MUSEUM-VERIFIED GARMENT REFERENCES] to create a 16:9 clothing-study sheet with front, side and back views on a neutral figure. Preserve seams, fastenings, fabric layers and supplied color evidence. Label only the approved garment name, region and period. Do not invent status, ethnicity, ritual meaning or undocumented ornament. Variables: references and exact labels. Distinguish uncertain colors in a supplied note and obtain specialist review.
```

## CUL-05 — Traditional craft process

```text
Create a 16:9 four-panel illustration of [DOCUMENTED CRAFT PROCESS] using [PRACTITIONER-APPROVED STEPS]. Show correct tools, hand positions and material states in sequence. Use clear naturalistic illustration and supplied labels only. Do not reveal restricted knowledge, invent sacred details or replace a living tradition with generic motifs. Variables: approved references, steps and attribution. Practitioner review and applicable permissions are required before publication.
```

<a id="cul-06"></a>

## CUL-06 — Bilingual heritage panel

```text
Create a 3:4 heritage interpretation panel using [APPROVED TWO-LANGUAGE COPY] and one authorized site image. Give both languages equal typographic status in separate clearly aligned blocks. Preserve names, dates, diacritics and reading direction; place the image above the text. No invented history, tourism claims, institutional logo or translation. Variables: final bilingual copy, image and source credit. Keep the result a layout concept requiring community and factual review.
```

<a id="cul-07"></a>

## CUL-07 — Historic map overlay

```text
Use an authorized historical map and [VERIFIED MODERN ALIGNMENT] to create a 16:9 comparison illustration. Preserve the historical map as the base and add only supplied modern reference lines in a distinct blue overlay. Include a legend distinguishing the two dates and any uncertain alignment. Do not invent boundaries, ownership claims, routes or geospatial precision. Variables: map, alignment and exact labels; require historical and geographic review.
```

<a id="cul-08"></a>

## CUL-08 — Continuity across a reconstruction

```text
Create a 16:9 four-panel reconstruction of the same documented courtyard at dawn, midday, afternoon and dusk in [VERIFIED PERIOD]. Lock architecture, materials, furniture and camera position using [EVIDENCE PACK]. Change only light and supplied everyday activities. Avoid modern objects, invented inscriptions or unsupported ceremonial events. Label times of day only. Variables: references and approved activity list. This is an interpretive sequence, not evidence that the depicted events occurred.
```

<a id="cul-09"></a>

## CUL-09 — Archive handling poster

```text
Create a 3:4 training-poster concept using [ARCHIVIST-APPROVED HANDLING RULES]. Show three clear panels with the supplied handling actions, matching tools and exact short labels. Use neutral technical illustration, high contrast and generous margins. Do not invent glove requirements, cleaning methods or conservation treatments. Variables: verified procedure and object type; review the poster with an archivist before use. No institutional seals, signatures or unsupported preservation claims.
```

<a id="cul-10"></a>

## CUL-10 — Oral-history quotation panel

```text
Create a 4:3 exhibition panel using [CONSENTED VERIFIED QUOTATION], [APPROVED ATTRIBUTION] and an authorized contextual image. Place the quote prominently with attribution below and image to the side. Preserve wording, dialect and punctuation exactly; do not rewrite testimony or invent a speaker portrait. Use quiet editorial typography and a cream background. Variables: consented text, attribution and image. Include only the supplied context and permissions credit.
```
