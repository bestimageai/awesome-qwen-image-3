# Science, technical diagrams, and explainers

Ten Qwen Image 3.0 prompt recipes. Replace bracketed inputs before generation. All quoted text is exact; no translation is implied unless explicitly requested. Outputs require human review.

<a id="sci-01"></a>

## SCI-01 — Plant stem cutaway

```text
Create a 3:4 educational cutaway of [VERIFIED PLANT STEM STRUCTURE] using [APPROVED DIAGRAM REFERENCES]. Show one main cross-section and one enlarged tissue inset, with labels connected to the correct structures. Use restrained scientific illustration, consistent colors and clear white space. Render only supplied names and units. Do not invent anatomy, scale, functions or decorative molecules. Variables: reference pack, labels and source note; a subject expert must verify the result.
```

## SCI-02 — Mechanical fault diagram

```text
Create a 16:9 explanatory diagram from [VERIFIED MECHANICAL DRAWING AND FAULT DESCRIPTION]. Show the normal assembly at left and the documented fault at right, highlighting only the affected part. Preserve component order, connections and geometry. Render supplied labels and the headings "Normal" and "Fault shown". No repair steps, torque values, electrical advice or safety claims unless provided. Variables: drawing and reviewed fault description; engineering review is required.
```

## SCI-03 — Human-reviewed AI workflow

```text
Create a 16:9 system diagram with exactly five nodes: "Input", "Model", "Review", "Approved output", and "Revision". Connect Input to Model, Model to Review, Review to Approved output, and Review to Revision; connect Revision back to Model. Use a left-to-right layout, navy boxes, teal approval path and amber revision path. Keep arrows unambiguous and include no extra services or data stores. This is an illustrative workflow, not a verified system architecture.
```

## SCI-04 — Climate data comparison

```text
Create a 16:9 chart using only [VERIFIED CLIMATE DATA AND UNCERTAINTY]. Show the supplied time series with labeled axes, units, baseline and source note. Render uncertainty as the specified band and preserve gaps for missing values. Use a neutral background and one restrained blue series. Do not invent projections, causal explanations, records or precision. Variables: dataset, interval definition and approved title; data and chart interpretation require expert review.
```

## SCI-05 — Laboratory sequence board

```text
Create a 3:4 illustrated sequence using only [APPROVED NON-HAZARDOUS LAB PROCEDURE]. Show exactly the supplied steps in order, with matching equipment, labels and units. Use clear technical illustration and separate warnings from action labels. Do not invent quantities, temperatures, timings, safety measures or additional experiments. Variables: reviewed procedure and exact copy. The output is a visual aid, not a substitute for an approved protocol or supervision.
```

## SCI-06 — Appliance maintenance overview

```text
Create a 16:9 overview from [MANUFACTURER-APPROVED USER MAINTENANCE GUIDE]. Show only externally accessible, user-serviceable parts and the supplied sequence of actions. Use simple labeled illustrations with consistent orientation. Preserve warnings and power-state instructions exactly; do not invent disassembly, wiring, chemicals or repair advice. Variables: verified guide and appliance reference. Require expert review before instructional use and add no certification or guarantee.
```

## SCI-07 — Research evidence summary

```text
Create a 3:4 research-summary layout using [REVIEWED STUDY SUMMARY]. Divide it into "Question", "Method", "Finding", and "Limitations", with exact supplied copy and one approved chart. Keep sample size, uncertainty and source visible. Use readable dark type and restrained blue accents. Do not invent significance, causality, recommendations or citations. Variables: verified summary and chart data. This is a communication concept, not a scientific peer review.
```

Create a 16:9 educational diagram linking [APPROVED LARGE-SCALE OBJECT], [COMPONENT] and [DETAIL]. Use three clearly separated panels with supplied scale labels and connecting zoom boxes. ## SCI-09 — Unit conversion teaching board

```text
Create a 4:3 teaching board showing exactly "1 m = 100 cm" and "1 cm = 10 mm". Draw one long reference bar divided into ten equal large segments, with a separate enlarged segment divided into ten smaller parts. Label the diagrams only as specified by [TEACHER-APPROVED SCALE MAP] so visual scales do not imply an incorrect conversion. Use black lines and one blue accent. No additional equations or approximate labels; teacher review is required.
```

## SCI-10 — Network status legend

```text
Create a 16:9 technical information card using [APPROVED NETWORK TOPOLOGY AND STATUS DATA]. Preserve every supplied node and connection; show normal, warning and unavailable states with both color and distinct shapes. Include the exact legend and timestamp supplied. Use clean lines and generous spacing. Do not invent IP addresses, credentials, failures, recovery instructions or monitoring coverage. Variables: reviewed topology and status snapshot. This is a static illustration, not a live dashboard.
```
