# 캐릭터, 인물 사진, 스토리보드

Qwen Image 3.0 프롬프트 10개입니다. 생성 전에 대괄호 안의 입력값을 바꾸세요. 따옴표 안의 문구는 정확히 재현하며, 명시적인 요청이 없으면 추가로 번역하지 않습니다. 결과물은 사람이 검토해야 합니다.

<a id="art-01"></a>

## ART-01 — 미라의 책 반납 이야기

```text
짧은 검은 곱슬머리, 둥근 안경, 녹슨 적갈색 카디건, 파란 자전거 바구니를 가진 창작 성인 이동 도서관 사서 미라의 16:9 네 칸 이야기 시트를 만든다. 왼쪽에서 오른쪽으로 벤치에서 책을 발견하고, 무지 표지를 살펴보고, 바구니에 넣고, 작은 도서관 입구로 배달하는 모습을 보여 준다. 따뜻한 과슈 일러스트와 부드러운 아침 빛을 사용한다. 얼굴, 옷, 자전거, 노란 책을 끝까지 동일하게 유지한다. 같은 크기의 정확히 네 칸으로 하고 설명문, 말풍선, 읽을 수 있는 책 제목은 넣지 않는다. 정지 스토리보드이며 동영상이 아니다.
```

<a id="art-02"></a>

## ART-02 — 자연스러운 인물 편집

```text
사용 허가를 받은 성인 인물 사진을 정체성 참조로 사용한다. 눈높이의 3:4 업무용 인물 사진을 만들고 배경만 부드러운 빛의 연파랑 스튜디오로, 옷만 무지 차콜 재킷으로 바꾼다. 나이, 얼굴 비율, 머리 모양, 피부 질감, 표정을 유지한다. 새 배경의 빛을 얼굴에 맞추고 어깨는 해부학적으로 자연스럽게 유지한다. 문구, 장신구, 미용 보정, 체형 변경은 하지 않는다. 변수: 배경색과 승인된 의상. 허가받지 않은 사람의 외모를 사용하지 않는다.
```

<a id="art-03"></a>

## ART-03 — 가상의 역무원

```text
작은 해안 철도 사무실에 있는 창작 성인 역무원의 정사각형 인물 사진을 만든다. 은색 짧은 머리, 세월의 흔적이 있는 남색 재킷, 주의 깊은 표정을 설정하고 뒤에 흐릿한 벽시계를 둔다. 자연스러운 필름 느낌의 사진, 흐린 날의 창빛, 보이는 피부 질감을 사용한다. 얼굴을 중앙에 놓고 머리 주위에 공간을 남긴다. 실명 인물을 닮게 하지 말고 공식 제복 휘장, 읽을 수 있는 표, 신분증을 넣지 않는다. 변수: 연령대, 색상 구성, 가상의 직업.
```

<a id="art-04"></a>

## ART-04 — 배달원의 사계절 설정 시트

```text
긴 땋은 머리, 녹색 숄더백, 빨간 자전거를 가진 동일한 창작 성인 택배 배달원의 16:9 네 칸 캐릭터 시트를 만든다. 봄 이슬비, 여름 그늘, 가을바람, 겨울 서리를 같은 크기의 칸에 보여 준다. 계절별 겉옷과 날씨만 바꾸고 얼굴 특징, 신체 비율, 자전거 형상은 고정한다. 명확한 편집 일러스트, 같은 카메라 높이, 중립적인 자세를 사용한다. 각 칸 아래에는 “봄”, “여름”, “가을”, “겨울”만 표시한다. 브랜드 로고나 가상의 안전 인증은 넣지 않는다. 변수: 캐릭터 디자인과 계절별 색상 구성.
```

<a id="art-05"></a>

## ART-05 — 수달 그림책 펼침면

```text
작은 수달이 거북이를 도와 갈대에서 종이배를 되찾는 2:1 그림책 펼침면을 만든다. 수달은 왼쪽, 거북이는 오른쪽, 배는 아래쪽 중앙 근처에 두되 제본 가운데 홈에서 떨어뜨린다. 수채화 번짐, 따뜻한 오후 빛, 읽기 쉬운 표정을 사용한다. 왼쪽 위 하늘은 나중에 조판하도록 비워 둔다. 생성 문구, 위험한 물가 장면, 추가 캐릭터를 넣지 않는다. 동물 크기 비율과 배 모양을 일치시킨다. 변수: 배경, 색상 구성, 승인된 캐릭터 참조.
```

<a id="art-06"></a>

## ART-06 — 대사 없는 우산 만화

```text
세로 2:3 비율에 두 열 세 행으로 같은 크기의 여섯 칸 만화를 만든다. 창작 성인이 작은 우산을 펴고, 젖은 개를 발견하고, 함께 쓰고, 둘 다 물웅덩이 물을 뒤집어쓰고, 넓은 가게 차양을 발견한 뒤, 그 아래에서 비를 피하며 앉는 순서다. 명확한 잉크와 담채 일러스트, 일관된 옷, 갈색 개 한 마리를 유지한다. 왼쪽에서 오른쪽, 위에서 아래로 읽고 행동에 인과관계가 이어지게 한다. 대사, 표지판, 추가 칸, 부상은 넣지 않는다. 변수: 인물 외모와 우산 색상.
```

<a id="art-07"></a>

## ART-07 — 차 광고 스토리보드

```text
가상의 20초 차 광고를 위한 16:9 여섯 칸 정지 스토리보드를 만든다. 닫힌 차 통, 손으로 열기, 찻잎이 컵에 들어가기, 뜨거운 물 붓기, 창가의 김, 통 옆의 컵을 순서대로 보여 준다. 같은 크림색 통 하나, 파란 컵 하나, 일관된 아침 빛을 사용한다. 마지막 칸에만 “고요한 한순간”을 표시한다. 각 칸은 서로 다른 쇼트로 하고 소품은 모두 일정하게 유지한다. 건강 효능, 우리는 온도, 브랜드 주장은 넣지 않는다. 변수: 소품 디자인과 승인된 마지막 문구. 콘셉트이며 생성 영상이 아니다.
```

<a id="art-08"></a>

## ART-08 — 역사적 거리 복원

```text
[DATED EVIDENCE PACK]을 사용해 [YEAR]년 [PLACE]의 일상 활동을 담은 16:9 일러스트를 만든다. 기록으로 확인된 거리 배치, 건축 재료, 의상을 유지하고 불확실한 배경은 세부 표현을 낮춘다. 제공된 대응 관계에 따라 “기록 기반”, “해석적 복원” 요소를 구별하는 좁은 범례를 넣는다. 비문, 유명인 얼굴, 기념물, 현대 물건을 지어내지 않는다. 실제 사진처럼 제시하지 말고 절제된 기록적 일러스트를 사용한다. 변수: 장소, 연도, 근거 자료, 불확실성 대응도. 역사 분야 검토를 받아야 한다.
```

## ART-09 — 표정 참조 시트

```text
[APPROVED CHARACTER REFERENCE]를 사용해 동일한 창작 성인 캐릭터의 머리와 어깨 뷰 여섯 개를 담은 3:2 시트를 만든다. 2×3 격자에 평온함, 호기심, 안도, 당혹감, 결의, 즐거움의 표정을 보여 준다. 두개골 형태, 머리, 나이, 옷, 카메라 거리를 유지하고 눈썹, 입, 미세한 고개 기울기만 바꾼다. 부드러운 스튜디오풍 일러스트와 균일한 옅은 배경을 사용한다. 각 표정을 정확히 한 번씩 표시한다. 해부학적 과장, 인물 정체성 변화, 추가 장신구는 넣지 않는다. 변수: 참조, 색상 구성, 번역된 라벨.
```

## ART-10 — 사물 연속성 스토리보드

```text
빨간 도자기 그릇이 선반에서 탁자로 옮겨지고, 오렌지 세 개를 담고, 창가로 운반되는 16:9 네 칸 스토리보드를 만든다. 모든 칸에서 테두리의 깨진 자국 하나가 보이는 같은 그릇을 사용한다. 오렌지는 등장한 뒤 정확히 세 개를 유지하고, 방의 형상과 따뜻한 측면광을 일치시킨다. 명확하고 사실적인 일러스트, 중간 거리에서 근접으로 진행하는 구도를 사용하며 문구는 넣지 않는다. 깨진 위치를 옮기거나 과일을 복제하거나 그릇 모양을 바꾸지 않는다. 변수: 물체 참조와 승인된 실내 배치.
```
