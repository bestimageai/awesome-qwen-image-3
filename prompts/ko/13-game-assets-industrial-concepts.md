# 게임 소재, 장비, 산업 콘셉트

Qwen Image 3.0 프롬프트 10개입니다. 생성 전에 대괄호 안의 입력값을 바꾸세요. 따옴표 안의 문구는 정확히 재현하며, 명시적인 요청이 없으면 추가로 번역하지 않습니다. 결과물은 사람이 검토해야 합니다.

<a id="pro-01"></a>

## PRO-01 — 산림 측량사 장비

```text
성인 산림 측량사를 위한 16:9 창작 게임 캐릭터 장비 시트를 만든다. 중립 전신 자세 하나와 캔버스 숄더백, 접이식 자, 비바람에 견디는 노트의 별도 뷰를 보여 준다. 양식화된 사실적 일러스트, 차분한 녹색, 일관된 크기 관계를 사용한다. 의상, 끈, 공구 부착은 기계적으로 타당해야 한다. 무기, 식별 가능한 프랜차이즈 기호, 문구는 넣지 않는다. 변수: 창작 캐릭터 설명과 승인된 장비 목록. 콘셉트 아트이며 제작용 완성 소재가 아니다.
```

<a id="pro-02"></a>

## PRO-02 — 모듈식 온실 키트

```text
직선 벽, 모서리, 출입구, 지붕 패널, 창 패널, 바닥 타일이라는 모듈식 온실 부품 여섯 개로 16:9 게임 환경 보드를 만든다. 정투영에 가까운 뷰, 공통 격자 비율, 옅은 금속 프레임, 반투명 유리를 사용한다. 두 줄에 배치하고 제공된 이름만 표시한다. 연결 지점이 호환되게 하고 불가능한 지붕 접합을 피한다. 변수: 승인된 모듈 치수와 라벨. 형상은 3D 도구에서 다시 만들고 시험해야 한다.
```

<a id="pro-03"></a>

## PRO-03 — 인벤토리 아이콘 시트

```text
[APPROVED ITEM LIST]에서 서로 다른 인벤토리 아이콘 열여섯 개의 정사각형 4×4 시트를 만든다. 같은 등각 각도, 왼쪽 위의 일관된 빛, 평평한 중성 배경을 사용한다. 같은 크기 셀마다 물건 하나를 중앙에 놓고 안쪽 여백을 충분히 두어 작은 크기에서도 실루엣이 읽히게 한다. 문구, 중복 물건, 잘림, 가상의 브랜드 장비는 넣지 않는다. 변수: 정확한 열여섯 항목 목록과 색상 구성. 콘셉트 시트이며 검증된 투명 스프라이트 아틀라스가 아니다.
```

<a id="pro-04"></a>

## PRO-04 — 네 재질 미리보기

```text
닳은 페인트 목재, 브러시드 강철, 거친 돌, 직조 캔버스의 같은 크기 정사각형 네 개를 담은 16:9 재질 보드를 만든다. [AUTHORIZED REFERENCES]로 재료 특성과 일정한 척도 느낌을 유지한다. 중성 빛의 평면 표면 뷰를 보여 주고 극적인 그림자나 물체는 넣지 않는다. 각 재료명은 미리보기 바깥에 한 번 표시한다. 변수: 참조와 정확한 라벨. 별도 처리 없이 무봉제 텍스처, 물리 기반 맵, 엔진용 완성 소재라고 주장하지 않는다.
```

<a id="pro-05"></a>

## PRO-05 — 휴대용 라디오 콘셉트

```text
둥근 직사각형 몸체, 조율 다이얼 하나, 접이식 손잡이를 가진 창작 휴대용 라디오의 3:2 산업 디자인 시트를 만든다. 정면, 후면, 사선 뷰의 비율과 조작부 위치를 맞춘다. 따뜻한 회색 고분자 소재, 파란 스피커 그릴, 부드러운 스튜디오 빛을 사용한다. “앞면”, “뒷면”, “투시”만 넣는다. 제공되지 않은 브랜드 표시, 전기 정격, 치수, 안전 인증은 넣지 않는다. 변수: 승인된 스케치와 색상 구성. 엔지니어링 사양이 아니다.
```

<a id="pro-06"></a>

## PRO-06 — 조립 교육 보드

```text
[VERIFIED MANUAL AND PART LIST]로 16:9 네 단계 조립 일러스트를 만든다. 제공된 부품만 보여 주고 각 패널은 명확한 행동 하나이며 주요 물체 방향은 일정하게 한다. 깔끔한 기술 도면, 단계 번호, 승인된 순서와 맞는 화살표를 사용한다. 제공된 경고와 라벨만 표시한다. 토크 값, 공구, 안전 절차, 빠진 단계를 지어내지 않는다. 변수: 설명서, 부품, 정확한 문구. 교육용으로 쓰기 전에 전문가 검증이 필요하다.
```

<a id="pro-07"></a>

## PRO-07 — 외함 분해도

```text
[APPROVED CAD VIEWS]로 작은 전자 외함의 4:3 분해 일러스트를 만든다. 덮개, 개스킷, 내부 기판, 바닥을 같은 축을 따라 분리하고 부착 지점과 제공된 구성품 순서를 유지한다. 중성 기술 음영과 [APPROVED PART NAMES]의 라벨을 사용한다. 배선, 치수, 전기 연결을 지어내지 않는다. 변수: 허가된 뷰와 라벨. 설명 이미지이며 검증된 CAD나 수리 절차가 아니다.
```

<a id="pro-08"></a>

## PRO-08 — 캐릭터 소품 일관성

```text
창작 탐험가의 랜턴 하나를 손잡이로 들기, 돌 위에 놓기, 고리에 걸기의 세 상태로 보여 주는 16:9 시트를 만든다. 모든 패널에서 육각 몸체, 호박색 유리, 황동 걸쇠, 손잡이 형상을 유지한다. 양식화된 사실적 게임 아트와 일관된 빛을 사용한다. 문구, 추가 기구, 식별 가능한 프랜차이즈 모티프는 넣지 않는다. 변수: 승인된 소품 참조와 배경. 메시 구현 가능성은 별도로 확인한다.
```

<a id="pro-09"></a>

## PRO-09 — 게임 대화 인물 세트

```text
동일한 창작 성인 등대지기의 흉상 여섯 개를 담은 3:2의 2×3 시트를 만든다. 회색 곱슬머리, 파란 코트, 얼굴 모양, 눈썹의 작은 흉터를 유지한다. 차분함, 호기심, 의심, 걱정, 안도, 기쁨을 보여 준다. 깔끔한 페인팅 게임 아트, 평평한 중성 배경을 사용하고 문구는 넣지 않는다. 카메라 거리와 머리 크기를 동일하게 한다. 변수: 캐릭터 참조와 색상 구성. 콘셉트 세트이며 리깅되거나 자동 애니메이션되는 캐릭터가 아니다.
```

<a id="pro-10"></a>

## PRO-10 — 접이식 거치대 연구

```text
창작 접이식 태블릿 거치대의 닫힘, 반쯤 열림, 사용 상태를 담은 16:9 산업 콘셉트 보드를 만든다. 같은 알루미늄 프레임, 경첩 축, 고무발을 유지하고 아이보리 배경에서 명확한 측면을 보여 준다. 패널 아래에 “닫힘”, “펼치는 중”, “준비 완료”만 표시한다. 기계적 동작을 타당하게 하고 하중이나 호환성 주장을 지어내지 않는다. 변수: 승인된 스케치와 재료 마감. 엔지니어링 검토가 필요하다.
```
