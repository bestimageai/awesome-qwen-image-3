# 일러스트와 재료 실험

Qwen Image 3.0 프롬프트 10개입니다. 생성 전에 대괄호 안의 입력값을 바꾸세요. 따옴표 안의 문구는 정확히 재현하며, 명시적인 요청이 없으면 추가로 번역하지 않습니다. 결과물은 사람이 검토해야 합니다.

<a id="ill-01"></a>

## ILL-01 — 겹종이 유역

```text
언덕, 개울, 연못을 색종이 층으로 보여 주는 3:4 교육 종이 아트 콘셉트를 만든다. 뚜렷한 종이 가장자리, 절제된 파랑과 녹색, 위쪽의 부드러운 그림자를 사용한다. 개울은 내리막을 따라 연못으로 끊김 없이 흐르게 하고 위쪽 4분의 1은 제공된 제목을 위해 비운다. [APPROVED TITLE AND LABELS]만 표시한다. 측정치나 생태 주장을 지어내지 않는다. 변수: 검증된 지형 관계와 정확한 문구. 수업 전에 과학적 정확성을 검토한다.
```

<a id="ill-02"></a>

## ILL-02 — 두 잉크 동네 지도

```text
광장 하나를 둘러싼 제과점, 도서관, 정원, 수리점의 4:3 가상 동네 지도를 만든다. 아이보리 종이에 코발트와 따뜻한 주황 잉크만 사용하며 가벼운 인쇄 정합 질감을 넣는다. 건물은 명확한 보행로로 연결하고 제공된 네 장소 라벨만 표시한다. 실제 주소, 로고, 거리 주장, 임의의 경로 접근성 가정은 넣지 않는다. 변수: 가상 배치와 라벨. 잉크 겹침을 일관되게 하고 세 번째 인쇄색은 추가하지 않는다.
```

<a id="ill-03"></a>

## ILL-03 — 과슈 식물 도판

```text
[VERIFIED PLANT REFERENCE]로 따뜻한 아이보리 종이에 줄기 하나, 잎 두 장, 꽃 한 송이를 담은 3:4 과슈 습작을 만든다. 종 특유의 구조를 유지하고 해부학을 가리지 않는 붓 질감을 사용한다. 아래에는 제공된 식물명만 놓고 다른 문구는 넣지 않는다. 제공되지 않으면 축척은 표시하지 않는다. 약용 용도, 장식용 가짜 라틴어, 꽃잎 수 변경은 금지한다. 변수: 참조, 승인된 이름, 색상 구성.
```

<a id="ill-04"></a>

## ILL-04 — 동네 서비스 일러스트

```text
도서 키오스크, 공구 창고, 정원, 좌석 구역을 연결하는 가상 공동 마당을 16:9 등각 일러스트로 만든다. 명확히 분리된 네 구역, 따뜻한 건축색을 사용하며 연속된 무장애처럼 보이는 길은 [APPROVED LAYOUT]에 지정된 대로만 그린다. 제공된 구역명은 각각 한 번 표시한다. 법규 준수, 참석 인원, 사회적 효과를 주장하지 않는다. 계단, 문, 지붕 원근을 일관되게 한다. 변수: 배치와 라벨. 콘셉트 일러스트다.
```

<a id="ill-05"></a>

## ILL-05 — 자수 아이콘 연구

```text
[APPROVED MOTIF LIST]로 자수 아이콘 콘셉트 열여섯 개를 정사각형 4×4 시트로 만든다. 같은 크림색 천, 남색과 황토색 실, 보이는 바늘땀 방향을 사용하고 셀 중앙마다 모티프 하나를 둔다. 작은 크기에서도 이해할 만큼 실루엣을 단순하게 한다. 문구, 중복 모티프, 복제 로고, 불가능하게 떠 있는 바늘땀은 넣지 않는다. 변수: 열여섯 모티프와 실 색. 래스터 공예 콘셉트이며 기계 자수 파일이 아니다.
```

<a id="ill-06"></a>

## ILL-06 — 작은 문제 해결 그림책 펼침면

```text
창작 어린 토끼가 달팽이를 위해 정원의 얕은 물웅덩이에 징검다리를 놓는 2:1 그림책 펼침면을 만든다. 부드러운 색연필 질감, 은은한 봄빛, 명확한 왼쪽에서 오른쪽 이야기 흐름을 사용한다. 제본 가운데에는 얼굴과 핵심 동작을 두지 않는다. 왼쪽 위는 나중에 조판하도록 비운다. 문구, 추가 캐릭터, 위험한 물은 넣지 않는다. 변수: 승인된 캐릭터와 색상 구성.
```

<a id="ill-07"></a>

## ILL-07 — 도자기 부조 포스터

```text
수제 도자기 부조를 촬영한 듯한 3:4 포스터를 만든다. 굽은 가지에 앉은 양식화된 새 세 마리를 코발트 유약, 아이보리 점토, 작고 자연스러운 표면 차이로 표현한다. 평평한 위쪽 띠에는 “흙과 비행”, 아래 띠에는 “스튜디오 전시”를 둔다. 각 문구는 한 번씩, 떠 있는 종이에 인쇄한 것이 아니라 명확한 양각으로 표시한다. 날짜, 후원 표시, 가상 장소는 넣지 않는다. 변수: 승인된 문구와 유약 색.
```

<a id="ill-08"></a>

## ILL-08 — 추상적 편집 은유

```text
주의력을 정리하는 주제의 정사각형 편집 일러스트를 만든다. 열린 서랍 하나에 색종이 형태가 깔끔히 나뉘어 있고 빨간 리본 하나만 밖으로 늘어지게 한다. 촉감 있는 콜라주, 따뜻한 아이보리 배경, 부드러운 그림자를 사용한다. 단어, 사람 얼굴, 회사 로고, 의료 이미지 없이 질서와 방해를 전달한다. 서랍 형상은 타당하게 하고 지나친 혼잡을 피한다. 변수: 승인된 주제와 색상 구성. 은유는 창의적 해석이며 사실 주장이 아니다.
```

<a id="ill-09"></a>

## ILL-09 — 리노컷 빵 일러스트

```text
접힌 천 위 둥근 빵 하나의 3:4 창작 리노컷 스타일 일러스트를 만든다. 굵은 검은 조각 자국, 따뜻한 크림 종이, 빵 뒤 테라코타 강조 하나를 사용한다. 칼집 패턴과 껍질 부피가 읽히게 하고 무작위 긁힘 대신 방향성 해칭을 사용한다. 문구, 제과점 로고, 서명, 작가 구도 복제는 넣지 않는다. 변수: 빵 형태와 강조색. 적은 수의 잉크로 인쇄한 시각 논리를 유지한다.
```

## ILL-10 — 펠트 풍경 미니어처

```text
겹친 펠트로 둥근 언덕 둘, 작은 파란 연못 하나, 단순한 나무 셋의 4:3 미니어처 풍경을 만든다. 보이는 섬유, 꿰맨 가장자리, 부드러운 스튜디오 빛을 사용하고 재미있지만 일관된 척도를 유지한다. 나무는 정확히 세 그루이며 다른 물건은 추가하지 않는다. 문구, 얼굴, 브랜드 표시, 플라스틱 같은 표면은 넣지 않는다. 변수: 색상 구성과 승인된 풍경 요소. 재료 스타일 일러스트이며 실제 제품을 찍은 사진이 아니다.
```
