# 타이포그래피, 편집 디자인, 패턴

Qwen Image 3.0 프롬프트 10개입니다. 생성 전에 대괄호 안의 입력값을 바꾸세요. 따옴표 안의 문구는 정확히 재현하며, 명시적인 요청이 없으면 추가로 번역하지 않습니다. 결과물은 사람이 검토해야 합니다.

<a id="typ-01"></a>

## TYP-01 — 두 위계 타이포그래피 포스터

```text
정확한 제목 “이야기가 있는 물건”, 부제 “일상 디자인 연구”로 3:4 타이포그래피 포스터를 만든다. 제목은 큰 짙은 파란 세리프 글자로 균형 잡힌 세 줄에 놓고, 부제는 아래의 작지만 읽기 쉬운 산세리프 띠에 넣는다. 제목 오른쪽 아래 영역 뒤에 단순한 테라코타 원 하나를 두되 글자를 가리지 않는다. 따뜻한 종이 질감과 넉넉한 여백을 사용한다. 추가 단어, 휘어진 기준선, 복제한 브랜드 표시는 넣지 않는다. 변수: 승인된 제목, 부제, 색상 구성.
```

<a id="typ-02"></a>

## TYP-02 — 여러 문자 체계 표본

```text
같은 너비의 세 열에 정확히 “你好”, “Hello”, “こんにちは”를 넣은 16:9 서체 표본을 만든다. 올바른 중국어, 라틴 문자, 일본어 형태를 같은 시각적 무게로 짙은 잉크와 아이보리 배경에 쓴다. 각 표본 아래에 가는 파란 선을 두고 언어명이나 추가 문구는 넣지 않는다. 음역하거나 자동 번역하지 말고 제공된 문자 체계를 유지한다. 간격은 넉넉하게 하고 장식용 가짜 글자는 피한다. 변수: 승인된 다국어 문자열과 서체 스타일.
```

<a id="typ-03"></a>

## TYP-03 — 창작 공방 워드마크

```text
가상의 도자기 스튜디오 “Soft Corner”를 위한 정사각형 래스터 워드마크 콘셉트를 만든다. 맞춤 제작처럼 보이는 둥근 소문자, 절제된 차콜색, 유일한 기호인 작은 어긋난 사각형 하나를 사용한다. 이름은 읽기 쉽고 정확히 한 번만 쓴다. 아이보리 위 평면 콘셉트 하나만 보여 주고 벽 목업이나 여러 대안은 넣지 않는다. 기존 브랜드를 모방하거나 상표 사용 허가를 확보했다고 주장하지 않는다. 변수: 가상 이름과 색상 구성. 최종 벡터 마크는 디자이너가 재구성하고 확인해야 한다.
```

<a id="typ-04"></a>

## TYP-04 — 모노그램 탐색 시트

```text
제공된 “A”, “R”로 서로 다른 창작 모노그램 세 개를 담은 3:2 콘셉트 시트를 만든다. 무지 배경의 같은 크기 패널마다 하나를 놓고 검은 선 굵기를 통일하며 주변에 충분한 공간을 둔다. 두 글자가 모두 알아보이게 하고 장식 왕관이나 패션 브랜드 문양을 복제하지 않는다. 단어나 번호는 넣지 않는다. 래스터 탐색이며 등록 로고나 편집 가능한 벡터가 아니다. 변수: 이니셜과 기하학적 스타일.
```

<a id="typ-05"></a>

## TYP-05 — 잡지 도입 페이지

```text
“수리한 물건의 선반”이라는 3:4 잡지 도입 레이아웃을 만든다. 위쪽 절반에 수리된 생활용품 큰 사진, 그 아래 제목, 더 아래에 제공된 짧은 두 문단을 두 열로 놓는다. 크림 종이, 차콜 세리프, 파란 선 하나를 사용한다. [APPROVED BODY COPY]와 제목만 표시하며 더미 문구, 가상 작가, 페이지 번호는 넣지 않는다. 문구는 읽히고 물건은 사실적이어야 한다. 변수: 정확한 문구와 허가된 이미지. 편집 교정이 필요하다.
```

<a id="typ-06"></a>

## TYP-06 — 마을 신문 1면

```text
“마당 소식”이라는 3:4 가상 신문 표지를 만든다. 명확한 세 열 격자, 공동 정원의 큰 사진 하나, 작은 이미지 칸 두 개를 사용한다. 제목과 본문 영역에는 [APPROVED SHORT COPY]만 넣는다. 열 사이 여백은 넓게, 위계는 일관되게, 모든 단어는 읽히게 한다. 뉴스, 날짜, 인용, 기자 이름, 공식 인장을 지어내지 않는다. 변수: 승인된 문구, 이미지, 제공된 경우 발행일. 레이아웃 콘셉트이며 실제 사건 보도가 아니다.
```

<a id="typ-07"></a>

## TYP-07 — 반복 패턴 콘셉트

```text
아이보리 배경에 창작 양식화 배와 잎을 담은 정사각형 패턴 타일을 만든다. 황토색, 세이지, 짙은 파랑만 사용하고 방향을 다양하게 하며 빈 공간을 균형 있게 둔다. 한쪽 가장자리를 넘는 무늬는 반대편에서 자연스럽게 이어져야 하며 간격은 시각적으로 고르게 한다. 문구, 로고, 그라데이션, 식별 가능한 브랜드 패턴은 넣지 않는다. 변수: 모티프, 색상 구성, 밀도. 생성된 반복 후보이므로 제조 전에 타일 미리보기로 가장자리 연결을 검증한다.
```

<a id="typ-08"></a>

## TYP-08 — 반응형 히어로 배경

```text
겹친 옅은 파란 종이 형태가 오른쪽 아래에서 대각선으로 흐르는 16:9 웹사이트 히어로 배경을 만든다. 왼쪽 절반은 나중에 HTML 문구를 넣도록 낮은 대비로 거의 비운다. 은은한 물리적 그림자와 부드러운 크림 바탕을 사용하고 단어, 로고, UI 구성 요소는 넣지 않는다. 중앙 정사각형 자르기에서도 중요한 형태를 자르지 않고 차분한 초점이 남게 한다. 변수: 색상 구성, 방향, 문구 안전 영역. 인터페이스 문구를 이미지에 고정하지 않는다.
```

<a id="typ-09"></a>

## TYP-09 — 큰 글자 행사 안내판

```text
흰 바탕에 3:4 행사 방향 안내판을 만든다. “워크숍은 위층에”, “엘리베이터는 왼쪽에”와 큰 위쪽 화살표 하나를 정확히 표시한다. 매우 큰 남색 산세리프 글자와 넓은 간격을 사용하고 장식 이미지는 넣지 않는다. 화살표는 제목 위, 두 번째 줄은 아래에 놓고 여백을 명확히 한다. 경로 접근성을 임의로 가정하거나 시설 로고를 추가하지 않는다. 제공된 방향은 실제 장소에서 검증해야 한다. 변수: 승인된 방향 문구와 화살표 방향.
```

<a id="typ-10"></a>

## TYP-10 — 책등 디자인 시스템

```text
같은 높이로 세워진 책등 다섯 개를 보여 주는 16:9 편집 목업을 만든다. 크림색과 코발트의 통일된 디자인을 사용하고 각 책등에 제공된 제목 하나와 동일한 시리즈명을 일관되게 반복한다. 제목과 책의 순서, 읽기 쉬운 세로 방향, 넉넉한 간격을 유지한다. 제공되지 않은 작가, 출판사 로고, ISBN, 바코드, 수상 표시는 넣지 않는다. 변수: 제목 다섯 개와 시리즈명. 시각적 출판 콘셉트이며 인쇄 준비 파일이 아니다.
```
