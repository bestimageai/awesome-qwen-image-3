# 여행, 풍경, 도시, 탈것

Qwen Image 3.0 프롬프트 10개입니다. 생성 전에 대괄호 안의 입력값을 바꾸세요. 따옴표 안의 문구는 정확히 재현하며, 명시적인 요청이 없으면 추가로 번역하지 않습니다. 결과물은 사람이 검토해야 합니다.

<a id="trv-01"></a>

## TRV-01 — 언덕 전차 여행 포스터

```text
가상의 언덕 마을을 위한 3:4 여행 포스터 콘셉트를 만든다. 작은 노란 전차 하나가 파스텔 집 사이 굽은 거리를 올라가고 멀리 바다가 보이게 한다. 창작 실크스크린 일러스트, 따뜻한 테라코타 그림자, 명확한 제목 공간을 사용한다. “조금 돌아가도 괜찮아”, “언덕 마을의 주말”만 표시한다. 실제 관광 캠페인, 알아볼 수 있는 명소, 교통 로고를 복제하지 않는다. 변수: 색상 구성과 승인된 제목. 실제 여행지 사진처럼 제시하지 않는다.
```

<a id="trv-02"></a>

## TRV-02 — 산책 경로 일러스트

```text
[VERIFIED MAP AND ROUTE]로 3:4 동네 산책 안내를 만든다. 도로 연결, 시작과 끝, 제공된 경유지를 유지한다. 끊김 없는 파란 선으로 경로 하나를 강조하고 번호 표식은 제공된 목록과 정확히 대응하게 한다. 간단한 건축 아이콘과 읽기 쉬운 라벨을 사용한다. 거리, 영업시간, 접근성, 안전한 횡단 지점을 지어내지 않는다. 바닥글에 “현지 상황을 확인하세요”를 넣는다. 변수: 지도, 경로, 경유지, 승인된 문구.
```

<a id="trv-03"></a>

## TRV-03 — 해안 풍경 사진

```text
겹쳐진 어두운 바위, 낮은 바다 안개, 풀 덮인 곶의 좁은 길 하나를 가진 16:9 가상 해안 풍경을 만든다. 일출 때 자연스러운 광각 사진 원근, 절제된 하이라이트, 타당한 파도 크기를 사용한다. 수평선은 수평으로, 길은 물리적으로 연결되게 유지한다. 사람, 문구, 식별 가능한 명소, 불가능한 태양 반사는 넣지 않는다. 변수: 날씨, 해안 지질, 색상 구성. 실제 여행지 사진이 아니라 생성 이미지라고 표시한다.
```

<a id="trv-04"></a>

## TRV-04 — 밤의 역 장면

```text
비 온 뒤 가상의 교외 철도 승강장을 16:9로 만든다. 빈 벤치 하나, 작은 대기 쉼터, 배경의 정차한 무브랜드 열차를 보여 준다. 사실적인 따뜻한 쉼터 빛과 차가운 하늘빛의 혼합, 적당한 반사, 옅은 연무를 사용한다. 선로는 평행하게, 쉼터 지지대는 타당하게 한다. 읽을 수 있는 시간표, 목적지 표지, 사람, 운행사 로고, 극적인 위험 행위는 넣지 않는다. 변수: 건축 양식, 날씨, 조명.
```

<a id="trv-05"></a>

## TRV-05 — 탈것 정체성 유지 편집

```text
사용 허가를 받은 자전거 사진으로 정사각형 카탈로그 이미지를 만든다. 배경만 옅은 회색 스튜디오로 바꾸고 조명은 부드러운 측면광으로 조정한다. 프레임 형상, 바퀴 크기, 바퀴살, 구동계, 액세서리, 도장, 모든 기존 데칼을 정확히 유지한다. 양 타이어를 바닥에 닿게 하고 일관된 접촉 그림자를 만든다. 손상 부품을 펴거나 구성품을 추가하거나 브랜드를 바꾸지 않는다. 변수: 참조와 승인된 배경 색조.
```

<a id="trv-06"></a>

## TRV-06 — 산장 휴식 일러스트

```text
호수 옆 작은 목조 산장 하나와 뒤의 겹친 숲 실루엣으로 3:4 가상 산장 포스터를 만든다. 질감 있는 과슈, 차분한 소나무 녹색, 따뜻한 창빛을 사용한다. 위쪽 4분의 1은 “더 고요한 지평선”을 위해, 아래 여백은 “산장 습작”을 위해 남긴다. 반사를 산장과 맞추고 지형을 타당하게 한다. 실제 숙소명, 예약 주장, 별점, 가상 편의 시설은 넣지 않는다. 변수: 풍경, 색상 구성, 승인된 문구.
```

<a id="trv-07"></a>

## TRV-07 — 도시 이동 수단 비교

```text
가상의 한 거리 블록 안에서 자전거, 전차, 도보 경로를 비교하는 16:9 편집 일러스트를 만든다. 세 방식 모두 명확히 분리하고 같은 시각적 비중을 준다. 깔끔한 등각투영, 차분한 색상, “자전거”, “승차”, “도보” 라벨을 사용한다. 이동 시간, 배출량, 안전 우월성 주장은 넣지 않는다. 선로, 보도, 횡단 구간을 연결한다. 변수: 승인된 거리 배치와 라벨.
```

<a id="trv-08"></a>

## TRV-08 — 자동차 네 방향 보드

```text
사용 허가를 받은 차량 참조로 앞면, 뒷면, 왼쪽 측면, 사선 뷰의 16:9 네 방향 콘셉트 보드를 만든다. 차체 비율, 축간거리, 등, 거울, 도장을 모든 뷰에서 유지한다. 같은 중성 스튜디오 환경과 일관된 축척을 사용한다. 각 뷰를 한 번씩 표기하고 번호판은 생략하거나 명시적인 가상 빈 번호판을 사용한다. 가상의 배지, 주행 거리, 성능 주장은 넣지 않는다. 변수: 참조와 정확한 뷰 라벨.
```

<a id="trv-09"></a>

## TRV-09 — 여행 일지 펼침면

```text
가상의 강변 주말을 위한 3:2 일러스트 여행 일지 펼침면을 만든다. 왼쪽에 다리 스케치, 오른쪽에 배, 카페 컵, 잎 달린 가지의 작은 습작 세 개를 놓는다. 연필 선, 수채 번짐, 아이보리 종이를 사용한다. “강변의 주말”, “느린 하루의 기록”만 표시하고 나머지 메모 영역은 실제로 비워 둔다. 가짜 표, 여권 도장, 주소, 가짜 손글씨는 넣지 않는다. 변수: 장소 콘셉트와 색상 구성.
```

<a id="trv-10"></a>

## TRV-10 — 날씨 연속성 세 장 그림

```text
같은 가상 호숫가 부두를 맑은 날, 가벼운 비, 안개 속에서 보여 주는 16:9 세 패널 뷰를 만든다. 카메라, 부두 판자, 난간, 정박한 배, 해안선을 고정한다. 가시거리, 하늘, 젖음, 빛 반응만 바꾼다. 패널에는 “맑음”, “비”, “안개”를 표시한다. 반사는 물리적으로 일관되게 하고 패널 간 물체를 추가하거나 제거하지 않는다. 예보, 날짜, 실제 장소 주장은 넣지 않는다. 변수: 승인된 장면 참조와 날씨 라벨.
```
