# 아바타, 팀, 일상 인물 사진

Qwen Image 3.0 프롬프트 10개입니다. 생성 전에 대괄호 안의 입력값을 바꾸세요. 따옴표 안의 문구는 정확히 재현하며, 명시적인 요청이 없으면 추가로 번역하지 않습니다. 결과물은 사람이 검토해야 합니다.

<a id="ava-01"></a>

## AVA-01 — 공방 창업자 인물 사진

```text
사용 허가를 받은 성인 인물 사진으로 작은 가구 공방의 3:4 창업자 이미지를 만든다. 나이, 얼굴 비율, 자연스러운 피부 질감을 유지한다. 미완성 나무 스툴 옆에 앉히고 손은 자연스럽게 놓으며 뒤의 공구는 부드럽게 흐리게 한다. 눈높이 다큐멘터리 사진과 넓은 창빛을 사용한다. 고급 사무실 소품, 가상의 수상 내역, 추가 인물, 문구는 넣지 않는다. 교체 의상이 명시적으로 제공되지 않으면 참조 속 옷을 유지한다. 변수: 인물 사진, 승인된 의상, 공방 배경.
```

<a id="ava-02"></a>

## AVA-02 — 원형 크리에이터 아바타

```text
사용 허가를 받은 성인 인물 사진 하나로 정사각형 아바타를 만든다. 원형 자르기에서 머리나 턱이 잘리지 않도록 얼굴과 어깨 윗부분을 중앙 70퍼센트 안에 둔다. 따뜻한 회색 배경, 부드러운 정면광, 자연스러운 표정을 사용한다. 정체성, 나이, 헤어스타일, 눈에 보이는 얼굴의 차이를 유지하고 배경의 잡동사니만 제거한다. 문구, 배지, 새 장신구, 과도한 피부 평활화, 체형 수정은 하지 않는다. 변수: 참조 인물과 배경 색조. 최종 결과를 작은 프로필 아이콘 크기로 확인한다.
```

<a id="ava-03"></a>

## AVA-03 — 세 사람 팀 소개 띠

```text
사용 허가를 받은 성인 인물 사진 세 장으로, 같은 너비의 독립된 얼굴 사진 세 개와 일치하는 중성 배경을 갖춘 16:9 띠를 만든다. 각자의 얼굴과 머리 모양을 유지하고 특징을 섞지 않는다. 자연스러운 차이를 남기면서 눈높이, 겉보기 카메라 거리, 빛 방향을 맞춘다. 제공된 이름을 대응하는 사진 아래 정확히 한 번씩 둔다. 직함을 지어내거나 사람을 추가하거나 미화하지 않는다. 변수: 세 참조와 이름-이미지 대응표. 이 작업에는 참조 이미지 세 장을 모두 받는 편집 흐름이 필요하다.
```

## AVA-04 — 공예 인터뷰 인물 사진

```text
창작 성인 제본사가 나무 책상에서 천 표지 책을 고치는 3:2 편집용 인물 사진을 만든다. 작업 맥락 속 손, 작은 붓, 면지 한 장을 보여 주고 공구는 논리적으로 배치한다. 측면 창빛, 절제된 색, 오른쪽 여백이 있는 중간 거리 구도를 사용한다. 실명 인물을 모방하거나 읽을 수 있는 책 문구, 자격, 역사적 주장을 추가하지 않는다. 손가락은 타당하게 하고 접착제는 얼굴에서 멀리 둔다. 변수: 공예 종류, 가상 인물, 승인된 색상 구성.
```

<a id="ava-05"></a>

## AVA-05 — 가족 요리 시간

```text
사용 허가를 받은 가족 참조로 같은 사람들이 식탁에서 채소를 정리하는 16:9 가정 장면을 만든다. 정체성, 나이 차이, 관계, 옷을 유지하고 억지로 눈을 맞추게 하지 않은 자연스러운 표정을 사용한다. 칼과 뜨거운 기구는 아이 손이 닿지 않는 곳에 둔다. 부드러운 오후 빛과 실제 생활감 있는 배경을 사용한다. 가족 구성원, 문구를 추가하거나 신체를 과장되게 바꾸거나 실제 주소를 드러내지 않는다. 변수: 허가된 참조와 승인된 배경. 설명에 없는 관계를 추정하지 않는다.
```

## AVA-06 — 적응형 스포츠 인물 특집

```text
창작 성인 휠체어 테니스 선수가 야외 코트 옆에서 쉬는 3:4 편집용 인물 사진을 만든다. 스포츠 휠체어의 바퀴, 프레임, 잡는 부분을 사실적으로 보여 주고 라켓은 무릎 위에 가로로 둔다. 늦은 오후 빛, 눈높이 구도, 차분하고 주체적인 표정을 사용한다. 인물을 불쌍하게 표현하거나 감동 표어, 메달, 후원사, 의료 주장을 넣지 않는다. 해부학과 장비는 타당하게 유지한다. 변수: 가상 선수 외모, 의상, 코트 색상 구성.
```

## AVA-07 — 비 오는 거리 인물 사진

```text
사용 허가를 받은 성인 참조로 투명 우산 아래의 3:4 스트리트 인물 사진을 만든다. 얼굴 정체성, 의상, 신체 비율을 유지한다. 무늬 없는 벽돌 벽 근처에 인물을 놓고 젖은 포장길과 부드러운 반사를 보여 준다. 네온 대신 흐린 날 자연광을 사용한다. 우산살, 손잡이, 손으로 잡는 자세를 일관되게 한다. 다른 사람, 보이는 주소, 상점 로고, 문구를 넣거나 나이를 바꾸지 않는다. 변수: 인물 사진, 승인된 겉옷, 배경 재료.
```

<a id="ava-08"></a>

## AVA-08 — 작가 홍보 사진

```text
사용 허가를 받은 성인 참조로 정사각형 언론 자료용 인물 사진을 만든다. 무지 책 더미 옆에 앉히고 어깨는 살짝 틀되 얼굴은 카메라를 보게 한다. 부드러운 측면광, 정돈된 아이보리 벽, 사실적인 피부 질감을 사용한다. 머리 모양, 얼굴 특징, 표정을 유지한다. 다른 자르기를 위해 머리 주위에 여유를 둔다. 가상의 책 제목, 상, 서명, 문구, 미용 필터 효과는 넣지 않는다. 변수: 인물 사진, 승인된 옷, 벽 색상.
```

## AVA-09 — 자원봉사자 단체 일러스트

```text
[APPROVED GROUP DESCRIPTION]로 성인 자원봉사자 정확히 다섯 명이 긴 탁자 주위에서 기증된 책을 분류하는 16:9 일러스트를 만든다. 각자 다른 일을 맡기고 제공된 외모 세부를 희화화 없이 유지한다. 따뜻한 편집용 과슈와 명확한 손-물체 상호작용을 사용한다. 통로를 열어 두고 책 더미를 안정적으로 만든다. 이름, 단체 로고, 기부 수치, 수혜자 관련 주장은 넣지 않는다. 변수: 승인된 단체 세부와 배경. 가상 인물이 식별 가능한 개인을 닮아서는 안 된다.
```

## AVA-10 — 인물 조명 연구

```text
사용 허가를 받은 성인 인물 사진 하나로 3:2 두 패널 조명 연구를 만든다. 왼쪽은 카메라 왼쪽에서 들어오는 넓은 창빛, 오른쪽은 같은 빛을 커튼으로 부드럽게 한 조명을 사용한다. 정체성, 카메라 위치, 표정, 의상, 자르기, 배경을 고정한다. 해당 패널 아래에 “직접 창빛”, “확산 창빛”만 표시한다. 변화는 그림자 부드러움과 하이라이트 전이에 한정한다. 얼굴을 재조형하거나 피부색을 바꾸거나 다른 나이를 흉내 내지 않는다. 변수: 참조와 번역된 라벨.
```
