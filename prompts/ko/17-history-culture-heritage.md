# 역사, 문화, 근거 중심 해석

Qwen Image 3.0 프롬프트 10개입니다. 생성 전에 대괄호 안의 입력값을 바꾸세요. 따옴표 안의 문구는 정확히 재현하며, 명시적인 요청이 없으면 추가로 번역하지 않습니다. 결과물은 사람이 검토해야 합니다.

<a id="cul-01"></a>

## CUL-01 — 역사적 거리의 일상

```text
[DATED PHOTOGRAPHS AND MAP]으로 [YEAR]년 [STREET]의 일상을 16:9로 복원한다. 기록된 건물 윤곽, 교통 유형, 거리 표면을 유지한다. 제공된 근거가 뒷받침하는 일상 행동만 보여 주고 불확실한 부분은 시각적으로 절제한다. 기록 일러스트를 사용하며 기록 보관 사진이라고 주장하지 않는다. 비문, 유명인, 현대 물건을 지어내지 않는다. 변수: 장소, 날짜, 근거, 불확실성 주석. 역사 검토가 필요하다.
```

<a id="cul-02"></a>

## CUL-02 — 유물 복원 연구 보드

```text
[AUTHORIZED ARTIFACT IMAGES]로 16:9 세 패널 박물관 연구 보드를 만든다. 현존 유물, 절제된 복원, 불확실한 부분을 표시한 도해를 보여 준다. 기록된 형상과 표면 손상을 유지한다. 패널은 “현존”, “복원”, “불확실”로 표기하고 시각 처리를 달리해 추측을 증거로 오인하지 않게 한다. 제작자, 출처 이력, 의례적 의미를 지어내지 않는다. 변수: 참조 자료와 승인된 해석. 전문가 검토가 필요하다.
```

<a id="cul-03"></a>

## CUL-03 — 역사 시장 일러스트

```text
[EVIDENCE PACK]으로 [VERIFIED REGION AND PERIOD]의 시장을 3:2 교육 일러스트로 만든다. 제공된 가판대 유형, 의상, 상품, 건축만 넣는다. 전경의 거래는 읽기 쉽게, 배경은 차분하게 하고 자연광과 절제된 세부를 사용한다. 읽을 수 있는 가격, 가상 문자 체계, 고정관념, 다른 시대의 물건은 넣지 않는다. 변수: 지역, 날짜, 기록된 요소. 진짜 역사 이미지가 아니라 해석 일러스트로 표시한다.
```

<a id="cul-04"></a>

## CUL-04 — 역사 의복 연구

```text
[MUSEUM-VERIFIED GARMENT REFERENCES]로 중립 인체의 정면, 측면, 후면을 담은 16:9 의복 연구 시트를 만든다. 솔기, 여밈, 원단 겹, 제공된 색 근거를 유지한다. 승인된 의복명, 지역, 시대만 표기한다. 신분, 민족, 의례 의미, 기록되지 않은 장식을 지어내지 않는다. 변수: 참조와 정확한 라벨. 불확실한 색은 제공된 주석으로 구별하고 전문 검토를 받는다.
```

<a id="cul-05"></a>

## CUL-05 — 전통 공예 과정

```text
[PRACTITIONER-APPROVED STEPS]로 [DOCUMENTED CRAFT PROCESS]를 설명하는 16:9 네 패널 일러스트를 만든다. 올바른 공구, 손 위치, 재료 상태를 순서대로 보여 준다. 명확한 자연주의 일러스트와 제공된 라벨만 사용한다. 제한된 지식을 공개하거나 신성한 세부를 지어내거나 살아 있는 전통을 일반적 모티프로 대체하지 않는다. 변수: 승인된 참조, 단계, 출처 표기. 게시 전에 실천자 검토와 해당 허가가 필요하다.
```

<a id="cul-06"></a>

## CUL-06 — 두 언어 문화유산 해설판

```text
[APPROVED TWO-LANGUAGE COPY]와 허가된 현장 이미지 하나로 3:4 문화유산 해설판을 만든다. 두 언어는 분리되고 명확히 정렬된 블록에서 같은 조판 위상을 갖게 한다. 이름, 날짜, 발음 구별 기호, 읽기 방향을 유지하고 이미지는 문구 위에 둔다. 역사, 관광 주장, 기관 로고, 번역을 지어내지 않는다. 변수: 최종 이중언어 문구, 이미지, 출처 크레딧. 지역 공동체와 사실 검토가 필요한 레이아웃 콘셉트로 유지한다.
```

<a id="cul-07"></a>

## CUL-07 — 역사 지도 오버레이

```text
허가된 역사 지도와 [VERIFIED MODERN ALIGNMENT]로 16:9 비교 일러스트를 만든다. 역사 지도를 바탕으로 유지하고 제공된 현대 기준선만 뚜렷한 파란 오버레이로 더한다. 두 날짜와 불확실한 정렬을 구분하는 범례를 넣는다. 경계, 소유권 주장, 경로, 지리공간 정밀도를 지어내지 않는다. 변수: 지도, 정렬, 정확한 라벨. 역사와 지리 검토가 필요하다.
```

<a id="cul-08"></a>

## CUL-08 — 복원 장면의 연속성

```text
[VERIFIED PERIOD]의 동일한 기록된 마당을 새벽, 정오, 오후, 해질녘의 16:9 네 패널로 복원한다. [EVIDENCE PACK]으로 건축, 재료, 가구, 카메라 위치를 고정한다. 빛과 제공된 일상 행동만 바꾼다. 현대 물건, 가상 비문, 근거 없는 의례 행사를 피한다. 시간대만 표기한다. 변수: 참조와 승인된 활동 목록. 해석적 연속 장면이며 묘사된 사건이 일어났다는 증거가 아니다.
```

<a id="cul-09"></a>

## CUL-09 — 기록물 취급 포스터

```text
[ARCHIVIST-APPROVED HANDLING RULES]로 3:4 교육 포스터 콘셉트를 만든다. 명확한 세 패널에 제공된 취급 행동, 알맞은 도구, 정확한 짧은 라벨을 넣는다. 중성 기술 일러스트, 높은 대비, 넉넉한 여백을 사용한다. 장갑 요구, 세척법, 보존 처리를 지어내지 않는다. 변수: 검증된 절차와 물체 유형. 사용 전에 기록 전문가와 검토한다. 기관 인장, 서명, 근거 없는 보존 주장은 넣지 않는다.
```

<a id="cul-10"></a>

## CUL-10 — 구술 역사 인용 패널

```text
[CONSENTED VERIFIED QUOTATION], [APPROVED ATTRIBUTION], 허가된 맥락 이미지로 4:3 전시 패널을 만든다. 인용문은 눈에 띄게, 출처 표기는 아래에, 이미지는 옆에 둔다. 표현, 방언, 문장 부호를 정확히 유지하고 증언을 고쳐 쓰거나 화자 초상을 지어내지 않는다. 차분한 편집 타이포그래피와 크림 배경을 사용한다. 변수: 동의된 문구, 출처, 이미지. 제공된 맥락과 허가 크레딧만 포함한다.
```
