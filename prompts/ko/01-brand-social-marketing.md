# 브랜드, 포스터, 캠페인

Qwen Image 3.0 프롬프트 10개입니다. 생성 전에 대괄호 안의 입력값을 바꾸세요. 따옴표 안의 문구는 정확히 재현하며, 명시적인 요청이 없으면 추가로 번역하지 않습니다. 결과물은 사람이 검토해야 합니다.

## MKT-01 — 수리 가능한 스탠드 출시 포스터

```text
가상의 스튜디오 LATCH와 수리 가능한 책상 스탠드를 위한 3:4 출시 포스터를 만든다. 파란 작업대 위에 접힌 황토색 스탠드 하나를 놓고 분리형 갓을 옆에 둔다. 스탠드가 화면 아래쪽 3분의 2를 차지하게 한다. 선명한 제품 사진, 부드러운 측면광, 절제된 편집 디자인 격자를 사용한다. 크기 위계를 낮춰 가며 “LATCH”, “오래 함께하도록”, “부품은 바꾸고, 스탠드는 그대로.”만 표시한다. 관절은 기계적으로 타당하고 부품은 서로 맞아야 한다. 가격, 지속 가능성 인증, 성능 주장을 추가하지 않는다. 변수: 스튜디오 이름, 마감, 승인된 표어.
```

## MKT-02 — 강변 독서 축제

```text
가상의 수상 도서관 축제를 위한 3:4 일러스트 포스터를 만든다. 오른쪽 아래에 파란 도서 운반선을 정박시키고, 굽은 빨간 보행교가 왼쪽 위 제목에서 줄무늬 차양 아래의 독자 세 명으로 시선을 이끌게 한다. 평면적인 실크스크린 형태, 아이보리 종이, 넉넉한 여백을 사용한다. “河畔读书节”, “RIVER READING DAYS”, “川辺の読書会”, “SAT–SUN · 10:00–17:00”를 각각 별도 블록에 정확히 한 번씩 표시한다. 제공된 중국어, 영어, 일본어를 그대로 유지한다. 다른 표지판, 후원사, 워터마크는 넣지 않는다. 변수: 승인된 축제 문구와 색상 구성.
```

## MKT-03 — 소리 아카이브 팟캐스트 표지

```text
가상의 팟캐스트 “작은 소리들”을 위한 정사각형 표지를 만든다. 얕은 쟁반에 놓인 황동 열쇠 하나를 크게 보여 주고, 뒤쪽에 섬세한 동심원 진동 고리 세 개를 그린다. 따뜻한 접사 사진과 짙은 가지색 배경을 사용한다. 위쪽 4분의 1에 제목을 가로로 배치하고 아래에 “귀 기울일 만한 이야기”를 넣는다. 두 줄 모두 너비 100픽셀로 보아도 읽혀야 한다. 마이크, 헤드폰, 플랫폼 배지, 회차 번호는 넣지 않는다. 열쇠는 하나만, 반사는 사실적으로, 여백은 깔끔하게 유지한다. 변수: 제목, 물체, 배경색.
```

## MKT-04 — 공구 비교 동영상 썸네일

```text
수공구 선택법을 설명하는 16:9 동영상 썸네일을 만든다. 오른쪽에 브랜드 없는 드라이버 세 개를 세로로 배치하고 일자, 십자, 육각 팁을 확연히 구분한다. 왼쪽에는 “어떤 팁이 맞을까?”만 두 줄로 표시한다. 각 팁 아래에 맞는 나사 머리의 작은 도해를 하나씩 넣되 추가 라벨은 쓰지 않는다. 밝은 탁상 사진, 차콜색 글자, 노란 배경 강조색을 사용한다. 팁과 나사 머리 홈은 기계적으로 일치해야 한다. 거짓 반응, 평점, 과장된 주장을 넣지 않는다. 변수: 공구 구성과 정확한 제목.
```

## MKT-05 — 포장 안내 캐러셀 표지

```text
깨지기 쉬운 도자기를 포장하는 6장짜리 안내서의 3:4 표지를 만든다. 접힌 골판지 칸막이 사이에 그릇 하나가 시각적으로 떠 있는 모습을 보여 주고 아래쪽에 종이 완충재 한 롤을 놓는다. 연회색 배경에서 정돈된 수직 항공 구도의 사진을 사용한다. 위에는 “정성을 담아 포장”, 그 아래에는 “도자기 배송 안내”, 오른쪽 아래에는 “1/6”을 넣는다. 그릇은 온전하게, 재료는 사실적으로 유지한다. 배송 회사 로고, 파손 방지 보장, 다른 문구는 추가하지 않는다. 변수: 물체, 제목, 슬라이드 수.
```

## MKT-06 — 지역 작업장 모집

```text
가상의 자전거 수리 협동조합을 위한 세로 3:4 모집 포스터를 만든다. 정돈된 공구판 옆에 아무도 입지 않은 정비사 앞치마를 걸고, 위쪽 절반을 문구용으로 비워 둔다. 다큐멘터리 사진, 은은한 창빛, 짙은 녹색 글자를 사용한다. 제공된 값으로 치환해 “작업장의 동료를 찾습니다”, “[ROLE]”, “[CITY] · [SCHEDULE]”, “지원 마감: [DATE]”를 표시한다. 공구는 알아볼 수 있게 하고 급여, 자격 인증, 연락처를 지어내지 않는다. QR 코드를 생성하지 않는다. 생성 전에 모든 변수를 바꿔야 한다.
```

## MKT-07 — 개인 컵 지참 안내

```text
재사용 컵 지참을 권하는 9:16 카페 안내문을 만든다. 사용감 있는 크림색 휴대용 컵 하나를 분필빛 파란 도자기 주전자 옆에 놓고, 따뜻한 아침 햇빛 아래 카운터 높이에서 촬영한다. 컵 위에는 “나의 컵, 나의 일상”, 아래에는 “다음에는 꼭 챙겨 오세요”를 넣는다. 중앙은 넓게 비우고 멀리서도 글자 대비가 높게 유지되도록 한다. 할인, 환경 통계, 건강 주장, 다른 물체나 문구를 추가하지 않는다. 뚜껑 구조와 바닥에 닿은 그림자는 사실적으로 유지한다. 변수: 컵 색상과 승인된 두 줄 문구.
```

## MKT-08 — 등불 산책 키 비주얼

```text
가상의 저녁 등불 산책 행사 “빛의 길”을 위한 16:9 정지 키 비주얼을 만든다. 작은 호박색 종이등 줄이 어두운 식물원을 굽이쳐 지나 열린 문으로 향하게 한다. 중앙 왼쪽은 제목을 넣도록 차분하게 비우고 바로 아래에 “함께하는 저녁”을 놓는다. 은은한 깊이와 보이는 섬유 질감이 있는 겹종이 일러스트를 사용하며 네온 효과는 쓰지 않는다. 식별 가능한 명소, 후원사 로고, 추가 문구를 피한다. 이것은 정지된 콘셉트 한 장이며 애니메이션 결과물이 아니다. 변수: 제목, 길의 형태, 강조색.
```

## MKT-09 — 수리 워크숍 포스터

```text
가상의 지역 수리 워크숍을 위한 3:4 포스터를 만든다. 테라코타색 탁자 위에 노란 토스터, 작은 드라이버, 파란 실타래를 그리고, 서로 반대쪽에서 나온 성인의 손 두 개가 토스터를 수리하게 한다. 깔끔한 종이 오리기 형태, 크림색 배경, 남색 글자, 넉넉한 간격을 사용한다. 위에는 “토요일은 수리하는 날”, 아래에는 “작은 물건 하나를 가져오세요”, 맨 아래에는 “14:00–17:00”를 표시한다. 각 줄은 한 번씩만 쓰고 다른 문구는 넣지 않는다. 손은 해부학적으로 자연스럽고 토스터는 전원이 뽑혀 있어야 한다. 변수: 승인된 현지화 문구와 색상 구성.
```

## MKT-10 — 사진 인화점 개업 창문 안내

```text
가상의 동네 사진 인화 스튜디오를 위한 2:3 창문 안내문을 만든다. 아래쪽 절반에 브랜드 없는 즉석사진 세 장을 가로 끈 하나에 집게로 매단다. 위에는 “일상을 인화하세요”, 이어서 “[DATE] 오픈”, “[STREET]”를 표시한다. 촉감이 느껴지는 크림색 종이, 코발트 글자, 자연스러운 그림자를 사용한다. 생성 전에 날짜와 주소를 제공하고 개업 혜택을 지어내지 않는다. 사진 세 장은 서로 다른 이미지여야 하며, 문구 없이 사적인 얼굴이나 읽을 수 있는 개인 문서를 포함하지 않는다. 변수: 날짜, 위치, 사진 소재.
```
