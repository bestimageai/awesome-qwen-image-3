# 소셜 게시물, 표지, 크리에이터 콘텐츠

Qwen Image 3.0 프롬프트 10개입니다. 생성 전에 대괄호 안의 입력값을 바꾸세요. 따옴표 안의 문구는 정확히 재현하며, 명시적인 요청이 없으면 추가로 번역하지 않습니다. 결과물은 사람이 검토해야 합니다.

<a id="soc-01"></a>

## SOC-01 — 베란다 재배 안내 표지

```text
초보자 베란다 재배 안내서의 3:4 소셜 표지를 만든다. 좁은 선반에 작은 테라코타 화분 세 개를 놓고 각각 다른 잎채소 허브를 심으며 아래에 작은 물뿌리개를 둔다. 밝은 자연 사진과 따뜻한 크림 배경을 사용한다. “작은 베란다, 새로운 시작”, “화분 세 개로 시작해요”, “1/5”를 표시하고 제목은 위쪽 3분의 1을 차지하게 한다. 수확량, 건강, 성장 보장을 주장하지 않는다. 화분을 바닥에 안정적으로 놓고 난간 형상을 일관되게 한다. 변수: 승인된 허브와 제목.
```

<a id="soc-02"></a>

## SOC-02 — 세 장짜리 공예 행사 안내

```text
정사각형 소셜 게시물 세 개로 나눌 3:1 원본 이미지 하나를 만든다. 긴 작업대의 왼쪽에는 점토 공구, 중앙에는 도자기 주전자, 오른쪽에는 접힌 리넨을 놓는다. 각 정사각형이 독립적으로 균형을 이루게 하고 “만들기”, “나누기”, “만나기”를 별도 패널에 표시한다. 일관된 따뜻한 조명과 차분한 크림색 여백을 사용한다. 중요한 물체나 글자는 자르기 경계를 넘지 않는다. 시각 원본이며 내보낸 파일 세 개가 아니다. 변수: 공예 물건과 승인된 세 단어.
```

<a id="soc-03"></a>

## SOC-03 — 연구 결과 카드

```text
[VERIFIED FINDING, DATA AND SOURCE]로 16:9 전문 소셜 카드를 만든다. 위에 정확한 발견 하나, 중앙에 간단한 근거 차트, 아래에 출처를 놓는다. 흰 바탕에 차콜 글자와 청록색 강조 하나를 사용한다. 단위, 날짜, 표본 한계, 불확실성을 유지한다. 상관관계를 인과관계로 바꾸거나 극적인 백분율을 추가하지 않는다. 휴대전화에서도 문구가 읽혀야 한다. 변수: 승인된 결과, 데이터셋, 인용. 차트 정확성은 사람이 검토해야 한다.
```

<a id="soc-04"></a>

## SOC-04 — 요리 비교 썸네일

```text
서양배를 담는 세 가지 자르기 방법인 얇은 조각, 깍둑썰기, 부채꼴을 비교하는 16:9 동영상 썸네일을 만든다. 코발트 탁자 위에 동일한 흰 접시 세 개를 나란히 두고 배 색상과 위쪽 빛을 일치시킨다. 위에는 “배 하나, 세 가지 썰기”만 표시한다. 자른 형태를 뚜렷하게 구별하고 양은 타당하게 한다. 영양 주장, 가짜 평점, 손 가까이의 칼, 추가 문구는 넣지 않는다. 변수: 과일과 승인된 제목.
```

<a id="soc-05"></a>

## SOC-05 — 책상 정리 숏폼 표지

```text
반쯤 정돈된 책상을 보여 주는 9:16 표지를 만든다. 왼쪽에는 정렬된 종이, 오른쪽에는 닫힌 노트와 컵을 둔다. 자연스러운 탑뷰 사진, 부드러운 그림자, 절제된 모래색과 파란색 구성을 사용한다. 중앙 안전 영역에 “책상을 새롭게 정리해요”, 아래에 “한 면부터 시작하세요”를 표시한다. 플랫폼 표시가 겹칠 수 있도록 중요한 문구는 아래쪽 4분의 1과 오른쪽 가장자리를 피한다. 소요 시간 주장, 앱 로고, 추가 문구는 넣지 않는다. 변수: 책상 물건과 두 줄 제목.
```

<a id="soc-06"></a>

## SOC-06 — 두 게스트 라이브 방송 안내

```text
사용 허가를 받은 성인 인물 사진 두 장으로 3:4 라이브 방송 안내를 만든다. 두 게스트에게 같은 시각 공간, 자르기 비율, 중성 조명을 주고 이름은 대응 사진 바로 아래 둔다. [EVENT TITLE], [GUEST NAMES], [DATE], [TIME ZONE]만 표시한다. 단순한 남색과 크림색 격자를 사용하고 가짜 실시간 표시나 플랫폼 로고는 넣지 않는다. 정체성을 유지하고 자격이나 참석 수치를 지어내지 않는다. 변수: 두 참조와 승인된 행사 문구.
```

<a id="soc-07"></a>

## SOC-07 — 검증된 인용문 카드

```text
[EXACT VERIFIED QUOTE]와 [AUTHOR ATTRIBUTION]으로 정사각형 인용문 카드를 만든다. 따뜻한 미색 종이에 크고 읽기 쉬운 세리프 글꼴로 인용문을 놓고, 아래에 같은 왼쪽 기준선으로 저자를 표기한다. 아래 모서리에 작은 추상 파란 선화 하나를 추가한다. 문장 부호와 표현을 정확히 유지하고 줄이거나 날조하거나 다른 사람의 말로 돌리지 않는다. 인물 사진, 서명, 추천 배지는 넣지 않는다. 변수: 검증된 인용문, 저자 표기, 색상 구성.
```

<a id="soc-08"></a>

## SOC-08 — 아홉 단계 공예 격자

```text
[NINE APPROVED CRAFT STEPS]를 설명하는 정사각형 3×3 격자를 만든다. 같은 탁자, 손, 재료를 끝까지 사용하고 원재료에서 완성품까지의 진행을 명확히 한다. 패널에는 왼쪽에서 오른쪽, 위에서 아래 순으로 “1”부터 “9”만 표시한다. 공구와 물체 비율을 유지하고 단계를 지어내거나 위험한 공구 사용을 보여 주지 않는다. 장식 문구나 중복 패널은 넣지 않는다. 변수: 검증된 단계와 재료. 교육 내용 정확성은 검토가 필요하다.
```

<a id="soc-09"></a>

## SOC-09 — 행사 회고 모자이크

```text
가상의 지역 그림 그리기 행사를 위한 3:4 편집 회고 레이아웃을 만든다. 탁자의 스케치북, 그리는 손, 서명 없는 스케치 벽, 마무리 때의 빈 스툴이라는 네 이미지 패널을 배치한다. 일관된 자연광과 위쪽 작은 제목 “그림을 그린 하루”를 사용한다. 얼굴은 식별 불가능하게 하고 작품은 창작물로 한다. 참석 수, 후원사 표시, 후기 인용문은 넣지 않는다. 차분한 바닥글 띠는 비워 둔다. 변수: 활동과 정확한 제목.
```

<a id="soc-10"></a>

## SOC-10 — 세로 표지 자르기 연구

```text
옅은 하늘을 배경으로 중앙에 빨간 종이연 하나를 놓은 9:16 크리에이터 표지 콘셉트를 만든다. 가운데 3분의 1에 “종이연 만들기”를 놓고 위쪽 15퍼센트와 아래쪽 25퍼센트는 문구 없이 비운다. 중앙 정사각형으로 잘라도 연과 제목이 읽히게 한다. 깔끔한 일러스트 질감과 부드럽게 굽은 연줄을 사용한다. 플랫폼 UI, 추가 연, 가짜 버튼, 작은 설명은 넣지 않는다. 변수: 물체 색상과 승인된 제목.
```
