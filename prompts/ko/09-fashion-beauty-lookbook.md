# 패션, 뷰티, 섬유 콘셉트

Qwen Image 3.0 프롬프트 10개입니다. 생성 전에 대괄호 안의 입력값을 바꾸세요. 따옴표 안의 문구는 정확히 재현하며, 명시적인 요청이 없으면 추가로 번역하지 않습니다. 결과물은 사람이 검토해야 합니다.

<a id="fas-01"></a>

## FAS-01 — 네 가지 캡슐 옷장 스타일

```text
사용 허가를 받은 성인 모델 참조와 [APPROVED GARMENT LIST]로 같은 크기의 네 패널을 가진 16:9 룩북을 만든다. 옅은 배경에서 같은 카메라 거리로 제공된 네 의상 조합을 보여 준다. 인물 정체성과 각 의류의 구조, 색상, 핏을 유지한다. 패널은 “01”, “02”, “03”, “04”로만 표기한다. 신체 비율을 바꾸지 않는 부드러운 패션 편집 조명을 사용한다. 장신구, 로고, 지속 가능성 주장은 추가하지 않는다. 변수: 참조, 의류, 의상 대응표.
```

<a id="fas-02"></a>

## FAS-02 — 유틸리티 조끼 디자인 시트

```text
창작 슬레이트 블루 유틸리티 조끼의 4:3 의류 콘셉트 시트를 만든다. 앞면, 뒷면, 주머니 세부 하나를 보여 주고 솔기, 지퍼 방향, 원단 질감을 모두 맞춘다. 명확한 기술 일러스트를 사용하며 “앞면”, “뒷면”, “주머니”만 표시한다. 주머니 수와 실루엣을 유지하고 제공되지 않은 치수는 넣지 않는다. 유명 브랜드의 독특한 디자인을 복제하거나 제조 준비가 끝났다고 암시하지 않는다. 변수: 승인된 스케치, 원단, 라벨.
```

<a id="fas-03"></a>

## FAS-03 — 도자기 장신구 캠페인

```text
접힌 아이보리 리넨 위에 창작 코발트 도자기 귀걸이 두 개를 놓은 정사각형 장신구 사진을 만든다. 유약 하이라이트가 날아가지 않도록 부드러운 측면광을 사용하고 크기와 질감 기준으로 작은 마른 가지 하나를 넣는다. 두 귀걸이는 구조적으로 맞추되 자연스러운 수작업 마감을 남긴다. 문구, 보석, 귀금속 주장, 브랜드 표시는 넣지 않는다. 부착 금속 부품과 타당한 그림자를 유지한다. 변수: 허가된 제품 참조, 유약, 섬유 색상.
```

<a id="fas-04"></a>

## FAS-04 — 메이크업 비교 편집

```text
사용 허가를 받은 성인 인물 사진 하나로 4:3의 2×2 메이크업 비교를 만든다. 얼굴, 피부색, 머리, 조명, 표정을 동일하게 유지한다. 제공된 네 가지 메이크업 팔레트만 적용하고 입술, 눈꺼풀, 볼만 바꾼다. [APPROVED LOOK NAMES]로 패널을 표기한다. 자연스러운 피부 질감과 얼굴 차이를 보존한다. 얼굴 재조형, 나이 변경, 제품 효능 주장, 추가 장신구는 넣지 않는다. 변수: 인물 사진, 팔레트, 라벨 대응표.
```

<a id="fas-05"></a>

## FAS-05 — 제품 사용 순서 카드

```text
[MANUFACTURER-APPROVED ORDER AND COPY]로 3:4 제품 사용 카드를 만든다. 제공된 용기 정확히 네 개를 세로 순서로 보여 주고, 간단한 아래 화살표와 용기별 승인된 단계 라벨 하나를 둔다. 깔끔한 스튜디오 사진, 옅은 파란 배경, 넉넉한 간격을 사용한다. 포장 문구와 모양을 유지하고 성분, 의학적 효과, 빈도, 호환성을 지어내지 않는다. 피부 전후 비교 이미지는 넣지 않는다. 변수: 제품 참조와 검증된 사용 순서. 게시 전에 모든 주장을 검토한다.
```

<a id="fas-06"></a>

## FAS-06 — 여행 액세서리 플랫레이

```text
창작 캔버스 토트백 하나, 접힌 무늬 스카프, 무지 선글라스, 작은 노트로 3:4 탑뷰 패션 플랫레이를 만든다. 모래색 표면에 대각선으로 배치하고 중요한 형태가 겹쳐 가려지지 않게 한다. 부드러운 자연 그림자와 절제된 남색 강조를 사용한다. 명품 로고, 여권, 표, 읽을 수 있는 개인 정보는 넣지 않는다. 안경은 대칭이고 천 주름은 자연스러워야 한다. 변수: 승인된 액세서리, 섬유 무늬, 색상 구성.
```

<a id="fas-07"></a>

## FAS-07 — 헤어스타일 시각화

```text
사용 허가를 받은 성인 인물 사진 하나로 제공된 여섯 헤어스타일의 3:2 시트를 만든다. 얼굴, 헤어라인, 나이, 피부색, 카메라 각도, 조명을 유지한다. [APPROVED STYLE LIST]에 따라 머리 길이, 배열, 질감만 바꾸고 요청이 없으면 원래 머리색을 유지한다. 패널 번호는 “1”부터 “6”까지다. 얼굴 보정, 메이크업 변경, 이마에서 불가능하게 자라는 머리카락은 넣지 않는다. 변수: 원본 인물 사진과 여섯 스타일 설명.
```

<a id="fas-08"></a>

## FAS-08 — 직물 조직 비교

```text
리넨 평직, 면 능직, 편직 울을 같은 크기의 접사 세 패널로 보여 주는 16:9 섬유 참조 보드를 만든다. 질감과 색상은 [AUTHORIZED MATERIAL REFERENCES]를 사용한다. 배율과 중성 조명을 맞추고 각 구조의 고유한 실 패턴을 보존한다. 제공된 재료명만 표시한다. 섬유 조성, 내구성, 원산지, 관리 주장을 지어내지 않는다. 변수: 참조와 정확한 라벨. 재료 식별에는 전문가 검증이 필요하다.
```

<a id="fas-09"></a>

## FAS-09 — 드러나는 수선 패치 콘셉트

```text
눈에 보이는 황토색 바느질로 수선한 창작 데님 무릎 패치의 정사각형 의류 세부 이미지를 만든다. 솔기와 바늘땀 경로를 명확히 보여 주고 작은 주름으로 천이 굽는 방식을 드러낸다. 아이보리 배경에서 근접 편집 사진과 부드러운 자연광을 사용한다. 문구, 브랜드 라벨, 의류 강도 주장은 넣지 않는다. 바늘땀을 연결하고 최종 이미지에 바늘은 남기지 않는다. 변수: 허가된 의류 세부, 패치 모양, 실 색상.
```

<a id="fas-10"></a>

## FAS-10 — 신발 색상 연구

```text
사용 허가를 받은 신발 참조 하나로 16:9 세 패널 색상 연구를 만든다. 밑창, 솔기, 끈, 재료, 카메라 각도를 동일하게 하고 [THREE APPROVED COLOR PALETTES]만 적용한다. 중성 배경과 일치하는 스튜디오 빛을 사용한다. 신발 아래에 제공된 색상 이름을 표시한다. 밑창 무늬를 바꾸거나 로고를 추가하거나 성능 사양을 지어내지 않는다. 변수: 참조, 세 팔레트, 라벨. 형상 일관성과 색 정확성은 따로 확인한다.
```
