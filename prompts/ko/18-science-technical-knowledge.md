# 과학, 기술 도해, 해설

Qwen Image 3.0 프롬프트 10개입니다. 생성 전에 대괄호 안의 입력값을 바꾸세요. 따옴표 안의 문구는 정확히 재현하며, 명시적인 요청이 없으면 추가로 번역하지 않습니다. 결과물은 사람이 검토해야 합니다.

<a id="sci-01"></a>

## SCI-01 — 식물 줄기 절개도

```text
[APPROVED DIAGRAM REFERENCES]로 [VERIFIED PLANT STEM STRUCTURE]의 3:4 교육 절개도를 만든다. 주요 횡단면 하나와 확대 조직 삽화 하나를 보여 주고 라벨은 올바른 구조에 연결한다. 절제된 과학 일러스트, 일관된 색, 명확한 여백을 사용한다. 제공된 이름과 단위만 표시한다. 해부학, 축척, 기능, 장식 분자를 지어내지 않는다. 변수: 참조 자료, 라벨, 출처 주석. 분야 전문가가 결과를 검증해야 한다.
```

<a id="sci-02"></a>

## SCI-02 — 기계 결함 도해

```text
[VERIFIED MECHANICAL DRAWING AND FAULT DESCRIPTION]로 16:9 해설 도해를 만든다. 왼쪽은 정상 조립, 오른쪽은 기록된 결함을 보여 주고 영향받은 부품만 강조한다. 구성품 순서, 연결, 형상을 유지한다. 제공된 라벨과 제목 “정상”, “결함 표시”를 쓴다. 제공되지 않은 수리 단계, 토크 값, 전기 조언, 안전 주장은 넣지 않는다. 변수: 도면과 검토된 결함 설명. 엔지니어링 검토가 필요하다.
```

<a id="sci-03"></a>

## SCI-03 — 사람이 검토하는 AI 흐름

```text
“입력”, “모델”, “검토”, “승인된 출력”, “수정”의 정확히 다섯 노드를 가진 16:9 시스템 도해를 만든다. 입력에서 모델, 모델에서 검토, 검토에서 승인된 출력, 검토에서 수정으로 연결하고 수정은 모델로 돌아간다. 왼쪽에서 오른쪽 배치, 남색 상자, 청록색 승인 경로, 호박색 수정 경로를 사용한다. 화살표는 명확히 하고 추가 서비스나 데이터 저장소는 넣지 않는다. 예시 작업 흐름이며 검증된 시스템 아키텍처가 아니다.
```

<a id="sci-04"></a>

## SCI-04 — 기후 데이터 비교

```text
[VERIFIED CLIMATE DATA AND UNCERTAINTY]만 사용해 16:9 차트를 만든다. 제공된 시계열에 라벨 있는 축, 단위, 기준선, 출처 주석을 표시한다. 불확실성은 지정된 띠로 나타내고 결측값은 빈 구간으로 유지한다. 중성 배경과 절제된 파란 계열 하나를 사용한다. 전망, 인과 설명, 기록, 정밀도를 지어내지 않는다. 변수: 데이터셋, 구간 정의, 승인된 제목. 데이터와 차트 해석에는 전문가 검토가 필요하다.
```

<a id="sci-05"></a>

## SCI-05 — 실험실 순서 보드

```text
[APPROVED NON-HAZARDOUS LAB PROCEDURE]만으로 3:4 순서 일러스트를 만든다. 제공된 단계를 정확한 순서와 맞는 장비, 라벨, 단위로 보여 준다. 명확한 기술 일러스트를 사용하고 경고와 행동 라벨을 분리한다. 양, 온도, 시간, 안전 조치, 추가 실험을 지어내지 않는다. 변수: 검토된 절차와 정확한 문구. 결과는 시각 보조이며 승인된 절차나 감독을 대신하지 않는다.
```

<a id="sci-06"></a>

## SCI-06 — 가전 유지관리 개요

```text
[MANUFACTURER-APPROVED USER MAINTENANCE GUIDE]로 16:9 개요를 만든다. 외부에서 접근 가능하고 사용자가 관리할 수 있는 부분과 제공된 작업 순서만 보여 준다. 일정한 방향의 단순한 라벨 일러스트를 사용한다. 경고와 전원 상태 지침을 정확히 유지하고 분해, 배선, 화학물질, 수리 조언을 지어내지 않는다. 변수: 검증된 안내와 가전 참조. 교육에 쓰기 전에 전문가 검토가 필요하며 인증이나 보장은 넣지 않는다.
```

<a id="sci-07"></a>

## SCI-07 — 연구 근거 요약

```text
[REVIEWED STUDY SUMMARY]로 3:4 연구 요약 레이아웃을 만든다. “질문”, “방법”, “발견”, “한계”로 나누고 제공된 문구 그대로와 승인된 차트 하나를 넣는다. 표본 수, 불확실성, 출처를 보이게 한다. 읽기 쉬운 어두운 글자와 절제된 파란 강조를 사용한다. 유의성, 인과관계, 권고, 인용을 지어내지 않는다. 변수: 검증된 요약과 차트 데이터. 전달 콘셉트이며 과학적 동료 심사가 아니다.
```

## SCI-08 — 다중 척도 구조도

```text
[APPROVED LARGE-SCALE OBJECT], [COMPONENT], [DETAIL]을 연결하는 16:9 교육 도해를 만든다. 명확히 분리된 세 패널에 제공된 축척 라벨과 연결된 확대 상자를 사용한다. 실제 포함 관계와 일관된 색 대응을 유지한다. 검토된 라벨, 단위, 출처 문구만 표시한다. 배율, 물리 치수, 인과 화살표를 지어내지 않는다. 변수: 참조 이미지와 정확한 척도 정보. 전문가 검증이 필요하다.
```

<a id="sci-09"></a>

## SCI-09 — 단위 변환 교육 보드

```text
정확히 “1 m = 100 cm”, “1 cm = 10 mm”를 보여 주는 4:3 교육 보드를 만든다. 긴 기준 막대 하나를 큰 열 구간으로 등분하고, 별도의 확대 구간은 작은 열 부분으로 등분한다. 시각 척도가 잘못된 변환을 암시하지 않도록 [TEACHER-APPROVED SCALE MAP]에 지정된 대로만 도해 라벨을 붙인다. 검은 선과 파란 강조 하나를 사용한다. 추가 수식이나 근사 라벨은 넣지 않는다. 교사 검토가 필요하다.
```

