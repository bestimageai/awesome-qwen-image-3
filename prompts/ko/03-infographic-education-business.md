# 인포그래픽, 교육, 비즈니스

Qwen Image 3.0 프롬프트 10개입니다. 생성 전에 대괄호 안의 입력값을 바꾸세요. 따옴표 안의 문구는 정확히 재현하며, 명시적인 요청이 없으면 추가로 번역하지 않습니다. 결과물은 사람이 검토해야 합니다.

<a id="edu-01"></a>

## EDU-01 — 빗물의 여행

```text
“빗물은 어디로 갈까”라는 16:9 수업용 인포그래픽을 만든다. 왼쪽에서 오른쪽으로 지붕 하나, 연결된 홈통 하나, 뚜껑 덮인 빗물통 하나, 식물이 심어진 빗물 정원 하나를 네 단계로 명확히 보여 준다. 파란 물 흐름 화살표로 지붕에서 홈통, 물통까지 연결하고, 물통에서 정원으로는 별도의 넘침 화살표를 둔다. 정확한 물체 옆에 “지붕”, “홈통”, “저장”, “빗물 정원”만 표시한다. 크림색 배경과 간단한 절개 일러스트를 사용한다. 식수 사용을 보여 주거나 용량을 지어내지 않는다. 화살표는 명확하게, 물통은 닫힌 상태로 유지한다.
```

<a id="edu-02"></a>

## EDU-02 — 도시 그늘 비교

```text
같은 태양 각도 아래의 가상 거리 두 구간을 비교하는 16:9 교육 도해를 만든다. 왼쪽에는 나무가 없고 오른쪽에는 다 자란 나무 두 그루가 보도에 그늘을 드리운다. 건물, 도로 폭, 보행자를 동일하게 하고 간단한 건축 일러스트와 명확한 그림자 범위를 사용한다. 패널 라벨은 “직사광선”, “나무 그늘”이다. 온도, 백분율, 건강 효과를 추가하지 않는다. 태양 방향을 일치시키고 그늘이 모든 열을 없앤다고 암시하지 않는다. 변수: 거리 형태와 승인된 라벨.
```

<a id="edu-03"></a>

## EDU-03 — 씨앗 성장 관찰 활동지

```text
콩 씨앗을 관찰하는 어린이용 세로 3:4 활동지를 만든다. 같은 크기의 칸 네 개에 씨앗, 뿌리가 나오는 모습, 첫 싹, 잎 두 장을 그린다. 각 칸 아래에 줄이 있는 관찰 기록 영역을 비워 둔다. 선명한 회색조 선화와 큰 글자를 사용한다. “씨앗이 자라는 모습을 관찰해요”, “1”, “2”, “3”, “4”, “나의 관찰”만 표시한다. 지난 일수를 지정하지 말고 생물학적 순서를 명확히 한다. 답란을 채우거나 장식용 가짜 글자를 넣지 않는다. 변수: 승인된 식물 종과 활동지 제목.
```

<a id="edu-04"></a>

## EDU-04 — 분수 막대 비교

```text
동일한 가로 막대 세 개를 보여 주는, 회색조에서도 읽기 쉬운 3:4 학습지를 만든다. 각각 2등분, 4등분, 8등분하고 1칸, 2칸, 4칸을 칠한다. 행 라벨은 “1/2”, “2/4”, “4/8”, 제목은 “나눈 조각은 달라도 양은 같아요”다. 막대의 시작과 끝을 정확히 맞추고 아래쪽 4분의 1은 토론 메모용으로 비워 둔다. 명확한 검은 윤곽선과 한 가지 회색 채움을 사용한다. 원, 고르지 않은 칸, 답안 버블, 추가 수식은 넣지 않는다.
```

<a id="edu-05"></a>

## EDU-05 — 월간 서비스 대시보드

```text
[VERIFIED MONTHLY TABLE]만 사용해 16:9 대시보드 콘셉트를 만든다. 제공된 핵심 지표를 왼쪽에, 꺾은선그래프를 오른쪽에 놓고 아래에는 라벨이 있는 보조 수치 세 개를 표시한다. 흰 배경, 차콜 글자, 파란 데이터 계열 하나를 사용한다. 표의 날짜, 단위, 출처 주석을 정확히 표시한다. 결측값은 빈 구간으로 남기고 보간하거나 비교를 지어내지 않는다. 축은 제공된 눈금과 일치해야 하며 단위를 보여 줘야 한다. 변수: 표, 지표 이름, 출처, 기간.
```

<a id="edu-06"></a>

## EDU-06 — 세 단계 로드맵

```text
[APPROVED INITIATIVES]를 사용해 16:9 제품 로드맵을 만든다. 같은 너비의 세 열에 “현재”, “다음”, “검토 중”이라는 제목을 달고 각각 추진 과제 카드를 최대 세 개 놓는다. 깔끔한 편집 격자, 크림색 카드, 차분한 파란 강조색을 사용하고 명시적으로 제공된 의존 관계만 연결한다. 바닥글에 “계획을 보여 주는 자료이며 출시 약속이 아닙니다”를 넣는다. 날짜, 완료 상태, 담당자, 약속을 지어내지 않는다. 모든 과제를 제공된 열에 유지한다. 변수: 추진 과제 목록과 의존 관계 목록.
```

## EDU-07 — 박물관 관람 경로 지도

```text
승인된 평면도와 [ROOM LABELS]로 세로형 관람 지도 콘셉트를 만든다. 입구, 계단, 승강기, 벽, 무장애 경로를 정확히 유지하고 장식적 세부만 단순화한다. 제공된 경로 하나를 끊김 없는 파란 선으로 강조하고 시작과 끝을 표시한다. 제공된 기호로 명확한 범례를 만들고 승인된 방 이름만 쓴다. 출구, 접근성 시설, 축척을 지어내지 않는다. “그림 안내 — 현장에서 확인하세요”를 포함한다. 변수: 평면도, 경로, 라벨. 게시 전에 시설의 검토가 필요하다.
```

## EDU-08 — 도서관 서비스 청사진

```text
도서관 자료 대출을 위한 16:9 서비스 청사진을 만든다. 열은 “찾기”, “예약”, “수령”, “반납” 네 개, 행은 “이용자”, “도서관”, “시스템” 세 개로 한다. 셀에는 [APPROVED ACTIONS]만 채우고 제공된 인계 관계에만 화살표를 그린다. 절제된 파란 선, 흰 셀, 큰 글자를 사용한다. 이용자의 행동과 내부 작업을 구별한다. 처리 시간을 지어내거나 개인 데이터를 넣지 말고, 행동을 장식용 아이콘으로 대체하지 않는다. 변수: 행동 행렬과 검증된 인계 관계.
```

## EDU-09 — 워크숍 잔여 좌석 차트

```text
월요일 8석, 화요일 12석, 수요일 6석이라는 가상 데이터로 4:3 정보 카드를 만든다. 제목은 “워크숍 잔여 좌석”으로 하고 공통의 0 시작 눈금에 가로 막대 세 개를 그린 뒤 막대 끝에 정확한 값을 표시한다. 흰 바탕에 남색 라벨과 황토색 막대를 사용한다. 바닥글에 “예시 데이터”를 넣는다. 좌석을 참석 인원이나 백분율로 바꾸지 말고 막대 순서도 바꾸지 않는다. 12석 막대 길이는 6석 막대의 두 배여야 한다.
```

## EDU-10 — 의사결정나무 교육 카드

```text
[TEACHER-APPROVED QUESTIONS AND OUTCOMES]로 가상의 식물 돌보기 수업용 3:4 의사결정나무 카드를 만든다. 맨 위에 시작 질문 하나, 아래에 분기 질문 두 개, 맨 아래에 제공된 결과를 놓는다. 가지에는 “예”, “아니요”를 표시하고 일관된 둥근 상자와 넓은 여백을 사용한다. 모든 조건과 종료 지점을 유지하며 물 주는 양, 진단, 품종별 조언을 지어내지 않는다. 승인된 문구와 제목만 표시한다. 변수: 정확한 나무 구조, 식물 맥락, 제목. 교사 검토가 필요하다.
```
