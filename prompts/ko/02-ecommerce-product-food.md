# 전자상거래, 제품, 음식

Qwen Image 3.0 프롬프트 10개입니다. 생성 전에 대괄호 안의 입력값을 바꾸세요. 따옴표 안의 문구는 정확히 재현하며, 명시적인 요청이 없으면 추가로 번역하지 않습니다. 결과물은 사람이 검토해야 합니다.

<a id="com-01"></a>

## COM-01 — 모듈형 책상 스탠드 대표 이미지

```text
가상의 모듈형 책상 스탠드의 정사각형 카탈로그 사진을 만든다. 무광 버터색 스탠드 하나에 원통형 무게추 받침대, 단일 경첩식 암, 얕은 원뿔형 갓을 사용한다. 아이보리 탁상에 놓고 받침대 옆에 코발트색 수리용 손잡이를 둔다. 왼쪽 위의 부드러운 빛과 은은한 접촉 그림자를 사용한다. 유일한 문구는 받침대의 “LATCH”와 왼쪽 위 여백의 “빛을 오래 간직하세요”다. 관절은 타당하게 유지하고 전원선은 하나만 둔다. 인증 배지, 가격, 추가 부품은 넣지 않는다. 변수: 마감과 승인된 브랜드 문구.
```

<a id="com-02"></a>

## COM-02 — 도시락통 제품 뷰

```text
사용 허가를 받은 제품 사진 한 장을 형상 기준으로 삼아, 같은 직사각형 도시락통의 네 가지 동일 크기 뷰를 담은 16:9 프레젠테이션을 만든다. 닫힌 정면, 닫힌 후면, 열린 상태의 위쪽 뷰, 잠금장치 접사를 보여 준다. 옅은 무한 배경과 동일한 부드러운 조명을 사용한다. 라벨은 “앞면”, “뒷면”, “내부”, “잠금장치”만 쓴다. 모든 뷰에서 칸 수, 밀폐 패킹 색상, 잠금장치 위치를 유지하고 치수나 소재 주장을 지어내지 않는다. 패널 사이에 눈에 보이는 간격을 둔다. 변수: 제품 참조와 번역된 라벨.
```

<a id="com-03"></a>

## COM-03 — 세 가지 차 통

```text
동일한 원통형 형태를 공유하는 가상의 차 통 세 개를 위한 3:2 패키지 콘셉트를 만든다. 크림색, 연보라색, 세이지색 라벨 띠를 각각 사용해 일렬로 배열한다. 공통 브랜드는 “Field Notes”, 각 이름은 “아침”, “정오”, “저녁”으로 하고 다른 문구는 넣지 않는다. 중성색 선반에서 촬영하며 하이라이트와 크기 비율을 일치시킨다. 세 통의 뚜껑, 글자 정렬, 라벨 너비를 동일하게 유지한다. 원재료, 원산지, 건강 효능을 주장하지 않는다. 변수: 승인된 브랜드, 이름, 색상.
```

<a id="com-04"></a>

## COM-04 — 배낭 기능 보드

```text
사용 허가를 받은 배낭 참조와 제공된 기능 설명 세 개로 3:4 제품 정보 이미지를 만든다. 왼쪽에 배낭 전체를 놓고 오른쪽에 세부 원형 확대창 세 개를 세로로 정렬해 각각 해당 지퍼, 어깨끈, 옆주머니에만 연결한다. 알맞은 원 옆에 [APPROVED FEATURE LABELS]를 정확히 표시한다. 옅은 회색 배경과 제어된 스튜디오 조명을 사용한다. 실제 구조와 색상을 유지하고 명시적으로 제공되지 않은 방수, 용량, 인체공학 주장은 하지 않는다. 변수: 참조, 라벨, 강조색.
```

<a id="com-05"></a>

## COM-05 — 빵 만들기 과정

```text
가상의 제과점에서 사워도우를 만드는 과정을 담은 16:9 네 칸 이미지를 만든다. 반죽 섞기, 반죽 접기, 성형한 반죽에 칼집 내기, 구운 빵 보여 주기를 순서대로 담는다. 같은 나무 작업대의 근접 다큐멘터리 사진, 왼쪽에서 오른쪽으로 읽는 순서, 일관된 밀가루 묻은 손을 사용한다. 라벨은 “섞기”, “접기”, “칼집 내기”, “굽기”다. 정확히 네 칸을 유지하고 생반죽과 구운 껍질을 구분한다. 조리 온도나 시간을 추가하지 않는다. 이는 과정 설명 콘셉트이며 식품 안전 지침이 아니다. 변수: 반죽 종류와 승인된 라벨.
```

<a id="com-06"></a>

## COM-06 — 점심 메뉴 모음

```text
사실적인 점심 그릇 네 개를 2×2 격자로 배열한 16:9 수직 탑뷰 카탈로그 이미지를 만든다. 구운 호박과 밥, 버섯과 면, 렌틸콩과 당근, 토마토와 쿠스쿠스를 담는다. 동일한 얕은 흰 그릇, 구별되는 질감, 부드러운 자연광, 차분한 녹색 탁자를 사용한다. 간격을 같게 하고 식기가 겹치지 않게 한다. 문구, 열량, 식단 적합성 보장, 재료 라벨을 추가하지 않는다. 양은 타당하게 하고 음식 질감을 반복하지 않는다. 변수: 제공된 네 가지 레시피, 그릇 마감, 탁상 색상.
```

<a id="com-07"></a>

## COM-07 — 두 언어 면 요리 메뉴

```text
가상의 식당 “小巷面馆”을 위한 3:4 메뉴를 만들고 부제는 “LANE NOODLES”로 한다. 아이보리 종이, 차콜 글자, 가로 세 줄을 사용한다. 각 줄 왼쪽에 작은 사실적 면 그릇 사진, 오른쪽에 해당 문구를 배치한다. “番茄面 · Tomato noodles · 28”, “菌菇面 · Mushroom noodles · 32”, “芝麻面 · Sesame noodles · 30”를 정확히 표시한다. 빨간 토마토 국물, 버섯 고명, 참깨 소스가 각 줄에 맞도록 한다. 통화 기호, 알레르기 유발 물질, 추가 메뉴, 주장을 넣지 않는다. 가상의 메뉴 문구이므로 두 언어를 정확히 그대로 유지한다.
```

<a id="com-08"></a>

## COM-08 — 실내 패브릭 비교

```text
사용 허가를 받은 실내 사진 한 장으로 16:9 두 패널 비교를 만든다. 왼쪽은 원본을 재현하고 오른쪽은 소파 덮개와 쿠션 두 개만 [APPROVED COLORS]로 바꾼다. 창문, 벽, 가구 위치, 카메라 각도, 빛은 그대로 둔다. 사진 바깥의 얇은 테두리에 “원본”, “패브릭 콘셉트”를 표시한다. 천의 주름과 접촉 그림자를 유지하고 방을 수리하거나 개인 물건을 치우거나 추가 장식을 지어내지 않는다. 변수: 원본 이미지와 색상.
```

<a id="com-09"></a>

## COM-09 — 리필 포장 사용법

```text
세 패널을 세로로 쌓은 3:4 포장 사용 콘셉트를 만든다. 빈 병 옆의 리필 파우치, 파우치 주둥이에서 병으로 따르는 모습, 닫힌 병 옆에 접어 둔 빈 파우치를 보여 준다. 모든 패널에서 같은 무브랜드 호박색 병과 아이보리 파우치를 사용하고, 깔끔한 기술 일러스트와 세이지색 화살표로 표현한다. “열기”, “채우기”, “닫기”만 표시한다. 정확히 세 단계로 유지하고 액체를 흘리거나 따르는 방향을 뒤집지 않는다. 식품이나 화학물질과의 적합성을 암시하지 않는다. 변수: 검증된 용기 설계와 승인된 안내 라벨.
```

<a id="com-10"></a>

## COM-10 — 세트 구성품 플랫레이

```text
[APPROVED CONTENTS LIST]와 사용 허가를 받은 제품 참조를 사용해, 입문용 문구 세트에 포함된 각 물건을 정확히 하나씩 보여 주는 정사각형 플랫레이를 만든다. 노트를 가운데 놓고 작은 물건을 주위에 넉넉한 간격으로 배치하며 따뜻한 종이 질감과 부드러운 위쪽 빛을 사용한다. 제목 “세트 구성품”과 각 물체에 정렬된 제공된 품목명만 넣는다. 물건 수, 상대적 크기, 색상을 유지한다. 목록에 없는 사은품, 가격, 보증 표시, 부속품을 추가하지 않는다.
```
