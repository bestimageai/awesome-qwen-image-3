# 인터페이스, 범위 제한 편집, 현지화

Qwen Image 3.0 프롬프트 10개입니다. 생성 전에 대괄호 안의 입력값을 바꾸세요. 따옴표 안의 문구는 정확히 재현하며, 명시적인 요청이 없으면 추가로 번역하지 않습니다. 결과물은 사람이 검토해야 합니다.

<a id="dig-01"></a>

## DIG-01 — 공구 도서관 모바일 인터페이스

```text
가상의 앱 “Borrow Bench”의 목록, 물품 상세, 예약 확인이라는 모바일 화면 세 개를 보여 주는 16:9 보드를 만든다. 아이보리 배경, 남색 글자, 청록색 작업 버튼, 일관된 둥근 카드를 사용한다. 선택된 물품은 노란 드릴이다. 알맞은 화면에 “Borrow Bench”, “공구 찾기”, “충전 드릴”, “예약”, “수령 시간”, “토요일 10:00”, “예약이 저장되었습니다”, “예약 보기”만 표시한다. 가격, 개인 정보, 추가 탐색 라벨은 넣지 않는다. 정지 인터페이스 콘셉트이며 실제 작동하는 조작부라고 암시하지 않는다.
```

## DIG-02 — CSV 가져오기 검토 화면

```text
가상의 재고 앱 “Stockroom”을 위한 16:9 데스크톱 인터페이스 목업을 만든다. “품목”, “수량”, “상태” 열이 있는 가져오기 검토 표를 보여 주고 제공된 예시 세 행 중 하나를 “검토 필요”로 뚜렷하게 표시한다. 표 위에는 “가져올 내용을 검토하세요”, 아래에는 “뒤로”, “유효한 행 가져오기” 버튼을 둔다. 깨끗한 흰 레이아웃, 호박색 오류 강조, “재고”만 있는 읽기 쉬운 사이드바를 사용한다. 제공된 데이터를 유지하고 개인 정보는 표시하지 않는다. 변수: 예시 행과 승인된 문구.
```

## DIG-03 — 지역 철도 홈페이지

```text
가상의 여행 계획 서비스 “Local Lines”의 16:9 데스크톱 홈페이지 콘셉트를 만든다. 오른쪽에 큰 해안 열차 사진, 왼쪽에 실용적인 검색 패널을 배치한다. “조금 느린 길로 떠나요”, “출발지”, “도착지”, “여행 날짜”, “여정 찾기”를 정확히 표시하고 입력칸은 비워 둔다. 크림색 배경, 짙은 녹색 조작부, 넉넉한 간격을 사용한다. 실제 시간표, 운임, 운행사 로고, 이용 가능성 주장은 넣지 않는다. 열차는 물리적으로 타당해야 하며 인터페이스 문구는 사진과 분리한다. 변수: 지역 이미지와 승인된 제목.
```

## DIG-04 — 협동 게임 HUD

```text
가상의 산악 배달 게임을 위한 16:9 정지 HUD 콘셉트를 만든다. 눈 덮인 길의 중앙 60퍼센트를 가리지 않는다. 위쪽에 작은 나침반, 왼쪽 위에 팀원 상태 막대 두 개, 오른쪽 아래에 물품 슬롯 세 개를 둔다. “북”, “팀”, “소포”, “밧줄”, “지도”만 표시한다. 대비가 높은 형태와 절제된 호박색 강조를 사용하고 영화 같은 공중 홀로그램은 쓰지 않는다. 실제 군대 휘장, 읽을 수 없는 미세 글자, 과도한 오버레이를 피한다. 변수: 게임 배경과 승인된 라벨.
```

## DIG-05 — 포스터 문구 교체

```text
이미지 1을 편집 대상으로 삼고 [APPROVED SOURCE-TO-TARGET TEXT MAP]만 교체 문구로 사용한다. 지정된 포스터 글자를 교체하되 사진, 일러스트, 색상 구성, 여백, 로고, 대상이 아닌 문구는 바꾸지 않는다. 글자 굵기와 위계를 유지하고 대상 언어가 요구할 때만 줄바꿈을 조정한다. 문장 부호, 발음 구별 기호, 읽는 방향을 정확히 유지한다. 기존 글자는 제거하고 중복시키지 않는다. 지정하지 않은 문구를 번역하거나 설명을 넣지 않는다. 변수: 원본 이미지와 완전한 문구 대응표.
```

## DIG-06 — 사진 손상 복원

```text
사용 허가를 받은 스캔 사진 한 장을 편집 대상으로 삼는다. 보이는 먼지, 흠집, 접힘 손상만 복원하고 작은 누락 영역은 주변 질감에서 재구성한다. 인물 정체성, 나이, 표정, 자르기, 의상, 원본 입자, 명암 범위를 유지한다. 흑백 원본에 색을 입히거나 피부를 매끈하게 하거나 감은 눈을 뜨게 하거나 배경 물체를 지어내지 않는다. 불확실한 큰 누락 영역은 세부를 날조하지 말고 그대로 둔다. 비교 라벨이나 워터마크 없는 복원 이미지 한 장을 출력한다. 변수: 원본 사진과 명확히 표시한 복원 영역.
```

## DIG-07 — 세 참조 이미지 제품 합성

```text
이미지 1은 기본 탁상 장면, 이미지 2는 도자기 컵의 정확한 참조, 이미지 3은 유약 색상 참조로만 사용한다. 이미지 2의 컵 하나를 이미지 1의 빈 컵받침에 놓고 제공된 유약 색조만 적용한다. 기본 카메라, 자르기, 주변 물체, 컵 형상을 유지한다. 빛 방향, 접촉 그림자, 원근, 반사를 맞춘다. 이미지 3의 물체나 문구는 복사하지 않는다. 문구는 넣지 않는다. 변수: 사용 허가를 받은 이미지 세 장과 의도한 컵 위치.
```

## DIG-08 — 스케치에서 독서실로

```text
승인된 방 스케치를 배치 참조로 사용한다. 옅은 참나무 선반, 이끼색 벤치, 확산된 천장 빛을 갖춘 4:3 사실적 독서실 콘셉트를 만든다. 스케치의 모든 벽, 창문, 출입구, 가구 점유 면적을 보존하고 재료 팔레트는 기존 표면을 마감하는 데만 쓴다. 원근을 일관되게 하고 통로 폭이 시각적으로 변하지 않게 한다. 사람, 추가 가구, 식물, 표지판은 넣지 않는다. 이는 설명용 콘셉트이며 실측 시공 도면이 아니다. 변수: 스케치와 승인된 재료.
```

## DIG-09 — 접근성을 고려한 빈 상태

```text
저장된 읽기 목록이 비어 있는 상태를 위한 3:4 모바일 인터페이스 목업을 만든다. 크림색 배경, 남색 글자, 닫힌 책 세 권의 작은 일러스트를 사용한다. “아직 저장한 글이 없어요”, “유용한 글을 한곳에 모아 보세요”, “글 둘러보기”를 정확히 표시한다. 제목 아래에 설명, 그 아래에 큰 버튼을 놓고 편안한 여백을 둔다. 대비를 높이고 작은 글자, 로딩 스켈레톤, 가짜 글 카드, 알림 배지는 넣지 않는다. 정적인 디자인 제안이며 접근성은 구현 후 테스트가 필요하다.
```

## DIG-10 — 언어 읽기 방향 비교

```text
[APPROVED ENGLISH AND ARABIC COPY]로 16:9 나란한 인터페이스 타이포그래피 보드를 만든다. 왼쪽 패널은 왼쪽에서 오른쪽 정렬, 오른쪽은 자연스러운 오른쪽에서 왼쪽 정렬을 사용한다. 읽기 순서를 조정하면서 같은 구성 요소 위계, 간격, 두 버튼의 역할을 유지한다. 제품 사진은 좌우 반전하지 않고 그대로 둔다. 제공된 문자열만 표시하며 아랍어 글자는 올바르게 이어 쓰고 라틴 문자 브랜드명은 온전히 유지한다. 음역, 원문 중복, 문구 창작은 하지 않는다. 변수: 쌍을 이루는 문자열과 구성 요소 라벨. 아랍어에 능숙한 사람의 검토가 필요하다.
```
