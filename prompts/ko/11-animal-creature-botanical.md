# 동물, 상상 속 생물, 식물 연구

Qwen Image 3.0 프롬프트 10개입니다. 생성 전에 대괄호 안의 입력값을 바꾸세요. 따옴표 안의 문구는 정확히 재현하며, 명시적인 요청이 없으면 추가로 번역하지 않습니다. 결과물은 사람이 검토해야 합니다.

<a id="nat-01"></a>

## NAT-01 — 참조 기반 반려동물 초상

```text
사용 허가를 받은 반려동물 사진으로 무지 따뜻한 회색 배경의 3:4 초상을 만든다. 털무늬, 눈 색, 귀 모양, 몸집, 자연스러운 표정을 유지한다. 부드러운 창빛과 동물 해부학에 맞는 편안한 앉은 자세를 사용한다. 수염, 발, 털 가장자리를 자세하게 유지하되 과도하게 매끈하게 하지 않는다. 옷, 사람 같은 손, 문구는 넣지 않으며 참조에 없는 목줄도 추가하지 않는다. 변수: 반려동물 참조와 승인된 배경색.
```

<a id="nat-02"></a>

## NAT-02 — 판타지 습지 생물

```text
수달 같은 비율, 이끼색 털, 넓은 물갈퀴 발을 가진 창작 소형 습지 생물의 16:9 콘셉트 시트를 만든다. 옅은 배경에서 정면, 측면, 사선 뷰를 보여 주고 해부학과 무늬를 동일하게 유지한다. 설득력 있는 자연사 일러스트를 사용하고 문구는 넣지 않는다. 알려진 가상 캐릭터를 복제하거나 일관되지 않은 뿔, 팔다리, 날개를 추가하지 않는다. 변수: 창작 생물 설명과 서식지 색상 구성. 상상 속 생물이며 실제 종이 아니다.
```

<a id="nat-03"></a>

## NAT-03 — 꽃가루 매개 동물 관찰 도판

```text
[VERIFIED SPECIES REFERENCES]로 꽃가루 매개 동물 하나와 승인된 기주 꽃을 나란히 보여 주는 4:3 교육 도판을 만든다. 관련 먹이 섭취 구조의 확대 삽화를 넣고 가는 선 하나로 정확한 위치에 연결한다. 제공된 종 이름과 라벨만 표시한다. 정밀한 자연사 일러스트, 흰 배경을 사용하고 축척 표기는 제공된 경우에만 일관되게 넣는다. 해부학, 생태 주장, 장식용 과학 기호를 지어내지 않는다. 변수: 참조, 라벨, 출처 주석. 전문가 검토가 필요하다.
```

<a id="nat-04"></a>

## NAT-04 — 숲속 야생동물 장면

```text
새벽에 쓰러진 자작나무 줄기 옆에 멈춘 붉은여우 한 마리의 16:9 가상 숲 장면을 만든다. 사실적인 털, 절제된 안개, 나무 사이의 낮은 따뜻한 빛을 사용한다. 발은 울퉁불퉁한 땅에 닿고 귀는 자연스럽게 경계하게 한다. 의인화 표정, 다친 먹잇감, 인간 물건, 문구는 넣지 않는다. 나무 패턴 반복과 과장된 신체 비율을 피한다. 변수: 종, 계절, 승인된 서식지 세부. 실제 야생동물 사진이라고 표시하지 않는다.
```

<a id="nat-05"></a>

## NAT-05 — 동물 동작 연구

```text
[VERIFIED ANATOMICAL REFERENCES]로 집고양이가 왼쪽에서 오른쪽으로 걷는 16:9 네 패널 연구를 만든다. 털무늬, 크기, 카메라 높이, 배경을 동일하게 한다. 승인된 서로 다른 보행 네 단계를 타당한 체중 이동과 지면에 닿은 발로 보여 준다. 패널 라벨은 “1”부터 “4”뿐이다. 팔다리 위치를 지어내거나 추가 테스트 없이 애니메이션용 프레임이라고 제시하지 않는다. 변수: 참조와 보행 순서.
```

<a id="nat-06"></a>

## NAT-06 — 잎 식별 학습지

```text
[VERIFIED LEAF REFERENCES]로 3:4 식물 학습지를 만든다. 잎 여섯 장을 2×3 격자에 놓고 각 아래에 제공된 일반명을 표시한다. 잎몸 형태, 가장자리, 잎맥, 잎자루 연결을 유지하며 동일한 중성 조명과 무지 아이보리 배경을 사용한다. 종 이름, 약용 용도, 상대적 축척을 지어내지 않는다. 승인된 제목과 라벨만 넣는다. 변수: 여섯 참조와 이름 대응표. 식물 식별은 검토가 필요하다.
```

<a id="nat-07"></a>

## NAT-07 — 식물 생활사 도해

```text
[VERIFIED PLANT SPECIES]의 [APPROVED STAGES]를 사용해 16:9 생활사 일러스트를 만든다. 씨앗부터 제공된 성체 형태까지 정확히 다섯 단계를 왼쪽에서 오른쪽으로 간단한 화살표로 연결한다. 자연스러운 수채 세부와 각 단계 아래 명확한 라벨을 사용한다. 종 특유의 잎, 뿌리, 열매를 유지하고 기간이나 재배 조언을 지어내지 않는다. 변수: 참조 자료, 단계, 정확한 라벨. 교육 도해로 유지하며 분야 전문가 검토가 필요하다.
```

<a id="nat-08"></a>

## NAT-08 — 수족관 서식지 콘셉트

```text
둥근 돌, 수생 식물, 제공된 같은 종의 작은 물고기 세 마리가 있는 4:3 가상 담수 서식지 콘셉트를 만든다. 명확한 측면, 자연스러운 수중 빛, 타당한 축척을 사용한다. 물고기 해부학을 일관되게 하고 과밀이나 부적합한 종 조합을 피한다. 장비 주장, 입식 조언, 라벨, 장식 보물상자는 넣지 않는다. 변수: 검증된 종 참조와 서식지 설명. 이 일러스트는 동물 관리 권고가 아니다.
```

<a id="nat-09"></a>

## NAT-09 — 씨앗 봉투 일러스트

```text
[VERIFIED PLANT REFERENCE]로 가상 씨앗 봉투의 3:4 앞면 콘셉트를 만든다. 꽃 핀 줄기 하나와 작은 씨앗 삽화를 보여 주고 위쪽 4분의 1은 [APPROVED PLANT NAME]을 위해 비워 둔다. 크림 종이에 창작 식물 과슈를 사용한다. 제공된 이름과 “일러스트 습작”만 표시한다. 제공되지 않은 발아율, 원산지, 인증, 심기 지침, 무게는 넣지 않는다. 꽃과 잎 형태를 유지한다. 변수: 참조, 이름, 색상 구성.
```

<a id="nat-10"></a>

## NAT-10 — 도시 새 관찰 카드

```text
[VERIFIED BIRD SPECIES]의 정사각형 관찰 카드를 만든다. 옅은 배경에 앉아 있는 측면과 더 작은 날개 세부 삽화 하나를 보여 준다. 정확한 부리, 발, 깃털을 가진 자연사 일러스트를 사용한다. 승인된 일반명과 제공된 세 관찰 라벨만 표시하고 올바른 특징에 연결한다. 희귀성, 이동 날짜, 보전 상태를 지어내지 않는다. 변수: 참조 자료, 라벨, 출처 주석. 사람이 검증해야 한다.
```
