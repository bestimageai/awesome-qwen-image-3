# 건축, 실내, 부동산 콘셉트

Qwen Image 3.0 프롬프트 10개입니다. 생성 전에 대괄호 안의 입력값을 바꾸세요. 따옴표 안의 문구는 정확히 재현하며, 명시적인 요청이 없으면 추가로 번역하지 않습니다. 결과물은 사람이 검토해야 합니다.

<a id="arc-01"></a>

## ARC-01 — 작은 독서 공간

```text
계단 아래의 아담한 독서 공간을 담은 4:3 건축 실내 이미지를 만든다. 붙박이 참나무 벤치 하나, 얕은 책장, 둥근 벽등, 접힌 파란 방석을 보여 준다. 타당한 인체 척도, 곧은 수직선, 화면 밖 창에서 들어오는 부드러운 자연광을 사용한다. 사용 가능한 머리 위 공간과 통행 공간을 유지한다. 사람, 문구, 불가능한 캔틸레버, 과도하게 큰 가구는 넣지 않는다. 변수: 방 치수, 승인된 재료, 색상 구성. 디자인 일러스트이며 시공 문서가 아니다.
```

<a id="arc-02"></a>

## ARC-02 — 제과점 카운터 개조

```text
사용 허가를 받은 제과점 실내 사진 한 장을 편집 대상으로 삼는다. 카운터 앞면만 옅은 세로 목재 슬랫으로, 뒤 벽만 차분한 파랑으로 바꾼다. 카운터 치수, 진열 유리, 문, 천장 설비, 카메라 각도, 모든 기존 문구를 유지한다. 반사와 접촉 그림자를 원래 빛에 맞춘다. 제품을 추가하거나 장비를 제거하거나 방을 넓히지 않는다. 변수: 원본 사진과 승인된 표면 마감. 전후 비교 라벨 없는 콘셉트 이미지 하나를 출력한다.
```

<a id="arc-03"></a>

## ARC-03 — 가구 평면 배치 렌더링

```text
[APPROVED FLOOR PLAN]으로 수직 탑뷰 4:3 가구 배치 일러스트를 만든다. 모든 벽, 개구부, 계단, 제공된 치수를 유지한다. [APPROVED FURNITURE LIST]의 물건만 지정 위치에 일관된 축척과 부드러운 중성 음영으로 놓는다. 이동 경로를 보이게 하고 제공된 방 이름만 표시한다. 치수를 지어내거나 벽을 옮기거나 법규 준수를 암시하지 않는다. 변수: 평면도, 가구 위치, 라벨. 공간 정확성은 별도로 확인한다.
```

<a id="arc-04"></a>

## ARC-04 — 블루아워 외관 편집

```text
사용 허가를 받은 부동산 사진을 편집 대상으로 삼는다. 시간대만 블루아워 초반으로 바꾸고 기존 창문 안에서 부드러운 따뜻한 빛이 보이게 한다. 명시된 경우 외에는 건물, 조경, 이웃 구조물, 카메라 위치, 기상 조건을 유지한다. 하늘 밝기와 창 반사는 물리적으로 타당하게 한다. 조명을 추가하거나 결함을 숨기거나 조망을 바꾸지 않는다. 문구나 부동산 주장은 넣지 않는다. 변수: 원본 이미지와 승인된 조명 처리. 게시 시 시각화 이미지로 표시한다.
```

<a id="arc-05"></a>

## ARC-05 — 객실 정보 카드

```text
[VERIFIED ROOM PLAN AND AMENITIES]로 3:4 숙박 정보 카드를 만든다. 단순화한 방 일러스트 아래에 제공된 짧은 시설 목록을 둔다. 침대 수, 욕실 위치, 창문 위치를 유지한다. 따뜻한 중성색, 큰 글자, 승인된 라벨만 사용한다. 바다 전망, 접근성 시설, 별점, 치수, 예약 가능 여부를 지어내지 않는다. 제목 아래에 “그림으로 보는 객실 안내”를 넣는다. 변수: 검증된 평면도, 시설 목록, 승인된 제목.
```

<a id="arc-06"></a>

## ARC-06 — 재료 팔레트 보드

```text
“고요한 작업장”이라는 16:9 실내 재료 보드를 만든다. 옅은 참나무, 브러시드 알루미늄, 파란 울, 따뜻한 석고, 반점 도자기라는 서로 다른 샘플 다섯 개를 배치한다. 사실적인 질감과 두께, 부드러운 방향성 그림자, 깨끗한 크림 배경을 사용한다. 각 샘플 아래에 재료명을 정확히 한 번 표시한다. 샘플 크기는 시각적으로 균형 있게 하되 실제 축척이 같다고 암시하지 않는다. 공급사 브랜드, 환경 인증, 성능 주장은 넣지 않는다. 변수: 재료, 라벨, 프로젝트 제목.
```

<a id="arc-07"></a>

## ARC-07 — 전시 관람 동선

```text
[APPROVED EXHIBITION PLAN]으로 16:9 축측 일러스트를 만든다. 모든 칸막이 벽, 입구, 제공된 설치물을 유지한다. 승인된 관람 경로 하나를 파란 선과 방향 화살표로 표시하고, 비상 경로는 제공된 경우에만 시각적으로 구별한다. [APPROVED ZONE NAMES]로 구역을 표기한다. 중성 건축 음영을 사용하고 장식적인 군중은 넣지 않는다. 비상구, 접근성, 수용 인원을 지어내지 않는다. 변수: 평면도, 경로, 라벨. 사용 전 시설 검토가 필요하다.
```

<a id="arc-08"></a>

## ARC-08 — 마당의 사계절

```text
동일한 작은 마당의 봄, 여름, 가을, 겨울을 담은 16:9 네 패널 조경 콘셉트를 만든다. 카메라, 돌길, 벤치, 나무 위치, 건물 벽을 고정한다. [VERIFIED CLIMATE]에 맞는 식생 모습, 자연광, 계절별 지면 상태만 바꾼다. 각 계절을 한 번씩 표시한다. 사실적인 건축 시각화를 사용하고 패널 사이에 물체를 옮기지 않는다. 연중 개화나 성목 성장 속도를 지어내지 않는다. 변수: 승인된 식재 목록과 기후.
```

<a id="arc-09"></a>

## ARC-09 — 매장 시선 연구

```text
승인된 평면도 하나로 16:9 두 패널 매장 배치 콘셉트를 만든다. 두 패널 모두 입구에서 같은 눈높이로 본다. 왼쪽은 현재 선반 배치, 오른쪽은 [APPROVED NEW POSITIONS]만 사용한다. 건축, 선반 치수, 재고 분류, 조명은 그대로 둔다. 이미지 바깥에 “현재”, “제안”을 표시한다. 매출 개선, 접근성 주장, 추가 바닥 면적을 지어내지 않는다. 변수: 평면도와 승인된 가구 이동.
```

<a id="arc-10"></a>

## ARC-10 — 창가 좌석 자연광 연구

```text
같은 창가 좌석을 아침, 정오, 늦은 오후에 보여 주는 3:2 세 패널 자연광 연구를 만든다. 같은 방, 방석, 카메라 위치, 창 방향을 사용한다. [SUPPLIED ORIENTATION AND LOCATION]에 따라 빛의 방향과 강도만 바꾼다. 해당 패널 아래에 “아침”, “정오”, “오후”를 표시한다. 반사와 그림자 방향은 설명과 일치해야 한다. 에너지 절약이나 실측 주광 수치를 지어내지 않는다. 변수: 위치, 방향, 재료. 설명용이며 시뮬레이션이 아니다.
```
