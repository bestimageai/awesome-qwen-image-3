# Бренды, плакаты и кампании

Десять готовых промптов для Qwen Image 3.0. Перед генерацией замените данные в квадратных скобках. Текст в кавычках следует воспроизводить точно; перевод предполагается только при прямом указании. Результаты требуют проверки человеком.

<a id="mkt-01"></a>

## MKT-01 — Премьера ремонтопригодной лампы

```text
Создайте плакат формата 3:4 для запуска ремонтопригодной настольной лампы вымышленной студии LATCH. Покажите одну сложенную охристую лампу на синем верстаке, а рядом — её съёмный плафон; лампа занимает нижние две трети. Используйте чёткую предметную фотографию, мягкий боковой свет и сдержанную редакционную сетку. Разместите только «LATCH», «Надолго с вами» и «Замените деталь. Сохраните лампу.» по убыванию значимости. Соединения должны быть механически правдоподобными, детали — соответствовать друг другу. Не добавляйте цены, экологические сертификаты или заявления о характеристиках. Переменные: название студии, отделка и утверждённый слоган.
```

<a id="mkt-02"></a>

## MKT-02 — Фестиваль чтения у реки

```text
Создайте иллюстрированный плакат 3:4 для вымышленного фестиваля плавучей библиотеки. Внизу справа стоит пришвартованная синяя баржа с книгами; изогнутый красный пешеходный мост ведёт взгляд от заголовка вверху слева к трём читателям под полосатыми навесами. Используйте плоские формы шелкографии, бумагу цвета слоновой кости и широкие поля. Воспроизведите точно «河畔读书节», «RIVER READING DAYS», «川辺の読書会» и «SAT–SUN · 10:00–17:00», каждую строку один раз в отдельном блоке. Сохраните китайский, английский и японский тексты без изменений. Никаких других надписей, спонсоров или водяных знаков. Переменные: утверждённый текст фестиваля и палитра.
```

<a id="mkt-03"></a>

## MKT-03 — Подкаст об архиве звуков

```text
Создайте квадратную обложку вымышленного подкаста «Тихие звуки». Покажите крупным планом латунный ключ в неглубоком лотке, а за ним нарисуйте три тонких концентрических кольца вибрации. Используйте тёплую макрофотографию и тёмно-баклажановый фон; название разместите в верхней четверти, а «Истории, которые стоит услышать» — ниже. Обе строки должны читаться при ширине изображения 100 пикселей. Без микрофонов, наушников, значков платформ и номеров выпусков. Сохраните один ключ, реалистичные отражения и чистое свободное пространство. Переменные: название, предмет и цвет фона.
```

<a id="mkt-04"></a>

## MKT-04 — Миниатюра сравнения инструментов

```text
Создайте миниатюру видео 16:9 о выборе ручного инструмента. Справа расположите вертикально три отвёртки без брендов с явно различающимися плоским, крестовым и шестигранным наконечниками. Слева разместите только «Какой наконечник подходит?» в две строки. Под каждым наконечником добавьте маленькую схему соответствующей головки винта без дополнительных подписей. Используйте яркую настольную фотографию, угольно-серый шрифт и жёлтые акценты фона. Наконечники и углубления головок должны механически соответствовать друг другу; без постановочных реакций, оценок или преувеличений. Переменные: набор инструментов и точный заголовок.
```

<a id="mkt-05"></a>

## MKT-05 — Обложка карусели об упаковке

```text
Создайте обложку 3:4 для руководства из шести слайдов об упаковке хрупкой керамики. Покажите одну миску, визуально подвешенную между сложенными картонными перегородками, с рулоном амортизирующей бумаги внизу. Используйте аккуратную фотографию сверху на светло-сером фоне. Вверху разместите «Упакуйте бережно», ниже — «Как отправлять керамику», внизу справа — «1/6». Миска должна оставаться целой, материалы — реалистичными. Без логотипов перевозчиков, гарантий защиты от повреждений и других слов. Переменные: предмет, название и количество слайдов.
```

<a id="mkt-06"></a>

## MKT-06 — Набор в общественную мастерскую

```text
Создайте вертикальный плакат 3:4 для набора сотрудников в вымышленный кооператив по ремонту велосипедов. Покажите пустой фартук механика рядом с аккуратно организованной доской инструментов; верхнюю половину оставьте свободной для текста. Используйте документальную фотографию, мягкий свет из окна и тёмно-зелёный шрифт. Разместите «Присоединяйтесь к мастерской», «[ROLE]», «[CITY] · [SCHEDULE]» и «Подайте заявку до [DATE]», подставив предоставленные значения. Инструменты должны быть узнаваемыми; не придумывайте зарплату, сертификаты или контакты. Не создавайте QR-код. До генерации замените все переменные.
```

## MKT-07 — Напоминание о многоразовой чашке

```text
Создайте объявление для кафе формата 9:16, призывающее гостей приносить многоразовую чашку. Покажите одну хорошо послужившую дорожную чашку кремового цвета рядом с керамическим кувшином приглушённого голубого цвета; съёмка на уровне стойки при тёплом утреннем свете. Над чашкой напишите «Ваша чашка, ваш ритуал», под ней — «Возьмите её в следующий раз». Оставьте просторную середину и обеспечьте высокий контраст букв для чтения с расстояния. Без скидок, экологической статистики и заявлений о здоровье; без лишних предметов или текста. Сохраните реалистичную геометрию крышки и контактные тени. Переменные: цвет чашки и утверждённое сообщение из двух строк.
```

## MKT-08 — Ключевой образ прогулки с фонариками

```text
Создайте статичный ключевой образ 16:9 для вымышленной вечерней прогулки с фонариками «Тропы света». Цепочка небольших янтарных бумажных фонариков изгибается через тёмный ботанический сад к открытым воротам. Оставьте спокойную область слева от центра для названия; сразу под ним разместите «Вечер вместе». Используйте многослойную бумажную иллюстрацию с лёгкой глубиной и видимой фактурой волокон, без неоновых эффектов. Избегайте узнаваемых достопримечательностей, логотипов спонсоров и лишнего текста. Это один неподвижный концептуальный кадр, не анимация. Переменные: название, форма тропы и акцентный цвет.
```

<a id="mkt-09"></a>

## MKT-09 — Плакат ремонтной мастерской

```text
Создайте плакат 3:4 для вымышленной районной ремонтной мастерской. Изобразите один терракотовый стол с жёлтым тостером, небольшой отвёрткой и катушкой синей нити; две взрослые руки работают над тостером с противоположных сторон. Используйте чёткие формы бумажной аппликации, кремовый фон, тёмно-синий шрифт и свободные интервалы. Вверху напишите «Ремонтная суббота», ниже — «Принесите одну небольшую вещь», внизу — «14:00–17:00». Каждую строку воспроизведите один раз, без другого текста. Руки должны быть анатомически правдоподобными, тостер — отключённым от розетки. Переменные: утверждённый локализованный текст и палитра.
```

<a id="mkt-10"></a>

## MKT-10 — Объявление об открытии на витрине

```text
Создайте объявление на окно формата 2:3 для вымышленной районной студии фотопечати. В нижней половине покажите три моментальных снимка без брендов, закреплённых прищепками на одном горизонтальном шнуре. Над ними разместите «Печатайте моменты повседневности», затем «Открытие [DATE]» и «[STREET]». Используйте фактурную кремовую бумагу, кобальтовый шрифт и естественные тени. Перед генерацией укажите дату и адрес; не придумывайте предложение к открытию. Все три снимка должны различаться, содержать только изображения, без лиц частных лиц и читаемых личных документов. Переменные: дата, место и сюжеты снимков.
```
