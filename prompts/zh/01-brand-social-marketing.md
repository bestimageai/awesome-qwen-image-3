# 品牌、海报与宣传活动

十条 Qwen Image 3.0 提示词配方。生成前请替换方括号中的输入内容。所有引号内文字均须原样呈现；除非明确要求，否则不作额外翻译。输出结果需要人工审核。

## MKT-01 — 可维修台灯发布海报

```text
为虚构工作室 LATCH 及其可维修台灯制作一张 3:4 发布海报。在蓝色工作台上展示一盏折叠的赭黄色台灯，将可拆卸灯罩放在旁边；台灯占据画面下方三分之二。采用清晰的产品摄影、柔和侧光和克制的编辑式网格排版。仅按由大到小的层级呈现“LATCH”、“为长久陪伴而造”和“更换零件，留下台灯。”。保持关节结构符合机械原理，各部件彼此匹配。不添加价格、可持续性认证或性能承诺。可调变量：工作室名称、表面处理和经批准的标语。
```

## MKT-02 — 河畔读书节

```text
为虚构的水上图书馆节制作一张 3:4 插画海报。右下方是一艘停泊的蓝色图书驳船；弯曲的红色人行桥将视线从左上方标题引向条纹遮阳篷下的三位读者。采用平面的丝网印刷色块、象牙白纸张和宽裕页边距。准确呈现“河畔读书节”、“RIVER READING DAYS”、“川辺の読書会”和“SAT–SUN · 10:00–17:00”，每项在独立文字区块中仅出现一次。保留所提供的中文、英文和日文原文。不添加其他标牌、赞助商或水印。可调变量：经批准的节日文案和配色。
```

## MKT-03 — 声音档案播客封面

```text
为虚构播客“小小声响”制作方形封面。展示一把放大的黄铜钥匙，置于浅托盘内，在钥匙后方绘制三圈纤细的同心振动纹。采用暖调微距摄影和深茄紫色背景；标题横跨上方四分之一，下方写“值得聆听的故事”。两行文字在画面缩至 100 像素宽时仍须清晰可读。不出现麦克风、耳机、平台徽章或期数。仅保留一把钥匙、真实的反射和干净的留白。可调变量：标题、物件和背景色。
```

## MKT-04 — 工具对比视频缩略图

```text
制作一张讲解手工具选择的 16:9 视频缩略图。右侧竖向排列三把无品牌螺丝刀，一字、十字和六角刀头须明显不同。左侧仅呈现“哪种刀头合适？”，分为两行。每种刀头下方添加一个与之匹配的螺钉头小示意图，不加其他标签。采用明亮的桌面摄影、炭灰色文字和黄色背景点缀。刀头与螺钉头凹槽须在机械结构上匹配；不添加虚假反应、评分或夸张承诺。可调变量：工具组合和准确标题。
```

## MKT-05 — 包装教程轮播封面

```

```

## MKT-07 — 自带杯提醒

```text
制作一张 9:16 咖啡馆告示，鼓励顾客自带可重复使用的杯子。在暖调晨光下，以柜台高度拍摄一个使用过的奶油色随行杯，旁边放一只粉笔蓝色陶壶。杯子上方写“你的杯子，你的日常仪式”，下方写“下次记得带上它”。中部保持宽松留白，文字在远观时仍须对比鲜明。不添加折扣、环保数据或健康宣称；不添加额外物品或文字。保持杯盖结构真实，阴影自然落在台面上。可调变量：杯子颜色和经批准的两行文案。
```

## MKT-08 — 提灯夜游主视觉

```text

```

```

```
