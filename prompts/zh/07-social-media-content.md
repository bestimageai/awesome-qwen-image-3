## SOC-01 — 阳台种植教程封面

```text
为新手阳台种植指南制作 3:4 社交封面。在窄搁板上放三只小陶土盆，每盆种一种不同的绿叶香草，下方放小浇水壶。采用明亮自然摄影和暖奶油色背景。呈现“小阳台，新开始”、“从三盆植物开始”和“1/5”，标题占上方三分之一。不宣称产量、健康效益或保证生长。花盆须有支撑，栏杆几何结构一致。可调变量：经批准的香草和标题。
```

## SOC-02 — 三联手作活动公告

```text
制作一张 3:1 主图，计划分割为三个方形社交帖子。长工作台左侧放陶艺工具，中央放陶瓷水壶，右侧放折叠亚麻布。每个方形独立构图均衡；三个画面分别写“动手”、“分享”和“相聚”。采用一致暖光和安静的奶油色边距。重要物件或字母不得跨越裁切边界。这是视觉主图，不是三个已导出文件。可调变量：手作物件和三个经批准的词。
```

## SOC-03 — 研究发现卡片

```text
使用 [VERIFIED FINDING, DATA AND SOURCE] 制作 16:9 专业社交卡片。顶部放一个准确发现，中央放简洁辅助图表，底部标注来源。采用白底、炭灰文字和单一蓝绿色点缀。保留单位、日期、样本局限和不确定性。不将相关性变成因果关系，也不添加夸张百分比。文字在手机上须可读。可调变量：经批准的发现、数据集和引用；图表准确性需要人工审核。
```

## SOC-04 — 烹饪对比缩略图

```text
制作 16:9 视频缩略图，对比梨的三种摆盘切法：片状、方块和扇形。钴蓝桌面上一排三个相同白盘，梨的颜色与顶光保持一致。上方仅写“一个梨，三种切法”。三种切法须明显不同，份量合理。不添加营养宣称、虚假评分、靠近手的刀具或其他文字。可调变量：水果和经批准的标题。
```

## SOC-05 — 桌面整理短视频封面

```text
制作 9:16 封面，展示整理了一半的桌面：左侧纸张对齐，右侧放合上的笔记本和杯子。采用自然俯视摄影、柔和阴影和克制的沙色与蓝色配色。中央安全区写“重新整理你的桌面”，下方写“从一块台面开始”。重要文字避开下方四分之一和右边缘，以预留平台叠加界面空间。不承诺完成用时，不添加应用标志或额外文案。可调变量：桌面物件和两行标题。
```

## SOC-06 — 双嘉宾直播预告

```text
使用两张获授权的成年人人像制作 3:4 直播预告。两位嘉宾占据等量视觉空间，裁切比例和中性照明一致；姓名直接放在对应人像下方。仅呈现 [EVENT TITLE]、[GUEST NAMES]、[DATE] 和 [TIME ZONE]。采用简洁海军蓝与奶油色网格，不添加虚假直播指示或平台标志。保留身份，不编造资质或参与人数。可调变量：两张参考图和经批准的活动文案。
```

## SOC-07 — 核实引语卡片

```text
使用 [EXACT VERIFIED QUOTE] 和 [AUTHOR ATTRIBUTION] 制作方形引语卡片。在暖调灰白纸面上以大号、易读衬线字排引语；下方放作者署名，左边缘对齐。下角添加一幅小型抽象蓝色线描。准确保留标点和措辞；不缩短、不虚构，也不将引语归给其他人。不添加人像、签名或背书徽章。可调变量：已核实引语、署名和配色。
```

## SOC-08 — 九步手作网格

```text
制作方形三乘三网格，图解 [NINE APPROVED CRAFT STEPS]。全程采用同一桌面、双手和材料，清楚展示原料到成品的推进。画面仅编号“1”至“9”，按从左到右、从上到下顺序排列。工具与物件比例保持稳定，不编造步骤，也不展示不安全的工具操作。不添加装饰文字或重复画格。可调变量：经核实的步骤和材料；教学准确性需要审核。
```

## SOC-09 — 活动回顾拼图

```text
为虚构社区绘画日制作 3:4 编辑式回顾版面。排列四个图片画面：桌上的速写本、正在画画的双手、一面未署名速写墙，以及结束时的空凳。采用一致日光，顶部小标题写“一起画画的一天”。人物面孔不可识别，画作须原创。不添加参与人数、赞助标记或评价引语。底部留一条安静空白页脚。可调变量：活动和准确标题。
```

