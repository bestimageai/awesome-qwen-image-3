# 界面、受控编辑与本地化

十条 Qwen Image 3.0 提示词配方。生成前请替换方括号中的输入内容。所有引号内文字均须原样呈现；除非明确要求，否则不作额外翻译。输出结果需要人工审核。

<a id="dig-01"></a>

## DIG-01 — 工具借阅移动界面

```text
制作一张 16:9 展示板，呈现虚构应用“Borrow Bench”的三个手机页面：工具目录、物品详情和预约确认。采用象牙白背景、海军蓝文字、蓝绿色操作按钮和一致的圆角卡片。选中的物品是一把黄色电钻。仅在合适页面呈现“Borrow Bench”、“找一件工具”、“无绳电钻”、“预约”、“领取时间”、“周六 10:00”、“预约已保存”和“查看预约”。不添加价格、个人信息或额外导航标签。这是静态界面概念图，不暗示控件可实际操作。
```

## DIG-02 — CSV 导入审核界面

```text
为虚构库存应用“Stockroom”制作一张 16:9 桌面界面稿。展示导入审核表，列名为“物品”、“数量”和“状态”；包含提供的三行示例数据，其中一行醒目标记“需要审核”。表格上方写“审核导入内容”；下方放置“返回”和“导入有效行”按钮。使用整洁的白色布局，以琥珀色突出错误，可读的侧栏仅包含“库存”。保留提供的数据，不显示个人信息。可调变量：示例行和经批准的文案。
```

<a id="dig-03"></a>

## DIG-03 — 区域铁路首页

```text
为虚构旅行规划工具“Local Lines”制作一张 16:9 桌面首页概念图。右侧放置大幅海岸列车照片，左侧放实用的搜索面板。准确呈现“换一条慢行路线”、“出发地”、“目的地”、“出行日期”和“查找行程”；输入框保持为空。采用奶油色背景、深绿色控件和宽裕间距。不添加真实时刻表、票价、运营商标志或有票承诺。列车结构须符合物理常识，界面文字与照片分离。可调变量：地区图像和经批准的标题。
```

<a id="dig-04"></a>

## DIG-04 — 合作游戏 HUD

```text
为虚构山地送货游戏制作一张 16:9 静态 HUD 概念图。积雪小径中央百分之六十的区域保持无遮挡。顶部放紧凑罗盘，左上角放两条队友状态条，右下角放三个物品栏位。仅呈现“北”、“队伍”、“包裹”、“绳索”和“地图”。采用高对比形状和克制的琥珀色高亮，不使用电影式悬浮全息效果。避免真实军队徽记、不可读的微小文字和过多覆盖层。可调变量：游戏场景和经批准的标签。
```

## DIG-05 — 海报文字替换

```text
将图像 1 用作编辑目标，仅使用 [APPROVED SOURCE-TO-TARGET TEXT MAP] 中的替换文案。替换指定海报文字，不改变摄影、插画、配色、页边距、标志或非目标文字。保留字重和层级；只有目标语言需要时才调整换行。保持标点、重音符号和阅读方向正确。移除原文字，不要重复保留。不翻译未指定文字，也不添加解释。可调变量：源图和完整文字映射表。
```

<a id="dig-06"></a>

## DIG-06 — 照片损伤修复

```text
将一张获授权的扫描照片作为编辑目标。仅修复可见灰尘、划痕和折痕损伤，依据邻近纹理补全小面积缺失。保留人物身份、年龄、表情、裁切、服装、原始颗粒和色调范围。不为黑白原图上色、不磨皮、不睁开闭着的眼睛，也不虚构背景物件。不确定的大块缺失区域保持原样，不凭空补造细节。输出一张修复图，不添加对比标签或水印。可调变量：源照片和明确标记的修复区域。
```

## DIG-07 — 三参考图产品合成

```text
将图像 1 作为基础桌面场景，图像 2 作为陶瓷杯的准确参考，图像 3 仅作为釉色参考。将图像 2 中的一只杯子放到图像 1 的空杯垫上，并仅应用提供的釉色色相。保留基础画面的镜头、裁切、周边物件和杯子几何结构。匹配光线方向、接触阴影、透视和反射。不复制图像 3 中的物件或文字。不添加文字。可调变量：三张获授权的图片和预期杯子位置。
```

## DIG-08 — 从草图到阅览室

```text
使用经批准的房间草图作为布局参考。制作一张 4:3 写实阅览室概念图，采用浅橡木书架、苔绿色长凳和漫射顶光。保留草图中的每面墙、窗、门口和家具占地位置；仅用材质方案装饰现有表面。透视须一致，过道宽度在视觉上保持不变。不添加人物、额外家具、植物或标牌。这是示意概念图，不是具有测量尺寸的施工图。可调变量：草图和经批准的材料。
```

## DIG-09 — 无障碍空状态界面

```text
为尚无内容的收藏阅读列表制作一张 3:4 手机界面稿。使用奶油色背景、海军蓝文字和一幅由三本合起的书组成的小插画。准确呈现“尚未收藏内容”、“把实用文章收藏在一起”和“探索文章”。说明放在标题下方，大按钮放在更下方；保留舒适的页边距。使用高对比度，不添加微小文字、加载骨架、虚假文章卡片或通知徽章。这是静态设计提案；无障碍表现仍需在实现后测试。
```

## DIG-10 — 语言阅读方向对比

```text
使用 [APPROVED ENGLISH AND ARABIC COPY] 制作一张 16:9 并排界面排版展示板。左侧采用从左到右的对齐方式；右侧采用自然的从右到左对齐方式。调整阅读顺序时，保留相同的组件层级、间距和两个按钮的功能角色。产品照片保持原样，不进行镜像翻转。仅呈现提供的字符串，阿拉伯文字母须正确连写，拉丁字母品牌名称保持完整。不音译、不重复源文字，也不编造文案。可调变量：成对字符串和组件标签；须由阿拉伯语流利使用者审核。
```
