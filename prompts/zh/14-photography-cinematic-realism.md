# 摄影与电影写实风格

十条 Qwen Image 3.0 提示词配方。生成前请替换方括号中的输入内容。所有引号内文字均须原样呈现；除非明确要求，否则不作额外翻译。输出结果需要人工审核。

<a id="pho-01"></a>

## PHO-01 — 清晨市场纪实

```text
制作 3:4 虚构纪实照片，成年花商在开门前整理无品牌花桶。采用平视中景、阴天晨光和克制自然色。双手可信、地面潮湿，摊位保留小瑕疵。背景人物模糊，不出现可读店招。不模仿名人、不摆拍广告笑容，不使用戏剧性 HDR，也不编造事件宣称。可调变量：虚构人物、鲜花和地点特色。
```

<a id="pho-02"></a>

## PHO-02 — 手机镜头下的早餐

```text
制作 3:4 随手手机照片，展示吃了一半的早餐：厨房桌上的吐司、一小碟果酱和陶瓷杯。采用柔和窗光、中等景深和略不完美的取景。食物份量真实，面包屑形态多样，杯子反射合理。不添加文字、奢侈品牌、过度背景虚化或精修棚拍道具。可调变量：餐食、桌面和光线方向；图像应有日常感，而非商业目录感。
```

<a id="pho-03"></a>

## PHO-03 — 可复用产品布光

```text
使用获授权的产品参考图，在浅灰背景上制作方形棚拍照片。镜头左侧放大面积柔光，右侧提供轻微白色补光；保留产品几何结构、颜色、标签和表面磨损。保持一处接地的接触阴影和自然高光衰减。不添加配件、文字、悬浮物体或过度锐化边缘。可调变量：参考图和经批准背景。生成相关产品图时沿用该布光说明，但不保证输出完全相同。
```

<a id="pho-04"></a>

## PHO-04 — 夜间公交候车亭画面

```text
制作 16:9 虚构电影静帧，小雨后的夜间空公交候车亭。暖色顶灯对比远处冷色街道，反射适度，阴影深但可辨。长椅上放一份折叠报纸，无可读文字。透视、玻璃反射和光线衰减可信。不添加人物、线路编号、广告或真实地点宣称。可调变量：候车亭设计、天气和色彩平衡。
```

<a id="pho-05"></a>

## PHO-05 — 四帧接触印样条

```text
制作 16:9 接触印样条，四个等大摄影画面展示同一原创成年陶艺师转向窗户。四个不同时刻依次为低头、开始转身、面向光线和轻轻微笑。锁定身份、服装、房间和曝光。采用细微胶片颗粒和真实动作差异，不重复姿势。不添加帧号、胶片品牌或文字。可调变量：虚构人物和工作室场景；这是编排的静态图集，不是视频截帧。
```

<a id="pho-06"></a>

## PHO-06 — 玻璃反射研究

```text
制作方形静物照片，深蓝桌上一个透明平底杯，装半杯水。采用大面积侧光和浅色竖向反光板，水面弯月面可见但细微，透过玻璃的折射可信。杯口保持椭圆、杯底接地、水面水平。不添加文字、冰块、水果、其他杯子或不可能的内部反射。可调变量：杯形、注水量和背景色调。
```

<a id="pho-07"></a>

## PHO-07 — 食物蒸汽特写

```text
制作 4:3 近距离照片，窗边一只素陶碗装着蔬菜汤。采用暖自然光，一缕细而不规则的蒸汽从汤面升起。蔬菜可辨，液体反射一致，碗沿干净。不添加文字、漂浮在汤中的餐具、过量烟雾、热量标签或健康宣称。可调变量：经批准食谱、碗和光线方向。不要把蒸汽画成装饰性的实体飘带。
```

<a id="pho-08"></a>

## PHO-08 — 安静工坊广角照

```text
制作 16:9 广角室内照片，展示虚构维修工坊打烊时的场景。中央木工作台、一盏亮着的台灯、后墙整齐收纳的工具。采用适度广角透视、笔直垂线、暖实景灯光和冷环境补光。通道畅通，物件有物理支撑。不添加人物、可读品牌、电影雾气或不可能的房间几何结构。可调变量：工坊类型和经批准的材质配色。
```

<a id="pho-09"></a>

## PHO-09 — 浅景深材质细节

```text
制作 3:2 微距照片，展示无品牌包上缝合帆布与磨损皮革之间的接缝。中央三针清晰对焦，细节朝边缘逐渐柔化。采用大面积自然光、真实纤维和低饱和颜色。针距、针孔和材料厚度合理。不添加文字、品牌徽记、极端锐化或重复纹理印章。可调变量：获授权的产品细节和材料颜色。
```

<a id="pho-10"></a>

## PHO-10 — 长曝光流水概念

```text
制作 16:9 虚构风景照片，小石人行桥跨过溪流。使用长曝光视觉处理柔化流动水体，同时保持桥、岩石和植物清晰。桥偏离中心，水流绕岩石的方向可信。采用阴天光和自然绿色调。不添加文字、人物、可识别地标、过量薄雾或发光水体。可调变量：桥梁设计和季节；不宣称真实相机曝光或地点。
```
