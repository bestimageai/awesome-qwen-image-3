# 历史、文化与基于证据的诠释

十条 Qwen Image 3.0 提示词配方。生成前请替换方括号中的输入内容。所有引号内文字均须原样呈现；除非明确要求，否则不作额外翻译。输出结果需要人工审核。

<a id="cul-01"></a>

## CUL-01 — 历史街道日常

```text
使用 [DATED PHOTOGRAPHS AND MAP]，制作 [YEAR] 年 [STREET] 日常生活的 16:9 重建图。保留有记录的建筑轮廓、交通类型和街道路面。仅展示提供证据支持的日常活动，不确定区域在视觉上弱化。采用纪实插画，不声称是档案照片。不编造铭文、名人或现代物件。可调变量：地点、日期、证据和不确定性注记；须进行历史审核。
```

<a id="cul-02"></a>

## CUL-02 — 文物复原研究板

```text
根据 [AUTHORIZED ARTIFACT IMAGES] 制作 16:9 三格博物馆研究板。展示现存物件、克制复原图和标记不确定区域的示意图。保留有记录的几何结构和表面损伤。画格标注“现存”、“复原”和“不确定”；用不同视觉处理避免推测被误认作证据。不编造制作者、来源沿革或仪式含义。可调变量：参考资料包和经批准解读；须由专家审核。
```

<a id="cul-03"></a>

## CUL-03 — 历史市场插画

```text
使用 [EVIDENCE PACK]，为 [VERIFIED REGION AND PERIOD] 的市场制作 3:2 教育插画。仅包含提供的摊位类型、服装、商品和建筑。前景交易清楚，背景安静，采用自然日光和克制细节。不添加可读价格、虚构文字体系、刻板印象或其他时代物件。可调变量：地区、日期和有记录的元素。输出须标明为诠释插画，而非真实历史图像。
```

<a id="cul-04"></a>

## CUL-04 — 历史服饰研究

```text
使用 [MUSEUM-VERIFIED GARMENT REFERENCES] 制作 16:9 服装研究图，在中性人物上展示正面、侧面和背面。保留缝线、扣合方式、面料层次和提供的颜色证据。仅标注经批准的服饰名、地区和时期。不编造身份地位、族群、仪式含义或无记录的装饰。可调变量：参考图和准确标签。用提供的注记区分不确定颜色，并请专业人员审核。
```

<a id="cul-05"></a>

## CUL-05 — 传统工艺流程

```text
使用 [PRACTITIONER-APPROVED STEPS]，为 [DOCUMENTED CRAFT PROCESS] 制作 16:9 四格插画。依序展示正确工具、手部位置和材料状态。采用清晰自然主义插画，仅用提供的标签。不披露受限知识、不编造神圣细节，也不用通用纹样替代活态传统。可调变量：经批准参考、步骤和署名。发布前须由实践者审核并取得适用许可。
```

<a id="cul-06"></a>

## CUL-06 — 双语遗产解说板

```text
使用 [APPROVED TWO-LANGUAGE COPY] 和一张获授权遗址图，制作 3:4 遗产解说板。两种语言排在独立、清晰对齐的区块，排版地位相等。保留名称、日期、变音符号和阅读方向；图片位于文字上方。不编造历史、旅游宣称、机构标志或翻译。可调变量：定稿双语文案、图片和来源署名。结果是需社群与事实审核的版式概念。
```

<a id="cul-07"></a>

## CUL-07 — 历史地图叠加

```text
使用获授权的历史地图和 [VERIFIED MODERN ALIGNMENT] 制作 16:9 对比插画。历史地图保留为底图，仅将提供的现代参照线以明显蓝色叠加。图例区分两个日期及不确定的对齐。不编造边界、所有权宣称、路线或地理空间精度。可调变量：地图、对齐关系和准确标签；须进行历史与地理审核。
```

<a id="cul-08"></a>

## CUL-08 — 复原过程的连续性

```text
制作 16:9 四格复原图，展示 [VERIFIED PERIOD] 中同一有文献依据的庭院在黎明、正午、午后和黄昏的状态。使用 [EVIDENCE PACK] 锁定建筑、材料、家具和相机位置。仅改变光线与提供的日常活动。避免现代物件、虚构铭文或无依据的仪式事件。仅标注时段。可调变量：参考图和经批准活动清单。这是诠释性序列，不是所示事件发生过的证据。
```

<a id="cul-09"></a>

## CUL-09 — 档案操作海报

```text
使用 [ARCHIVIST-APPROVED HANDLING RULES] 制作 3:4 培训海报概念。三个清楚画格展示提供的操作动作、匹配工具和准确短标签。采用中性技术插画、高对比和宽裕边距。不编造戴手套要求、清洁方法或保护处理。可调变量：核实过的流程和物件类型；使用前与档案专业人员共同审阅。不加机构印章、签名或无依据的保存效果宣称。
```

## CUL-10 — 口述历史引语展板

```text
使用 [CONSENTED VERIFIED QUOTATION]、[APPROVED ATTRIBUTION] 和获授权的背景图片制作 4:3 展板。突出引语，下方放署名，侧面放图片。准确保留措辞、方言和标点；不改写证言或虚构讲述者肖像。采用安静编辑排版和奶油色背景。可调变量：获同意文字、署名和图片。仅包含提供的背景说明与许可署名。
```
