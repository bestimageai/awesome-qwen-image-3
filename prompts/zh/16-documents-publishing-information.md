# 文档、出版与信息设计

十条 Qwen Image 3.0 提示词配方。生成前请替换方括号中的输入内容。所有引号内文字均须原样呈现；除非明确要求，否则不作额外翻译。输出结果需要人工审核。

<a id="doc-01"></a>

## DOC-01 — 双页项目简报

```text
制作 16:9 展示图，将两张竖版项目简报并排放置。使用 [APPROVED COPY]，第一页包含目的与背景，第二页包含范围与下一步。页边距和标题层级一致，只有提供页码时才加入。采用炭灰文字、蓝线和白纸。不添加占位文字、虚构日期、签名或批准印章。可调变量：完整文案和页面对应表。这是位图版式概念；最终文档需要可编辑排版。
```

<a id="doc-02"></a>

## DOC-02 — 产品护理单页

```text
根据 [MANUFACTURER-APPROVED CARE INSTRUCTIONS] 制作 3:4 图解护理单页。提供的四个动作排成二乘二网格，每项有匹配的简洁物件插画和准确标签。警告文字放在独立底部带。不编造清洁化学品、温度、处置建议或保修条款。采用高对比文字和克制蓝色配色。可调变量：核实过的说明和产品参考；发布前确认每步。
```

<a id="doc-03"></a>

## DOC-03 — 博物馆藏品标签

```text
使用 [VERIFIED OBJECT METADATA] 制作 4:3 博物馆标签概念。左侧放获授权的藏品小图，右侧放准确的标题、制作者、日期、材料和说明。采用安静奶油色背景和可读深色文字。未提供的字段直接省略，不猜测。不编造来源沿革、估值、入藏编号或机构标志。可调变量：图片和经批准元数据。这是版式研究，不是真实性或所有权证据。
```

<a id="doc-04"></a>

## DOC-04 — 年报跨页

```text
使用 [APPROVED REPORT COPY AND DATA] 制作 16:9 双页年报版面。左页一个标题和简短叙述，右页一个标签清楚的图表及来源注记。采用一致编辑网格和克制海军蓝点缀。保留所有单位、期间和限定说明。不编造财务数字、审计声明、签名或背书。可调变量：核实过的文案、数据和来源；这是需事实与制作审核的设计概念。
```

<a id="doc-05"></a>

## DOC-05 — 会议日程卡

```text
根据 [APPROVED SESSION TABLE] 制作 3:4 活动日程。纵向时间线包含准确开始时间、场次标题和房间，同步举行的场次在视觉上分组。顶部放活动标题，下方放提供的时区。象牙白底上使用大号深色文字和蓝分隔线。不编造演讲者、休息时段、无障碍安排或场馆细节。可调变量：日程和准确文案；核实时间顺序及房间对应。
```

<a id="doc-06"></a>

## DOC-06 — 已审核提醒卡

```text
仅使用 [CLINICIAN-APPROVED TEXT] 制作 3:4 大字提醒卡。提供的信息按清晰分隔的行组织，采用高对比黑字和一个蓝标题。准确保留名称、数量、单位、时间和警告；不添加剂量、诊断或医疗建议。不生成药片、标志、签名或官方印章。可调变量：经批准文字和标题。这是视觉格式概念；任何实际使用前须由合格专业人员核验。
```

<a id="doc-07"></a>

## DOC-07 — 图书馆会员指南

```text
使用 [APPROVED MEMBERSHIP RULES] 为虚构社区图书馆制作 3:4 信息单页。三个区块标题为“加入”、“借阅”和“归还”，每块配一个简洁插画与提供的短文。采用奶油色纸、海军蓝字和宽裕间距。不编造费用、身份证明要求、开放时间或借阅限额。可调变量：经核实规则和经批准标题。设计中不包含个人数据或可扫描码。
```

<a id="doc-08"></a>

## DOC-08 — 文档对比版面

```text
制作 16:9 并排版面，对比提供的两个短公共文档版本。页面比例一致，仅用浅黄突出 [APPROVED CHANGED PASSAGES]。画格标注“旧版”和“修订版”。所有文字逐字保留，不推断法律意义、不添加评论，也不改动未变措辞。可调变量：两份源文本和明确变更对应表。这是视觉对比概念，不是法律审查或修订跟踪文件。
```

<a id="doc-09"></a>

## DOC-09 — 志愿者交接单

```text
使用 [APPROVED TASK LIST] 制作 3:4 交接单概念。页面分“已完成”、“进行中”和“下一班次”区块，每个提供的事项旁有一个复选框。未明确提供状态时复选框留空。采用大号可读文字、简洁网格，不加装饰摄影。不编造姓名、截止日期、联系方式或完成宣称。可调变量：任务清单和提供的状态；最终业务使用需要可编辑文字。
```

<a id="doc-10"></a>

## DOC-10 — 展览价目表

```text
使用 [APPROVED ITEM TABLE] 制作 3:4 虚构展览价目表版式。物品名称、尺寸和价格对齐成三栏，每项一行。采用克制衬线标题、无衬线数字和白底。准确保留货币符号、小数分隔符和单位。不编造折扣、税务处理、售出状态或艺术家履历。可调变量：核实过的表格和标题。这是排版概念，不是报价或交易记录。
```
