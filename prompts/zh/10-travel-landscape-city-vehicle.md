# 旅行、景观、城市与交通工具

十条 Qwen Image 3.0 提示词配方。生成前请替换方括号中的输入内容。所有引号内文字均须原样呈现；除非明确要求，否则不作额外翻译。输出结果需要人工审核。

<a id="trv-01"></a>

## TRV-01 — 山城电车旅行海报

```text
为虚构山坡小镇制作 3:4 旅行海报概念图。一辆小黄电车沿弯曲街道在浅彩色房屋间爬坡，远处可见大海。采用原创丝网印刷插画、暖陶土色阴影和清楚的标题区域。仅呈现“绕远一点也无妨”和“山城周末”。不复制真实旅游宣传、可识别地标或交通标志。可调变量：配色和经批准标题；不将场景呈现为真实目的地照片。
```

## TRV-02 — 步行路线插画

```text
使用 [VERIFIED MAP AND ROUTE] 制作 3:4 街区步行指南。保留道路连接、起终点和提供的停靠点。用连续蓝线突出一条路线，编号标记须与提供的清单完全对应。使用简洁建筑图标和可读标签。不编造距离、营业时间、无障碍条件或安全过街点。页脚写“请确认当地情况”。可调变量：地图、路线、停靠点和经批准文案。
```

## TRV-03 — 海岸风景照片

```text
制作 16:9 虚构海岸风景，包含层叠深色岩石、低海雾和草地岬角上的一条窄路。采用日出时自然广角摄影视角，克制高光和可信的海浪尺度。地平线水平，道路在物理上相连。不添加人物、文字、可识别地标或不可能的太阳反射。可调变量：天气、海岸地质和配色；结果须标明为生成图像，而非真实目的地照片。
```

## TRV-04 — 夜间车站场景

```text
制作 16:9 雨后虚构郊区铁路站台场景。展示一张空长椅、小候车棚和背景中静止的无品牌列车。采用真实的棚内暖光与天空冷光混合、适度反射和轻微薄雾。轨道保持平行，候车棚支撑结构合理。不添加可读时刻表、目的地标牌、人物、运营商标志或戏剧性危险活动。可调变量：建筑风格、天气和照明。
```

<a id="trv-05"></a>

## TRV-05 — 保持车辆特征的编辑

```text
使用获授权的自行车照片制作方形目录图。仅将背景换为浅灰摄影棚，并将照明调整为柔和侧光。准确保留车架结构、车轮尺寸、辐条、传动系统、配件、漆面和全部已有贴花。两条轮胎须接地，接触阴影一致。不矫正损坏部件、不增加组件，也不改变品牌。可调变量：参考图和经批准的背景色调。
```

## TRV-06 — 山间小屋插画

```text
制作 3:4 虚构山间小屋海报，湖边一间小木屋，背后是层叠森林剪影。使用有质感的水粉画、低饱和松绿色和暖窗光。上方四分之一留给“更宁静的远方”，下边距写“小屋习作”。反射与小屋对齐，地形可信。不添加真实物业名称、预订宣称、星级或虚构设施。可调变量：景观、配色和经批准文案。
```

## TRV-07 — 城市出行方式对比

```text
制作 16:9 编辑插画，在一个虚构街区内对比自行车、电车和步行路线。三种方式须清楚分离，视觉权重相等。采用干净的等距视角、低饱和颜色，标签为“骑行”、“乘车”和“步行”。不添加出行时间、排放数字或安全性更优的宣称。轨道、人行道和过街处须相连。可调变量：经批准街道布局和标签。
```

<a id="trv-08"></a>

## TRV-08 — 汽车四视图展示板

```text
使用获授权的车辆参考图制作 16:9 四视图概念板：正面、后面、左侧和四分之三视角。各视图保持车身比例、轴距、车灯、后视镜和漆面一致。采用相同中性摄影棚环境与统一比例。每个视图标注一次；省略车牌，或使用明确虚构的空白车牌。不编造徽章、续航数字或性能宣称。可调变量：参考图和准确视图标签。
```

## TRV-09 — 旅行手账跨页

```text
为虚构河畔周末制作 3:2 插画旅行手账跨页。左侧放桥梁速写，右侧放船、咖啡杯和带叶树枝的三幅小习作。采用铅笔线条、水彩晕染和象牙白纸。仅呈现“河畔周末”和“慢日子的笔记”；其余笔记区必须真正留白。不添加假票据、护照印章、地址或伪手写字。可调变量：地点概念和配色。
```

## TRV-10 — 天气连续性三联图

```text
制作 16:9 三格图，展示同一虚构湖畔码头在晴天、小雨和雾中的状态。锁定相机、码头木板、栏杆、停泊船只和岸线。仅改变能见度、天空、湿润程度和光照响应。画格标注“晴”、“雨”和“雾”。反射须符合物理规律，不在画格间增加或移除物件。不添加预报、日期或真实地点宣称。可调变量：经批准的场景参考和天气标签。
```
