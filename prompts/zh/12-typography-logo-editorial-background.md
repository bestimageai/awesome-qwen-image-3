# 字体排版、编辑设计与图案

十条 Qwen Image 3.0 提示词配方。生成前请替换方括号中的输入内容。所有引号内文字均须原样呈现；除非明确要求，否则不作额外翻译。输出结果需要人工审核。

<a id="typ-01"></a>

## TYP-01 — 双层级文字海报

```text
制作 3:4 文字海报，准确标题为“有故事的物件”，副标题为“日常设计研究”。标题用大号深蓝衬线字，分为均衡三行；下方以较小但可读的无衬线文字带放副标题。标题区域右下方背后添加一个简洁陶土色圆形，不遮挡文字。采用暖纸纹理和宽裕边距。不添加其他文字、扭曲基线或复制的品牌标记。可调变量：经批准的标题、副标题和配色。
```

<a id="typ-02"></a>

## TYP-02 — 多文字系统字样

```text
制作 16:9 字体样张，三个等宽栏分别准确包含“你好”、“Hello”和“こんにちは”。使用结构正确的中文、拉丁字母和日文，视觉权重相等，深色油墨与象牙白背景。每组字样下方放一条细蓝线，不加语言标签或其他文字。保留提供的文字系统，不音译或自动翻译。间距充足，避免装饰性伪文字。可调变量：经批准的多语言字符串和字体风格。
```

<a id="typ-03"></a>

## TYP-03 — 原创工坊字标

```text
为虚构陶瓷工作室“Soft Corner”制作方形位图字标概念。使用具有定制感的圆润小写字形、克制炭灰配色，唯一符号是一个小型错位方块。名称易读，准确拼写且仅出现一次。象牙白底上只展示一个平面概念，不用墙面样机或多方案。不模仿已有品牌，不宣称已通过商标审查。可调变量：虚构名称和配色；设计师须重建并检查最终矢量标志。
```

<a id="typ-04"></a>

## TYP-04 — 字母组合探索图

```text
制作 3:2 概念图，使用提供的字母“A”和“R”设计三个不同的原创字母组合。纯背景上每个等大画面放一个方案，黑色线宽一致，每个方案周围留足空间。两个字母均须可辨，不添加装饰皇冠或复制时装品牌图案。不加文字或编号。这是位图探索，不是注册标志或可编辑矢量图。可调变量：首字母和几何风格。
```

<a id="typ-05"></a>

## TYP-05 — 杂志开篇版面

```text
制作标题为“修补物件的搁板”的 3:4 杂志开篇版面。上半部放修复过的家居物件大照片，下方放标题，再下方以两栏排提供的两段短文。采用奶油色纸、炭灰衬线字和一条蓝线。仅呈现 [APPROVED BODY COPY] 与标题；不加占位文字、虚构作者或页码。文字可读，物件真实。可调变量：准确文案和获授权图像；须进行编辑校对。
```

## TYP-06 — 社区报纸头版

```text
制作标题为“庭院报”的 3:4 虚构报纸封面。采用清楚三栏网格、一张共享花园大照片和两个小图片位。标题和正文区域仅填入 [APPROVED SHORT COPY]。栏间距宽裕、层级一致，所有文字均可读。不编造新闻、日期、引语、作者署名或官方印章。可调变量：经批准的文案、图片，以及提供时的刊期日期。这是版式概念，不是真实事件报道。
```

<a id="typ-07"></a>

## TYP-07 — 重复图案概念

```text
制作方形图案单元，象牙白底上是原创风格化梨和叶片。仅用赭黄、鼠尾草绿和深蓝，方向多样，空白均衡。越过一侧边缘的纹样须在对侧连贯衔接；视觉间距均匀。不添加文字、标志、渐变或可识别品牌图案。可调变量：纹样、配色和密度。这是生成的候选重复单元；生产前须通过平铺预览检查边缘匹配。
```

## TYP-08 — 响应式首屏背景

```text
制作 16:9 网站首屏背景，层叠浅蓝纸形从右下沿对角线流动。左半部低对比且几乎留空，供后续 HTML 文字使用。采用细微物理阴影和柔奶油色底，不添加文字、标志或界面组件。中央方形裁切须保留平静焦点且不切掉重要形状。可调变量：配色、方向和预期文字安全区。不将界面文案烘焙进图片。
```

## TYP-09 — 大字活动指示牌

```text
在白底上制作 3:4 活动方向指示牌。准确呈现“工坊在楼上”、“电梯在左侧”和一个大号向上箭头。采用特大海军蓝无衬线文字、明显间距，不加装饰图像。箭头放在标题上方，第二行在下方，边距清楚。不自行假设无障碍路线条件，不添加场馆标志；提供的方向须在真实地点核实。可调变量：经批准的方向文字和箭头朝向。
```

## TYP-10 — 书脊设计系统

```text
制作 16:9 编辑样机，展示五个等高竖立书脊。采用统一奶油色与钴蓝设计，每个书脊使用一个提供的书名，系列名一致重复。保留书名与书的顺序、可读的竖排方向和宽裕间距。未提供时不加作者、出版社标志、ISBN、条码或奖项。可调变量：五个书名和系列名。这是出版视觉概念，不是印刷就绪文件。
```
