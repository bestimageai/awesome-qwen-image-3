# 角色、人像与分镜

十条 Qwen Image 3.0 提示词配方。生成前请替换方括号中的输入内容。所有引号内文字均须原样呈现；除非明确要求，否则不作额外翻译。输出结果需要人工审核。

<a id="art-01"></a>

## ART-01 — 米拉归还图书

```text
制作一张 16:9 四格故事图，主角是原创成年流动图书管理员米拉，她有黑色短卷发、圆眼镜、铁锈色开衫和蓝色自行车车篮。从左到右，她在长椅上找到一本书、查看素色封面、将书放入车篮，最后送到一家小图书馆门口。采用暖调水粉插画和柔和晨光。她的面容、服装、自行车和黄色图书始终相同。严格保持四个等大的画格；不添加字幕、对话气泡或可读的书名。这是静态分镜，不是视频。
```

<a id="art-02"></a>

## ART-02 — 自然人像编辑

```text
使用一张获授权的成年人人像作为身份参考。制作一张平视的 3:4 职业人像，仅将背景改为柔光浅蓝色摄影棚，服装改为纯炭灰色外套。保留年龄、面部比例、发型、皮肤纹理和表情。新背景的光线须与面部匹配，肩部解剖结构须自然。不添加文字、珠宝、美颜修饰，也不改变体型。可调变量：背景色和经批准的服装；不得使用未获授权的人物肖像。
```

<a id="art-03"></a>

## ART-03 — 虚构车站管理员

```text
创作一张原创成年车站管理员的方形人像，场景为海边小铁路办公室。角色有银色短发，穿着有岁月痕迹的海军蓝夹克，神情专注；身后有一只虚化的挂钟。采用自然的胶片感摄影、阴天窗光和可见的皮肤纹理。面部居中，头部周围留出空间。不模仿指定人物，不出现官方制服徽记、可读车票或身份证件。可调变量：年龄段、配色和虚构职业。
```

<a id="art-04"></a>

## ART-04 — 四季快递员设定图

```text
制作一张 16:9 四格角色设定图，展示同一位原创成年包裹快递员，拥有长辫子、绿色挎包和红色自行车。等大的四格分别展示春日细雨、夏日树荫、秋风和冬霜。仅改变季节外衣和天气；锁定面部特征、身体比例和自行车几何结构。采用清晰的编辑式插画、一致的镜头高度和中性姿势。各格下方仅呈现“春”、“夏”、“秋”和“冬”。不添加品牌标志或虚构的安全认证。可调变量：角色设计和季节配色。
```

<a id="art-05"></a>

## ART-05 — 水獭绘本跨页

```text
制作一张 2:1 绘本跨页，展示一只小水獭帮助乌龟从芦苇中取回纸船。水獭在左，乌龟在右，纸船位于下方中央附近但避开装订中缝。使用水彩晕染、暖调午后光线和清楚可辨的表情。左上方天空留白，供后续排字。不生成文字，不出现危险涉水场景或额外角色。保持动物尺度和纸船形状一致。可调变量：场景、配色和经批准的角色参考。
```

<a id="art-06"></a>

## ART-06 — 无对白雨伞漫画

```text
制作一张竖版 2:3 漫画，六个等大画格按两列三行排列。一位原创成年人打开小雨伞、注意到一只淋湿的狗、与它共撑伞、双方被水洼溅湿、发现宽大的商店雨篷，最后坐在篷下保持干爽。采用清楚的墨线淡彩插画，服装一致，始终只有一只棕狗。阅读顺序为从左到右、从上到下，动作须有因果衔接。不添加对白、标牌、额外画格或受伤情节。可调变量：角色外貌和雨伞颜色。
```

<a id="art-07"></a>

## ART-07 — 茶叶广告分镜

```text
为虚构的二十秒茶叶广告制作一张 16:9 六格静态分镜。依次展示闭合茶罐、手打开罐子、茶叶落入杯中、倒入热水、窗边蒸汽，以及杯子放在茶罐旁。使用同一个奶油色茶罐、同一个蓝杯和一致晨光。仅在最后一格呈现“片刻宁静”。每格为不同镜头，全部道具保持稳定。不添加健康益处、冲泡温度或品牌宣称。可调变量：道具设计和经批准的结束语；这是概念图，不是生成的视频片段。
```

<a id="art-08"></a>

## ART-08 — 历史街景重建

```text
使用 [DATED EVIDENCE PACK]，制作一张展示 [YEAR] 年 [PLACE] 日常活动的 16:9 插画。保留有史料记载的街道走向、建筑材料和服装；对不确定的背景区域降低细节表现。添加窄幅图例，依据提供的对应关系区分“有文献依据”和“推测性复原”元素。不虚构铭文、名人面孔、纪念物或现代物件。采用克制的纪实插画，不将场景伪装成真实照片。可调变量：地点、年份、证据和不确定性对应图；须进行历史专业审核。
```

<a id="art-09"></a>

## ART-09 — 表情参考图

```text
使用 [APPROVED CHARACTER REFERENCE]，制作一张 3:2 设定图，包含同一原创成年角色的六个头肩视图。以二乘三网格展示平静、好奇、释然、困惑、坚定和愉悦表情。保留头骨形状、头发、年龄、服装和镜头距离；仅改变眉毛、嘴部和轻微的头部倾角。采用柔和棚拍风格插画和统一浅色背景。每种表情准确标注一次。不出现夸张变形的解剖结构、身份漂移或额外配件。可调变量：参考图、配色和翻译后的标签。
```

<a id="art-10"></a>

## ART-10 — 物件连续性分镜

```text
制作一张 16:9 四格分镜：红色陶碗从搁板移到桌上、装入三个橙子，然后被端到窗边。每格使用同一只碗，碗沿始终有一处可见缺口。橙子出现后严格保持三个，房间几何结构一致，采用暖调侧光。使用清晰的写实插画，镜头从中景推进至近景，不添加文字。不移动缺口、不复制水果，也不改变碗的形状。可调变量：物件参考和经批准的房间布局。
```
