# 头像、团队与日常人像

十条 Qwen Image 3.0 提示词配方。生成前请替换方括号中的输入内容。所有引号内文字均须原样呈现；除非明确要求，否则不作额外翻译。输出结果需要人工审核。

<a id="ava-01"></a>

## AVA-01 — 工坊创始人人像

```text
使用获授权的成年人人像，为小型家具工坊制作一张 3:4 创始人照片。保留人物年龄、面部比例和自然皮肤纹理。让人物坐在未完成的木凳旁，双手自然放置，背景工具轻微虚化。采用平视纪实摄影和大面积窗光。不添加豪华办公室道具、虚构奖项、额外人物或文字。除非明确提供替换服装，否则保持参考图中的衣着。可调变量：人像、经批准的服装和工坊场景。
```

<a id="ava-02"></a>

## AVA-02 — 圆形创作者头像

```text
根据一张获授权的成年人人像制作方形头像。面部和上肩置于中央百分之七十区域，确保圆形裁切不会切掉头发或下巴。采用暖灰背景、柔和正面光和自然表情。保留身份、年龄、发型和可见的面部差异；仅移除杂乱背景。不添加文字、徽章、新配件，不过度磨皮或重塑体型。可调变量：参考人像和背景色相。以小尺寸个人头像检查最终效果。
```

## AVA-03 — 三人团队人像条幅

```text
使用三张获授权的成年人人像，制作 16:9 三人独立头肩照条幅，三个画面等宽，采用匹配的中性背景。保留每个人独有的面容和发型，不混合特征。统一眼睛高度、视觉上的镜头距离和光线方向，同时保留自然差异。将提供的姓名放在对应人像下方，各出现一次。不编造职位、不增加人物，也不进行美颜。可调变量：三张参考图和姓名与图像的对应表。本任务需要可同时接收三张参考图的编辑流程。
```

## AVA-04 — 手艺人访谈人像

```text
制作一张 3:2 编辑人像，展示原创成年装订师在木桌上修复布面精装书。双手在操作情境中清楚可见，旁边放一把小刷子和一张衬纸；工具排列须符合使用逻辑。采用侧窗光、克制配色和中景，右侧留白。不模仿具名人物，不添加可读书中文字、资质或历史宣称。手指须合理，胶水远离面部。可调变量：手艺、虚构人物和经批准的配色。
```

## AVA-05 — 家庭烹饪时刻

```text
使用获授权的家庭参考图，制作 16:9 居家场景，展示同一群人在厨房桌边整理蔬菜。保留身份、年龄差异、关系和服装；表情自然，不强求看镜头。刀具和高温设备放在儿童触及不到的位置。采用柔和午后光和可信的生活化背景。不增加家庭成员、文字，不夸张改变体型，也不泄露真实地址。可调变量：获授权参考图和经批准场景；不推断任务说明未提及的人物关系。
```

## AVA-06 — 适应性体育人物特写

```text
制作一张 3:4 编辑人像，展示原创成年轮椅网球运动员在室外球场旁休息。真实呈现运动轮椅的车轮、车架和握持部位，球拍横放在腿上。采用傍晚光线、平视构图以及平静自主的表情。不将人物表现得可怜，不添加励志标语、奖牌、赞助商或医疗宣称。解剖结构和装备须合理。可调变量：虚构运动员外貌、服装和球场配色。
```

## AVA-07 — 雨天街头人像

```text
使用获授权的成年人参考图，制作透明伞下的 3:4 街拍人像。保留面部身份、服装和身体比例。人物靠近素砖墙，地面潮湿并有柔和反射；采用阴天日光，不使用霓虹照明。伞骨、伞柄和握持手势须协调。不增加人物、可见地址、店铺标志或文字，也不改变年龄。可调变量：人像、经批准的外衣和背景材质。
```

<a id="ava-08"></a>

## AVA-08 — 作者媒体照片

```text
根据获授权的成年人参考图制作方形媒体资料人像。让人物坐在一摞无字书旁，肩部略微转向，面部朝向镜头。采用柔和侧光、整洁象牙白墙面和真实皮肤纹理。保留发型、面部特征和表情。头部周围留出空间，便于其他裁切。不编造书名、奖项、签名或文字，不添加美颜滤镜效果。可调变量：人像、经批准的服装和墙面颜色。
```

## AVA-09 — 志愿者群像插画

```text
使用 [APPROVED GROUP DESCRIPTION]，制作一张 16:9 插画，恰好五位成年志愿者围着长桌整理捐赠图书。每人执行不同任务，保留提供的外貌细节，不作漫画式丑化或夸张。采用暖调编辑水粉画，手与物件的互动清楚。保持通道畅通、书堆稳定。不添加姓名、组织标志、捐赠数字或受助者相关宣称。可调变量：经批准的群体细节和场景；虚构人物不应像可识别的真实个人。
```

## AVA-10 — 人像布光研究

```text
使用一张获授权的成年人人像制作 3:2 双格布光研究图。左格使用来自镜头左侧的大面积窗光；右格使用同样的光线，但通过窗帘柔化。锁定身份、相机位置、表情、服装、裁切和背景。仅在对应画面下方写“直接窗光”和“柔化窗光”。变化仅限阴影柔软度和高光过渡。不重塑面部、不改变肤色，也不模拟其他年龄。可调变量：参考图和翻译后的标签。
```
