# 动物、幻想生物与植物研究

十条 Qwen Image 3.0 提示词配方。生成前请替换方括号中的输入内容。所有引号内文字均须原样呈现；除非明确要求，否则不作额外翻译。输出结果需要人工审核。

<a id="nat-01"></a>

## NAT-01 — 参考图宠物肖像

```text
使用获授权的宠物照片，在纯暖灰背景上制作 3:4 肖像。保留毛色花纹、眼睛颜色、耳形、体型和自然表情。采用柔和窗光，以及符合动物解剖结构的放松坐姿。胡须、爪子和毛发边缘细节清楚，不过度平滑。不添加衣服、人类手形或文字；参考图没有项圈时不新增。可调变量：宠物参考图和经批准的背景色。
```

<a id="nat-02"></a>

## NAT-02 — 幻想沼泽生物

```text
为原创小型沼泽生物制作 16:9 概念设定图，比例类似水獭，苔色皮毛，宽大的蹼足。浅背景上展示正面、侧面和四分之三视角，全程保持同一解剖结构与斑纹。采用可信的博物插画，不添加文字。不复制已知虚构角色，不添加不一致的角、肢体或翅膀。可调变量：原创生物说明和栖息地配色；这是想象生物，不是真实物种。
```

<a id="nat-03"></a>

## NAT-03 — 传粉动物观察图版

```text
使用 [VERIFIED SPECIES REFERENCES] 制作 4:3 教育图版，展示一个传粉动物及经批准的宿主花。加入相关取食结构的放大插图，用一条细线连接到正确位置。仅呈现提供的物种名称与标签。采用精确博物插画、白底；只有提供比例标注时才统一加入。不编造解剖结构、生态宣称或装饰性科学符号。可调变量：参考图、标签和来源注记；须由专家审核。
```

<a id="nat-04"></a>

## NAT-04 — 林地野生动物场景

```text
制作 16:9 虚构林地场景，一只赤狐在黎明时停在倒下的桦树干旁。采用真实皮毛、克制薄雾和穿过树木的低角度暖光。爪子接触不平地面，耳朵自然警觉。不添加拟人表情、猎物受伤、人造物件或文字。避免重复树木纹样或夸张身体比例。可调变量：物种、季节和经批准的栖息地细节；不称其为真实野生动物照片。
```

<a id="nat-05"></a>

## NAT-05 — 动物运动研究

```text
使用 [VERIFIED ANATOMICAL REFERENCES] 制作 16:9 四格研究图，展示家猫从左向右行走。毛色花纹、比例、镜头高度和背景相同。展示四个不同且经批准的步态阶段，重心转移合理，爪子接地。画格仅标“1”至“4”。不编造肢体位置，未经进一步测试不宣称其为可直接用于动画的帧。可调变量：参考图和步态顺序。
```

## NAT-06 — 叶片识别教学单

```text
使用 [VERIFIED LEAF REFERENCES] 制作 3:4 植物教学单。六片叶子排列为二乘三网格，下方分别标注提供的俗名。保留叶片形状、叶缘、叶脉和叶柄连接处；采用相同中性照明和纯象牙白背景。不编造物种名、药用用途或相对比例。仅添加经批准的标题和标签。可调变量：六张参考图和名称对应表；植物识别需要审核。
```

## NAT-07 — 植物生命周期图

```text
为 [VERIFIED PLANT SPECIES] 使用 [APPROVED STAGES] 制作 16:9 生命周期插画。从种子到提供的成熟形态，恰好五个阶段从左到右排列，用简洁箭头连接。采用自然水彩细节，各阶段下方标签清晰。保留该物种特有的叶片、根和果实；不编造持续时间或种植建议。可调变量：参考资料包、阶段和准确标签。图示用于教育，须由相关领域专家审核。
```

## NAT-08 — 水族栖息地概念

```text
制作 4:3 虚构淡水栖息地概念图，包含圆石、水草和提供的同一物种的三条小鱼。采用清楚侧视图、自然水下光和可信比例。鱼类解剖结构一致，避免过度拥挤或不相容物种。不添加设备宣称、放养建议、标签或装饰宝箱。可调变量：已核实物种参考和栖息地说明；此插画不是动物饲养建议。
```

## NAT-09 — 种子包装插画

```text
使用 [VERIFIED PLANT REFERENCE] 为虚构种子袋制作 3:4 正面概念图。展示一枝开花茎和小型种子插图，上方四分之一留给 [APPROVED PLANT NAME]。采用奶油色纸上的原创植物水粉画。仅呈现提供的名称和“插画习作”。未提供时不添加发芽率、产地、认证、种植说明或重量。保留花和叶的形态。可调变量：参考图、名称和配色。
```
