# 信息图、教育与商业

十条 Qwen Image 3.0 提示词配方。生成前请替换方括号中的输入内容。所有引号内文字均须原样呈现；除非明确要求，否则不作额外翻译。输出结果需要人工审核。

## EDU-01 — 雨水的旅程

```text
制作一张 16:9 课堂信息图，标题为“雨水去了哪里”。从左到右清晰展示四个阶段：一处屋顶、一条相连的檐沟、一个有盖蓄水桶和一座种有植物的雨水花园。使用蓝色水流箭头依次连接屋顶、檐沟和蓄水桶，再用单独的溢流箭头从蓄水桶指向花园。在正确物件旁仅标注“屋顶”、“檐沟”、“蓄水”和“雨水花园”。采用奶油色背景和简洁的剖视插画。不展示饮用水用途，不编造容量数据。箭头须明确无歧义，蓄水桶须有盖封闭。
```

## EDU-02 — 城市遮阴对比

```text
制作一张 16:9 教学示意图，对比相同太阳角度下的两段虚构街道。左侧没有树木；右侧有两棵成熟树木为人行道遮阴。两侧建筑、道路宽度和行人相同，采用简洁建筑插画，并清楚呈现阴影覆盖范围。两格标签分别为“阳光直晒”和“树荫遮蔽”。不添加温度、百分比或健康结果。太阳方向保持一致，不暗示树荫可以消除全部热量。可调变量：街道几何布局和经批准的标签。
```

## EDU-03 — 种子生长观察单

```text
制作一张竖版 3:4 儿童豆种观察单。绘制四个等大的方框，分别包含种子、根冒出、第一根芽和两片叶子。每框下方保留带横线的观察记录区。使用清晰的灰度线描和大号文字。仅呈现“观察种子生长”、“1”、“2”、“3”、“4”和“我的观察”。生物生长顺序须明确，不指定经过的天数。不填写作答区域，也不添加装饰性伪文字。可调变量：经批准的植物种类和观察单标题。
```

## EDU-04 — 分数条对比

```text
制作一张适合灰度打印的 3:4 教学单，展示三条相同的横向长条。分别等分成两格、四格和八格；分别为一格、两格和四格涂色。各行标注“1/2”、“2/4”和“4/8”；标题为“分法不同，数量相同”。长条起点与终点精确对齐，下方四分之一留白用于讨论笔记。采用清晰黑色轮廓和单一灰色填充。不添加圆形、不等分的格子、答题气泡或其他算式。
```

## EDU-05 — 月度服务仪表板

```text
仅使用 [VERIFIED MONTHLY TABLE] 制作一张 16:9 仪表板概念图。左侧放置提供的核心指标，右侧放折线图；下方展示三个有标签的辅助数据。使用白色背景、炭灰色文字和一条蓝色数据系列。准确呈现表中的日期、单位和来源注记。缺失值保留为空缺；不插值，也不虚构对比。坐标轴必须符合提供的刻度并显示单位。可调变量：数据表、指标名称、来源和时期。
```

## EDU-06 — 三阶段路线图

```text
使用 [APPROVED INITIATIVES] 制作一张 16:9 产品路线图。排列三个等宽栏，标题分别为“当前”、“下一步”和“探索中”，每栏最多三张事项卡片。采用干净的编辑式网格、奶油色卡片和低饱和蓝色点缀；仅连接明确提供的依赖关系。页脚写“规划视图，不代表发布承诺”。不编造日期、完成状态、负责人或承诺。每项事项必须保留在提供的栏位中。可调变量：事项列表和依赖关系列表。
```

## EDU-07 — 博物馆参观路线图

```text
使用经批准的平面图和 [ROOM LABELS] 制作一张竖版参观地图概念图。准确保留入口、楼梯、电梯、墙体和无障碍路线；仅简化装饰细节。用连续蓝线突出一条提供的路线，并标记起点和终点。使用包含所提供符号的清晰图例，仅呈现经批准的房间名称。不编造出口、无障碍设施或比例尺。包含“示意导览——请以现场为准”。可调变量：平面图、路线和标签；发布前必须由场馆审核。
```

## EDU-08 — 图书馆服务蓝图

```text
制作一张 16:9 图书馆借阅服务蓝图。四列分别为“查找”、“预约”、“领取”、“归还”；三行分别为“读者”、“图书馆”、“系统”。单元格仅填写 [APPROVED ACTIONS]，箭头仅表示所提供的交接关系。采用克制的蓝色线条、白色单元格和大号文字。读者行为与内部操作清楚区分。不编造处理时长、不显示个人数据，也不用装饰图标代替行为。可调变量：行为矩阵和经核实的交接关系。
```

## EDU-09 — 工坊剩余名额图表

```text
根据以下虚构数据制作一张 4:3 信息卡：周一 8 个名额、周二 12 个名额、周三 6 个名额。标题为“工坊剩余名额”，绘制三条共享同一零起点刻度的水平条形，在条形末端标注准确数值。使用白色背景、海军蓝标签和赭黄色条形。页脚写“示例数据”。不将名额换算为出席人数或百分比，也不改变条形顺序。十二个名额的条形长度须为六个名额的两倍。
```

## EDU-10 — 决策树教学卡

```text
使用 [TEACHER-APPROVED QUESTIONS AND OUTCOMES]，为虚构植物养护课程制作一张 3:4 决策树卡片。顶部放一个根问题，下方放两个分支问题，底部放提供的结果。分支标注“是”和“否”，采用统一圆角框和充足留白。保留全部条件与停止点；不编造浇水量、诊断或品种建议。仅呈现经批准的文字和标题。可调变量：准确的树结构、植物背景和标题；须由教师审核。
```
