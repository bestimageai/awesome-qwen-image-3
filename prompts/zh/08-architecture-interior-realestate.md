# 建筑、室内与物业概念

十条 Qwen Image 3.0 提示词配方。生成前请替换方括号中的输入内容。所有引号内文字均须原样呈现；除非明确要求，否则不作额外翻译。输出结果需要人工审核。

<a id="arc-01"></a>

## ARC-01 — 小型阅读壁龛

```text
制作 4:3 建筑室内图，展示楼梯下紧凑的阅读壁龛。一条嵌入式橡木长凳、一个浅书架和一盏圆壁灯，配折叠蓝坐垫。采用可信的人体尺度、笔直垂线和来自画外窗户的柔和日光。保留可用的头部净空与畅通出入空间。不添加人物、文字、不可能的悬挑或过大家具。可调变量：房间尺寸、经批准的材料和配色；这是设计插画，不是施工文件。
```

<a id="arc-02"></a>

## ARC-02 — 面包店柜台改造

```text
将一张获授权的面包店室内照片作为编辑目标。仅将柜台正面改为浅色竖向木条，后墙改为低饱和蓝色。保留柜台尺寸、展示玻璃、门、天花灯具、相机角度和全部已有文字。反射和接触阴影须匹配原有光线。不添加产品、不移除设备，也不拓宽房间。可调变量：源照片和经批准的表面处理。输出一张概念图，不带改造前后标签。
```

<a id="arc-03"></a>

## ARC-03 — 家具平面布置渲染

```text
使用 [APPROVED FLOOR PLAN] 制作俯视 4:3 家具布置插画。保留全部墙体、开口、楼梯和提供的尺寸。仅将 [APPROVED FURNITURE LIST] 中的家具放到指定位置，采用统一比例和柔和中性阴影。通行动线须清楚，仅呈现提供的房间名称。不编造尺寸、不移动墙体，也不暗示符合规范。可调变量：平面图、家具位置和标签；空间准确性须单独核验。
```

<a id="arc-04"></a>

## ARC-04 — 蓝调时刻外景编辑

```text
将获授权的物业照片作为编辑目标。仅将时间改为蓝调时刻初期，现有窗内可见柔和暖光。除非明确指定，否则保留建筑、景观、邻近建筑、相机位置和天气条件。天空亮度和窗户反射须符合物理规律。不新增灯具、不遮掩缺陷，也不改变景观视野。不添加文字或房产宣称。可调变量：源图和经批准的照明处理；发布时标明是可视化效果图。
```

<a id="arc-05"></a>

## ARC-05 — 客房信息卡

```text
使用 [VERIFIED ROOM PLAN AND AMENITIES] 制作 3:4 住宿信息卡。简化房间插画置于上方，下方列出提供的简短设施清单。保留床位数、浴室位置和窗户位置。采用暖中性色、大号字体和经批准的标签。不编造海景、无障碍设施、星级、尺寸或可预订状态。标题下写“客房图解指南”。可调变量：已核实的平面图、设施清单和经批准标题。
```

<a id="arc-06"></a>

## ARC-06 — 材料配色板

```text
制作标题为“静谧工坊”的 16:9 室内材料板。排列五种不同样品：浅橡木、拉丝铝、蓝色羊毛、暖色灰泥和斑点陶瓷。呈现真实纹理与厚度，采用柔和定向阴影和干净奶油色背景。每种材料在其样品下方准确标注一次。样品尺寸在视觉上均衡，但不暗示物理比例相同。不添加供应商品牌、环保认证或性能宣称。可调变量：材料、标签和项目标题。
```

<a id="arc-07"></a>

## ARC-07 — 展览参观动线

```text
使用 [APPROVED EXHIBITION PLAN] 制作 16:9 轴测插画。保留全部隔墙、入口和提供的装置。用蓝线和方向箭头展示一条经批准的参观路线；仅在提供紧急疏散路线时才将其明确区分。使用 [APPROVED ZONE NAMES] 标注分区。采用中性建筑阴影，不添加装饰性人群。不编造安全出口、无障碍条件或容纳人数。可调变量：平面图、路线和标签；使用前须由场馆审核。
```

<a id="arc-08"></a>

## ARC-08 — 庭院四季

```text
制作 16:9 四格景观概念图，展示同一小庭院的春、夏、秋、冬。锁定相机、石路、长凳、树木位置和建筑墙面。仅改变符合 [VERIFIED CLIMATE] 的植被外观、日光与季节地面状态。每个季节标注一次。采用写实建筑可视化，不在画格间移动物件。不编造全年开花或成熟生长速度。可调变量：经批准的植物清单和气候。
```

<a id="arc-09"></a>

## ARC-09 — 零售空间视线研究

```text
根据一份经批准的平面图制作 16:9 双格零售布局概念图。两格都从入口以相同平视角度观看。左格使用当前货架位置；右格仅采用 [APPROVED NEW POSITIONS]。建筑、货架尺寸、商品类别和照明保持不变。图像外分别标注“现状”和“提案”。不虚构销售提升、无障碍宣称或额外使用面积。可调变量：平面图和经批准的家具移动方案。
```

<a id="arc-10"></a>

## ARC-10 — 窗边座位日光研究

```text
制作 3:2 三格日光研究图，展示同一窗边座位的早晨、正午和傍晚。使用同一房间、坐垫、相机位置和窗户朝向。仅根据 [SUPPLIED ORIENTATION AND LOCATION] 改变光线方向和强度。对应画格下写“早晨”、“正午”和“午后”。反射和阴影方向须符合任务说明。不编造节能效果或实测日光数值。可调变量：地点、朝向和材料；这是示意图，不是模拟计算。
```
