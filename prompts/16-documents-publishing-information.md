# Documents, publishing, and information design

Ten Qwen Image 3.0 prompt recipes. Replace bracketed inputs before generation. All quoted text is exact; no translation is implied unless explicitly requested. Outputs require human review.

<a id="doc-01"></a>

## DOC-01 — Two-page project brief

```text
Create a 16:9 presentation of two portrait project-brief pages side by side. Use [APPROVED COPY] with page one containing the purpose and context, and page two containing scope and next steps. Keep consistent margins, heading hierarchy and page numbering only if supplied. Use charcoal type, blue rules and white paper. No lorem ipsum, invented dates, signatures or approval stamps. Variables: complete copy and page mapping. This is a raster layout concept; final documents require editable typesetting.
```

## DOC-02 — Product care leaflet

```text
Create a 3:4 illustrated care leaflet from [MANUFACTURER-APPROVED CARE INSTRUCTIONS]. Arrange four supplied actions in a two-by-two grid, each with a matching simple object illustration and exact label. Keep warning text in a distinct bottom band. Do not invent cleaning chemicals, temperatures, disposal advice or warranty terms. Use high-contrast type and a restrained blue palette. Variables: verified instructions and product reference; confirm every step before publication.
```

## DOC-03 — Museum object label

```text
Create a 4:3 museum-label concept using [VERIFIED OBJECT METADATA]. Place a small authorized object image at left and exact title, maker, date, material and description at right. Use a quiet cream background and readable dark type. Omit any field not supplied rather than guessing it. No invented provenance, valuation, accession number or institutional logo. Variables: image and approved metadata. This is a layout study, not evidence of authenticity or ownership.
```

## DOC-04 — Annual report spread

```text
Create a 16:9 two-page annual-report layout using [APPROVED REPORT COPY AND DATA]. The left page contains one headline and a short narrative; the right contains one clearly labeled chart and a source note. Use a consistent editorial grid and restrained navy accents. Preserve all units, periods and qualifications. No invented financial figures, audit statements, signatures or endorsements. Variables: verified copy, data and source; this is a design concept requiring factual and production review.
```

## DOC-05 — Conference schedule card

```text
Create a 3:4 event schedule from [APPROVED SESSION TABLE]. Use a vertical timeline with exact start times, session titles and rooms, keeping simultaneous sessions visually grouped. Place the event title at top and the supplied time zone beneath. Use large dark text on ivory with blue separators. Do not invent speakers, breaks, accessibility arrangements or venue details. Variables: schedule and exact copy; verify chronological order and room mapping.
```

## DOC-06 — Reviewed reminder card

```text
Create a 3:4 large-print reminder card using only [CLINICIAN-APPROVED TEXT]. Organize the supplied information into clearly separated rows, with high-contrast black type and one blue heading. Preserve names, amounts, units, timing and warnings exactly; add no dosage, diagnosis or medical advice. Do not generate pills, logos, signatures or official seals. Variables: approved text and heading. This is a visual formatting concept; a qualified professional must verify it before any real use.
```

## DOC-07 — Library membership guide

```text
Create a 3:4 information leaflet for a fictional community library using [APPROVED MEMBERSHIP RULES]. Show three sections titled "Join", "Borrow", and "Return", each with one simple illustration and supplied short text. Use cream paper, navy type and generous spacing. Do not invent fees, identity requirements, opening hours or borrowing limits. Variables: verified rules and approved title. Keep personal data and scannable codes out of the design.
```

## DOC-08 — Document comparison layout

```text
Create a 16:9 side-by-side layout comparing two supplied versions of a short public document. Keep identical page scale and highlight only [APPROVED CHANGED PASSAGES] with pale yellow. Label panels "Previous" and "Revised". Preserve all text verbatim and do not infer legal significance, add commentary or alter unchanged wording. Variables: two source texts and explicit change map. This is a visual comparison concept, not a legal review or tracked-change file.
```

## DOC-09 — Volunteer handover sheet

```text
Create a 3:4 handover-sheet concept using [APPROVED TASK LIST]. Divide the page into "Completed", "In progress", and "Next shift" sections, with one checkbox beside each supplied item. Leave checkboxes empty unless status is explicitly provided. Use large readable text, a simple grid and no decorative photography. Do not invent names, deadlines, contact details or completion claims. Variables: task list and supplied statuses; final operational use requires editable text.
```

## DOC-10 — Exhibition price list

```text
Create a 3:4 fictional exhibition price-list layout using [APPROVED ITEM TABLE]. Align item names, sizes and prices in three clear columns with one row per item. Use restrained serif headings, sans-serif numbers and a white background. Preserve currency symbols, decimal separators and units exactly. Do not invent discounts, tax treatment, sold status or artist biographies. Variables: verified table and title. This is a typesetting concept, not an offer or transaction record.
```
