# Fashion, beauty, and textile concepts

Ten Qwen Image 3.0 prompt recipes. Replace bracketed inputs before generation. All quoted text is exact; no translation is implied unless explicitly requested. Outputs require human review.

<a id="fas-01"></a>

## FAS-01 — Four-look capsule wardrobe

```text
Create a 16:9 lookbook with four equal panels using one authorized adult model reference and [APPROVED GARMENT LIST]. Show four supplied outfit combinations at the same camera distance on a pale background. Preserve the person's identity and each garment's construction, color and fit. Label panels "01", "02", "03", and "04" only. Use soft fashion-editorial light without altering body proportions. No added accessories, logos or claims about sustainability. Variables: reference, garments and outfit mapping.
```

<a id="fas-02"></a>

## FAS-02 — Utility vest design sheet

```text
Create a 4:3 apparel concept sheet for an original slate-blue utility vest. Show front, back and one pocket detail, all matching in seams, zipper direction and fabric texture. Use clear technical illustration and render only "Front", "Back", and "Pocket". Keep pocket count and silhouette consistent; include no measurements unless supplied. Do not copy a known brand's distinctive design or imply manufacturing readiness. Variables: approved sketch, fabric and labels.
```

<a id="fas-03"></a>

## FAS-03 — Ceramic jewelry campaign

```text
Create a square jewelry photograph of two original cobalt ceramic earrings on folded ivory linen. Use soft side light that reveals glazed highlights without clipping; include one small dry branch for scale and texture. Keep both earrings structurally matched but naturally hand-finished. Add no text, gemstones, precious-metal claims or brand marks. Preserve attachment hardware and plausible shadows. Variables: authorized product reference, glaze and textile color.
```

<a id="fas-04"></a>

## FAS-04 — Makeup comparison edit

```text
Use one authorized adult portrait to create a 4:3 two-by-two makeup comparison. Keep face, skin tone, hair, lighting and expression identical. Apply only four supplied makeup palettes, with changes limited to lips, eyelids and cheeks. Label the panels with [APPROVED LOOK NAMES]. Preserve natural skin texture and facial differences. No face reshaping, age change, product efficacy claims or extra accessories. Variables: portrait, palettes and label mapping.
```

<a id="fas-05"></a>

## FAS-05 — Product-use order card

```text
Create a 3:4 product-use card from [MANUFACTURER-APPROVED ORDER AND COPY]. Show exactly four supplied containers in a vertical sequence, with simple downward arrows and one approved step label per container. Use clean studio photography, pale blue background and generous spacing. Preserve packaging text and shape; do not invent ingredients, medical effects, frequency or compatibility. No before-and-after skin images. Variables: product references and verified instruction sequence; review all claims before publication.
```

<a id="fas-06"></a>

## FAS-06 — Travel accessory flat lay

```text
Create a 3:4 overhead fashion flat lay with one original canvas tote, a folded patterned scarf, plain sunglasses and a small notebook. Arrange objects diagonally on a sand-colored surface, with no overlap hiding essential shapes. Use soft natural shadows and restrained navy accents. No luxury logos, passport, tickets or readable personal information. Keep glasses symmetric and fabric folds believable. Variables: approved accessories, textile patterns and palette.
```

<a id="fas-07"></a>

## FAS-07 — Hairstyle visualization

```text
Use one authorized adult portrait to create a 3:2 sheet of six supplied hairstyle options. Preserve face, hairline, age, skin tone, camera angle and lighting. Change only hair length, arrangement and texture according to [APPROVED STYLE LIST]; retain the original hair color unless requested. Number panels "1" through "6". No facial retouching, makeup changes or impossible hair growth from the forehead. Variables: source portrait and six style descriptions.
```

<a id="fas-08"></a>

## FAS-08 — Fabric weave comparison

```text
Create a 16:9 textile reference board showing linen plain weave, cotton twill and knitted wool as three equal macro panels. Use [AUTHORIZED MATERIAL REFERENCES] for texture and color. Match magnification and neutral lighting while preserving each structure's distinct thread pattern. Label only the supplied material names. Do not invent fiber composition, durability, origin or care claims. Variables: references and exact labels; material identification needs expert verification.
```

<a id="fas-09"></a>

## FAS-09 — Visible mending patch concept

```text
Create a square clothing-detail image of an original denim knee patch repaired with visible ochre stitching. Show the seam and stitch path clearly, with a small fold suggesting how the fabric bends. Use close editorial photography and soft daylight on an ivory background. Add no text, brand labels or claims about garment strength. Keep stitches connected and needle-free in the final image. Variables: authorized garment detail, patch shape and thread color.
```

<a id="fas-10"></a>

## FAS-10 — Footwear color study

```text
Use one authorized shoe reference to create a 16:9 three-panel colorway study. Keep sole, seams, laces, materials and camera angle identical; apply only [THREE APPROVED COLOR PALETTES]. Use neutral backgrounds and matching studio light. Label the panels with supplied colorway names beneath the shoes. Do not alter tread, add logos or invent performance specifications. Variables: reference, three palettes and labels. Check geometry consistency separately from color accuracy.
```
