# เอกสาร สิ่งพิมพ์ และการออกแบบข้อมูล

ชุดพรอมป์ต์ Qwen Image 3.0 จำนวนสิบรายการ เปลี่ยนข้อมูลในวงเล็บเหลี่ยมก่อนสร้างภาพ ข้อความในเครื่องหมายคำพูดต้องแสดงตรงตามที่ระบุ ไม่ต้องแปลเว้นแต่สั่งไว้อย่างชัดเจน ผลลัพธ์ต้องผ่านการตรวจสอบโดยมนุษย์

<a id="doc-01"></a>

## DOC-01 — สรุปโครงการสองหน้า

```text
สร้างงานนำเสนอ 16:9 ของสรุปโครงการแนวตั้งสองหน้าเคียงกัน ใช้ [APPROVED COPY] หน้าแรกเป้าหมายและบริบท หน้าสองขอบเขตและขั้นต่อไป คงขอบ ลำดับชื่อ และเลขหน้าเฉพาะที่ให้ ใช้ตัวถ่าน เส้นน้ำเงิน กระดาษขาว ไม่มีข้อความเติม วันแต่ง ลายเซ็น หรือตราอนุมัติ ตัวแปร: ข้อความครบและการจับคู่หน้า เป็นแนวคิดแรสเตอร์ เอกสารจริงต้องจัดตัวอักษรแก้ได้
```

<a id="doc-02"></a>

## DOC-02 — ใบดูแลสินค้า

```text
สร้างใบดูแลมีภาพ 3:4 จาก [MANUFACTURER-APPROVED CARE INSTRUCTIONS] จัดสี่การกระทำที่ให้ในสองคูณสอง แต่ละข้อมีภาพวัตถุง่ายตรงและป้ายตรง คำเตือนอยู่แถบล่างแยก ห้ามแต่งสารทำความสะอาด อุณหภูมิ วิธีทิ้ง หรือประกัน ใช้ตัวตัดสูงและน้ำเงินเรียบ ตัวแปร: คำแนะนำที่ตรวจและภาพสินค้า ยืนยันทุกขั้นก่อนเผยแพร่
```

<a id="doc-03"></a>

## DOC-03 — ป้ายวัตถุพิพิธภัณฑ์

```text
สร้างแนวคิดป้าย 4:3 จาก [VERIFIED OBJECT METADATA] วางภาพวัตถุเล็กที่อนุญาตซ้าย ชื่อ ผู้ทำ วัน วัสดุ คำอธิบายตรงขวา พื้นครีมสงบ ตัวเข้มอ่านได้ ตัดช่องที่ไม่ให้แทนเดา ไม่มีประวัติที่มา มูลค่า เลขทะเบียน หรือตราสถาบันแต่ง ตัวแปร: ภาพและข้อมูลที่อนุมัติ เป็นศึกษาเลย์เอาต์ไม่ใช่หลักฐานแท้หรือเจ้าของ
```

<a id="doc-04"></a>

## DOC-04 — หน้าคู่รายงานปี

```text
สร้างรายงานปีสองหน้า 16:9 ด้วย [APPROVED REPORT COPY AND DATA] ซ้ายชื่อหนึ่งกับเรื่องสั้น ขวากราฟป้ายชัดหนึ่งและแหล่ง ใช้กริดบรรณาธิการคงที่และกรมท่าเรียบ คงหน่วย ช่วง และข้อจำกัด ไม่มีตัวเลขการเงิน คำรับรองตรวจสอบ ลายเซ็น หรือสนับสนุนแต่ง ตัวแปร: คำ ข้อมูล แหล่งที่ตรวจ เป็นแนวคิดที่ต้องตรวจข้อเท็จจริงและการผลิต
```

<a id="doc-05"></a>

## DOC-05 — การ์ดกำหนดการประชุม

```text
สร้างตารางงาน 3:4 จาก [APPROVED SESSION TABLE] ใช้ไทม์ไลน์ตั้ง เวลาเริ่ม ชื่อช่วง ห้องตรง จัดช่วงพร้อมกันเป็นกลุ่ม วางชื่องานบนและเขตเวลาที่ให้ใต้ ตัวเข้มใหญ่บนงาช้าง เส้นคั่นน้ำเงิน ห้ามแต่งวิทยากร พัก การเข้าถึง หรือรายละเอียดสถานที่ ตัวแปร: ตารางและข้อความตรง ตรวจเวลาและห้อง
```

<a id="doc-06"></a>

## DOC-06 — การ์ดเตือนผ่านตรวจ

```text
สร้างการ์ดเตือนตัวใหญ่ 3:4 ด้วย [CLINICIAN-APPROVED TEXT] เท่านั้น จัดข้อมูลเป็นแถวแยกชัด ตัวดำตัดสูง ชื่อน้ำเงินหนึ่ง คงชื่อ จำนวน หน่วย เวลา คำเตือนตรง ไม่เพิ่มขนาดยา วินิจฉัย หรือคำแนะนำแพทย์ ไม่สร้างยา โลโก้ ลายเซ็น หรือตราทางการ ตัวแปร: คำและชื่อที่อนุมัติ เป็นแนวคิดจัดภาพ ผู้เชี่ยวชาญมีคุณสมบัติต้องตรวจก่อนใช้จริง
```

<a id="doc-07"></a>

## DOC-07 — คู่มือสมาชิกห้องสมุด

```text
สร้างใบข้อมูล 3:4 ของห้องสมุดชุมชนสมมติด้วย [APPROVED MEMBERSHIP RULES] มี "สมัคร", "ยืม" และ "คืน" แต่ละส่วนภาพง่ายหนึ่งกับคำสั้นที่ให้ ใช้ครีม ตัวกรมท่า ช่องห่าง ห้ามแต่งค่าใช้จ่าย เอกสารยืนยัน เวลาเปิด หรือจำกัดยืม ตัวแปร: กฎที่ตรวจและชื่อที่อนุมัติ ไม่ใส่ข้อมูลส่วนตัวหรือรหัสสแกน
```

<a id="doc-08"></a>

## DOC-08 — เลย์เอาต์เทียบเอกสาร

```text
สร้างเลย์เอาต์ข้างกัน 16:9 เทียบเอกสารสาธารณะสั้นสองเวอร์ชันที่ให้ คงสเกลหน้าเท่ากัน ไฮไลต์เฉพาะ [APPROVED CHANGED PASSAGES] เหลืองอ่อน ป้าย "ก่อนหน้า" และ "แก้ไขแล้ว" คงคำตรงทั้งหมด ไม่ตีความกฎหมาย เพิ่มความเห็น หรือเปลี่ยนส่วนคงเดิม ตัวแปร: สองข้อความต้นฉบับและแผนเปลี่ยนชัด เป็นแนวคิดเทียบภาพไม่ใช่รีวิวกฎหมายหรือไฟล์ติดตามแก้
```

<a id="doc-09"></a>

## DOC-09 — ใบส่งต่องานอาสา

```text
สร้างแนวคิดใบส่งต่อ 3:4 ด้วย [APPROVED TASK LIST] แบ่ง "เสร็จแล้ว", "กำลังทำ", "กะถัดไป" มีช่องเลือกหนึ่งต่อรายการ เว้นช่องว่างเว้นแต่ระบุสถานะชัด ตัวใหญ่ชัด กริดง่าย ไม่มีภาพตกแต่ง ห้ามแต่งชื่อ เส้นตาย ติดต่อ หรือคำอ้างเสร็จ ตัวแปร: รายการงานและสถานะ การใช้จริงต้องมีข้อความแก้ได้
```

<a id="doc-10"></a>

## DOC-10 — รายการราคานิทรรศการ

```text
สร้างเลย์เอาต์ราคาสมมติ 3:4 ด้วย [APPROVED ITEM TABLE] จัดชื่อ ขนาด ราคาเป็นสามคอลัมน์ชัดรายการละแถว ใช้ชื่อมีเชิงเรียบ ตัวเลขไม่มีเชิง พื้นขาว คงสัญลักษณ์เงิน จุดทศนิยม และหน่วยตรง ไม่แต่งส่วนลด ภาษี ขายแล้ว หรือประวัติศิลปิน ตัวแปร: ตารางที่ตรวจและชื่อ เป็นแนวคิดตัวพิมพ์ไม่ใช่ข้อเสนอหรือบันทึกธุรกรรม
```
