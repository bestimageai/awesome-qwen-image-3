# การเดินทาง ภูมิทัศน์ เมือง และยานพาหนะ

ชุดพรอมป์ต์ Qwen Image 3.0 จำนวนสิบรายการ เปลี่ยนข้อมูลในวงเล็บเหลี่ยมก่อนสร้างภาพ ข้อความในเครื่องหมายคำพูดต้องแสดงตรงตามที่ระบุ ไม่ต้องแปลเว้นแต่สั่งไว้อย่างชัดเจน ผลลัพธ์ต้องผ่านการตรวจสอบโดยมนุษย์

<a id="trv-01"></a>

## TRV-01 — โปสเตอร์เที่ยวรถรางบนเนิน

```text
สร้างแนวคิดโปสเตอร์เที่ยว 3:4 ของเมืองบนเนินสมมติ แสดงรถรางเหลืองเล็กหนึ่งคันขึ้นถนนโค้งระหว่างบ้านพาสเทล เห็นทะเลไกล ใช้ภาพสกรีนต้นฉบับ เงาดินเผาอุ่น และพื้นที่ชื่อชัด แสดงเพียง "เลือกทางที่ยาวขึ้น" และ "สุดสัปดาห์บนเนินเขา" ห้ามคัดแคมเปญท่องเที่ยวจริง สถานที่รู้จัก หรือโลโก้ขนส่ง ตัวแปร: ชุดสีและชื่อที่อนุมัติ อย่าเสนอว่าเป็นภาพจุดหมายจริง
```

<a id="trv-02"></a>

## TRV-02 — ภาพเส้นทางเดิน

```text
ใช้ [VERIFIED MAP AND ROUTE] สร้างคู่มือเดินย่าน 3:4 คงการเชื่อมถนน จุดเริ่มจบ และจุดแวะที่ให้ เน้นเส้นเดียวด้วยสีน้ำเงินต่อเนื่องและหมุดเลขตรงรายการ ใช้ไอคอนสถาปัตยกรรมง่ายและป้ายอ่านได้ ห้ามแต่งระยะ เวลาเปิด การเข้าถึง หรือจุดข้ามปลอดภัย ใส่ "ตรวจสอบสภาพพื้นที่จริง" ท้ายภาพ ตัวแปร: แผนที่ เส้นทาง จุดแวะ และข้อความที่อนุมัติ
```

<a id="trv-03"></a>

## TRV-03 — ภาพภูมิทัศน์ชายฝั่ง

```text
สร้างภูมิทัศน์ชายฝั่งสมมติ 16:9 มีชั้นหินมืด หมอกทะเลต่ำ และทางแคบหนึ่งเส้นบนแหลมหญ้า ใช้มุมถ่ายกว้างธรรมชาติยามอาทิตย์ขึ้น ไฮไลต์พอดีและขนาดคลื่นสมจริง ขอบฟ้าราบและทางเชื่อมจริง ไม่มีคน ข้อความ สถานที่รู้จัก หรือเงาดวงอาทิตย์เป็นไปไม่ได้ ตัวแปร: อากาศ ธรณีชายฝั่ง และชุดสี ระบุว่าเป็นภาพสร้างไม่ใช่ภาพถ่ายจุดหมายจริง
```

<a id="trv-04"></a>

## TRV-04 — ฉากสถานีกลางคืน

```text
สร้างฉากชานชาลาชานเมืองสมมติ 16:9 หลังฝน มีม้านั่งว่างหนึ่งตัว ที่พักเล็ก และรถไฟไร้แบรนด์หยุดในพื้นหลัง ใช้แสงอุ่นจากหลังคาผสมแสงฟ้าเย็นสมจริง เงาสะท้อนพอดีและหมอกบาง รางขนานและเสารองสมเหตุสมผล ไม่มีตารางอ่านได้ ป้ายปลายทาง คน โลโก้ผู้ให้บริการ หรือกิจกรรมอันตรายเร้าใจ ตัวแปร: สไตล์สถาปัตยกรรม อากาศ และแสง
```

<a id="trv-05"></a>

## TRV-05 — แก้ภาพคงอัตลักษณ์ยานพาหนะ

```text
ใช้ภาพจักรยานที่อนุญาตสร้างภาพแค็ตตาล็อกสี่เหลี่ยม เปลี่ยนเฉพาะพื้นเป็นสตูดิโอเทาอ่อนและแสงเป็นด้านข้างนุ่ม คงรูปโครง ขนาดล้อ ซี่ล้อ ชุดขับ อุปกรณ์ สี และสติกเกอร์ทุกชิ้นตรงเดิม ยางทั้งสองแตะพื้นมีเงาสัมผัสสอดคล้อง ห้ามดัดส่วนเสีย เพิ่มอะไหล่ หรือเปลี่ยนแบรนด์ ตัวแปร: ภาพอ้างอิงและโทนพื้นที่อนุมัติ
```

<a id="trv-06"></a>

## TRV-06 — ภาพบ้านพักสงบ

```text
สร้างโปสเตอร์กระท่อมภูเขาสมมติ 3:4 มีกระท่อมไม้เล็กหนึ่งหลังข้างทะเลสาบและเงาป่าซ้อนหลัง ใช้กวอชมีผิว เขียวสนหม่น และแสงหน้าต่างอุ่น เว้นหนึ่งในสี่บนให้ "ขอบฟ้าที่เงียบกว่า" และขอบล่าง "ศึกษากระท่อม" เงาสะท้อนตรงบ้านและภูมิประเทศสมจริง ไม่มีชื่อที่พักจริง คำอ้างจอง ดาว หรือสิ่งอำนวยความสะดวกแต่ง ตัวแปร: ภูมิทัศน์ สี และข้อความที่อนุมัติ
```

<a id="trv-07"></a>

## TRV-07 — เปรียบเทียบเดินทางในเมือง

```text
สร้างภาพบรรณาธิการ 16:9 เปรียบเทียบจักรยาน รถราง และทางเดินในบล็อกถนนสมมติเดียว แยกทั้งสามชัดและให้น้ำหนักภาพเท่ากัน ใช้มุมไอโซเมตริกสะอาด สีหม่น และป้าย "ปั่น", "นั่งรถ" และ "เดิน" ไม่เพิ่มเวลาเดินทาง ตัวเลขปล่อยก๊าซ หรือคำอ้างปลอดภัยกว่า คงราง ทางเท้า และทางข้ามเชื่อมกัน ตัวแปร: ผังถนนที่อนุมัติและป้าย
```

<a id="trv-08"></a>

## TRV-08 — บอร์ดรถยนต์สี่มุม

```text
ใช้ภาพรถที่อนุญาตสร้างบอร์ดแนวคิดสี่มุม 16:9: หน้า หลัง ซ้าย และสามส่วนสี่ คงสัดส่วนตัวถัง ฐานล้อ ไฟ กระจก และสีข้ามมุม ใช้สตูดิโอกลางเดิมและสเกลคงที่ กำกับแต่ละมุมหนึ่งครั้ง ลบทะเบียนหรือใช้ป้ายว่างที่ชัดว่าเป็นสมมติ ไม่มีตราแต่ง ระยะวิ่ง หรือคำอ้างประสิทธิภาพ ตัวแปร: ภาพอ้างอิงและป้ายมุมที่ตรง
```

<a id="trv-09"></a>

## TRV-09 — หน้าคู่สมุดเที่ยว

```text
สร้างหน้าคู่สมุดบันทึกเที่ยวภาพประกอบ 3:2 สำหรับสุดสัปดาห์ริมแม่น้ำสมมติ วางภาพร่างสะพานซ้าย และภาพศึกษาเล็กสามภาพของเรือ แก้วคาเฟ่ และกิ่งใบด้านขวา ใช้เส้นดินสอ สีน้ำ และกระดาษงาช้าง แสดงเฉพาะ "สุดสัปดาห์ริมแม่น้ำ" และ "บันทึกวันเนิบช้า" เว้นพื้นที่บันทึกอื่นว่างจริง ไม่มีตั๋วปลอม ตราหนังสือเดินทาง ที่อยู่ หรือลายมือปลอม ตัวแปร: แนวคิดสถานที่และชุดสี
```

<a id="trv-10"></a>

## TRV-10 — สามช่องอากาศต่อเนื่อง

```text
สร้างภาพสามช่อง 16:9 ของท่าเรือริมทะเลสาบสมมติเดิมในฟ้าใส ฝนเบา และหมอก ตรึงกล้อง กระดานท่า ราว เรือจอด และแนวฝั่ง เปลี่ยนเฉพาะทัศนวิสัย ฟ้า ความเปียก และการตอบสนองแสง กำกับ "ฟ้าใส", "ฝน" และ "หมอก" เงาสะท้อนถูกฟิสิกส์ ไม่เพิ่มหรือลบของข้ามช่อง ไม่มีพยากรณ์ วัน หรือคำอ้างสถานที่จริง ตัวแปร: ภาพฉากที่อนุมัติและป้ายอากาศ
```
