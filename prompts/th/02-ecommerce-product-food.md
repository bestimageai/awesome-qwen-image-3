# อีคอมเมิร์ซ ผลิตภัณฑ์ และอาหาร

ชุดพรอมป์ต์ Qwen Image 3.0 จำนวนสิบรายการ เปลี่ยนข้อมูลในวงเล็บเหลี่ยมก่อนสร้างภาพ ข้อความในเครื่องหมายคำพูดต้องแสดงตรงตามที่ระบุ ไม่ต้องแปลเว้นแต่สั่งไว้อย่างชัดเจน ผลลัพธ์ต้องผ่านการตรวจสอบโดยมนุษย์

<a id="com-01"></a>

## COM-01 — ภาพหลักโคมไฟตั้งโต๊ะแบบโมดูลาร์

```text
สร้างภาพถ่ายแค็ตตาล็อกสี่เหลี่ยมจัตุรัสของโคมไฟตั้งโต๊ะแบบโมดูลาร์สมมติ โคมสีเหลืองเนื้อเนยด้านหนึ่งดวงมีฐานทรงกระบอกถ่วงน้ำหนัก แขนบานพับหนึ่งแขน และฝาครอบกรวยตื้น วางบนโต๊ะสีงาช้างพร้อมปุ่มซ่อมสีโคบอลต์ข้างฐาน ใช้แสงนุ่มจากซ้ายบนและเงาสัมผัสเบา ๆ มีข้อความเพียง "LATCH" บนฐานและ "เก็บแสงนี้ไว้" ที่ขอบซ้ายบน คงข้อต่อสมเหตุสมผลและสายไฟหนึ่งเส้น ไม่มีตรารับรอง ราคา หรือชิ้นส่วนเพิ่ม ตัวแปร: ผิววัสดุและข้อความแบรนด์ที่อนุมัติ
```

<a id="com-02"></a>

## COM-02 — มุมมองสินค้ากล่องอาหาร

```text
ใช้ภาพสินค้าที่ได้รับอนุญาตหนึ่งภาพเป็นแบบอ้างอิงรูปทรง สร้างงานนำเสนอ 16:9 ที่มีสี่มุมขนาดเท่ากันของกล่องอาหารสี่เหลี่ยมผืนผ้าใบเดียว: ปิดมองหน้า ปิดมองหลัง เปิดมองบน และระยะใกล้ตัวล็อก ใช้พื้นหลังอ่อนต่อเนื่องและแสงนุ่มเหมือนกัน กำกับเฉพาะ "ด้านหน้า", "ด้านหลัง", "ด้านใน" และ "ตัวล็อก" คงจำนวนช่อง สีซีล และตำแหน่งล็อกทุกมุม ห้ามแต่งขนาดหรือคุณสมบัติวัสดุ เว้นช่องว่างระหว่างภาพให้เห็น ตัวแปร: แบบอ้างอิงสินค้าและป้ายที่แปลแล้ว
```

<a id="com-03"></a>

## COM-03 — กระป๋องชาสามใบ

```text
สร้างแนวคิดบรรจุภัณฑ์ 3:2 สำหรับกระป๋องชาสมมติสามใบทรงกระบอกเดียวกัน เรียงเป็นเส้นตรงด้วยแถบฉลากสีครีม ลาเวนเดอร์ และเขียวเสจที่ต่างกัน ใช้แบรนด์ร่วม "Field Notes" และชื่อตามลำดับ "เช้า", "เที่ยง" และ "ค่ำ" ไม่เพิ่มข้อความอื่น ถ่ายบนชั้นสีกลางโดยแสงสะท้อนและขนาดสม่ำเสมอ ฝา การจัดแนวตัวอักษร และความกว้างฉลากต้องเหมือนกันทั้งสามใบ ห้ามกล่าวอ้างส่วนผสม แหล่งกำเนิด หรือประโยชน์สุขภาพ ตัวแปร: แบรนด์ ชื่อ และสีที่อนุมัติ
```

<a id="com-04"></a>

## COM-04 — แผงคุณสมบัติกระเป๋าเป้

```text
ใช้ภาพอ้างอิงกระเป๋าเป้ที่ได้รับอนุญาตและคำอธิบายคุณสมบัติสามข้อที่ให้มา สร้างภาพข้อมูลสินค้า 3:4 วางกระเป๋าทั้งใบด้านซ้าย จัดวงกลมรายละเอียดสามวงแนวตั้งด้านขวา เชื่อมเฉพาะซิป สายสะพาย และกระเป๋าข้างที่เกี่ยวข้อง แสดง [APPROVED FEATURE LABELS] ตรงตามต้นฉบับข้างวงที่ตรงกัน ใช้พื้นเทาอ่อนและแสงสตูดิโอควบคุม คงโครงสร้างและสีจริง ห้ามอ้างกันน้ำ ความจุ หรือการยศาสตร์เว้นแต่ให้ข้อมูลชัดเจน ตัวแปร: ภาพอ้างอิง ป้าย และสีเน้น
```

<a id="com-05"></a>

## COM-05 — กระบวนการทำขนมปัง

```text
สร้างภาพสี่ช่อง 16:9 แสดงขั้นตอนซาวร์โดว์ของร้านขนมปังสมมติ: ผสมแป้ง พับแป้ง กรีดก้อนที่ขึ้นรูป และนำเสนอขนมปังอบแล้ว ใช้ภาพสารคดีระยะใกล้บนโต๊ะไม้ตัวเดียว ลำดับอ่านซ้ายไปขวา และมือเปื้อนแป้งชุดเดิม กำกับ "ผสม", "พับ", "กรีด" และ "อบ" คงสี่ช่องพอดีและแยกแป้งดิบจากเปลือกอบชัดเจน ไม่เพิ่มอุณหภูมิหรือเวลา นี่เป็นภาพแนวคิดอธิบายกระบวนการ ไม่ใช่คำแนะนำความปลอดภัยอาหาร ตัวแปร: ชนิดแป้งและป้ายที่อนุมัติ
```

<a id="com-06"></a>

## COM-06 — ชุดอาหารกลางวัน

```text
สร้างภาพแค็ตตาล็อกมุมบน 16:9 ของชามอาหารกลางวันสมจริงสี่ใบในกริดสองคูณสอง: ฟักทองอบกับข้าว เห็ดกับเส้น ถั่วเลนทิลกับแครอต และมะเขือเทศกับคูสคูส ใช้ชามขาวตื้นเหมือนกัน เนื้อสัมผัสต่างกัน แสงกลางวันนุ่ม และโต๊ะเขียวหม่น เว้นช่องเท่ากันและไม่มีช้อนส้อมทับกัน ห้ามเพิ่มข้อความ แคลอรี การรับรองด้านอาหาร หรือป้ายวัตถุดิบ ปริมาณต้องสมเหตุสมผลและไม่ใช้พื้นผิวอาหารซ้ำ ตัวแปร: สูตรสี่อย่างที่ให้มา ผิวชาม และสีโต๊ะ
```

<a id="com-07"></a>

## COM-07 — เมนูเส้นสองภาษา

```text
สร้างเมนู 3:4 สำหรับคาเฟ่สมมติ "小巷面馆" พร้อมชื่อรอง "LANE NOODLES" ใช้กระดาษงาช้าง ตัวอักษรสีถ่าน และสามแถวแนวนอน แต่ละแถวจับคู่ภาพชามเล็กสมจริงด้านซ้ายกับข้อความด้านขวา แสดง "番茄面 · Tomato noodles · 28", "菌菇面 · Mushroom noodles · 32" และ "芝麻面 · Sesame noodles · 30" ให้ตรงทุกตัว จับคู่น้ำซุปมะเขือเทศแดง หน้าเห็ด และน้ำปรุงงากับแถวที่ถูกต้อง ไม่มีสัญลักษณ์เงิน สารก่อภูมิแพ้ เมนูเพิ่ม หรือคำกล่าวอ้าง นี่เป็นข้อความเมนูสมมติ ให้คงทั้งสองภาษาตามเดิมทุกประการ
```

<a id="com-08"></a>

## COM-08 — เปรียบเทียบผ้าตกแต่งห้อง

```text
ใช้ภาพห้องที่ได้รับอนุญาตหนึ่งภาพสร้างภาพเปรียบเทียบสองช่อง 16:9 ช่องซ้ายคงภาพต้นฉบับ ช่องขวาเปลี่ยนเฉพาะผ้าคลุมโซฟาและหมอนสองใบเป็น [APPROVED COLORS] คงหน้าต่าง ผนัง ตำแหน่งเฟอร์นิเจอร์ มุมกล้อง และแสง กำกับ "ต้นฉบับ" และ "แนวคิดผ้าตกแต่ง" ในขอบบางนอกภาพถ่าย คงรอยพับผ้าและเงาสัมผัส ห้ามซ่อมห้อง ลบของส่วนตัว หรือเพิ่มของตกแต่ง ตัวแปร: ภาพต้นฉบับและสี
```

<a id="com-09"></a>

## COM-09 — คำแนะนำใช้บรรจุภัณฑ์เติม

```text
สร้างแนวคิดการใช้บรรจุภัณฑ์ 3:4 มีสามช่องซ้อนแนวตั้ง: ขวดเปล่าข้างถุงเติม ปากถุงเทลงขวด และขวดปิดข้างถุงเปล่าพับ ใช้ขวดสีอำพันไร้แบรนด์กับถุงงาช้างชุดเดิมทุกช่อง พร้อมภาพเทคนิคสะอาดและลูกศรเขียวเสจ แสดงเฉพาะ "เปิด", "เติม" และ "ปิด" มีสามขั้นพอดี ไม่มีของเหลวหกหรือทิศการเทกลับด้าน อย่าสื่อว่าเข้ากันได้กับอาหารหรือสารเคมี ตัวแปร: แบบภาชนะที่ตรวจสอบแล้วและป้ายคำแนะนำที่อนุมัติ
```

<a id="com-10"></a>

## COM-10 — ภาพจัดวางสิ่งของในชุด

```text
ใช้ [APPROVED CONTENTS LIST] และภาพสินค้าที่ได้รับอนุญาต สร้างภาพจัดวางมุมบนสี่เหลี่ยมจัตุรัสที่แสดงสิ่งของในชุดเครื่องเขียนเริ่มต้นอย่างละหนึ่งชิ้นเท่านั้น วางสมุดกลางภาพและของชิ้นเล็กรอบ ๆ โดยเว้นระยะกว้าง ใช้ผิวกระดาษโทนอุ่นและแสงบนนุ่ม เพิ่มเฉพาะชื่อ "ภายในชุด" และชื่อสิ่งของที่ให้มาตรงกับวัตถุ คงจำนวน ขนาดสัมพันธ์ และสี ห้ามเพิ่มของแถม ราคา ตรารับประกัน หรืออุปกรณ์ที่ไม่มีในรายการ
```
