# ภาพถ่ายและความสมจริงแบบภาพยนตร์

ชุดพรอมป์ต์ Qwen Image 3.0 จำนวนสิบรายการ เปลี่ยนข้อมูลในวงเล็บเหลี่ยมก่อนสร้างภาพ ข้อความในเครื่องหมายคำพูดต้องแสดงตรงตามที่ระบุ ไม่ต้องแปลเว้นแต่สั่งไว้อย่างชัดเจน ผลลัพธ์ต้องผ่านการตรวจสอบโดยมนุษย์

<a id="pho-01"></a>

## PHO-01 — ภาพเช้าตลาด

```text
สร้างภาพสารคดีสมมติ 3:4 ของคนจัดดอกไม้ผู้ใหญ่กำลังเรียงถังดอกไม้ไร้แบรนด์ก่อนเปิด ใช้มุมกลางระดับตา แสงเช้าครึ้ม สีธรรมชาติเรียบ มือสมจริง ทางเท้าชื้น และข้อบกพร่องเล็กในร้าน คนพื้นหลังไม่ชัด งดป้ายร้านอ่านได้ ไม่มีหน้าคนดัง ยิ้มโฆษณาจัดฉาก HDR เกิน หรือคำอ้างงานแต่ง ตัวแปร: คนสมมติ ดอกไม้ และลักษณะสถานที่
```

<a id="pho-02"></a>

## PHO-02 — อาหารเช้าจากกล้องมือถือ

```text
สร้างภาพมือถือสบาย ๆ 3:4 ของอาหารเช้ากินไปครึ่ง: ขนมปังปิ้ง จานแยมเล็ก และแก้วเซรามิกบนโต๊ะครัว ใช้แสงหน้าต่างนุ่ม ระยะชัดปานกลาง และเฟรมไม่สมบูรณ์นิดหน่อย ปริมาณจริง เศษหลากหลาย เงาแก้วสมจริง ไม่มีข้อความ แบรนด์หรู พื้นเบลอเกิน หรือพร็อพสตูดิโอขัดเงา ตัวแปร: อาหาร พื้นโต๊ะ และทิศแสง ต้องเหมือนทุกวันไม่ใช่แค็ตตาล็อก
```

<a id="pho-03"></a>

## PHO-03 — แสงสินค้าที่นำกลับใช้ได้

```text
ใช้ภาพสินค้าที่อนุญาตสร้างภาพสตูดิโอสี่เหลี่ยมบนเทาอ่อน วางแสงนุ่มกว้างซ้ายกล้องและแสงเติมขาวเบาขวา คงรูปทรง สี ป้าย และรอยใช้ คงเงาสัมผัสติดพื้นหนึ่งเงาและไฮไลต์ลดธรรมชาติ ไม่มีอุปกรณ์เพิ่ม ข้อความ ของลอย หรือขอบคมเกิน ตัวแปร: ภาพและพื้นที่อนุมัติ ใช้คำอธิบายแสงเดิมเมื่อทำสินค้าที่เกี่ยวกัน ไม่รับประกันผลเหมือนกัน
```

<a id="pho-04"></a>

## PHO-04 — เฟรมป้ายรถเมล์กลางคืน

```text
สร้างเฟรมภาพยนตร์นิ่งสมมติ 16:9 ของป้ายรถเมล์ว่างกลางคืนหลังฝนเบา ใช้โคมบนอุ่นเทียบถนนไกลเย็น เงาสะท้อนพอดี และเงาลึกแต่อ่านได้ มีหนังสือพิมพ์พับหนึ่งฉบับบนม้านั่งไม่เห็นคำ มุม เงากระจก และการตกแสงสมจริง ไม่มีคน เลขสาย โฆษณา หรือคำอ้างสถานที่จริง ตัวแปร: แบบป้าย อากาศ และสมดุลสี
```

<a id="pho-05"></a>

## PHO-05 — แถบภาพสี่เฟรม

```text
สร้างแถบภาพ 16:9 สี่เฟรมเท่ากันของช่างปั้นผู้ใหญ่ต้นฉบับหันไปหน้าต่าง แสดงช่วงต่าง: ก้ม เริ่มหัน รับแสง ยิ้มเบา ตรึงตัวตน ชุด ห้อง และการรับแสง ใช้เกรนฟิล์มบางและการเคลื่อนไหวต่างจริง ไม่ท่าซ้ำ ไม่มีเลขเฟรม แบรนด์ฟิล์ม หรือข้อความ ตัวแปร: คนสมมติและสตูดิโอ นี่เป็นแผ่นภาพนิ่งจัดไม่ใช่เฟรมตัดวิดีโอ
```

<a id="pho-06"></a>

## PHO-06 — ศึกษาเงาสะท้อนแก้ว

```text
สร้างภาพนิ่งสี่เหลี่ยมของแก้วใสหนึ่งใบใส่น้ำครึ่งบนโต๊ะน้ำเงินเข้ม ใช้แสงข้างกว้างและแผ่นสะท้อนสีอ่อนแนวตั้ง เห็นผิวน้ำโค้งบางและการหักเหสมจริง ขอบแก้ววงรี ฐานติดพื้น น้ำแนวนอน ไม่มีข้อความ น้ำแข็ง ผลไม้ แก้วเพิ่ม หรือเงาภายในเป็นไปไม่ได้ ตัวแปร: รูปแก้ว ระดับน้ำ และโทนพื้น
```

<a id="pho-07"></a>

## PHO-07 — ภาพใกล้ไออาหาร

```text
สร้างภาพใกล้ 4:3 ของชามเซรามิกเรียบใส่ซุปผักข้างหน้าต่าง ใช้แสงธรรมชาติอุ่นและไอบางไม่สม่ำเสมอลอยขึ้น ผักจำได้ เงาของเหลวสอดคล้อง ขอบชามสะอาด ไม่มีข้อความ ช้อนลอย ควันมาก ป้ายแคลอรี หรืออ้างสุขภาพ ตัวแปร: สูตรที่อนุมัติ ชาม และทิศแสง อย่าให้ไอเป็นริบบิ้นทึบตกแต่ง
```

<a id="pho-08"></a>

## PHO-08 — มุมกว้างเวิร์กช็อปเงียบ

```text
สร้างภาพภายในกว้าง 16:9 ของร้านซ่อมสมมติตอนปิด มีโต๊ะไม้กลาง โคมโต๊ะเปิดหนึ่งดวง เครื่องมือเก็บเรียบผนังหลัง ใช้มุมกว้างปานกลางเส้นตั้งตรง แสงใช้งานอุ่นกับแสงแวดล้อมเย็น ทางเดินโล่ง ของมีที่รอง ไม่มีคน แบรนด์อ่านได้ หมอกภาพยนตร์ หรือห้องเป็นไปไม่ได้ ตัวแปร: ประเภทร้านและวัสดุที่อนุมัติ
```

<a id="pho-09"></a>

## PHO-09 — รายละเอียดวัสดุชัดตื้น

```text
สร้างมาโคร 3:2 ของตะเข็บระหว่างแคนวาสเย็บกับหนังเก่าบนกระเป๋าไร้แบรนด์ โฟกัสสามฝีเข็มกลางชัดแล้วนุ่มทีละน้อยออกขอบ ใช้แสงธรรมชาติกว้าง เส้นใยจริง สีหม่น ระยะฝีเข็ม รู และความหนาสมจริง ไม่มีข้อความ ตรา คมสุดโต่ง หรือลายผิวปั๊มซ้ำ ตัวแปร: รายละเอียดที่อนุญาตและสีวัสดุ
```

<a id="pho-10"></a>

## PHO-10 — แนวคิดน้ำเปิดรับแสงนาน

```text
สร้างภาพภูมิทัศน์สมมติ 16:9 สะพานหินคนเดินเล็กข้ามลำธาร ใช้ลักษณะเปิดรับแสงนานให้น้ำเคลื่อนนุ่มแต่สะพาน หิน ใบคม วางสะพานนอกกลางและน้ำไหลรอบหินสมจริง ใช้แสงครึ้มกับเขียวธรรมชาติ ไม่มีข้อความ คน สถานที่รู้จัก หมอกมาก หรือน้ำเรือง ตัวแปร: แบบสะพานและฤดู ห้ามอ้างค่ากล้องหรือสถานที่จริง
```
