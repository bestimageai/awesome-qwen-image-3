# อินเทอร์เฟซ การแก้ไขแบบควบคุม และการปรับให้เข้ากับภาษา

ชุดพรอมป์ต์ Qwen Image 3.0 จำนวนสิบรายการ เปลี่ยนข้อมูลในวงเล็บเหลี่ยมก่อนสร้างภาพ ข้อความในเครื่องหมายคำพูดต้องแสดงตรงตามที่ระบุ ไม่ต้องแปลเว้นแต่สั่งไว้อย่างชัดเจน ผลลัพธ์ต้องผ่านการตรวจสอบโดยมนุษย์

<a id="dig-01"></a>

## DIG-01 — อินเทอร์เฟซมือถือห้องสมุดเครื่องมือ

```text
สร้างบอร์ด 16:9 ที่มีหน้าจอมือถือสามหน้าของแอปสมมติ "Borrow Bench": แค็ตตาล็อก รายละเอียดของ และยืนยันจอง ใช้พื้นงาช้าง ตัวอักษรกรมท่า ปุ่มสีเขียวน้ำเงิน และการ์ดมุมมนเหมือนกัน แสดงสว่านเหลืองเป็นของที่เลือก แสดงเฉพาะ "Borrow Bench", "ค้นหาเครื่องมือ", "สว่านไร้สาย", "จอง", "เวลารับ", "วันเสาร์ 10:00", "บันทึกการจองแล้ว" และ "ดูการจอง" บนหน้าที่เหมาะสม ไม่มีราคา ข้อมูลส่วนตัว หรือป้ายนำทางเพิ่ม นี่เป็นแนวคิดอินเทอร์เฟซนิ่ง อย่าสื่อว่าปุ่มใช้งานได้
```

<a id="dig-02"></a>

## DIG-02 — หน้าตรวจสอบการนำเข้า CSV

```text
สร้างภาพจำลองอินเทอร์เฟซเดสก์ท็อป 16:9 สำหรับแอปคลังสมมติ "Stockroom" แสดงตารางตรวจนำเข้ามีคอลัมน์ "รายการ", "จำนวน" และ "สถานะ" ใส่ตัวอย่างสามแถวที่ให้ โดยแถวหนึ่งระบุชัด "ต้องตรวจสอบ" เหนือตารางเขียน "ตรวจสอบข้อมูลนำเข้า" ใต้ตารางมีปุ่ม "ย้อนกลับ" และ "นำเข้าแถวที่ถูกต้อง" ใช้เค้าโครงขาวสะอาด เน้นข้อผิดพลาดสีอำพัน และแถบข้างอ่านง่ายที่มีเพียง "สินค้าคงคลัง" คงข้อมูลที่ให้และไม่แสดงข้อมูลส่วนตัว ตัวแปร: แถวตัวอย่างและข้อความที่อนุมัติ
```

<a id="dig-03"></a>

## DIG-03 — หน้าแรกการเดินทางรถไฟภูมิภาค

```text
สร้างแนวคิดหน้าแรกเดสก์ท็อป 16:9 สำหรับตัววางแผนเที่ยวสมมติ "Local Lines" ใช้ภาพรถไฟชายฝั่งขนาดใหญ่ด้านขวาและแผงค้นหาใช้งานง่ายด้านซ้าย แสดงให้ตรงว่า "เลือกเส้นทางที่ช้าลง", "จาก", "ถึง", "วันเดินทาง" และ "ค้นหาเที่ยวเดินทาง" ปล่อยช่องกรอกว่าง ใช้พื้นครีม ปุ่มเขียวเข้ม และระยะห่างกว้าง ไม่มีตารางเดินรถจริง ค่าโดยสาร โลโก้ผู้ให้บริการ หรือคำกล่าวอ้างที่นั่งว่าง รถไฟต้องสมเหตุสมผลทางกายภาพและข้อความแยกจากภาพ ตัวแปร: ภาพภูมิภาคและพาดหัวที่อนุมัติ
```

<a id="dig-04"></a>

## DIG-04 — HUD เกมร่วมมือ

```text
สร้างแนวคิด HUD นิ่ง 16:9 สำหรับเกมส่งของบนภูเขาสมมติ เว้นหกสิบเปอร์เซ็นต์กลางทางหิมะไม่ให้ถูกบัง วางเข็มทิศเล็กด้านบน แถบสถานะเพื่อนสองแถบซ้ายบน และช่องสัมภาระสามช่องขวาล่าง แสดงเฉพาะ "เหนือ", "ทีม", "พัสดุ", "เชือก" และ "แผนที่" ใช้รูปทรงตัดกันสูงกับจุดเน้นอำพันพอดี ไม่ใช่โฮโลแกรมลอยแบบภาพยนตร์ หลีกเลี่ยงเครื่องหมายทหารจริง ข้อความจิ๋วอ่านไม่ได้ และเลเยอร์ทับมากเกิน ตัวแปร: ฉากเกมและป้ายที่อนุมัติ
```

<a id="dig-05"></a>

## DIG-05 — เปลี่ยนข้อความโปสเตอร์

```text
ใช้ภาพ 1 เป็นเป้าหมายแก้ไขและ [APPROVED SOURCE-TO-TARGET TEXT MAP] เป็นข้อความแทนที่เพียงแหล่งเดียว เปลี่ยนคำที่ระบุโดยไม่เปลี่ยนภาพถ่าย ภาพประกอบ ชุดสี ขอบ โลโก้ หรือข้อความนอกเป้าหมาย คงน้ำหนักตัวอักษรและลำดับชั้น ปรับตัดบรรทัดเฉพาะเมื่อภาษาปลายทางจำเป็น รักษาวรรคตอน เครื่องหมายกำกับ และทิศอ่านให้ถูก ลบคำเดิมแทนการทำซ้ำ อย่าแปลส่วนที่ไม่ได้ระบุหรือเพิ่มคำอธิบาย ตัวแปร: ภาพต้นฉบับและแผนจับคู่ข้อความครบถ้วน
```

<a id="dig-06"></a>

## DIG-06 — ซ่อมความเสียหายภาพถ่าย

```text
ใช้ภาพถ่ายสแกนที่ได้รับอนุญาตหนึ่งภาพเป็นเป้าหมาย แก้เฉพาะฝุ่น รอยขีด และรอยพับที่เห็น โดยเติมส่วนขาดเล็กจากพื้นผิวรอบข้าง คงตัวตน อายุ สีหน้า การครอป เสื้อผ้า เกรนเดิม และช่วงโทน ห้ามลงสีต้นฉบับขาวดำ ทำผิวเรียบ เปิดตา หรือแต่งวัตถุพื้นหลัง คงพื้นที่ขาดใหญ่ที่ไม่แน่ใจไว้แทนการเดารายละเอียด ส่งภาพฟื้นฟูหนึ่งภาพไม่มีป้ายเปรียบเทียบหรือลายน้ำ ตัวแปร: ภาพต้นฉบับและบริเวณซ่อมที่ทำเครื่องหมายชัด
```

<a id="dig-07"></a>

## DIG-07 — ประกอบภาพสินค้าจากสามภาพอ้างอิง

```text
ใช้ภาพ 1 เป็นฉากโต๊ะหลัก ภาพ 2 เป็นแบบถ้วยเซรามิกที่ตรงทุกประการ และภาพ 3 เป็นแบบสีเคลือบเท่านั้น วางถ้วยหนึ่งใบจากภาพ 2 บนที่รองว่างในภาพ 1 และใช้เฉพาะเฉดเคลือบที่ให้ คงกล้องหลัก การครอป วัตถุรอบข้าง และรูปทรงถ้วย จับคู่ทิศแสง เงาสัมผัส มุมมอง และเงาสะท้อน ห้ามคัดวัตถุหรือข้อความจากภาพ 3 ไม่เพิ่มข้อความ ตัวแปร: ภาพที่ได้รับอนุญาตสามภาพและตำแหน่งถ้วยที่ต้องการ
```

<a id="dig-08"></a>

## DIG-08 — จากภาพร่างสู่ห้องอ่านหนังสือ

```text
ใช้ภาพร่างห้องที่อนุมัติเป็นแบบผัง สร้างแนวคิดห้องอ่านหนังสือสมจริง 4:3 มีชั้นโอ๊กสีอ่อน ม้านั่งเขียวมอส และแสงเพดานกระจาย คงผนัง หน้าต่าง ประตู และพื้นที่วางเฟอร์นิเจอร์ทุกชิ้นจากภาพร่าง ใช้ชุดวัสดุตกแต่งเฉพาะพื้นผิวที่มีอยู่ มุมมองต้องสอดคล้องและความกว้างทางเดินดูไม่เปลี่ยน ไม่เพิ่มคน เฟอร์นิเจอร์ ต้นไม้ หรือป้าย นี่เป็นภาพแนวคิด ไม่ใช่แบบก่อสร้างที่มีขนาด ตัวแปร: ภาพร่างและวัสดุที่อนุมัติ
```

<a id="dig-09"></a>

## DIG-09 — สถานะว่างที่เข้าถึงได้

```text
สร้างภาพจำลองอินเทอร์เฟซมือถือ 3:4 สำหรับรายการอ่านที่บันทึกไว้แต่ยังว่าง ใช้พื้นครีม ข้อความกรมท่า และภาพเล็กของหนังสือปิดสามเล่ม แสดงให้ตรงว่า "ยังไม่ได้บันทึกอะไร", "รวมบทอ่านดี ๆ ไว้ในที่เดียว" และ "สำรวจบทความ" วางคำอธิบายใต้ชื่อและปุ่มใหญ่ถัดลงมา เว้นขอบสบาย ใช้ความต่างสีสูง ไม่มีตัวจิ๋ว โครงโหลด การ์ดบทความปลอม หรือตราการแจ้งเตือน นี่เป็นข้อเสนอออกแบบนิ่ง การเข้าถึงยังต้องทดสอบเมื่อพัฒนาจริง
```

<a id="dig-10"></a>

## DIG-10 — เปรียบเทียบทิศทางภาษา

```text
สร้างบอร์ดตัวอักษรอินเทอร์เฟซ 16:9 แบบสองช่องเคียงกันจาก [APPROVED ENGLISH AND ARABIC COPY] ช่องซ้ายจัดแนวซ้ายไปขวา ช่องขวาจัดแนวขวาไปซ้ายอย่างเป็นธรรมชาติ คงลำดับชั้นองค์ประกอบ ระยะห่าง และหน้าที่ปุ่มสองปุ่ม พร้อมปรับลำดับอ่าน คงภาพสินค้าตามเดิมไม่กลับกระจก แสดงเฉพาะข้อความที่ให้ โดยอักษรอาหรับเชื่อมถูกต้องและชื่อแบรนด์ละตินไม่เปลี่ยน ไม่มีการถอดเสียง ข้อความต้นฉบับซ้ำ หรือข้อความแต่ง ตัวแปร: คู่ข้อความและป้ายองค์ประกอบ ต้องให้ผู้คล่องภาษาอาหรับตรวจสอบ
```
