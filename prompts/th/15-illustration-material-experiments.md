# ภาพประกอบและการทดลองวัสดุ

ชุดพรอมป์ต์ Qwen Image 3.0 จำนวนสิบรายการ เปลี่ยนข้อมูลในวงเล็บเหลี่ยมก่อนสร้างภาพ ข้อความในเครื่องหมายคำพูดต้องแสดงตรงตามที่ระบุ ไม่ต้องแปลเว้นแต่สั่งไว้อย่างชัดเจน ผลลัพธ์ต้องผ่านการตรวจสอบโดยมนุษย์

<a id="ill-01"></a>

## ILL-01 — ลุ่มน้ำกระดาษซ้อน

```text
สร้างแนวคิดกระดาษศึกษา 3:4 มีเนิน ลำธาร บ่อในชั้นสี เห็นขอบกระดาษชัด โทนน้ำเงินเขียวเรียบ เงาบนนุ่ม ให้ลำธารต่อเนื่องไหลลงบ่อ เว้นหนึ่งในสี่บนสำหรับชื่อที่ให้ แสดงเฉพาะ [APPROVED TITLE AND LABELS] ไม่มีค่าหรือคำอ้างนิเวศแต่ง ตัวแปร: ความสัมพันธ์ภูมิประเทศที่ตรวจแล้วและคำตรง ตรวจวิทยาศาสตร์ก่อนสอน
```

<a id="ill-02"></a>

## ILL-02 — แผนที่ย่านหมึกสองสี

```text
สร้างแผนที่ภาพประกอบ 4:3 ของย่านสมมติมีร้านขนมปัง ห้องสมุด สวน ร้านซ่อมรอบลานเดียว ใช้หมึกโคบอลต์และส้มอุ่นเท่านั้นบนงาช้าง มีผิวเหลื่อมพิมพ์เล็กน้อย เชื่อมอาคารด้วยทางชัด แสดงเฉพาะป้ายสถานที่สี่ชื่อที่ให้ ไม่มีที่อยู่จริง โลโก้ ระยะ หรือสมมติฐานทางเข้าไม่ถึง ตัวแปร: ผังสมมติและป้าย คงหมึกทับสอดคล้องไม่เพิ่มสีพิมพ์ที่สาม
```

<a id="ill-03"></a>

## ILL-03 — ภาพพฤกษศาสตร์กวอช

```text
ใช้ [VERIFIED PLANT REFERENCE] สร้างกวอชศึกษา 3:4 ของก้านหนึ่ง ใบสอง ดอกหนึ่งบนงาช้างอุ่น คงโครงสร้างชนิด เห็นรอยพู่กันไม่บังกายวิภาค ชื่อพืชที่ให้ด้านล่างไม่มีคำอื่น ไม่ใส่สเกลเว้นแต่ให้มา ไม่มีสรรพคุณยาแต่ง ละตินปลอมตกแต่ง หรือเปลี่ยนจำนวนกลีบ ตัวแปร: ภาพ ชื่อที่อนุมัติ และสี
```

<a id="ill-04"></a>

## ILL-04 — ภาพบริการชุมชน

```text
สร้างไอโซเมตริก 16:9 ของลานร่วมสมมติเชื่อมซุ้มห้องสมุด โรงเก็บเครื่องมือ สวน และที่นั่ง ใช้สี่โซนแยกชัด สีสถาปัตย์อุ่น และทางต่อเนื่องดูเข้าถึงได้เฉพาะตาม [APPROVED LAYOUT] แสดงชื่อโซนที่ให้ครั้งละหนึ่ง ไม่มีคำอ้างผ่านกฎหมาย ยอดคน หรือผลสังคม คงบันได ประตู มุมหลังคาถูก ตัวแปร: ผังและป้าย นี่เป็นภาพแนวคิด
```

<a id="ill-05"></a>

## ILL-05 — ศึกษาไอคอนปัก

```text
สร้างแผ่นสี่เหลี่ยมสี่คูณสี่มีแนวคิดไอคอนปักสิบหกจาก [APPROVED MOTIF LIST] ใช้ผ้าครีมเดิม ด้ายกรมท่าเหลืองดิน เห็นทิศเย็บ ลายเดียวกลางช่อง รูปร่างง่ายพอเข้าใจเมื่อเล็ก ไม่มีข้อความ ลายซ้ำ โลโก้คัด หรือด้ายลอยเป็นไปไม่ได้ ตัวแปร: สิบหกลายและสีด้าย นี่เป็นแนวคิดแรสเตอร์ไม่ใช่ไฟล์เครื่องปัก
```

<a id="ill-06"></a>

## ILL-06 — หน้าคู่ปัญหาเล็ก

```text
สร้างหน้าคู่ 2:1 ของกระต่ายน้อยต้นฉบับทำทางหินข้ามแอ่งตื้นในสวนให้หอยทาก ใช้ผิวดินสอสีอ่อน แสงใบไม้ผลินุ่ม เรื่องเคลื่อนซ้ายขวาชัด เว้นสันหนังสือจากหน้าและการกระทำสำคัญ เว้นซ้ายบนใส่คำภายหลัง ไม่มีคำ ตัวเพิ่ม หรือน้ำอันตราย ตัวแปร: ตัวละครที่อนุมัติและสี
```

<a id="ill-07"></a>

## ILL-07 — โปสเตอร์นูนเซรามิก

```text
สร้างโปสเตอร์ 3:4 ถ่ายเหมือนงานเซรามิกนูนทำมือ มีนกมีสไตล์สามตัวบนกิ่งโค้ง เคลือบโคบอลต์ ดินงาช้าง และผิวต่างธรรมชาติเล็กน้อย เว้นแถบบนเรียบให้ "ดินกับการบิน" แถบล่าง "นิทรรศการสตูดิโอ" แต่ละวลีครั้งเดียว นูนชัดไม่พิมพ์บนกระดาษลอย ไม่มีวัน ตราสปอนเซอร์ หรือสถานที่แต่ง ตัวแปร: คำที่อนุมัติและสีเคลือบ
```

<a id="ill-08"></a>

## ILL-08 — อุปมาภาพบรรณาธิการนามธรรม

```text
สร้างภาพบรรณาธิการสี่เหลี่ยมเรื่องจัดความสนใจ มีลิ้นชักเปิดหนึ่งอันใส่รูปกระดาษสีแยกเรียบ ริบบิ้นแดงหนึ่งเส้นยื่นออก ใช้คอลลาจมีผิว พื้นงาช้างอุ่น เงานุ่ม สื่อระเบียบและการขัดจังหวะโดยไม่มีคำ หน้าคน โลโก้บริษัท หรือภาพแพทย์ รูปลิ้นชักสมจริงไม่รกเกิน ตัวแปร: ธีมที่อนุมัติและสี อุปมาเป็นตีความสร้างสรรค์ไม่ใช่ข้อเท็จจริง
```

<a id="ill-09"></a>

## ILL-09 — ภาพขนมปังลิโนคัต

```text
สร้างภาพต้นฉบับลิโนคัต 3:4 ขนมปังกลมหนึ่งก้อนบนผ้าพับ ใช้รอยแกะดำหนา กระดาษครีมอุ่น และจุดเน้นดินเผาหนึ่งหลังขนมปัง รอยกรีดและมิติเปลือกชัดด้วยเส้นทิศไม่ใช่ขีดสุ่ม ไม่มีข้อความ โลโก้ร้าน ลายเซ็น หรือองค์ประกอบศิลปินคัด ตัวแปร: รูปขนมปังและสีเน้น คงเหตุผลการพิมพ์หมึกจำกัด
```

<a id="ill-10"></a>

## ILL-10 — ภูมิทัศน์จิ๋วสักหลาด

```text
สร้างภูมิทัศน์จิ๋ว 4:3 จากสักหลาดซ้อน: เนินมนสอง บ่อน้ำเงินเล็กหนึ่ง ต้นไม้ง่ายสาม เห็นเส้นใย ขอบเย็บ แสงสตูดิโอนุ่ม สเกลสนุกแต่สอดคล้อง มีสามต้นพอดีไม่มีวัตถุเพิ่ม ไม่มีข้อความ หน้า แบรนด์ หรือผิวเหมือนพลาสติก ตัวแปร: สีและองค์ประกอบที่อนุมัติ นี่เป็นภาพสไตล์วัสดุไม่ใช่ภาพถ่ายสินค้าจริง
```
