# สถาปัตยกรรม ภายใน และแนวคิดอสังหาริมทรัพย์

ชุดพรอมป์ต์ Qwen Image 3.0 จำนวนสิบรายการ เปลี่ยนข้อมูลในวงเล็บเหลี่ยมก่อนสร้างภาพ ข้อความในเครื่องหมายคำพูดต้องแสดงตรงตามที่ระบุ ไม่ต้องแปลเว้นแต่สั่งไว้อย่างชัดเจน ผลลัพธ์ต้องผ่านการตรวจสอบโดยมนุษย์

<a id="arc-01"></a>

## ARC-01 — มุมอ่านหนังสือเล็ก

```text
สร้างภาพภายในสถาปัตยกรรม 4:3 ของมุมอ่านใต้บันไดขนาดกะทัดรัด แสดงม้านั่งโอ๊กบิลต์อินหนึ่งตัว ชั้นตื้น โคมผนังกลม และเบาะน้ำเงินพับ ใช้สเกลมนุษย์สมจริง เส้นตั้งตรง และแสงวันนุ่มจากหน้าต่างนอกเฟรม คงระยะเหนือหัวพอใช้และทางเข้าโล่ง ไม่มีคน ข้อความ คานยื่นเป็นไปไม่ได้ หรือเฟอร์นิเจอร์ใหญ่เกิน ตัวแปร: ขนาดห้อง วัสดุที่อนุมัติ และชุดสี นี่เป็นภาพออกแบบ ไม่ใช่เอกสารก่อสร้าง
```

<a id="arc-02"></a>

## ARC-02 — ปรับเคาน์เตอร์ร้านขนมปัง

```text
ใช้ภาพภายในร้านขนมปังที่ได้รับอนุญาตหนึ่งภาพเป็นเป้าหมาย เปลี่ยนเฉพาะหน้าเคาน์เตอร์เป็นระแนงไม้แนวตั้งสีอ่อนและผนังหลังเป็นน้ำเงินหม่น คงขนาดเคาน์เตอร์ กระจกตู้ ประตู อุปกรณ์เพดาน มุมกล้อง และข้อความทั้งหมด จับคู่เงาสะท้อนและเงาสัมผัสกับแสงเดิม ไม่เพิ่มสินค้า ลบอุปกรณ์ หรือขยายห้อง ตัวแปร: ภาพต้นฉบับและผิววัสดุที่อนุมัติ ส่งภาพแนวคิดหนึ่งภาพไม่มีป้ายก่อนหลัง
```

<a id="arc-03"></a>

## ARC-03 — เรนเดอร์ผังเฟอร์นิเจอร์

```text
ใช้ [APPROVED FLOOR PLAN] สร้างภาพผังเฟอร์นิเจอร์มุมบน 4:3 คงผนัง ช่องเปิด บันได และขนาดที่ให้ทั้งหมด วางเฉพาะ [APPROVED FURNITURE LIST] ตามตำแหน่งระบุด้วยสเกลคงที่และเงากลางนุ่ม ให้ทางเดินเห็นชัดและแสดงเฉพาะชื่อห้องที่ให้ ห้ามแต่งขนาด ย้ายผนัง หรือสื่อว่าผ่านกฎหมายอาคาร ตัวแปร: ผัง ตำแหน่งเฟอร์นิเจอร์ และป้าย ตรวจความแม่นยำเชิงพื้นที่แยกต่างหาก
```

<a id="arc-04"></a>

## ARC-04 — แก้ภายนอกเป็นช่วงแสงสีน้ำเงิน

```text
ใช้ภาพอสังหาริมทรัพย์ที่ได้รับอนุญาตเป็นเป้าหมาย เปลี่ยนเฉพาะเวลาเป็นต้นช่วงแสงสีน้ำเงิน โดยเห็นแสงอุ่นนุ่มจากหน้าต่างเดิม คงอาคาร สวน สิ่งปลูกสร้างข้างเคียง กล้อง และอากาศเว้นแต่ระบุชัด ความสว่างท้องฟ้าและเงาหน้าต่างต้องสมจริง ห้ามเพิ่มไฟ ซ่อนข้อบกพร่อง หรือเปลี่ยนวิว ไม่มีข้อความหรือคำอ้างอสังหาริมทรัพย์ ตัวแปร: ภาพต้นฉบับและการปรับแสงที่อนุมัติ ระบุว่าเป็นภาพจำลองเมื่อเผยแพร่
```

<a id="arc-05"></a>

## ARC-05 — การ์ดข้อมูลห้องพัก

```text
สร้างการ์ดข้อมูลที่พัก 3:4 ด้วย [VERIFIED ROOM PLAN AND AMENITIES] วางภาพห้องเรียบง่ายเหนือรายการคุณสมบัติสั้นที่ให้ คงจำนวนเตียง ตำแหน่งห้องน้ำ และหน้าต่าง ใช้สีกลางอุ่น ตัวใหญ่ และป้ายที่อนุมัติเท่านั้น ห้ามแต่งวิวทะเล สิ่งอำนวยความสะดวกเข้าถึง ระดับดาว ขนาด หรือห้องว่างจอง ใส่ "คู่มือห้องพักแบบภาพประกอบ" ใต้ชื่อ ตัวแปร: ผังที่ตรวจสอบ รายการคุณสมบัติ และชื่อที่อนุมัติ
```

<a id="arc-06"></a>

## ARC-06 — บอร์ดชุดวัสดุ

```text
สร้างบอร์ดวัสดุภายใน 16:9 ชื่อ "เวิร์กช็อปสงบ" จัดตัวอย่างห้าชนิด: โอ๊กอ่อน อะลูมิเนียมขัดลาย ขนสัตว์น้ำเงิน ปูนโทนอุ่น และเซรามิกจุด แสดงผิวและความหนาสมจริง พร้อมเงาทิศทางนุ่มและพื้นครีมสะอาด กำกับแต่ละวัสดุหนึ่งครั้งใต้ชิ้น ขนาดตัวอย่างสมดุลทางสายตาไม่สื่อสเกลจริงเท่ากัน ไม่มีแบรนด์ผู้ขาย ใบรับรองสิ่งแวดล้อม หรือคำอ้างประสิทธิภาพ ตัวแปร: วัสดุ ป้าย และชื่อโครงการ
```

<a id="arc-07"></a>

## ARC-07 — เส้นทางผู้ชมนิทรรศการ

```text
ใช้ [APPROVED EXHIBITION PLAN] สร้างภาพแอกโซโนเมตริก 16:9 คงผนังกั้น ทางเข้า และงานติดตั้งที่ให้ทั้งหมด แสดงเส้นทางผู้ชมที่อนุมัติหนึ่งเส้นด้วยเส้นน้ำเงินและลูกศร แยกทางฉุกเฉินทางภาพเฉพาะเมื่อให้มา กำกับโซนตาม [APPROVED ZONE NAMES] ใช้เงาสถาปัตยกรรมกลาง ไม่มีฝูงชนตกแต่ง ห้ามแต่งทางออกปลอดภัย การเข้าถึง หรือความจุ ตัวแปร: ผัง เส้นทาง และป้าย ต้องให้สถานที่ตรวจสอบก่อนใช้
```

<a id="arc-08"></a>

## ARC-08 — ฤดูกาลในลาน

```text
สร้างแนวคิดภูมิทัศน์สี่ช่อง 16:9 ของลานเล็กเดิมในใบไม้ผลิ ร้อน ใบไม้ร่วง และหนาว ตรึงกล้อง ทางหิน ม้านั่ง ตำแหน่งต้นไม้ และผนัง เปลี่ยนเฉพาะรูปลักษณ์พืช แสงวัน และสภาพพื้นตามฤดูให้ตรง [VERIFIED CLIMATE] กำกับแต่ละฤดูครั้งเดียว ใช้ภาพจำลองสถาปัตยกรรมสมจริงไม่ย้ายวัตถุข้ามช่อง ห้ามแต่งดอกตลอดปีหรืออัตราโตเต็มวัย ตัวแปร: รายการพืชที่อนุมัติและภูมิอากาศ
```

<a id="arc-09"></a>

## ARC-09 — ศึกษาแนวสายตาร้านค้า

```text
สร้างแนวคิดผังร้านสองช่อง 16:9 จากผังอนุมัติหนึ่งชุด แสดงมุมระดับตาจากทางเข้าเหมือนกันทั้งคู่ ซ้ายใช้ตำแหน่งชั้นปัจจุบัน ขวาใช้เฉพาะ [APPROVED NEW POSITIONS] คงสถาปัตยกรรม ขนาดชั้น ประเภทสินค้า และแสง กำกับ "ปัจจุบัน" และ "ข้อเสนอ" นอกภาพ ห้ามแต่งยอดขายเพิ่ม คำอ้างการเข้าถึง หรือพื้นที่เพิ่ม ตัวแปร: ผังและการย้ายเฟอร์นิเจอร์ที่อนุมัติ
```

<a id="arc-10"></a>

## ARC-10 — ศึกษาแสงที่นั่งริมหน้าต่าง

```text
สร้างภาพศึกษาแสงวันสามช่อง 3:2 ของที่นั่งริมหน้าต่างหนึ่งจุดในเช้า เที่ยง และบ่ายแก่ ใช้ห้อง เบาะ กล้อง และทิศหน้าต่างเดิม เปลี่ยนเฉพาะทิศและความเข้มแสงตาม [SUPPLIED ORIENTATION AND LOCATION] แสดง "เช้า", "เที่ยง" และ "บ่าย" ใต้ช่องตรงกัน คงเงาสะท้อนและทิศเงาตรงคำสั่ง ห้ามแต่งค่าประหยัดพลังงานหรือแสงที่วัด ตัวแปร: สถานที่ ทิศ และวัสดุ นี่เป็นภาพประกอบไม่ใช่การจำลองเชิงคำนวณ
```
