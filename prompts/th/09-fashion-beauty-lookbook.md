# แฟชั่น ความงาม และแนวคิดสิ่งทอ

ชุดพรอมป์ต์ Qwen Image 3.0 จำนวนสิบรายการ เปลี่ยนข้อมูลในวงเล็บเหลี่ยมก่อนสร้างภาพ ข้อความในเครื่องหมายคำพูดต้องแสดงตรงตามที่ระบุ ไม่ต้องแปลเว้นแต่สั่งไว้อย่างชัดเจน ผลลัพธ์ต้องผ่านการตรวจสอบโดยมนุษย์

<a id="fas-01"></a>

## FAS-01 — ตู้เสื้อผ้าสี่ลุค

```text
สร้างลุคบุ๊ก 16:9 สี่ช่องเท่ากันโดยใช้ภาพนางแบบหรือนายแบบผู้ใหญ่ที่ได้รับอนุญาตหนึ่งภาพและ [APPROVED GARMENT LIST] แสดงชุดผสมสี่ชุดที่ให้ด้วยระยะกล้องเท่ากันบนพื้นอ่อน คงตัวตนและโครงสร้าง สี และความพอดีของทุกชิ้น กำกับเพียง "01", "02", "03" และ "04" ใช้แสงแฟชั่นบรรณาธิการนุ่มไม่เปลี่ยนสัดส่วนร่างกาย ไม่มีเครื่องประดับเพิ่ม โลโก้ หรือคำอ้างความยั่งยืน ตัวแปร: ภาพ เสื้อผ้า และการจับคู่ลุค
```

<a id="fas-02"></a>

## FAS-02 — แผ่นออกแบบเสื้อกั๊กอเนกประสงค์

```text
สร้างแผ่นแนวคิดเสื้อผ้า 4:3 สำหรับเสื้อกั๊กอเนกประสงค์ต้นฉบับสีน้ำเงินหินชนวน แสดงหน้า หลัง และรายละเอียดกระเป๋าหนึ่งจุด ทั้งหมดตรงกันด้านตะเข็บ ทิศซิป และผิวผ้า ใช้ภาพเทคนิคชัด แสดงเฉพาะ "หน้า", "หลัง" และ "กระเป๋า" คงจำนวนกระเป๋าและทรง ไม่ใส่ขนาดเว้นแต่ให้มา ห้ามคัดแบบเด่นของแบรนด์ดังหรือสื่อว่าพร้อมผลิต ตัวแปร: ภาพร่างที่อนุมัติ ผ้า และป้าย
```

<a id="fas-03"></a>

## FAS-03 — แคมเปญเครื่องประดับเซรามิก

```text
สร้างภาพเครื่องประดับสี่เหลี่ยมของต่างหูเซรามิกโคบอลต์ต้นฉบับสองชิ้นบนลินินงาช้างพับ ใช้แสงข้างนุ่มให้เห็นไฮไลต์เคลือบไม่ขาวล้น เพิ่มกิ่งแห้งเล็กหนึ่งกิ่งเพื่อสเกลและผิว ต่างหูทั้งคู่โครงสร้างตรงกันแต่มีร่องรอยงานมือธรรมชาติ ไม่มีข้อความ อัญมณี คำอ้างโลหะมีค่า หรือตราแบรนด์ คงตัวเกี่ยวและเงาสมเหตุสมผล ตัวแปร: ภาพสินค้าที่อนุญาต เคลือบ และสีผ้า
```

<a id="fas-04"></a>

## FAS-04 — แก้ภาพเปรียบเทียบเมกอัพ

```text
ใช้ภาพผู้ใหญ่ที่ได้รับอนุญาตหนึ่งภาพสร้างตารางเมกอัพสองคูณสอง 4:3 คงหน้า สีผิว ผม แสง และสีหน้าเหมือนกัน ใช้เฉพาะสี่ชุดสีที่ให้ เปลี่ยนแค่ริมฝีปาก เปลือกตา และแก้ม กำกับตาม [APPROVED LOOK NAMES] คงผิวธรรมชาติและลักษณะต่างของใบหน้า ไม่เปลี่ยนรูปหน้า อายุ อ้างผลผลิตภัณฑ์ หรือเพิ่มเครื่องประดับ ตัวแปร: ภาพ ชุดสี และการจับคู่ป้าย
```

<a id="fas-05"></a>

## FAS-05 — การ์ดลำดับใช้ผลิตภัณฑ์

```text
สร้างการ์ดใช้สินค้า 3:4 จาก [MANUFACTURER-APPROVED ORDER AND COPY] แสดงภาชนะที่ให้สี่ชิ้นพอดีเรียงตั้ง มีลูกศรลงง่ายและป้ายขั้นที่อนุมัติหนึ่งป้ายต่อชิ้น ใช้ภาพสตูดิโอสะอาด พื้นฟ้าอ่อน และช่องห่างมาก คงข้อความและทรงบรรจุภัณฑ์ ห้ามแต่งส่วนผสม ผลทางการแพทย์ ความถี่ หรือความเข้ากัน ไม่มีภาพผิวก่อนหลัง ตัวแปร: ภาพสินค้าและลำดับคำแนะนำที่ตรวจแล้ว ตรวจคำกล่าวอ้างทั้งหมดก่อนเผยแพร่
```

<a id="fas-06"></a>

## FAS-06 — จัดวางเครื่องแต่งกายเดินทาง

```text
สร้างภาพแฟชั่นมุมบน 3:4 มีกระเป๋าผ้าใบต้นฉบับหนึ่งใบ ผ้าพันคอลายพับ แว่นกันแดดเรียบ และสมุดเล็ก จัดเฉียงบนพื้นสีทราย ไม่ซ้อนบังรูปสำคัญ ใช้เงาธรรมชาตินุ่มและจุดเน้นกรมท่า ไม่มีโลโก้หรู หนังสือเดินทาง ตั๋ว หรือข้อมูลส่วนตัวอ่านได้ แว่นสมมาตรและรอยพับสมจริง ตัวแปร: อุปกรณ์ที่อนุมัติ ลายผ้า และชุดสี
```

<a id="fas-07"></a>

## FAS-07 — จำลองทรงผม

```text
ใช้ภาพผู้ใหญ่ที่ได้รับอนุญาตหนึ่งภาพสร้างแผ่น 3:2 ของทรงผมที่ให้หกแบบ คงหน้า แนวผม อายุ สีผิว กล้อง และแสง เปลี่ยนเฉพาะความยาว การจัด และเนื้อผมตาม [APPROVED STYLE LIST] คงสีเดิมเว้นแต่สั่ง กำกับ "1" ถึง "6" ไม่รีทัชหน้า เปลี่ยนเมกอัพ หรือให้ผมงอกจากหน้าผากเป็นไปไม่ได้ ตัวแปร: ภาพต้นฉบับและคำอธิบายหกทรง
```

<a id="fas-08"></a>

## FAS-08 — เปรียบเทียบโครงสร้างผ้า

```text
สร้างบอร์ดอ้างอิงสิ่งทอ 16:9 แสดงลินินทอขัด ฝ้ายทอลายทแยง และขนสัตว์ถักเป็นสามช่องมาโครเท่ากัน ใช้ [AUTHORIZED MATERIAL REFERENCES] สำหรับผิวและสี จับคู่กำลังขยายและแสงกลางพร้อมคงลายเส้นใยเฉพาะแต่ละแบบ กำกับเพียงชื่อวัสดุที่ให้ ห้ามแต่งส่วนผสมเส้นใย ความทน แหล่งกำเนิด หรือวิธีดูแล ตัวแปร: ภาพอ้างอิงและป้ายตรง ต้องให้ผู้เชี่ยวชาญยืนยันวัสดุ
```

<a id="fas-09"></a>

## FAS-09 — แนวคิดปะผ้าโชว์ด้าย

```text
สร้างภาพรายละเอียดเสื้อผ้าสี่เหลี่ยมของรอยปะเข่ายีนส์ต้นฉบับที่ซ่อมด้วยด้ายเหลืองดินมองเห็น แสดงตะเข็บและเส้นเย็บชัด มีรอยพับเล็กสื่อการงอผ้า ใช้ภาพบรรณาธิการใกล้และแสงวันนุ่มบนพื้นงาช้าง ไม่มีข้อความ ป้ายแบรนด์ หรือคำอ้างความแข็งแรง ตะเข็บเชื่อมกันและไม่มีเข็มในภาพสุดท้าย ตัวแปร: รายละเอียดเสื้อผ้าที่อนุญาต รูปแผ่นปะ และสีด้าย
```

<a id="fas-10"></a>

## FAS-10 — ศึกษาสีรองเท้า

```text
ใช้ภาพรองเท้าที่ได้รับอนุญาตหนึ่งภาพสร้างการศึกษาสีสามช่อง 16:9 คงพื้น ตะเข็บ เชือก วัสดุ และมุมกล้องเหมือนกัน ใช้เฉพาะ [THREE APPROVED COLOR PALETTES] ใช้พื้นกลางและแสงสตูดิโอตรงกัน กำกับชื่อสีที่ให้ใต้รองเท้า ห้ามเปลี่ยนดอกพื้น เพิ่มโลโก้ หรือแต่งสเปกประสิทธิภาพ ตัวแปร: ภาพ สามชุดสี และป้าย ตรวจรูปทรงแยกจากความแม่นยำสี
```
