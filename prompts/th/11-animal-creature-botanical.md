# สัตว์ สิ่งมีชีวิต และการศึกษาพฤกษศาสตร์

ชุดพรอมป์ต์ Qwen Image 3.0 จำนวนสิบรายการ เปลี่ยนข้อมูลในวงเล็บเหลี่ยมก่อนสร้างภาพ ข้อความในเครื่องหมายคำพูดต้องแสดงตรงตามที่ระบุ ไม่ต้องแปลเว้นแต่สั่งไว้อย่างชัดเจน ผลลัพธ์ต้องผ่านการตรวจสอบโดยมนุษย์

<a id="nat-01"></a>

## NAT-01 — ภาพสัตว์เลี้ยงจากต้นแบบ

```text
ใช้ภาพสัตว์เลี้ยงที่อนุญาตสร้างภาพ 3:4 บนพื้นเทาอุ่นเรียบ คงลายขน สีตา รูปหู ขนาดตัว และสีหน้าธรรมชาติ ใช้แสงหน้าต่างนุ่มและท่านั่งผ่อนคลายตรงกายวิภาค หนวด เท้า และขอบขนละเอียดไม่เรียบเกิน ไม่มีเสื้อผ้า มือคน ข้อความ หรือปลอกคอเพิ่มเว้นแต่มีในต้นแบบ ตัวแปร: ภาพสัตว์และสีพื้นที่อนุมัติ
```

<a id="nat-02"></a>

## NAT-02 — สัตว์บึงแฟนตาซี

```text
สร้างแผ่นแนวคิด 16:9 ของสัตว์บึงเล็กต้นฉบับมีสัดส่วนคล้ายนาก ขนมอส และเท้าพังผืดกว้าง แสดงหน้า ข้าง และสามส่วนสี่บนพื้นอ่อนโดยกายวิภาคและลายเหมือนกัน ใช้ภาพธรรมชาติวิทยาสมเหตุสมผล ไม่มีข้อความ ห้ามคัดตัวละครรู้จักหรือเพิ่มเขา แขนขา ปีกไม่สอดคล้อง ตัวแปร: คำอธิบายสิ่งมีชีวิตต้นฉบับและสีถิ่นอาศัย นี่คือจินตนาการไม่ใช่ชนิดจริง
```

<a id="nat-03"></a>

## NAT-03 — แผ่นสังเกตสัตว์ผสมเกสร

```text
ใช้ [VERIFIED SPECIES REFERENCES] สร้างแผ่นศึกษา 4:3 มีสัตว์ผสมเกสรหนึ่งตัวข้างดอกพืชอาศัยที่อนุมัติ เพิ่มภาพขยายโครงสร้างกินอาหารที่เกี่ยวข้อง เชื่อมจุดถูกด้วยเส้นบางหนึ่งเส้น แสดงเฉพาะชื่อชนิดและป้ายที่ให้ ใช้ภาพธรรมชาติวิทยาแม่น พื้นขาว และสเกลสม่ำเสมอเฉพาะเมื่อให้มา ไม่แต่งกายวิภาค คำอ้างนิเวศ หรือสัญลักษณ์วิทยาศาสตร์ตกแต่ง ตัวแปร: ภาพ ป้าย และแหล่ง ต้องให้ผู้เชี่ยวชาญตรวจ
```

<a id="nat-04"></a>

## NAT-04 — ฉากสัตว์ป่าในป่า

```text
สร้างฉากป่าสมมติ 16:9 มีจิ้งจอกแดงหนึ่งตัวหยุดข้างลำเบิร์ชล้มยามรุ่ง ใช้ขนสมจริง หมอกพอดี แสงอุ่นต่ำลอดต้นไม้ เท้าสัมผัสดินไม่เรียบและหูตื่นตัวธรรมชาติ ไม่มีสีหน้ามนุษย์ เหยื่อเจ็บ ของมนุษย์ หรือข้อความ หลีกเลี่ยงลายต้นไม้ซ้ำและสัดส่วนเกินจริง ตัวแปร: ชนิด ฤดู และถิ่นที่อนุมัติ อย่าเรียกว่าเป็นภาพสัตว์ป่าจริง
```

<a id="nat-05"></a>

## NAT-05 — ศึกษาการเคลื่อนไหวสัตว์

```text
ใช้ [VERIFIED ANATOMICAL REFERENCES] สร้างภาพศึกษาสี่ช่อง 16:9 ของแมวบ้านเดินซ้ายไปขวา คงลายขน สเกล ระดับกล้อง และพื้นเหมือนกัน แสดงสี่ระยะก้าวที่อนุมัติต่างกันด้วยถ่ายน้ำหนักสมจริงและเท้าติดพื้น กำกับเพียง "1" ถึง "4" ห้ามแต่งตำแหน่งขาหรืออ้างว่าพร้อมทำแอนิเมชันโดยไม่ทดสอบต่อ ตัวแปร: ภาพอ้างอิงและลำดับก้าว
```

<a id="nat-06"></a>

## NAT-06 — แผ่นระบุชนิดใบไม้

```text
สร้างแผ่นสอนพฤกษศาสตร์ 3:4 จาก [VERIFIED LEAF REFERENCES] จัดใบหกใบในกริดสองคูณสาม ใต้แต่ละใบชื่อสามัญที่ให้ คงรูปแผ่น ขอบ เส้นใบ และจุดต่อก้าน ใช้แสงกลางเดียวและพื้นงาช้างเรียบ ห้ามแต่งชื่อ สรรพคุณยา หรือสเกลสัมพันธ์ เพิ่มเพียงชื่อและป้ายที่อนุมัติ ตัวแปร: ภาพหกภาพและการจับคู่ชื่อ ต้องตรวจการระบุพฤกษศาสตร์
```

<a id="nat-07"></a>

## NAT-07 — แผนภาพวงจรชีวิตพืช

```text
สร้างภาพวงจรชีวิต 16:9 ของ [VERIFIED PLANT SPECIES] ด้วย [APPROVED STAGES] วางห้าขั้นพอดีซ้ายไปขวาด้วยลูกศรง่าย จากเมล็ดถึงรูปโตที่ให้ ใช้รายละเอียดสีน้ำธรรมชาติและป้ายชัดใต้ขั้น คงใบ ราก ผลเฉพาะชนิด ห้ามแต่งระยะเวลาหรือคำแนะนำปลูก ตัวแปร: ชุดอ้างอิง ขั้น และป้ายตรง ให้เป็นสื่อศึกษาและต้องให้ผู้เชี่ยวชาญตรวจ
```

<a id="nat-08"></a>

## NAT-08 — แนวคิดถิ่นอาศัยตู้ปลา

```text
สร้างแนวคิดน้ำจืดสมมติ 4:3 มีหินมน พืชน้ำ และปลาเล็กสามตัวชนิดเดียวที่ให้ ใช้มุมข้างชัด แสงใต้น้ำธรรมชาติ และสเกลสมจริง คงกายวิภาคปลา หลีกเลี่ยงแออัดหรือชนิดเข้ากันไม่ได้ ไม่มีคำอ้างอุปกรณ์ คำแนะนำจำนวนปลา ป้าย หรือหีบสมบัติตกแต่ง ตัวแปร: ภาพชนิดที่ตรวจแล้วและรายละเอียดถิ่น ภาพนี้ไม่ใช่คำแนะนำเลี้ยงสัตว์
```

<a id="nat-09"></a>

## NAT-09 — ภาพถุงเมล็ด

```text
สร้างแนวคิดหน้าถุงเมล็ดสมมติ 3:4 ด้วย [VERIFIED PLANT REFERENCE] แสดงก้านมีดอกหนึ่งก้านกับภาพเมล็ดเล็ก เว้นหนึ่งในสี่บนให้ [APPROVED PLANT NAME] ใช้กวอชพฤกษศาสตร์ต้นฉบับบนครีม แสดงเพียงชื่อที่ให้และ "ภาพประกอบศึกษา" ไม่มีอัตรางอก แหล่งกำเนิด ใบรับรอง วิธีปลูก หรือน้ำหนักเว้นแต่ให้มา คงรูปดอกและใบ ตัวแปร: ภาพ ชื่อ และสี
```

<a id="nat-10"></a>

## NAT-10 — การ์ดสังเกตนกเมือง

```text
สร้างการ์ดสี่เหลี่ยมสำหรับ [VERIFIED BIRD SPECIES] แสดงนกเกาะมุมข้างและภาพรายละเอียดปีกเล็กบนพื้นอ่อน ใช้ภาพธรรมชาติวิทยามีปาก เท้า และขนถูกต้อง แสดงเฉพาะชื่อสามัญที่อนุมัติและป้ายสังเกตสามป้ายที่ให้เชื่อมลักษณะถูก ห้ามแต่งความหายาก วันอพยพ หรือสถานะอนุรักษ์ ตัวแปร: ชุดภาพ ป้าย และแหล่ง ต้องให้มนุษย์ตรวจ
```
