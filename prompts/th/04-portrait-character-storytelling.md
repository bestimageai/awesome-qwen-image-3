# ตัวละคร ภาพบุคคล และสตอรีบอร์ด

ชุดพรอมป์ต์ Qwen Image 3.0 จำนวนสิบรายการ เปลี่ยนข้อมูลในวงเล็บเหลี่ยมก่อนสร้างภาพ ข้อความในเครื่องหมายคำพูดต้องแสดงตรงตามที่ระบุ ไม่ต้องแปลเว้นแต่สั่งไว้อย่างชัดเจน ผลลัพธ์ต้องผ่านการตรวจสอบโดยมนุษย์

<a id="art-01"></a>

## ART-01 — มีรากับการคืนหนังสือ

```text
สร้างแผ่นเรื่องราวสี่ช่อง 16:9 เกี่ยวกับมีรา ตัวละครผู้ใหญ่ที่ออกแบบใหม่ เป็นบรรณารักษ์เคลื่อนที่ผมหยิกดำสั้น แว่นกลม คาร์ดิแกนสีสนิม และตะกร้าจักรยานสีน้ำเงิน ในช่องจากซ้ายไปขวา เธอพบหนังสือบนม้านั่ง ดูปกเรียบ ใส่ตะกร้า แล้วส่งที่ประตูห้องสมุดเล็ก ใช้ภาพประกอบสีกวอชอุ่นและแสงเช้านุ่ม คงใบหน้า เสื้อผ้า จักรยาน และหนังสือเหลืองเหมือนเดิมตลอด มีสี่ช่องเท่ากันพอดี ไม่มีคำบรรยาย กล่องคำพูด หรือชื่อหนังสือที่อ่านได้ นี่เป็นสตอรีบอร์ดนิ่ง ไม่ใช่วิดีโอ
```

<a id="art-02"></a>

## ART-02 — แก้ภาพบุคคลอย่างเป็นธรรมชาติ

```text
ใช้ภาพผู้ใหญ่ที่ได้รับอนุญาตเป็นแบบอ้างอิงตัวตน สร้างภาพบุคคลมืออาชีพ 3:4 ระดับสายตา โดยเปลี่ยนเฉพาะพื้นหลังเป็นสตูดิโอฟ้าอ่อนแสงนุ่มและเสื้อผ้าเป็นแจ็กเก็ตสีถ่านเรียบ คงอายุ สัดส่วนใบหน้า ทรงผม ผิว และสีหน้า ปรับแสงพื้นหลังใหม่ให้ตรงกับหน้าและคงไหล่เป็นธรรมชาติทางกายวิภาค ไม่เพิ่มข้อความ เครื่องประดับ รีทัชความงาม หรือเปลี่ยนรูปร่าง ตัวแปร: สีพื้นหลังและชุดที่อนุมัติ ห้ามใช้ใบหน้าคนโดยไม่ได้รับอนุญาต
```

<a id="art-03"></a>

## ART-03 — นายสถานีสมมติ

```text
สร้างภาพบุคคลสี่เหลี่ยมจัตุรัสของนายสถานีผู้ใหญ่ที่ออกแบบใหม่ในสำนักงานรถไฟเล็กริมฝั่ง ตัวละครมีผมเงินตัดสั้น แจ็กเก็ตกรมท่าเก่า และสีหน้าใส่ใจ มีนาฬิกาผนังเบลอด้านหลัง ใช้ภาพถ่ายธรรมชาติคล้ายฟิล์ม แสงหน้าต่างวันครึ้ม และเห็นผิวจริง ให้ใบหน้าอยู่กลางพร้อมช่องว่างรอบศีรษะ ไม่คล้ายบุคคลที่ระบุชื่อ ไม่มีเครื่องหมายเครื่องแบบทางการ ตั๋วที่อ่านได้ หรือเอกสารประจำตัว ตัวแปร: ช่วงอายุ ชุดสี และอาชีพสมมติ
```

<a id="art-04"></a>

## ART-04 — แผ่นตัวละครคนส่งของตามฤดู

```text
สร้างแผ่นตัวละครสี่ช่อง 16:9 ของคนส่งพัสดุผู้ใหญ่ที่ออกแบบใหม่หนึ่งคน มีเปียยาว กระเป๋าเขียว และจักรยานแดง แสดงฝนปรอยฤดูใบไม้ผลิ ร่มเงาฤดูร้อน ลมฤดูใบไม้ร่วง และน้ำค้างแข็งฤดูหนาวในช่องเท่ากัน เปลี่ยนเฉพาะเสื้อคลุมตามฤดูและอากาศ ตรึงใบหน้า สัดส่วน และรูปทรงจักรยาน ใช้ภาพบรรณาธิการชัด ระดับกล้องตรงกัน และท่าเป็นกลาง ใต้ช่องแสดงเฉพาะ "ฤดูใบไม้ผลิ", "ฤดูร้อน", "ฤดูใบไม้ร่วง" และ "ฤดูหนาว" ไม่มีโลโก้หรือใบรับรองความปลอดภัยที่แต่งขึ้น ตัวแปร: แบบตัวละครและชุดสีฤดู
```

<a id="art-05"></a>

## ART-05 — หน้าคู่หนังสือภาพนาก

```text
สร้างหน้าคู่หนังสือภาพ 2:1 แสดงนากตัวเล็กช่วยเต่าเก็บเรือกระดาษจากกออ้อ วางนากซ้าย เต่าขวา และเรือใกล้กลางล่างแต่ห่างร่องสันหนังสือ ใช้สีน้ำโปร่ง แสงบ่ายอุ่น และสีหน้าที่เข้าใจได้ เว้นท้องฟ้าซ้ายบนสำหรับจัดตัวอักษรภายหลัง ไม่มีคำที่สร้างขึ้น ฉากน้ำอันตราย หรือตัวละครเพิ่ม คงขนาดสัตว์และรูปเรือสม่ำเสมอ ตัวแปร: ฉาก ชุดสี และภาพตัวละครที่อนุมัติ
```

<a id="art-06"></a>

## ART-06 — การ์ตูนร่มไร้คำพูด

```text
สร้างการ์ตูนแนวตั้ง 2:3 หกช่องเท่ากันในสองคอลัมน์สามแถว ผู้ใหญ่ที่ออกแบบใหม่กางร่มเล็ก เห็นสุนัขเปียก แชร์ร่ม ทั้งคู่ถูกน้ำในแอ่งสาด พบกันสาดร้านกว้าง แล้วนั่งแห้งอยู่ใต้กันสาด ใช้ภาพหมึกและสีระบายชัด เสื้อผ้าชุดเดิม และสุนัขน้ำตาลหนึ่งตัว คงลำดับอ่านซ้ายไปขวา บนลงล่าง และเหตุผลต่อเนื่องของการกระทำ ไม่มีบทพูด ป้าย ช่องเพิ่ม หรือการบาดเจ็บ ตัวแปร: หน้าตาตัวละครและสีร่ม
```

<a id="art-07"></a>

## ART-07 — สตอรีบอร์ดโฆษณาชา

```text
สร้างสตอรีบอร์ดนิ่งหกช่อง 16:9 สำหรับโฆษณาชาสมมติยี่สิบวินาที ช่องแสดงกระป๋องชาปิด มือเปิด ใบชาใส่ถ้วย น้ำร้อนเท ไอน้ำใกล้หน้าต่าง และถ้วยข้างกระป๋อง ใช้กระป๋องครีมหนึ่งใบ ถ้วยน้ำเงินหนึ่งใบ และแสงเช้าคงที่ แสดงข้อความเฉพาะช่องสุดท้าย "ช่วงเวลาที่เงียบลง" แต่ละช่องต้องเป็นมุมถ่ายต่างกันและอุปกรณ์ทั้งหมดคงเดิม ไม่มีประโยชน์สุขภาพ อุณหภูมิชง หรือคำกล่าวอ้างแบรนด์ ตัวแปร: แบบอุปกรณ์และประโยคท้ายที่อนุมัติ นี่คือแนวคิด ไม่ใช่วิดีโอที่สร้างแล้ว
```

<a id="art-08"></a>

## ART-08 — จำลองถนนประวัติศาสตร์

```text
ใช้ [DATED EVIDENCE PACK] สร้างภาพประกอบ 16:9 ของกิจวัตรที่ [PLACE] ใน [YEAR] คงแนวถนน วัสดุอาคาร และเสื้อผ้าที่มีหลักฐาน พื้นหลังส่วนไม่แน่นอนใช้รายละเอียดลดลง เพิ่มคำอธิบายแถบแคบแยก "มีหลักฐาน" และ "ตีความ" ตามการจับคู่ที่ให้ ห้ามแต่งจารึก ใบหน้าคนดัง อนุสาวรีย์ หรือสิ่งของสมัยใหม่ ใช้ภาพประกอบสารคดีเรียบแทนการอ้างว่าเป็นภาพถ่ายจริง ตัวแปร: สถานที่ ปี หลักฐาน และแผนที่ความไม่แน่นอน ต้องมีการตรวจสอบประวัติศาสตร์
```

<a id="art-09"></a>

## ART-09 — แผ่นอ้างอิงสีหน้า

```text
สร้างแผ่น 3:2 มีภาพศีรษะและไหล่หกภาพของผู้ใหญ่ที่ออกแบบใหม่คนเดียวตาม [APPROVED CHARACTER REFERENCE] แสดงสีหน้าเฉย สงสัยใคร่รู้ โล่งใจ งุนงง มุ่งมั่น และขบขันในกริดสองคูณสาม คงรูปกะโหลก ผม อายุ เสื้อผ้า และระยะกล้อง เปลี่ยนเฉพาะคิ้ว ปาก และการเอียงศีรษะเล็กน้อย ใช้ภาพสตูดิโอนุ่มและพื้นอ่อนเหมือนกัน กำกับแต่ละสีหน้าครั้งเดียว ไม่มีสัดส่วนล้อเลียน ตัวตนเปลี่ยน หรือเครื่องประดับเพิ่ม ตัวแปร: ภาพอ้างอิง ชุดสี และป้ายที่แปลแล้ว
```

<a id="art-10"></a>

## ART-10 — สตอรีบอร์ดความต่อเนื่องของวัตถุ

```text
สร้างสตอรีบอร์ดสี่ช่อง 16:9 ที่ชามเซรามิกแดงถูกย้ายจากชั้นไปโต๊ะ รับส้มสามผล แล้วถูกยกไปหน้าต่าง ใช้ชามใบเดิมที่มีรอยบิ่นเห็นชัดหนึ่งจุดบนขอบทุกช่อง คงส้มสามผลพอดีหลังปรากฏ รูปทรงห้องสม่ำเสมอ และแสงข้างอุ่น ใช้ภาพประกอบสมจริงชัด ไล่มุมจากกลางไปใกล้ และไม่มีข้อความ ห้ามย้ายรอยบิ่น เพิ่มผลไม้ซ้ำ หรือเปลี่ยนรูปชาม ตัวแปร: ภาพวัตถุอ้างอิงและผังห้องที่อนุมัติ
```
