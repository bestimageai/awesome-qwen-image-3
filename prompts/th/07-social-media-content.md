# โพสต์โซเชียล ปก และเนื้อหาครีเอเตอร์

ชุดพรอมป์ต์ Qwen Image 3.0 จำนวนสิบรายการ เปลี่ยนข้อมูลในวงเล็บเหลี่ยมก่อนสร้างภาพ ข้อความในเครื่องหมายคำพูดต้องแสดงตรงตามที่ระบุ ไม่ต้องแปลเว้นแต่สั่งไว้อย่างชัดเจน ผลลัพธ์ต้องผ่านการตรวจสอบโดยมนุษย์

<a id="soc-01"></a>

## SOC-01 — ปกคู่มือปลูกพืชบนระเบียง

```text
สร้างปกโซเชียล 3:4 สำหรับคู่มือมือใหม่ปลูกพืชระเบียง แสดงกระถางดินเผาเล็กสามใบบนชั้นแคบ แต่ละใบมีสมุนไพรใบต่างชนิด และบัวรดน้ำเล็กใต้ชั้น ใช้ภาพธรรมชาติสว่างและพื้นครีมอุ่น แสดง "ระเบียงเล็ก จุดเริ่มต้นสดชื่น", "เริ่มจากสามกระถาง" และ "1/5" โดยชื่ออยู่หนึ่งในสามบน ไม่มีคำกล่าวอ้างผลผลิต สุขภาพ หรือรับประกันโต กระถางมีที่รองและราวระเบียงสมเหตุสมผล ตัวแปร: สมุนไพรที่อนุมัติและชื่อ
```

<a id="soc-02"></a>

## SOC-02 — ประกาศงานฝีมือสามภาพ

```text
สร้างภาพต้นฉบับหนึ่งภาพ 3:1 สำหรับแบ่งเป็นโพสต์สี่เหลี่ยมสามภาพ แสดงโต๊ะยาวที่มีเครื่องมือดินซ้าย เหยือกเซรามิกกลาง และผ้าลินินพับขวา แต่ละช่องต้องสมดุลเอง วาง "สร้าง", "แบ่งปัน" และ "พบกัน" แยกช่อง ใช้แสงอุ่นคงที่และขอบครีมสงบ วัตถุสำคัญและตัวอักษรห้ามข้ามเส้นครอป นี่คือภาพต้นฉบับรวม ไม่ใช่ไฟล์ส่งออกสามไฟล์ ตัวแปร: ของงานฝีมือและคำที่อนุมัติสามคำ
```

<a id="soc-03"></a>

## SOC-03 — การ์ดผลการวิจัย

```text
สร้างการ์ดโซเชียลมืออาชีพ 16:9 ด้วย [VERIFIED FINDING, DATA AND SOURCE] วางข้อค้นพบที่แม่นยำหนึ่งข้อด้านบน กราฟสนับสนุนเรียบกลาง และแหล่งข้อมูลล่าง ใช้ข้อความสีถ่านกับจุดเน้นเขียวน้ำเงินหนึ่งสีบนขาว คงหน่วย วัน ข้อจำกัดกลุ่มตัวอย่าง และความไม่แน่นอน ห้ามเปลี่ยนความสัมพันธ์เป็นเหตุผลหรือเพิ่มเปอร์เซ็นต์เร้าใจ ข้อความต้องอ่านบนมือถือได้ ตัวแปร: ข้อค้นพบที่อนุมัติ ข้อมูล และแหล่งอ้างอิง ความถูกต้องกราฟต้องให้คนตรวจ
```

<a id="soc-04"></a>

## SOC-04 — ภาพย่อเปรียบเทียบการหั่น

```text
สร้างภาพย่อวิดีโอ 16:9 เปรียบเทียบการหั่นลูกแพร์สามแบบเพื่อเสิร์ฟ: แผ่น ลูกเต๋า และพัด วางจานขาวเหมือนกันสามใบเรียงบนโต๊ะโคบอลต์ สีแพร์เหมือนกันและแสงบนคงที่ แสดงเฉพาะ "แพร์หนึ่งผล หั่นได้สามแบบ" ด้านบน แบบหั่นต้องต่างชัดและปริมาณสมจริง ไม่มีคำกล่าวอ้างโภชนาการ คะแนนปลอม มีดใกล้มือ หรือข้อความเพิ่ม ตัวแปร: ผลไม้และพาดหัวที่อนุมัติ
```

<a id="soc-05"></a>

## SOC-05 — ปกวิดีโอสั้นจัดโต๊ะ

```text
สร้างปก 9:16 แสดงโต๊ะที่จัดเรียบร้อยครึ่งหนึ่ง กระดาษเรียงซ้าย สมุดปิดและแก้วขวา ใช้ภาพมุมบนธรรมชาติ เงานุ่ม และสีทรายกับน้ำเงินเรียบ แสดง "จัดโต๊ะให้พร้อมอีกครั้ง" ในพื้นที่ปลอดภัยกลางและ "เริ่มจากพื้นผิวเดียว" ใต้ลงมา เว้นข้อความสำคัญจากหนึ่งในสี่ล่างและขอบขวาเพื่อส่วนทับของแพลตฟอร์ม ไม่มีคำอ้างเวลา โลโก้แอป หรือข้อความเพิ่ม ตัวแปร: ของบนโต๊ะและชื่อสองบรรทัด
```

<a id="soc-06"></a>

## SOC-06 — ประกาศไลฟ์แขกสองคน

```text
ใช้ภาพผู้ใหญ่ที่ได้รับอนุญาตสองภาพสร้างประกาศไลฟ์ 3:4 ให้แขกแต่ละคนมีพื้นที่เท่ากัน สเกลครอปตรงกัน และแสงกลาง วางชื่อใต้คนตรงกัน แสดงเฉพาะ [EVENT TITLE], [GUEST NAMES], [DATE] และ [TIME ZONE] ใช้กริดกรมท่ากับครีมเรียบ ไม่มีสัญญาณไลฟ์ปลอมหรือโลโก้แพลตฟอร์ม คงตัวตนและห้ามแต่งคุณวุฒิหรือยอดผู้ชม ตัวแปร: ภาพสองภาพและข้อความงานที่อนุมัติ
```

<a id="soc-07"></a>

## SOC-07 — การ์ดคำอ้างอิงตรวจสอบแล้ว

```text
สร้างการ์ดคำอ้างอิงสี่เหลี่ยมด้วย [EXACT VERIFIED QUOTE] และ [AUTHOR ATTRIBUTION] จัดคำอ้างด้วยฟอนต์มีเชิงใหญ่ชัดบนกระดาษขาวนวลอุ่น วางชื่อผู้กล่าวด้านล่างชิดซ้ายแนวเดียวกัน เพิ่มภาพเส้นนามธรรมสีน้ำเงินเล็กหนึ่งภาพที่มุมล่าง คงวรรคตอนและถ้อยคำตรง ห้ามย่อ แต่ง หรือยกให้คนอื่น ไม่มีภาพบุคคล ลายเซ็น หรือตรารับรอง ตัวแปร: คำอ้างที่ตรวจแล้ว ผู้กล่าว และชุดสี
```

<a id="soc-08"></a>

## SOC-08 — กริดงานฝีมือเก้าขั้น

```text
สร้างกริดสี่เหลี่ยมสามคูณสามอธิบาย [NINE APPROVED CRAFT STEPS] ใช้โต๊ะ มือ และวัสดุเดิมตลอด มีลำดับชัดจากวัตถุดิบไปของสำเร็จ กำกับเพียง "1" ถึง "9" ซ้ายไปขวา บนลงล่าง คงเครื่องมือและสัดส่วนของ ห้ามแต่งขั้นหรือใช้เครื่องมือไม่ปลอดภัย ไม่มีคำตกแต่งหรือช่องซ้ำ ตัวแปร: ขั้นที่ตรวจแล้วและวัสดุ ต้องตรวจความถูกต้องคำสอน
```

<a id="soc-09"></a>

## SOC-09 — ภาพรวมสรุปกิจกรรม

```text
สร้างเลย์เอาต์สรุปบรรณาธิการ 3:4 สำหรับวันวาดภาพชุมชนสมมติ จัดสี่ช่อง: สมุดวาดบนโต๊ะ มือกำลังวาด ผนังภาพไม่ลงชื่อ และเก้าอี้ว่างตอนปิด ใช้แสงวันคงที่และชื่อเล็กด้านบน "หนึ่งวันกับการวาดภาพ" ใบหน้าต้องระบุตัวไม่ได้และผลงานเป็นต้นฉบับ ห้ามเพิ่มจำนวนคน ตราผู้สนับสนุน หรือคำรับรอง เว้นแถบล่างสงบว่าง ตัวแปร: กิจกรรมและชื่อที่แน่นอน
```

<a id="soc-10"></a>

## SOC-10 — ศึกษาการครอปปกแนวตั้ง

```text
สร้างแนวคิดปกครีเอเตอร์ 9:16 มีว่าวกระดาษแดงหนึ่งตัวกลางท้องฟ้าอ่อน วาง "มาทำว่าวกระดาษกัน" ในหนึ่งในสามกลาง เว้นสิบห้าเปอร์เซ็นต์บนและยี่สิบห้าเปอร์เซ็นต์ล่างไม่มีข้อความ ว่าวและชื่อยังต้องชัดเมื่อครอปสี่เหลี่ยมกลาง ใช้พื้นผิวภาพประกอบสะอาดและเชือกโค้งเล็กน้อย ไม่มี UI แพลตฟอร์ม ว่าวเพิ่ม ปุ่มปลอม หรือคำบรรยายจิ๋ว ตัวแปร: สีวัตถุและชื่อที่อนุมัติ
```
