# แบรนด์ โปสเตอร์ และแคมเปญ

ชุดพรอมป์ต์ Qwen Image 3.0 จำนวนสิบรายการ เปลี่ยนข้อมูลในวงเล็บเหลี่ยมก่อนสร้างภาพ ข้อความในเครื่องหมายคำพูดต้องแสดงตรงตามที่ระบุ ไม่ต้องแปลเว้นแต่สั่งไว้อย่างชัดเจน ผลลัพธ์ต้องผ่านการตรวจสอบโดยมนุษย์

<a id="mkt-01"></a>

## MKT-01 — เปิดตัวโคมไฟที่ซ่อมได้

```text
สร้างโปสเตอร์เปิดตัวอัตราส่วน 3:4 สำหรับสตูดิโอสมมติ LATCH และโคมไฟตั้งโต๊ะที่ซ่อมได้ แสดงโคมไฟสีเหลืองดินหนึ่งดวงในท่าพับบนโต๊ะช่างสีน้ำเงิน พร้อมฝาครอบที่ถอดได้วางข้างกัน ให้โคมไฟกินพื้นที่สองในสามด้านล่าง ใช้ภาพถ่ายผลิตภัณฑ์คมชัด แสงด้านข้างนุ่ม และกริดบรรณาธิการที่เรียบสงบ แสดงเฉพาะ "LATCH", "สร้างมาให้อยู่ด้วยกันนาน" และ "เปลี่ยนชิ้นส่วน เก็บโคมไฟไว้" ตามลำดับความสำคัญจากมากไปน้อย ข้อต่อต้องสมเหตุสมผลทางกลและชิ้นส่วนเข้ากัน ห้ามเพิ่มราคา ใบรับรองความยั่งยืน หรือคำกล่าวอ้างด้านประสิทธิภาพ ตัวแปร: ชื่อสตูดิโอ ผิววัสดุ และสโลแกนที่อนุมัติแล้ว
```

<a id="mkt-02"></a>

## MKT-02 — เทศกาลอ่านหนังสือริมแม่น้ำ

```text
สร้างโปสเตอร์ภาพประกอบ 3:4 สำหรับเทศกาลห้องสมุดลอยน้ำสมมติ เรือบรรทุกหนังสือสีน้ำเงินจอดอยู่ด้านขวาล่าง สะพานคนเดินสีแดงโค้งนำสายตาจากชื่อด้านซ้ายบนไปยังผู้อ่านสามคนใต้กันสาดลายทาง ใช้รูปทรงแบนแบบสกรีน กระดาษสีงาช้าง และขอบกว้าง แสดง "河畔读书节", "RIVER READING DAYS", "川辺の読書会" และ "SAT–SUN · 10:00–17:00" ให้ตรงทุกตัว แต่ละข้อความหนึ่งครั้งในบล็อกแยกกัน คงภาษาจีน อังกฤษ และญี่ปุ่นตามที่ให้มา ไม่มีป้ายอื่น ผู้สนับสนุน หรือลายน้ำ ตัวแปร: ข้อความเทศกาลที่อนุมัติและชุดสี
```

<a id="mkt-03"></a>

## MKT-03 — พอดแคสต์คลังเสียง

```text
สร้างปกสี่เหลี่ยมจัตุรัสสำหรับพอดแคสต์สมมติชื่อ "เสียงเล็ก ๆ" แสดงกุญแจทองเหลืองขนาดขยายวางในถาดตื้น พร้อมวงสั่นสะเทือนร่วมศูนย์กลางบาง ๆ สามวงวาดด้านหลัง ใช้ภาพมาโครโทนอุ่นและพื้นหลังสีม่วงมะเขือเข้ม วางชื่อพาดผ่านหนึ่งในสี่ด้านบน และ "เรื่องราวที่ควรค่าแก่การฟัง" ด้านล่าง ทั้งสองบรรทัดต้องอ่านได้เมื่อแสดงภาพกว้าง 100 พิกเซล ไม่มีไมโครโฟน หูฟัง ตราแพลตฟอร์ม หรือเลขตอน คงกุญแจหนึ่งดอก เงาสะท้อนสมจริง และพื้นที่ว่างสะอาด ตัวแปร: ชื่อ วัตถุ และสีพื้นหลัง
```

<a id="mkt-04"></a>

## MKT-04 — ภาพปกย่อเปรียบเทียบเครื่องมือ

```text
สร้างภาพปกย่อวิดีโอ 16:9 อธิบายการเลือกเครื่องมือช่าง จัดไขควงไร้แบรนด์สามอันในแนวตั้งด้านขวา โดยมีหัวแบน หัวแฉก และหัวหกเหลี่ยมที่ต่างกันชัดเจน ด้านซ้ายแสดงเพียง "หัวแบบไหนใช้ได้พอดี?" สองบรรทัด ใต้แต่ละหัวเพิ่มแผนภาพเล็กของหัวสกรูที่เข้ากันโดยไม่เพิ่มป้ายกำกับ ใช้ภาพถ่ายบนโต๊ะสว่าง ตัวอักษรสีถ่าน และจุดเน้นพื้นหลังสีเหลือง หัวไขควงกับร่องสกรูต้องเข้ากันทางกล ไม่มีปฏิกิริยาจัดฉาก คะแนน หรือคำกล่าวอ้างเกินจริง ตัวแปร: ชุดเครื่องมือและพาดหัวที่แน่นอน
```

<a id="mkt-05"></a>

## MKT-05 — ปกชุดภาพสอนบรรจุภัณฑ์

```text
สร้างปก 3:4 สำหรับคู่มือหกสไลด์เรื่องการบรรจุเซรามิกแตกง่าย แสดงชามหนึ่งใบที่ดูเหมือนลอยอยู่ระหว่างแผงกั้นกระดาษแข็งพับ พร้อมม้วนกระดาษกันกระแทกด้านล่าง ใช้ภาพถ่ายมุมบนที่เป็นระเบียบบนพื้นสีเทาอ่อน วาง "แพ็กอย่างใส่ใจ" ด้านบน "คู่มือส่งเซรามิก" ถัดลงมา และ "1/6" ที่มุมขวาล่าง ชามต้องสมบูรณ์และวัสดุสมจริง ไม่มีโลโก้บริษัทขนส่ง คำรับประกันป้องกันความเสียหาย หรือข้อความเพิ่ม ตัวแปร: วัตถุ ชื่อ และจำนวนสไลด์
```

<a id="mkt-06"></a>

## MKT-06 — รับสมัครทีมเวิร์กช็อปชุมชน

```text
สร้างโปสเตอร์รับสมัครแนวตั้ง 3:4 สำหรับสหกรณ์ซ่อมจักรยานสมมติ แสดงผ้ากันเปื้อนช่างที่ไม่มีคนสวมแขวนข้างแผงเครื่องมือเรียงเป็นระเบียบ เว้นครึ่งบนไว้สำหรับข้อความ ใช้ภาพถ่ายสารคดี แสงหน้าต่างนุ่ม และตัวอักษรสีเขียวเข้ม แสดง "มาร่วมงานที่เวิร์กช็อป", "[ROLE]", "[CITY] · [SCHEDULE]" และ "สมัครภายใน [DATE]" โดยแทนค่าตามข้อมูลที่ให้ เครื่องมือต้องจดจำได้และห้ามแต่งเงินเดือน ใบรับรอง หรือข้อมูลติดต่อ อย่าสร้างคิวอาร์โค้ด ต้องแทนตัวแปรทั้งหมดก่อนสร้างภาพ
```

<a id="mkt-07"></a>

## MKT-07 — เตือนให้นำแก้วใช้ซ้ำมา

```text
สร้างป้ายคาเฟ่ 9:16 ชวนลูกค้านำแก้วใช้ซ้ำมา แสดงแก้วพกพาสีครีมหนึ่งใบที่ผ่านการใช้งานมาแล้วข้างเหยือกเซรามิกสีฟ้าชอล์ก ถ่ายระดับเคาน์เตอร์ด้วยแสงเช้าอบอุ่น วาง "แก้วของคุณ ช่วงเวลาของคุณ" ด้านบน และ "ครั้งหน้าอย่าลืมพามา" ใต้แก้ว เว้นกลางภาพให้โปร่งและให้ตัวอักษรตัดกันสูงเมื่อมองจากระยะใช้งาน ไม่มีส่วนลด สถิติสิ่งแวดล้อม หรือคำกล่าวอ้างสุขภาพ ไม่มีวัตถุหรือข้อความเพิ่ม คงรูปทรงฝาสมจริงและเงาที่สัมผัสพื้น ตัวแปร: สีแก้วและข้อความสองบรรทัดที่อนุมัติ
```

<a id="mkt-08"></a>

## MKT-08 — ภาพหลักงานเดินชมโคมไฟ

```text
สร้างภาพหลักนิ่ง 16:9 สำหรับงานเดินชมโคมไฟยามค่ำสมมติชื่อ "เส้นทางแห่งแสง" แถวโคมกระดาษสีอำพันเล็ก ๆ โค้งผ่านสวนพฤกษศาสตร์มืดไปยังประตูที่เปิดอยู่ เว้นบริเวณกลางค่อนไปซ้ายให้สงบสำหรับชื่อ วาง "ค่ำคืนที่ได้อยู่ด้วยกัน" ใต้ชื่อทันที ใช้ภาพประกอบกระดาษซ้อนชั้นที่มีมิติเบา ๆ และเห็นเส้นใย ไม่ใช่เอฟเฟกต์นีออน หลีกเลี่ยงสถานที่สำคัญที่ระบุตัวตนได้ โลโก้ผู้สนับสนุน และข้อความเพิ่ม นี่คือเฟรมแนวคิดนิ่งหนึ่งภาพ ไม่ใช่แอนิเมชัน ตัวแปร: ชื่อ รูปเส้นทาง และสีเน้น
```

<a id="mkt-09"></a>

## MKT-09 — โปสเตอร์เวิร์กช็อปซ่อมของ

```text
สร้างโปสเตอร์ 3:4 สำหรับเวิร์กช็อปซ่อมของชุมชนสมมติ วาดโต๊ะสีดินเผาหนึ่งตัวที่มีเครื่องปิ้งขนมปังสีเหลือง ไขควงเล็ก และหลอดด้ายสีน้ำเงิน มือผู้ใหญ่สองมือทำงานกับเครื่องจากคนละด้าน ใช้รูปทรงกระดาษตัดที่สะอาด พื้นครีม ตัวอักษรกรมท่า และช่องว่างกว้าง ด้านบนเขียน "วันเสาร์ชวนซ่อม" ถัดลงมา "นำของชิ้นเล็กมาหนึ่งชิ้น" และด้านล่าง "14:00–17:00" แสดงแต่ละบรรทัดครั้งเดียวเท่านั้น มือสมเหตุสมผลทางกายวิภาคและเครื่องต้องถอดปลั๊ก ตัวแปร: ข้อความภาษาท้องถิ่นที่อนุมัติและชุดสี
```

<a id="mkt-10"></a>

## MKT-10 — ป้ายเปิดร้านบนกระจก

```text
สร้างป้ายติดหน้าต่าง 2:3 สำหรับร้านพิมพ์ภาพย่านชุมชนสมมติ แสดงภาพถ่ายสำเร็จรูปไร้แบรนด์สามใบหนีบบนเชือกแนวนอนเส้นเดียวในครึ่งล่าง ด้านบนเขียน "พิมพ์เรื่องราวในทุกวัน" ตามด้วย "เปิดร้าน [DATE]" และ "[STREET]" ใช้กระดาษครีมที่เห็นพื้นผิว ตัวอักษรสีโคบอลต์ และเงาธรรมชาติ ระบุวันและที่อยู่ก่อนสร้างภาพ ห้ามแต่งข้อเสนอเปิดร้าน ภาพทั้งสามต้องต่างกัน มีแต่ภาพ ไม่มีใบหน้าส่วนบุคคลหรือเอกสารส่วนตัวที่อ่านได้ ตัวแปร: วัน สถานที่ และเนื้อหาภาพพิมพ์
```
