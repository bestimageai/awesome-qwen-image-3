# แอสเซ็ตเกม อุปกรณ์ และแนวคิดอุตสาหกรรม

ชุดพรอมป์ต์ Qwen Image 3.0 จำนวนสิบรายการ เปลี่ยนข้อมูลในวงเล็บเหลี่ยมก่อนสร้างภาพ ข้อความในเครื่องหมายคำพูดต้องแสดงตรงตามที่ระบุ ไม่ต้องแปลเว้นแต่สั่งไว้อย่างชัดเจน ผลลัพธ์ต้องผ่านการตรวจสอบโดยมนุษย์

<a id="pro-01"></a>

## PRO-01 — อุปกรณ์นักสำรวจป่า

```text
สร้างแผ่นอุปกรณ์ตัวละครเกมต้นฉบับ 16:9 ของนักสำรวจป่าผู้ใหญ่ แสดงท่ายืนเป็นกลางเต็มตัวหนึ่งท่าและภาพแยกกระเป๋าผ้า ไม้บรรทัดพับ สมุดทนสภาพอากาศ ใช้ภาพสมจริงมีสไตล์ เขียวหม่น สเกลสัมพันธ์คงที่ เสื้อผ้า สาย และการยึดเครื่องมือสมเหตุสมผล ไม่มีอาวุธ สัญลักษณ์แฟรนไชส์รู้จัก หรือข้อความ ตัวแปร: รายละเอียดตัวละครต้นฉบับและอุปกรณ์ที่อนุมัติ นี่เป็นคอนเซปต์อาร์ตไม่ใช่แอสเซ็ตพร้อมผลิต
```

<a id="pro-02"></a>

## PRO-02 — ชุดเรือนกระจกโมดูลาร์

```text
สร้างบอร์ดฉากเกม 16:9 มีเรือนกระจกหกโมดูล: ผนังตรง มุม ประตู แผงหลังคา แผงหน้าต่าง และกระเบื้องพื้น ใช้มุมคล้ายออร์โธกราฟิก สัดส่วนกริดร่วม โครงโลหะอ่อน กระจกโปร่งแสง จัดสองแถวและกำกับเฉพาะชื่อที่ให้ จุดต่อเข้ากันได้ไม่ใช้ข้อต่อหลังคาเป็นไปไม่ได้ ตัวแปร: ขนาดโมดูลที่อนุมัติและป้าย ต้องสร้างรูปทรงใหม่และทดสอบในเครื่องมือ 3D
```

<a id="pro-03"></a>

## PRO-03 — แผ่นไอคอนสัมภาระ

```text
สร้างแผ่นสี่เหลี่ยมสี่คูณสี่มีไอคอนสัมภาระสิบหกแบบต่างกันจาก [APPROVED ITEM LIST] ใช้มุมไอโซเมตริกร่วม แสงซ้ายบนคงที่ และพื้นกลางแบน วางชิ้นเดียวกลางช่องเท่ากันมีขอบมาก รูปร่างอ่านได้เมื่อเล็ก ไม่มีข้อความ ของซ้ำ ตัดขอบ หรืออุปกรณ์แบรนด์แต่ง ตัวแปร: รายการสิบหกชิ้นตรงและสี นี่เป็นแผ่นแนวคิดไม่ใช่แอตลาสสไปรต์โปร่งใสที่ตรวจแล้ว
```

<a id="pro-04"></a>

## PRO-04 — ตัวอย่างวัสดุสี่แบบ

```text
สร้างบอร์ด 16:9 มีภาพศึกษาวัสดุสี่เหลี่ยมเท่ากันสี่ภาพ: ไม้ทาสีเก่า เหล็กขัดลาย หินหยาบ และแคนวาสทอ ใช้ [AUTHORIZED REFERENCES] คงตัวตนวัสดุและความรู้สึกสเกลร่วม แสดงผิวแบนแสงกลางไม่มีเงาดราม่าหรือวัตถุ กำกับแต่ละวัสดุหนึ่งครั้งนอกภาพ ตัวแปร: ภาพและป้ายตรง ห้ามอ้างว่าไร้รอยต่อ เป็นแมปตามฟิสิกส์ หรือพร้อมใช้ในเอนจินโดยไม่ประมวลผลแยก
```

<a id="pro-05"></a>

## PRO-05 — แนวคิดวิทยุพกพา

```text
สร้างแผ่นออกแบบอุตสาหกรรม 3:2 ของวิทยุพกพาต้นฉบับตัวสี่เหลี่ยมมน ปุ่มจูนหนึ่ง และหูหิ้วพับ แสดงหน้า หลัง สามส่วนสี่โดยสัดส่วนและปุ่มคงที่ ใช้พอลิเมอร์เทาอุ่น ตะแกรงลำโพงน้ำเงิน แสงสตูดิโอนุ่ม ใส่เฉพาะ "หน้า", "หลัง" และ "มุมมอง" ไม่มีแบรนด์ ค่าทางไฟฟ้า ขนาด หรือใบรับรองปลอดภัยเว้นแต่ให้ ตัวแปร: ภาพร่างที่อนุมัติและสี นี่ไม่ใช่สเปกวิศวกรรม
```

<a id="pro-06"></a>

## PRO-06 — บอร์ดฝึกประกอบ

```text
สร้างภาพประกอบสี่ขั้น 16:9 จาก [VERIFIED MANUAL AND PART LIST] แสดงเฉพาะชิ้นส่วนที่ให้ การกระทำชัดหนึ่งอย่างต่อช่องและทิศวัตถุหลักคงที่ ใช้ภาพเทคนิคสะอาด เลขขั้น และลูกศรตรงลำดับที่อนุมัติ แสดงเฉพาะคำเตือนและป้ายที่ให้ ห้ามแต่งแรงบิด เครื่องมือ ขั้นปลอดภัย หรือขั้นที่ขาด ตัวแปร: คู่มือ ชิ้นส่วน และข้อความตรง ต้องให้ผู้เชี่ยวชาญรับรองก่อนใช้สอน
```

<a id="pro-07"></a>

## PRO-07 — ภาพแยกชิ้นกล่องอิเล็กทรอนิกส์

```text
ใช้ [APPROVED CAD VIEWS] สร้างภาพแยกชิ้น 4:3 ของกล่องอิเล็กทรอนิกส์เล็ก แยกฝา ซีล แผงวงจร และฐานตามแกนเดียว คงจุดยึดและลำดับที่ให้ ใช้เงาเทคนิคกลางและป้ายจาก [APPROVED PART NAMES] ห้ามแต่งสาย ขนาด หรือการต่อไฟ ตัวแปร: มุมที่อนุญาตและป้าย นี่เป็นภาพอธิบายไม่ใช่ CAD ตรวจแล้วหรือขั้นตอนซ่อม
```

<a id="pro-08"></a>

## PRO-08 — ความต่อเนื่องอุปกรณ์ตัวละคร

```text
สร้างแผ่น 16:9 แสดงตะเกียงนักสำรวจต้นฉบับหนึ่งดวงสามสถานะ: ถือหู วางหิน แขวนตะขอ คงตัวหกเหลี่ยม กระจกอำพัน สลักทองเหลือง และรูปหูทุกช่อง ใช้อาร์ตเกมสมจริงมีสไตล์และแสงคงที่ ไม่มีข้อความ กลไกเพิ่ม หรือลายแฟรนไชส์รู้จัก ตัวแปร: ภาพอุปกรณ์ที่อนุมัติและฉาก ตรวจความเป็นไปได้ของเมชแยก
```

<a id="pro-09"></a>

## PRO-09 — ชุดภาพบทสนทนาเกม

```text
สร้างแผ่น 3:2 สองคูณสามภาพครึ่งตัวหกภาพของผู้ดูแลประภาคารผู้ใหญ่ต้นฉบับคนเดียว คงผมหยิกเทา เสื้อคลุมน้ำเงิน รูปหน้า และแผลคิ้วเล็ก แสดงสงบ อยากรู้ สงสัย กังวล โล่งใจ และร่าเริง ใช้อาร์ตเกมวาดสะอาด พื้นกลางแบนไม่มีข้อความ ระยะกล้องและหัวเท่ากัน ตัวแปร: ภาพตัวละครและสี นี่เป็นชุดแนวคิดไม่ใช่ตัวละครริกหรือเคลื่อนไหวอัตโนมัติ
```

<a id="pro-10"></a>

## PRO-10 — ศึกษาขาตั้งพับ

```text
สร้างบอร์ดแนวคิดอุตสาหกรรม 16:9 ของขาตั้งแท็บเล็ตพับต้นฉบับในท่าปิด เปิดครึ่ง ใช้งาน ใช้โครงอะลูมิเนียม แกนพับ และเท้ายางเดิม แสดงข้างชัดบนงาช้าง กำกับเฉพาะ "ปิด", "กำลังเปิด" และ "พร้อม" ใต้ช่อง การเคลื่อนไหวกลสมจริง ไม่แต่งน้ำหนักรับหรือความเข้ากัน ตัวแปร: ภาพร่างและผิวที่อนุมัติ ต้องตรวจวิศวกรรม
```
