# ประวัติศาสตร์ วัฒนธรรม และการตีความตามหลักฐาน

ชุดพรอมป์ต์ Qwen Image 3.0 จำนวนสิบรายการ เปลี่ยนข้อมูลในวงเล็บเหลี่ยมก่อนสร้างภาพ ข้อความในเครื่องหมายคำพูดต้องแสดงตรงตามที่ระบุ ไม่ต้องแปลเว้นแต่สั่งไว้อย่างชัดเจน ผลลัพธ์ต้องผ่านการตรวจสอบโดยมนุษย์

<a id="cul-01"></a>

## CUL-01 — กิจกรรมถนนประวัติศาสตร์

```text
ใช้ [DATED PHOTOGRAPHS AND MAP] สร้างจำลอง 16:9 ชีวิตบน [STREET] ใน [YEAR] คงโครงอาคาร ประเภทขนส่ง ผิวถนนที่มีหลักฐาน แสดงเพียงกิจวัตรที่หลักฐานรองรับ ส่วนไม่แน่ใจทำจาง ใช้ภาพสารคดีไม่อ้างรูปเก่า ไม่มีจารึกแต่ง คนดัง ของใหม่ ตัวแปร: ที่ วัน หลักฐาน และความไม่แน่นอน ต้องตรวจประวัติศาสตร์
```

<a id="cul-02"></a>

## CUL-02 — บอร์ดสร้างโบราณวัตถุใหม่

```text
สร้างบอร์ดศึกษาพิพิธภัณฑ์สามช่อง 16:9 จาก [AUTHORIZED ARTIFACT IMAGES] แสดงของที่เหลือ การจำลองเรียบ และแผนส่วนไม่แน่ใจ คงรูปทรงและเสียหายที่บันทึก ป้าย "ส่วนที่คงอยู่", "การจำลอง", "ไม่แน่นอน" ใช้วิธีภาพต่างไม่ให้เดาเป็นหลักฐาน ไม่แต่งผู้ทำ ที่มา ความหมายพิธี ตัวแปร: ชุดภาพและตีความที่อนุมัติ ต้องผู้เชี่ยวชาญตรวจ
```

<a id="cul-03"></a>

## CUL-03 — ภาพตลาดประวัติศาสตร์

```text
สร้างภาพศึกษา 3:2 ของตลาดใน [VERIFIED REGION AND PERIOD] ด้วย [EVIDENCE PACK] มีเฉพาะแผง เสื้อผ้า สินค้า อาคารที่ให้ จัดการซื้อขายหน้าเข้าใจง่ายและหลังสงบ แสงวันธรรมชาติ รายละเอียดพอดี ไม่มีราคาอ่านได้ อักษรแต่ง ภาพเหมารวม หรือของผิดยุค ตัวแปร: ภูมิภาค วัน และองค์ประกอบหลักฐาน ระบุว่าตีความไม่ใช่ภาพประวัติศาสตร์แท้
```

<a id="cul-04"></a>

## CUL-04 — ศึกษาเครื่องแต่งกายประวัติศาสตร์

```text
ใช้ [MUSEUM-VERIFIED GARMENT REFERENCES] สร้างแผ่น 16:9 หน้า ข้าง หลังบนหุ่นกลาง คงตะเข็บ ตัวยึด ชั้นผ้า และหลักฐานสี กำกับเฉพาะชื่อเสื้อ ภูมิภาค ยุคที่อนุมัติ ไม่แต่งสถานะ ชาติพันธุ์ ความหมายพิธี หรือเครื่องประดับไร้หลักฐาน ตัวแปร: ภาพและป้ายตรง แยกสีไม่แน่ด้วยหมายเหตุที่ให้และผู้เชี่ยวชาญตรวจ
```

<a id="cul-05"></a>

## CUL-05 — กระบวนการงานฝีมือดั้งเดิม

```text
สร้างภาพสี่ช่อง 16:9 ของ [DOCUMENTED CRAFT PROCESS] ด้วย [PRACTITIONER-APPROVED STEPS] แสดงเครื่องมือ มือ สภาพวัสดุถูกตามลำดับ ใช้ภาพธรรมชาติชัดและป้ายที่ให้เท่านั้น ไม่เผยความรู้จำกัด แต่งสิ่งศักดิ์สิทธิ์ หรือแทนประเพณีมีชีวิตด้วยลายทั่วไป ตัวแปร: ภาพอนุมัติ ขั้น และที่มา ต้องผู้ปฏิบัติตรวจและมีสิทธิ์ที่เกี่ยวก่อนเผยแพร่
```

<a id="cul-06"></a>

## CUL-06 — แผงมรดกสองภาษา

```text
สร้างแผงตีความมรดก 3:4 ด้วย [APPROVED TWO-LANGUAGE COPY] และภาพสถานที่อนุญาตหนึ่งภาพ ให้สองภาษาน้ำหนักเท่ากันในบล็อกแยกจัดชัด คงชื่อ วัน เครื่องหมาย ทิศอ่าน ภาพเหนือคำ ไม่มีประวัติแต่ง คำอ้างเที่ยว โลโก้สถาบัน หรือคำแปลแต่ง ตัวแปร: สองภาษาสุดท้าย ภาพ เครดิต เป็นแนวคิดที่ต้องชุมชนและข้อเท็จจริงตรวจ
```

<a id="cul-07"></a>

## CUL-07 — ซ้อนแผนที่เก่า

```text
ใช้แผนที่ประวัติศาสตร์ที่อนุญาตและ [VERIFIED MODERN ALIGNMENT] สร้างภาพเทียบ 16:9 คงแผนที่เก่าเป็นฐาน เพิ่มเฉพาะเส้นใหม่ที่ให้เป็นชั้นน้ำเงินต่าง มีคำอธิบายแยกสองวันและการตรงไม่แน่ ห้ามแต่งเขต คำอ้างกรรมสิทธิ์ เส้นทาง หรือความแม่นภูมิสารสนเทศ ตัวแปร: แผนที่ การจัด และป้าย ต้องตรวจประวัติศาสตร์และภูมิศาสตร์
```

<a id="cul-08"></a>

## CUL-08 — ความต่อเนื่องการจำลอง

```text
สร้างจำลองสี่ช่อง 16:9 ของลานที่บันทึกเดิมตอนรุ่ง เที่ยง บ่าย พลบใน [VERIFIED PERIOD] ตรึงอาคาร วัสดุ ของ กล้องด้วย [EVIDENCE PACK] เปลี่ยนเพียงแสงและกิจวัตรที่ให้ เลี่ยงของใหม่ จารึกแต่ง พิธีไม่มีหลักฐาน กำกับเวลาเท่านั้น ตัวแปร: ภาพและกิจกรรมที่อนุมัติ เป็นลำดับตีความไม่ใช่หลักฐานว่าเหตุเกิด
```

<a id="cul-09"></a>

## CUL-09 — โปสเตอร์จับเอกสารเก่า

```text
สร้างแนวคิดโปสเตอร์ฝึก 3:4 จาก [ARCHIVIST-APPROVED HANDLING RULES] สามช่องชัดมีการจับที่ให้ เครื่องมือตรง ป้ายสั้นตรง ภาพเทคนิคกลาง ตัดสูง ขอบกว้าง ห้ามแต่งข้อกำหนดถุงมือ วิธีล้าง หรืออนุรักษ์ ตัวแปร: ขั้นที่ตรวจและชนิดของ ตรวจร่วมกับนักจดหมายเหตุก่อนใช้ ไม่มีตราสถาบัน ลายเซ็น หรือคำอ้างรักษาไร้หลักฐาน
```

<a id="cul-10"></a>

## CUL-10 — แผงคำบอกเล่าประวัติศาสตร์

```text
สร้างแผงนิทรรศการ 4:3 ด้วย [CONSENTED VERIFIED QUOTATION], [APPROVED ATTRIBUTION] และภาพบริบทที่อนุญาต คำอ้างเด่น เครดิตใต้ ภาพข้าง คงถ้อยคำ ภาษาถิ่น วรรคตอนตรง ไม่เขียนคำให้การใหม่หรือแต่งหน้าผู้พูด ใช้ตัวบรรณาธิการสงบ พื้นครีม ตัวแปร: คำที่ยินยอม ที่มา ภาพ ใส่เพียงบริบทและเครดิตสิทธิ์ที่ให้
```
