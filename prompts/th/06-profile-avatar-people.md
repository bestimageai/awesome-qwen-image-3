# อวตาร ทีม และภาพบุคคลในชีวิตประจำวัน

ชุดพรอมป์ต์ Qwen Image 3.0 จำนวนสิบรายการ เปลี่ยนข้อมูลในวงเล็บเหลี่ยมก่อนสร้างภาพ ข้อความในเครื่องหมายคำพูดต้องแสดงตรงตามที่ระบุ ไม่ต้องแปลเว้นแต่สั่งไว้อย่างชัดเจน ผลลัพธ์ต้องผ่านการตรวจสอบโดยมนุษย์

<a id="ava-01"></a>

## AVA-01 — ภาพผู้ก่อตั้งเวิร์กช็อป

```text
ใช้ภาพผู้ใหญ่ที่ได้รับอนุญาตสร้างภาพผู้ก่อตั้ง 3:4 สำหรับเวิร์กช็อปเฟอร์นิเจอร์เล็ก คงอายุ สัดส่วนใบหน้า และผิวธรรมชาติ ให้นั่งข้างเก้าอี้ไม้ที่ยังไม่เสร็จ มือวางตามธรรมชาติ และเครื่องมือด้านหลังเบลอนุ่ม ใช้ภาพสารคดีระดับสายตากับแสงหน้าต่างกว้าง ไม่มีของสำนักงานหรู รางวัลแต่ง คนเพิ่ม หรือข้อความ คงเสื้อผ้าตามภาพอ้างอิงเว้นแต่ให้ชุดทดแทนชัดเจน ตัวแปร: ภาพบุคคล ชุดที่อนุมัติ และบรรยากาศเวิร์กช็อป
```

<a id="ava-02"></a>

## AVA-02 — อวตารวงกลมสำหรับครีเอเตอร์

```text
สร้างอวตารสี่เหลี่ยมจัตุรัสจากภาพผู้ใหญ่ที่ได้รับอนุญาตหนึ่งภาพ ให้ใบหน้าและไหล่บนอยู่ในเจ็ดสิบเปอร์เซ็นต์กลางเพื่อครอปวงกลมแล้วไม่ตัดผมหรือคาง ใช้พื้นเทาอุ่น แสงหน้านุ่ม และสีหน้าธรรมชาติ คงตัวตน อายุ ผม และลักษณะใบหน้าแตกต่างที่เห็น ลบเพียงความรกพื้นหลัง ไม่มีข้อความ ตรา อุปกรณ์ใหม่ การทำผิวเรียบเกิน หรือปรับรูปร่าง ตัวแปร: ภาพอ้างอิงและสีพื้นหลัง ตรวจผลที่ขนาดไอคอนโปรไฟล์เล็ก
```

<a id="ava-03"></a>

## AVA-03 — แถบภาพทีมสามคน

```text
ใช้ภาพผู้ใหญ่ที่ได้รับอนุญาตสามภาพ สร้างแถบ 16:9 มีภาพศีรษะแยกสามภาพกว้างเท่ากันและพื้นสีกลางสอดคล้อง คงใบหน้าและผมแต่ละคนโดยไม่ผสมลักษณะ จัดระดับตา ระยะกล้องที่ปรากฏ และทิศแสงให้ตรงพร้อมรักษาความแตกต่างธรรมชาติ ใส่ชื่อที่ให้ใต้ภาพตรงคนครั้งเดียว ไม่มีตำแหน่งงานแต่ง คนเพิ่ม หรือแต่งความงาม ตัวแปร: ภาพสามภาพและการจับคู่ชื่อกับภาพ งานนี้ต้องใช้กระบวนการแก้ไขที่รับภาพอ้างอิงทั้งสามได้
```

<a id="ava-04"></a>

## AVA-04 — ภาพสัมภาษณ์ช่างฝีมือ

```text
สร้างภาพบุคคลบรรณาธิการ 3:2 ของช่างเข้าเล่มผู้ใหญ่ที่ออกแบบใหม่กำลังซ่อมหนังสือปกผ้าที่โต๊ะไม้ แสดงมือในบริบท แปรงเล็ก และกระดาษรองปกหนึ่งแผ่น จัดเครื่องมือสมเหตุสมผล ใช้แสงหน้าต่างด้านข้าง สีเรียบ และมุมกลางมีที่ว่างขวา ห้ามเลียนบุคคลที่ระบุชื่อหรือเพิ่มข้อความหนังสือที่อ่านได้ คุณวุฒิ หรือคำกล่าวอ้างประวัติศาสตร์ นิ้วต้องสมจริงและกาวอยู่ห่างใบหน้า ตัวแปร: งานฝีมือ ตัวละครสมมติ และชุดสีที่อนุมัติ
```

<a id="ava-05"></a>

## AVA-05 — ช่วงเวลาครอบครัวทำอาหาร

```text
ใช้ภาพครอบครัวที่ได้รับอนุญาตสร้างฉากบ้าน 16:9 ของคนเดิมกำลังจัดผักบนโต๊ะครัว คงตัวตน ความต่างอายุ ความสัมพันธ์ และเสื้อผ้า ใช้สีหน้าธรรมชาติไม่บังคับสบตา ให้มีดและอุปกรณ์ร้อนพ้นมือเด็ก ใช้แสงบ่ายนุ่มและพื้นหลังบ้านที่มีชีวิตสมจริง ไม่มีสมาชิกเพิ่ม ข้อความ การเปลี่ยนร่างกายเกินจริง หรือเผยที่อยู่จริง ตัวแปร: ภาพที่ได้รับอนุญาตและฉากที่อนุมัติ ห้ามอนุมานความสัมพันธ์ที่ไม่ได้ระบุ
```

<a id="ava-06"></a>

## AVA-06 — ภาพบรรณาธิการกีฬาปรับรูปแบบ

```text
สร้างภาพบุคคลบรรณาธิการ 3:4 ของนักเทนนิสวีลแชร์ผู้ใหญ่ที่ออกแบบใหม่พักข้างสนามกลางแจ้ง แสดงล้อ โครง และขอบจับของรถกีฬาอย่างสมจริง ให้แร็กเกตพาดบนตัก ใช้แสงบ่ายแก่ มุมระดับตา และสีหน้าสงบเป็นตัวของตัวเอง ไม่ทำให้ดูน่าสงสารหรือเพิ่มสโลแกนสร้างแรงบันดาลใจ เหรียญ ผู้สนับสนุน หรือคำกล่าวอ้างทางการแพทย์ คงกายวิภาคและอุปกรณ์สมเหตุสมผล ตัวแปร: หน้าตานักกีฬาสมมติ ชุด และสีสนาม
```

<a id="ava-07"></a>

## AVA-07 — ภาพสตรีตวันฝนตก

```text
ใช้ภาพผู้ใหญ่ที่ได้รับอนุญาตสร้างภาพสตรีต 3:4 ใต้ร่มใส คงตัวตนใบหน้า ชุด และสัดส่วน วางคนใกล้ผนังอิฐเรียบพร้อมพื้นเปียกและเงาสะท้อนนุ่ม ใช้แสงวันครึ้มไม่ใช่นีออน โครงร่ม ด้าม และการจับต้องเข้ากัน ไม่มีคนเพิ่ม ที่อยู่ที่เห็น โลโก้ร้าน ข้อความ หรือเปลี่ยนอายุ ตัวแปร: ภาพบุคคล เสื้อคลุมที่อนุมัติ และวัสดุพื้นหลัง
```

<a id="ava-08"></a>

## AVA-08 — ภาพนักเขียนสำหรับสื่อ

```text
สร้างภาพบุคคลสี่เหลี่ยมสำหรับชุดสื่อจากภาพผู้ใหญ่ที่ได้รับอนุญาต ให้นั่งข้างกองหนังสือเรียบ ไหล่หันเล็กน้อยและหน้ามองกล้อง ใช้แสงข้างนุ่ม ผนังงาช้างไม่รก และผิวสมจริง คงผม ลักษณะหน้า และสีหน้า เว้นรอบหัวเพื่อครอปแบบอื่น ไม่มีชื่อหนังสือ รางวัล ลายเซ็นที่แต่ง ข้อความ หรือเอฟเฟกต์ฟิลเตอร์ความงาม ตัวแปร: ภาพ ชุดที่อนุมัติ และสีผนัง
```

<a id="ava-09"></a>

## AVA-09 — ภาพกลุ่มอาสาสมัคร

```text
ใช้ [APPROVED GROUP DESCRIPTION] สร้างภาพประกอบ 16:9 ของอาสาสมัครผู้ใหญ่ห้าคนพอดีกำลังคัดหนังสือบริจาครอบโต๊ะยาว ให้แต่ละคนมีงานต่างกันและคงรายละเอียดรูปลักษณ์ที่ให้โดยไม่ล้อเลียน ใช้กวอชบรรณาธิการอุ่นและมือจับวัตถุชัด ทางเดินต้องโล่งและกองหนังสือมั่นคง ไม่เพิ่มชื่อ โลโก้องค์กร ยอดบริจาค หรือคำกล่าวอ้างผู้รับประโยชน์ ตัวแปร: รายละเอียดกลุ่มที่อนุมัติและฉาก คนสมมติต้องไม่คล้ายบุคคลที่ระบุตัวได้
```

<a id="ava-10"></a>

## AVA-10 — ศึกษาแสงภาพบุคคล

```text
สร้างภาพศึกษาแสงสองช่อง 3:2 จากภาพผู้ใหญ่ที่ได้รับอนุญาตหนึ่งภาพ ซ้ายใช้แสงหน้าต่างกว้างจากซ้ายกล้อง ขวาใช้แสงเดิมที่ม่านทำให้นุ่ม ตรึงตัวตน ตำแหน่งกล้อง สีหน้า ชุด การครอป และพื้นหลัง แสดงเฉพาะ "แสงหน้าต่างตรง" กับ "แสงหน้าต่างกระจาย" ใต้ช่องที่ตรง เปลี่ยนเพียงความนุ่มเงาและการไล่ไฮไลต์ ห้ามปรับรูปหน้า เปลี่ยนสีผิว หรือจำลองอายุอื่น ตัวแปร: ภาพอ้างอิงและป้ายที่แปล
```
