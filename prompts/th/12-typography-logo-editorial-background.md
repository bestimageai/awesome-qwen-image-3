# ตัวอักษร งานออกแบบบรรณาธิการ และลวดลาย

ชุดพรอมป์ต์ Qwen Image 3.0 จำนวนสิบรายการ เปลี่ยนข้อมูลในวงเล็บเหลี่ยมก่อนสร้างภาพ ข้อความในเครื่องหมายคำพูดต้องแสดงตรงตามที่ระบุ ไม่ต้องแปลเว้นแต่สั่งไว้อย่างชัดเจน ผลลัพธ์ต้องผ่านการตรวจสอบโดยมนุษย์

<a id="typ-01"></a>

## TYP-01 — โปสเตอร์ตัวอักษรสองระดับ

```text
สร้างโปสเตอร์ตัวอักษร 3:4 ใช้ชื่อ "สิ่งของที่มีเรื่องเล่า" และชื่อรอง "ศึกษางานออกแบบในชีวิตประจำวัน" ตรงตามนี้ จัดชื่อด้วยตัวมีเชิงน้ำเงินเข้มใหญ่สามบรรทัดสมดุล ชื่อรองอยู่แถบตัวไม่มีเชิงเล็กแต่ชัดด้านล่าง เพิ่มวงกลมดินเผาง่ายหนึ่งวงหลังส่วนขวาล่างชื่อโดยไม่บังอักษร ใช้ผิวกระดาษอุ่นและขอบกว้าง ไม่มีคำเพิ่ม เส้นฐานบิด หรือตราแบรนด์คัด ตัวแปร: ชื่อ ชื่อรอง และสีที่อนุมัติ
```

<a id="typ-02"></a>

## TYP-02 — ตัวอย่างหลายระบบอักษร

```text
สร้างตัวอย่างอักษร 16:9 สามคอลัมน์เท่ากันมี "你好", "Hello" และ "こんにちは" ตรงตามนี้ ใช้อักษรจีน ละติน ญี่ปุ่นถูกต้องน้ำหนักภาพเท่ากัน หมึกเข้มและพื้นงาช้าง วางเส้นน้ำเงินบางใต้แต่ละตัวอย่าง ไม่มีชื่อภาษาหรือข้อความเพิ่ม คงระบบอักษรที่ให้ไม่ถอดเสียงหรือแปลอัตโนมัติ เว้นช่องมากและไม่ใช้อักษรปลอมตกแต่ง ตัวแปร: ข้อความหลายภาษาที่อนุมัติและแบบตัวอักษร
```

<a id="typ-03"></a>

## TYP-03 — เวิร์ดมาร์กเวิร์กช็อปต้นฉบับ

```text
สร้างแนวคิดเวิร์ดมาร์กแรสเตอร์สี่เหลี่ยมสำหรับสตูดิโอเซรามิกสมมติ "Soft Corner" ใช้ตัวพิมพ์เล็กโค้งมนดูออกแบบเฉพาะ สีถ่านเรียบ และสี่เหลี่ยมเล็กเยื้องหนึ่งชิ้นเป็นสัญลักษณ์เดียว ชื่ออ่านง่ายและสะกดครั้งเดียว แสดงแนวคิดแบนหนึ่งแบบบนงาช้าง ไม่ใช่ผนังจำลองหรือหลายตัวเลือก ห้ามเลียนแบรนด์เดิมหรืออ้างผ่านตรวจเครื่องหมายการค้า ตัวแปร: ชื่อสมมติและสี นักออกแบบต้องสร้างใหม่และตรวจเวกเตอร์สุดท้าย
```

<a id="typ-04"></a>

## TYP-04 — แผ่นสำรวจอักษรย่อ

```text
สร้างแผ่นแนวคิด 3:2 มีโมโนแกรมต้นฉบับต่างกันสามแบบจาก "A" และ "R" ที่ให้ วางแบบละช่องเท่ากันบนพื้นเรียบ เส้นดำหนาคงที่และรอบข้างมีช่อง ทั้งสองอักษรต้องจำได้ ไม่ใส่มงกุฎหรือคัดลายแฟชั่นเฮาส์ ไม่เพิ่มคำหรือเลข นี่เป็นสำรวจแรสเตอร์ไม่ใช่โลโก้จดทะเบียนหรือเวกเตอร์แก้ได้ ตัวแปร: อักษรย่อและสไตล์เรขาคณิต
```

<a id="typ-05"></a>

## TYP-05 — หน้าเปิดนิตยสาร

```text
สร้างเลย์เอาต์หน้าเปิด 3:4 ชื่อ "ชั้นวางของซ่อม" วางภาพใหญ่ของใช้บ้านที่ซ่อมแล้วครึ่งบน ชื่อด้านล่าง และสองย่อหน้าสั้นที่ให้ในสองคอลัมน์ถัดลงมา ใช้กระดาษครีม ฟอนต์มีเชิงสีถ่าน และเส้นน้ำเงินหนึ่งเส้น แสดงเพียง [APPROVED BODY COPY] กับชื่อ ไม่มีข้อความเติม ผู้เขียนแต่ง หรือเลขหน้า ข้อความอ่านได้และของสมจริง ตัวแปร: ข้อความตรงและภาพที่อนุญาต ต้องพิสูจน์อักษรบรรณาธิการ
```

<a id="typ-06"></a>

## TYP-06 — หน้าแรกหนังสือพิมพ์ชุมชน

```text
สร้างปกหนังสือพิมพ์สมมติ 3:4 ชื่อ "ข่าวลานบ้าน" ใช้กริดสามคอลัมน์ชัด ภาพใหญ่สวนร่วมหนึ่งภาพ และช่องภาพเล็กสองช่อง เติมพาดหัวและเนื้อหาเฉพาะ [APPROVED SHORT COPY] คงร่องคอลัมน์กว้าง ลำดับชั้นตรง และทุกคำอ่านได้ ห้ามแต่งข่าว วัน คำอ้าง ชื่อผู้เขียน หรือตราทางการ ตัวแปร: ข้อความที่อนุมัติ ภาพ และวันฉบับถ้ามี นี่เป็นแนวคิดจัดหน้าไม่ใช่รายงานเหตุจริง
```

<a id="typ-07"></a>

## TYP-07 — แนวคิดลายซ้ำ

```text
สร้างไทล์ลายสี่เหลี่ยมของแพร์และใบแบบต้นฉบับบนงาช้าง ใช้เพียงเหลืองดิน เขียวเสจ น้ำเงินเข้ม หันทิศหลากหลายและที่ว่างสมดุล ลายที่ข้ามขอบหนึ่งต้องต่อถูกอีกขอบ ระยะดูสม่ำเสมอ ไม่มีข้อความ โลโก้ ไล่สี หรือลายแบรนด์จำได้ ตัวแปร: ลาย สี และความหนาแน่น นี่เป็นตัวเลือกลายซ้ำที่สร้าง ต้องดูตัวอย่างปูซ้ำตรวจขอบก่อนผลิต
```

<a id="typ-08"></a>

## TYP-08 — พื้นหลังส่วนหลักแบบตอบสนอง

```text
สร้างพื้นหลังฮีโร่เว็บไซต์ 16:9 เป็นรูปกระดาษฟ้าอ่อนซ้อนชั้นไหลเฉียงจากขวาล่าง ให้ครึ่งซ้ายคอนทราสต์ต่ำและเกือบว่างสำหรับ HTML ภายหลัง ใช้เงากายภาพเบาและพื้นครีมนุ่ม ไม่มีคำ โลโก้ หรือส่วน UI เมื่อครอปสี่เหลี่ยมกลางต้องยังมีจุดสนใจสงบไม่ตัดรูปสำคัญ ตัวแปร: สี ทิศ และพื้นที่ปลอดภัยข้อความ อย่าฝังคำอินเทอร์เฟซในภาพ
```

<a id="typ-09"></a>

## TYP-09 — ป้ายงานตัวใหญ่

```text
สร้างป้ายบอกทางงาน 3:4 บนขาว แสดงตรงว่า "เวิร์กช็อปอยู่ชั้นบน", "ลิฟต์อยู่ทางซ้าย" และลูกศรขึ้นใหญ่หนึ่งอัน ใช้ตัวไม่มีเชิงกรมท่าใหญ่มาก ระยะชัด ไม่มีภาพตกแต่ง วางลูกศรเหนือชื่อและบรรทัดสองใต้ มีขอบชัด ไม่เพิ่มสมมติฐานทางที่เข้าถึงไม่ได้หรือโลโก้สถานที่ ทิศที่ให้ต้องตรวจพื้นที่จริง ตัวแปร: ทิศที่อนุมัติและการหันลูกศร
```

<a id="typ-10"></a>

## TYP-10 — ระบบสันหนังสือ

```text
สร้างภาพจำลองบรรณาธิการ 16:9 มีสันหนังสือตั้งห้าเล่มสูงเท่ากัน ใช้ดีไซน์ครีมโคบอลต์ร่วม แต่ละสันชื่อที่ให้หนึ่งชื่อและชื่อชุดซ้ำสม่ำเสมอ คงลำดับชื่อกับเล่ม แนวตั้งอ่านได้ และช่องกว้าง ไม่เพิ่มผู้แต่ง โลโก้สำนักพิมพ์ ISBN บาร์โค้ด หรือรางวัลเว้นแต่ให้มา ตัวแปร: ห้าชื่อและชื่อชุด ให้เป็นแนวคิดสิ่งพิมพ์ไม่ใช่ไฟล์พร้อมพิมพ์
```
