# วิทยาศาสตร์ แผนภาพเทคนิค และคำอธิบาย

ชุดพรอมป์ต์ Qwen Image 3.0 จำนวนสิบรายการ เปลี่ยนข้อมูลในวงเล็บเหลี่ยมก่อนสร้างภาพ ข้อความในเครื่องหมายคำพูดต้องแสดงตรงตามที่ระบุ ไม่ต้องแปลเว้นแต่สั่งไว้อย่างชัดเจน ผลลัพธ์ต้องผ่านการตรวจสอบโดยมนุษย์

<a id="sci-01"></a>

## SCI-01 — ภาพตัดลำต้น

```text
สร้างภาพตัดสอน 3:4 ของ [VERIFIED PLANT STEM STRUCTURE] ด้วย [APPROVED DIAGRAM REFERENCES] มีหน้าตัดหลักหนึ่งและเนื้อเยื่อขยายหนึ่ง ป้ายเชื่อมโครงถูก ใช้ภาพวิทย์เรียบ สีคงที่ ช่องขาวชัด แสดงเฉพาะชื่อและหน่วยที่ให้ ไม่แต่งกายวิภาค สเกล หน้าที่ หรือโมเลกุลตกแต่ง ตัวแปร: ชุดอ้างอิง ป้าย แหล่ง ผู้เชี่ยวชาญต้องตรวจ
```

<a id="sci-02"></a>

## SCI-02 — แผนภาพข้อเสียกล

```text
สร้างแผนภาพอธิบาย 16:9 จาก [VERIFIED MECHANICAL DRAWING AND FAULT DESCRIPTION] ซ้ายชุดปกติ ขวาข้อเสียที่บันทึก เน้นเฉพาะส่วนกระทบ คงลำดับชิ้น การต่อ รูปทรง ใช้ป้ายที่ให้และชื่อ "ปกติ", "ข้อเสียที่แสดง" ไม่มีขั้นซ่อม แรงบิด คำแนะนำไฟ หรืออ้างปลอดภัยเว้นแต่ให้ ตัวแปร: แบบและคำอธิบายตรวจแล้ว ต้องวิศวกรตรวจ
```

<a id="sci-03"></a>

## SCI-03 — กระบวนการ AI คนตรวจ

```text
สร้างแผนภาพระบบ 16:9 ห้าโหนดพอดี "ข้อมูลเข้า", "โมเดล", "ตรวจสอบ", "ผลลัพธ์อนุมัติ", "แก้ไข" ต่อข้อมูลเข้าไปโมเดล โมเดลไปตรวจ ตรวจไปผลอนุมัติและแก้ แก้กลับโมเดล จัดซ้ายไปขวา กล่องกรมท่า ทางอนุมัติเขียวน้ำเงิน ทางแก้อำพัน ลูกศรไม่กำกวม ไม่มีบริการหรือคลังข้อมูลเพิ่ม นี่เป็นตัวอย่างกระบวนการไม่ใช่สถาปัตยกรรมที่ตรวจแล้ว
```

<a id="sci-04"></a>

## SCI-04 — เทียบข้อมูลภูมิอากาศ

```text
สร้างกราฟ 16:9 ด้วย [VERIFIED CLIMATE DATA AND UNCERTAINTY] เท่านั้น แสดงอนุกรมเวลาที่ให้พร้อมแกน หน่วย ฐาน และแหล่ง ความไม่แน่นอนเป็นแถบที่ระบุและเว้นค่าหาย ใช้พื้นกลางและสีน้ำเงินหนึ่งชุดเรียบ ห้ามแต่งคาดการณ์ เหตุผล สถิติสูงสุด หรือความแม่น ตัวแปร: ข้อมูล นิยามช่วง และชื่อที่อนุมัติ ต้องผู้เชี่ยวชาญตรวจข้อมูลกับการตีความ
```

<a id="sci-05"></a>

## SCI-05 — บอร์ดลำดับห้องทดลอง

```text
สร้างลำดับภาพ 3:4 ด้วย [APPROVED NON-HAZARDOUS LAB PROCEDURE] เท่านั้น แสดงขั้นที่ให้ตรงลำดับ อุปกรณ์ ป้าย หน่วยตรง ใช้ภาพเทคนิคชัด แยกเตือนจากการกระทำ ไม่แต่งปริมาณ อุณหภูมิ เวลา มาตรการปลอดภัย หรือทดลองเพิ่ม ตัวแปร: ขั้นที่ตรวจและคำตรง เป็นสื่อช่วยไม่แทนระเบียบอนุมัติหรือผู้ดูแล
```

<a id="sci-06"></a>

## SCI-06 — ภาพรวมบำรุงเครื่องใช้

```text
สร้างภาพรวม 16:9 จาก [MANUFACTURER-APPROVED USER MAINTENANCE GUIDE] แสดงเฉพาะส่วนเข้าถึงภายนอกผู้ใช้ดูแลได้และลำดับที่ให้ ใช้ภาพป้ายง่ายทิศคง คงเตือนและสถานะไฟตรง ไม่แต่งถอด สาย สารเคมี หรือคำซ่อม ตัวแปร: คู่มือที่ตรวจและภาพเครื่อง ต้องผู้เชี่ยวชาญตรวจก่อนสอน ไม่เพิ่มใบรับรองหรือรับประกัน
```

<a id="sci-07"></a>

## SCI-07 — สรุปหลักฐานวิจัย

```text
สร้างเลย์เอาต์สรุป 3:4 จาก [REVIEWED STUDY SUMMARY] แบ่ง "คำถาม", "วิธี", "ข้อค้นพบ", "ข้อจำกัด" ด้วยคำที่ให้ตรงและกราฟอนุมัติหนึ่ง เห็นขนาดตัวอย่าง ความไม่แน่นอน แหล่ง ใช้ตัวเข้มชัด น้ำเงินเรียบ ไม่แต่งนัยสำคัญ เหตุผล คำแนะนำ หรืออ้างอิง ตัวแปร: สรุปที่ตรวจและข้อมูลกราฟ เป็นแนวคิดสื่อสารไม่ใช่ผู้ทรงคุณวุฒิวิทย์ตรวจ
```

<a id="sci-08"></a>

## SCI-08 — แผนภาพหลายสเกล

```text
สร้างแผนภาพศึกษา 16:9 เชื่อม [APPROVED LARGE-SCALE OBJECT], [COMPONENT] และ [DETAIL] ใช้สามช่องแยกชัด ป้ายสเกลที่ให้และกรอบซูมเชื่อม คงการบรรจุจริงและสีจับคู่ แสดงเฉพาะป้าย หน่วย แหล่งที่ตรวจ ไม่แต่งกำลังขยาย ขนาดจริง หรือลูกศรเหตุ ตัวแปร: ภาพและสเกลตรง ต้องผู้เชี่ยวชาญตรวจ
```

<a id="sci-09"></a>

## SCI-09 — บอร์ดสอนแปลงหน่วย

```text
สร้างบอร์ด 4:3 แสดงตรง "1 m = 100 cm" และ "1 cm = 10 mm" วาดแท่งยาวแบ่งสิบส่วนใหญ่เท่ากัน พร้อมส่วนขยายแยกแบ่งสิบส่วนเล็ก กำกับตาม [TEACHER-APPROVED SCALE MAP] เท่านั้นเพื่อสเกลภาพไม่สื่อแปลงผิด ใช้เส้นดำและน้ำเงินเน้นหนึ่ง ไม่มีสมการเพิ่มหรือป้ายประมาณ ต้องครูตรวจ
```

<a id="sci-10"></a>

## SCI-10 — คำอธิบายสถานะเครือข่าย

```text
สร้างการ์ดเทคนิค 16:9 ด้วย [APPROVED NETWORK TOPOLOGY AND STATUS DATA] คงทุกโหนดและการต่อ แสดงปกติ เตือน ใช้ไม่ได้ด้วยทั้งสีและรูปต่าง มีคำอธิบายและเวลาที่ให้ตรง เส้นสะอาด ช่องกว้าง ห้ามแต่ง IP ข้อมูลเข้าระบบ ความเสีย คำกู้คืน หรือขอบเขตติดตาม ตัวแปร: ผังที่ตรวจและภาพสถานะ เป็นภาพนิ่งไม่ใช่แดชบอร์ดสด
```
