# อินโฟกราฟิก การศึกษา และธุรกิจ

ชุดพรอมป์ต์ Qwen Image 3.0 จำนวนสิบรายการ เปลี่ยนข้อมูลในวงเล็บเหลี่ยมก่อนสร้างภาพ ข้อความในเครื่องหมายคำพูดต้องแสดงตรงตามที่ระบุ ไม่ต้องแปลเว้นแต่สั่งไว้อย่างชัดเจน ผลลัพธ์ต้องผ่านการตรวจสอบโดยมนุษย์

<a id="edu-01"></a>

## EDU-01 — เส้นทางน้ำฝน

```text
สร้างอินโฟกราฟิกในชั้นเรียน 16:9 ชื่อ "น้ำฝนไปไหน" แสดงหลังคาบ้านหนึ่งหลัง รางน้ำที่เชื่อมกันหนึ่งราง ถังน้ำมีฝาหนึ่งถัง และสวนรับน้ำฝนที่ปลูกต้นไม้หนึ่งแห่ง เป็นสี่ขั้นชัดจากซ้ายไปขวา ใช้ลูกศรน้ำสีน้ำเงินจากหลังคาไปรางไปถัง แล้วใช้ลูกศรน้ำล้นแยกจากถังไปสวน กำกับเฉพาะ "หลังคา", "รางน้ำ", "เก็บน้ำ" และ "สวนรับน้ำฝน" ข้างวัตถุที่ถูกต้อง ใช้พื้นครีมและภาพตัดขวางเรียบง่าย ห้ามแสดงการใช้น้ำดื่มหรือแต่งความจุ ลูกศรต้องไม่กำกวมและถังต้องปิด
```

<a id="edu-02"></a>

## EDU-02 — เปรียบเทียบร่มเงาในเมือง

```text
สร้างแผนภาพสอน 16:9 เปรียบเทียบหน้าตัดถนนสมมติสองส่วนภายใต้มุมดวงอาทิตย์เดียวกัน ด้านซ้ายไม่มีต้นไม้ ด้านขวามีต้นไม้โตเต็มที่สองต้นให้ร่มบนทางเท้า ใช้อาคาร ความกว้างถนน และคนเดินเหมือนกัน พร้อมภาพสถาปัตยกรรมเรียบง่ายและพื้นที่เงาชัด กำกับ "กลางแดด" และ "ร่มเงาต้นไม้" ไม่เพิ่มอุณหภูมิ เปอร์เซ็นต์ หรือผลสุขภาพ คงทิศแดดให้สอดคล้องและอย่าสื่อว่าร่มเงากำจัดความร้อนทั้งหมด ตัวแปร: รูปทรงถนนและป้ายที่อนุมัติ
```

<a id="edu-03"></a>

## EDU-03 — ใบงานการเติบโตของเมล็ด

```text
สร้างใบงานแนวตั้ง 3:4 สำหรับเด็กสังเกตเมล็ดถั่ว วาดกล่องเท่ากันสี่ช่องที่มีเมล็ด รากเริ่มงอก ยอดแรก และใบสองใบ ใต้แต่ละช่องเว้นพื้นที่มีเส้นสำหรับบันทึก ใช้ภาพลายเส้นเทาคมชัดและตัวหนังสือใหญ่ แสดงเฉพาะ "มาดูเมล็ดเติบโต", "1", "2", "3", "4" และ "สิ่งที่ฉันสังเกต" ลำดับชีววิทยาต้องชัดโดยไม่กำหนดจำนวนวัน ห้ามกรอกช่องคำตอบหรือเพิ่มอักษรปลอมตกแต่ง ตัวแปร: พันธุ์พืชที่อนุมัติและชื่อใบงาน
```

<a id="edu-04"></a>

## EDU-04 — เปรียบเทียบแถบเศษส่วน

```text
สร้างแผ่นการสอน 3:4 ที่เหมาะกับพิมพ์ระดับเทา แสดงแท่งแนวนอนเหมือนกันสามแท่ง แบ่งเป็นสอง สี่ และแปดส่วนเท่ากัน ระบายหนึ่ง สอง และสี่ส่วนตามลำดับ กำกับแถว "1/2", "2/4" และ "4/8" ตั้งชื่อ "ปริมาณเท่ากัน แบ่งส่วนต่างกัน" จัดจุดเริ่มและจุดจบให้ตรงพอดี เว้นหนึ่งในสี่ด้านล่างสำหรับบันทึกอภิปราย ใช้เส้นขอบดำชัดและสีเทาระบายเดียว ไม่มีวงกลม ส่วนไม่เท่า ช่องเลือกคำตอบ หรือสมการเพิ่ม
```

<a id="edu-05"></a>

## EDU-05 — แดชบอร์ดบริการรายเดือน

```text
สร้างแนวคิดแดชบอร์ด 16:9 โดยใช้ [VERIFIED MONTHLY TABLE] เท่านั้น วางตัวชี้วัดหลักที่ให้มาด้านซ้ายและกราฟเส้นด้านขวา ด้านล่างมีตัวเลขสนับสนุนสามค่าพร้อมป้าย ใช้พื้นขาว ข้อความสีถ่าน และชุดข้อมูลสีน้ำเงินหนึ่งชุด แสดงวัน หน่วย และหมายเหตุแหล่งข้อมูลตรงตามตาราง คงค่าที่หายเป็นช่องว่าง ไม่ประมาณค่าแทรกหรือแต่งการเปรียบเทียบ แกนต้องตรงกับสเกลที่ให้และมีหน่วย ตัวแปร: ตาราง ชื่อตัวชี้วัด แหล่งข้อมูล และช่วงเวลา
```

<a id="edu-06"></a>

## EDU-06 — แผนงานสามขั้น

```text
สร้างแผนงานผลิตภัณฑ์ 16:9 ด้วย [APPROVED INITIATIVES] จัดสามคอลัมน์เท่ากันชื่อ "ตอนนี้", "ถัดไป" และ "กำลังศึกษา" แต่ละคอลัมน์มีการ์ดไม่เกินสามใบ ใช้กริดบรรณาธิการสะอาด การ์ดครีม และจุดเน้นน้ำเงินหม่น เชื่อมเฉพาะความเกี่ยวเนื่องที่ระบุชัด ใส่ท้ายว่า "ภาพรวมการวางแผน ไม่ใช่คำมั่นกำหนดเปิดตัว" ห้ามแต่งวัน สถานะเสร็จ ผู้รับผิดชอบ หรือคำสัญญา คงทุกโครงการในคอลัมน์ที่ให้ ตัวแปร: รายการโครงการและรายการความเกี่ยวเนื่อง
```

<a id="edu-07"></a>

## EDU-07 — แผนที่เส้นทางพิพิธภัณฑ์

```text
ใช้ผังพื้นที่ที่อนุมัติและ [ROOM LABELS] เพื่อสร้างแนวคิดแผนที่ผู้เข้าชมแนวตั้ง คงทางเข้า บันได ลิฟต์ ผนัง และเส้นทางที่เข้าถึงได้ตามจริงทุกประการ ลดเฉพาะรายละเอียดตกแต่ง เน้นเส้นทางที่ให้หนึ่งเส้นด้วยเส้นน้ำเงินต่อเนื่องและทำเครื่องหมายต้นจบ ใช้คำอธิบายสัญลักษณ์ชัดตามที่ให้และแสดงเฉพาะชื่อห้องที่อนุมัติ ห้ามแต่งทางออก สิ่งอำนวยความสะดวกในการเข้าถึง หรือมาตราส่วน ใส่ "คู่มือภาพประกอบ — โปรดตรวจสอบหน้างาน" ตัวแปร: ผัง เส้นทาง และป้าย ต้องให้สถานที่ตรวจสอบก่อนเผยแพร่
```

<a id="edu-08"></a>

## EDU-08 — พิมพ์เขียวบริการห้องสมุด

```text
สร้างพิมพ์เขียวบริการ 16:9 สำหรับการยืมสิ่งของห้องสมุด ใช้สี่คอลัมน์ "ค้นหา", "จอง", "รับ", "คืน" และสามแถว "ผู้อ่าน", "ห้องสมุด", "ระบบ" เติมช่องด้วย [APPROVED ACTIONS] เท่านั้น และวาดลูกศรเฉพาะการส่งต่องานที่ให้ ใช้เส้นน้ำเงินเรียบ ช่องขาว และข้อความใหญ่ แยกการกระทำผู้ใช้จากงานภายใน ไม่มีเวลาทำงานที่แต่งขึ้น ข้อมูลส่วนตัว หรือไอคอนตกแต่งแทนการกระทำ ตัวแปร: ตารางการกระทำและการส่งต่องานที่ตรวจสอบแล้ว
```

<a id="edu-09"></a>

## EDU-09 — กราฟที่นั่งเวิร์กช็อป

```text
สร้างการ์ดข้อมูล 4:3 จากข้อมูลสมมติ: วันจันทร์ 8 ที่ วันอังคาร 12 ที่ วันพุธ 6 ที่ ใช้ชื่อ "ที่ว่างสำหรับเวิร์กช็อป" และวาดแท่งแนวนอนสามแท่งบนสเกลร่วมเริ่มศูนย์ พร้อมค่าที่แน่นอนตรงปลาย ใช้ป้ายกรมท่าและแท่งเหลืองดินบนพื้นขาว ใส่ "ข้อมูลประกอบตัวอย่าง" ด้านล่าง อย่าเปลี่ยนที่นั่งเป็นยอดเข้าร่วมหรือเปอร์เซ็นต์ และอย่าสลับลำดับ แท่งสิบสองที่ต้องยาวเป็นสองเท่าของแท่งหกที่
```

<a id="edu-10"></a>

## EDU-10 — การ์ดสอนต้นไม้การตัดสินใจ

```text
สร้างการ์ดต้นไม้การตัดสินใจ 3:4 สำหรับบทเรียนดูแลพืชสมมติโดยใช้ [TEACHER-APPROVED QUESTIONS AND OUTCOMES] วางคำถามรากหนึ่งข้อด้านบน คำถามกิ่งสองข้อด้านล่าง และผลลัพธ์ที่ให้ไว้ล่างสุด ใช้กิ่งกำกับ "ใช่" กับ "ไม่ใช่" กล่องมุมมนสม่ำเสมอ และพื้นที่ว่างมาก คงทุกเงื่อนไขและจุดหยุด ห้ามแต่งปริมาณน้ำ การวินิจฉัย หรือคำแนะนำสายพันธุ์ แสดงเฉพาะข้อความและชื่อที่อนุมัติ ตัวแปร: ผังที่แน่นอน บริบทพืช และชื่อ ต้องให้ครูตรวจสอบ
```
